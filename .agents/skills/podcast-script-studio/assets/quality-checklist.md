# 质检清单（阶段 D 逐项检查）

## A. 结构完整性

- [ ] A1 冷开场存在且非介绍性内容（是节目内最精彩的片段前置）
- [ ] A2 冷开场用了三型之一（金句悬念/论点预告/结论碎片）且 ≤60 秒
- [ ] A3 报幕+选题缘由完整（回答了"为什么现在听"）
- [ ] A4 主体按所选题型模板推进，无板块缺失
- [ ] A5 收束段回扣了核心判断
- [ ] A6 结尾菜单式：恒选项"总结回扣+告别语"齐备；按需项（挖坑/三连/拉群/放歌/讨论题）取舍合理（拉群不宜期期用）

## B. 选题基因

- [ ] B1 认知反差（你以为的 vs 实际上的）在脚本中真实落地，不只是标题党
- [ ] B2 小切口→大纵深的爬升路径完整
- [ ] B3 人性内核存在（删掉知识点后仍剩一个关于"人"的问题）
- [ ] B4 致用交付（以古鉴今）：知识对应听众的日常症状；结构症状→诊断→处方；结尾有可执行行动清单（"听众明天做什么不同的事"有具体答案）

## C. 对话动力学

- [ ] C1 主讲字数占比约 85%（±5%），主持每轮 30-60 字
- [ ] C2 话轮切换约每 30 秒一次（无主讲连续超 300 字不被打断的段落）
- [ ] C3 主持话轮无纯捧哏（"对/是的/嗯"单字轮 ≤2 处）
- [ ] C4 主持九功能（复述确认/代问/接梗/拉回/转场/逼问/个人叙事/立场口径确认/听众共创）每幕至少出现 3 种，全期 ≥6 种
- [ ] C5 话轮咬合：每轮主持话术承接上一轮具体内容（复述/追问/接梗），无自说自话转场
- [ ] C6 双人纯度：全稿仅两位说话人，无第三角色/嘉宾/旁白声线；历史人物引语均已第三人称转述（无引号直接引语）
- [ ] C7 互嘲/齐声/重复盖章等双人细节 ≥2 处

## D. 知识呈现

- [ ] D1 学术降维三步法完整执行 ≥2 次（原文→吐槽→比喻→回扣）

- [ ] D2 史料/事实引用标注了出处性质（正史/研究/野史/网传/影视分开）
- [ ] D3 至少一处史料辨伪或事实核查（侦探戏）
- [ ] D4 概念工具（可带走的尺子）已交付
- [ ] D5 数据流处配了人物锚点（每个硬数据有"人的故事"）
