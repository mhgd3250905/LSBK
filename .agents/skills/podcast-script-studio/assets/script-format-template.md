# 脚本格式模板

> 对话稿格式：说话人标注 + 估算时间戳。分幕撰写，每幕净台词约 2700-3900 字（对应约 7-10 分钟成品）。

```markdown
# {标题}（EP{编号}）完整脚本

> 预计时长：{N} 分钟 | 字数：{N} 字 | 阵容：{主讲}+{主持}（固定双人）
> 本文件由 podcast-script-studio 生成，合成语速实测约每分钟 400 字。

---

## 【00:00-00:50】冷开场

**主讲**（00:00）：
{台词}

**主持**（00:20）：
{台词}

## 【00:50-02:00】开场

**主讲**（00:50）：
大家好，这里是{节目名}，我是{主讲}。

**主持**（00:58）：
大家好，我是{主持}。{选题缘由话术}

---

## 第一幕：{幕名}【02:00-14:00】

**主讲**（02:00）：
{台词……}

**主持**（02:40）：
{台词……}

（……以此类推）

---
（分幕文件则在幕末加：）
> 本幕完。确认后继续第二幕。
```

## 格式细则

1. **说话人标注**用加粗角色名，括号内为估算时间戳，每 30-60 秒推进一格。
2. **舞台提示**用斜体括号，仅标注影响表达的状态，如（笑）（停顿）（齐声）（叹气），不写视觉性描述。
3. **路牌预告**直接写进台词，不加标记。
4. 全稿只允许{主讲}与{主持}两位说话人；历史人物的话一律第三人称转述，不写引号直接引语（合成引擎会为直接引语触发戏剧化第三音色）。
5. 每幕开头用一行引用块注明本幕要点（写稿时的自我提醒，交付前可删）。
6. 禁止在台词中出现任何"【主播开始说话】"式的机械标记；台词必须是可以直接念出来的完整口语。
