# 01 选题系统与标题工艺

> 来源：56 期节目选题全量归纳。选题的本质：**每一个选题都是"认知反差"的容器。**

## 一、选题七型（做批量选题时刻意搭配）

### 1. 系列连载型（占比最高，约 40%）
- 特征：围绕一条时间线或一个 IP 连续做多期，系列内命名互相呼应（如"蜀汉浪漫的开端：刘备"/"蜀汉浪漫的终结：姜维"——首尾成对）。
- 编排自由：可以正序、可以倒序（宋初系列从赵光义倒讲回柴荣，"倒叙挖根"本身就制造悬念）。
- 上下集切分：内容塞不下时切上下集，上集结尾必须留钩子（"这期讲不完了，下期专门讲XX"）。
- 系列公开承诺：在节目里预告系列规划（"两晋南北朝系列，一个月一到两期"），让听众形成追更预期。

### 2. 热点快反型
- 特征：3 天内蹭上热点，并在节目里**坦白自己在蹭**（"你要蹭热点，就要速度快一点，今天录今天发"）——坦白反而成为人设。
- 结构：新闻时间线（可信度）→利益分析（深度）→理论纵深（格局）→落地听众切身（油价/转机/工作）。
- 要点：热点是入口，知识是留存。需要时可借国际体系演变等框架帮助理解，不强制交付“尺子”。

### 3. 节日/纪念日型
- 特征：提前规划日历（母亲节、三八节、春节、忌辰纪念日）。
- 公式：**节日情感 × 相关历史专题**。妇女节→红颜祸水正名；春节→求财拜关羽；马年→马的人类文明史；金庸忌辰→纪念连做两期。
- 结尾配节日祝福或应景歌曲收束。

### 4. 影视 IP 借势型
- 特征：电影/电视剧上映前后一周内做"IP 背后的历史"。
- 公式：IP 是流量入口，正史/原著是留存内容；节目明确声明"不剧透"以服务没看过的听众。
- 自带吐槽素材库：影视穿帮（宋朝吃玉米、赵匡胤喊"后晋"）既是笑点又是知识巩固点。

### 5. 网感概念型
- 特征：现代痛点词（内卷/牛马/保健品/梗）× 历史纵深。
- 公式："XX 的根源是 YY？"——用一个反常识的历史对应物解释现代焦虑。
- 结构多为"小切口→通史→理论"三段火箭（身高→饮食史→内卷化理论）。

### 6. 争议站队型
- 特征：制造非此即彼的讨论（"古龙这些地方就是比金庸强！""第一竟不是李世民！"）。
- 要点：标题应呈现真实争议与听众关心的问题；证据不足时不要为了评论区强迫站队。
- 排名类是亚型：必须先公示评价标准（自建维度模型），再评测，最后抛给听众"你有你的排法，评论区聊"。

### 7. 群友点播型
- 特征：听众点题，节目里点名感谢（"应群友呼声"）。
- 运营价值：让听众参与内容规划，"挖坑—填坑—催更"生态的一环。

## 二、选题的三个共同基因（缺一不可）

1. **认知反差**：内嵌"你以为的 vs 实际上的"。例：刘备其实很能打；赵构武力值爆表；游牧民族平时不吃肉；西方人工业革命前很矮。没有反差的选题要反推：这个话题里大众最深的误解是什么？
2. **小切口大纵深**：日常经验入口（身高/餐桌/一部剧/一个词）→ 宏大落点（国运/文明/理论）。检验法：标题能否同时装下"小"与"大"（"从你家的餐桌到国家的命运"）。
3. **人性议题内核**：历史/知识是壳，权力、父子、忠诚、翻案、命运偶然是核。检验法：这期节目删掉知识点后，还剩不剩一个关于"人"的问题？

## 三、标题九型公式

写标题时按以下公式生成候选，每个公式产 1-2 个再选：

| 型 | 公式 | 例 |
|---|---|---|
| 反差颠覆型 | 大众认知 + 竟然不是/纯属虚构？ | "第一竟不是李世民！" |
| 网感嫁接型 | 现代热词 + 古代史 | "帝王嗑药简史：古代皇帝的'保健品'有多毒？" |
| 悬念问句型 | 藏了多少你不知道的秘密？ | "八仙过海，藏了多少你不知道的秘密？" |
| 挑衅站队型 | A 这些地方就是比 B 强！ | "古龙这些地方就是比金庸强！" |
| 三元比较型 | X 看什么，Y 看什么，我们看什么？ | "日本看血统，欧洲看神权，中国看什么？" |
| 大小相形型 | 从你的[小事]到[国家命运] | "从你家的餐桌到国家的命运" |
| 反讽成语型 | 成语加引号 + 真相 | "董卓和吕布的'父慈子孝'真相" |
| 系列命名型 | 系列 + 呼应式副题 | "蜀汉浪漫的开端/终结" |
| 口号判断型 | 颠覆性断言 + ！ | "鸦片战争从未结束！" |

标题共性：**具体钩子 + 大问题**双层结构；带情绪标点（？！）；口语化，拒绝学术腔；长度 15-30 字为宜。

## 四、选题卡上的"缘由栏"

选题卡应回答“听众为什么关心”，可以是热点、节日、系列延续或有吸引力的历史疑问。群友点播只有真实发生时才写入开场。
