# 02 结构系统与题型模板

> 来源：7 期全文精读 + 56 期首尾全量分析。节目时长目标 30-40 分钟（净台词约 1.1-1.5 万字，实测合成语速约 400 字/分钟；参考节目原身为 60 分钟档，本技能按用户定位压缩至 30-40 分钟档，骨架等比缩短）。

## 一、万能五段骨架（每期必用）

以 35 分钟基准（30-40 分钟档）：

```
[0:00-1:00]   冷开场（30-60秒精彩片段前置）
[1:00-2:30]   报幕 + 选题缘由
[2:30-30:00]  主体（四幕推进，每幕约7分钟；60分钟档则每幕拉长至10-12分钟）
[30:00-34:00] 收束（回扣核心判断 + 可选彩蛋升维）
[34:00-36:00] 结尾菜单
```

### 冷开场三种写法（选一）
1. **金句悬念式**：从节目中间挑一句最"炸"的话直接开场。例："中国堕入了地狱，然后日本短暂地上了天堂。"（甲午战争）
2. **论点预告式**：三个金句对应三大板块（等于预告本期"论文摘要"）。例：鹿鼎记期三连——"韦小宝是被各大势力推着走的"/"陈近南满足了他关于父亲的全部幻想"/"爱情是一个历史概念"。
3. **结论碎片式**：把最终判断拆碎片先抖出来。例："我倾向于认为这是阴谋。毒杀的可能，绝对高于斧杀。"

写法要点：冷开场**不用任何介绍性内容**，直接进入节目最精彩的对话片段，像电影预告片。报幕在冷开场之后才出现。

### 开场报幕段
1. 固定句式："大家好，这里是{节目名}，我是{主讲}。大家好，我是{主持}。"（有嘉宾则依次报幕）
2. **选题缘由**（回答"为什么现在听"）：热点 / 节日 / 群友点播 / 系列衔接（"书接上回"）。蹭热点要坦白地蹭。
3. 可加 30 秒内的人情寒暄（主播近况、互相调侃），建立"朋友感"。

### 结尾"菜单式"（全量分析修正：不是五件套清单，是菜单）
恒选项（每期必有）：
1. 一句收束总结（常回扣本期核心判断，可反复强调式："我认为它是个偶然"）
2. 告别语："谢谢朋友们，再见"（双人齐说）

按需选项（看题型与时机取舍）：
- **挖坑**：预告下期/未来选题。常规期用；题材越敏感越收敛（时政期可以不挖坑只表态）；连载期挖坑可前置到中段。
- **求三连**：收藏/点赞/转发/评论。
- **拉群**：**稀缺钩子，不宜期期都用**——原节目仅偶尔亮出（"一群二群都499人了"），用多了贬值。
- 变体组件：留讨论题（疑案类："毒杀还是斧杀？评论区聊"）；排行榜征集（"使劲喷我"）；节日祝福/红包预告；**导听式放歌**（情怀期用一首关联曲替代全套收尾，如诸葛亮期放《出师表》古曲）；"主持听后感代总结"（主持说"听完这期我自己都被说服了"）；挖坑统计互动（"大家数数这期挖了几个坑，课代表记下来"）；评论区管理预案（敏感期预告"不理智言论我会删"）。

### 上下集衔接四步闭环（连载必用）
1. 上集结尾**精确预告**下集内容（"下期专门聊人物"）
2. 下集报幕后**首句原样履约**（真的从"人物"讲起）
3. 正片中 1-2 次"上集说过 X"跨集回扣
4. 下集结尾**偏差自嘲**（"说聊人物结果聊了一堆武功"）+ 续挖坑
另：连载系列下期直接"书接上回"报幕即可，不必硬做冷开场。

## 二、节奏控制（写作时的节拍器）

**故事承载优先级（知识型节目的第一原则）**：故事（50-65%）> 新奇观点（20-30%，反直觉、从故事里长出）> 当下落点（5-10%，一两句点到）。三种结构都不许违反：纯概念递进（v2 教训：听众要听故事不是听课）、纯诊疗式"症状→药方"（v3 教训：说教压死生动性）。正确形态：**以人物/事件编年为幕，每幕至少一个完整戏剧性故事（起承转合+反转），故事讲完观点自然浮现，落点顺手一点**。

（注意：以上百分比是原节目的统计画像，用来校准大方向，不是逐幕核对的金科玉律——生动永远优先于精确配比。）

- **每 3-5 分钟一个梗锚点**（现代词、吐槽、荒诞类比、互嘲）
- **每 10 分钟左右一次转折或换板块**（用主持的推进转场完成："那接下来我们聊聊……"）
- **每期 1-2 处合法跑偏**：离题 3 分钟内（童年记忆/生活吐槽/相邻冷知识），再由主讲自我觉察式拉回："这个就扯远了，话题拉回来。"跑偏段是共鸣密集区，是设计出来的呼吸，不是失误。
- **路牌预告**防信息过载："这个我们后面专门讲""等会详细说"——重要的岔路话题挂路牌，不展开。
- **中段回拉**：如果开场抛了悬念，中后段让主持人主动拉回（"但是相应的，为什么我们最开始给大家讲的那个……"），防止话题漂移。

## 三、八大题型主体模板（按选题卡题型选用）

### 模板 1：编年通史型（主题贯穿全时间线）
结构：朝代/时期序列 → 每期挑 1-2 个代表案例（详略有致，高峰期给最长篇幅）→ 每段配对照组（信的 vs 不信的）→ 规律总结（为什么会递增/递减/循环）。
要点：猎奇钩子 + 通史骨架 = 娱乐与知识双重满足；结尾用时代背景解释规律（如"神秘主义衰退→嗑药递减"）。

### 模板 2：排名 PK 型
结构：①玩梗式话题界定（一词二义开场："既聊武功，也聊武功"）→②快排热身（先单维度简单排）→③**标准公示**（自建维度模型，公开展示权重）→④方法论展开（每个维度配降维三步法讲解+合法跑偏）→⑤逐个评测 →⑥分层揭榜（T0/T1/T2 游戏化段位）→⑦争议抛给评论区。
要点：**框架本身是可带走的知识产品**；排名结论不重要，评测过程才是内容；标准公示是争议排名的"合法性程序"。

### 模板 3：疑案推理型
结构：①破除字面误解开场（"光听名字就很惊悚，但其实……"）→②线索铺陈 →③列嫌疑人逐一排查（动机/能力/机会三要素）→④套"谁受益最大谁嫌疑最大"定律 →⑤原始文献复盘（考据过程戏剧化）→⑥前科引证（此人以前干过类似的事）→⑦概率化结论（"我认为概率最大""百分之百可以排除"）→⑧留互动题给评论区。
要点：把"读史的方法论"表演出来；结论保持概率化，既是学术诚实也是推理游戏感。

### 模板 4：IP 深读型（小说/影视/游戏）
结构：①问题引擎（用视角差发问："我不理解为什么男人都羡慕韦小宝"）→②清单盘点（身份/角色/老婆逐个过堂，每人一个判定词）→③文本细读（引用原文细节支撑心理推断，禁止空对空评论）→④理论武器支援（进化心理学/哲学/社会学随取随用）→⑤虚构×真实互锚（用真实案例佐证人性判断）→⑥分歧公开化（三人结论不同不强行统一，抛给听众）。
要点：服务"原著党"与"剧党"双人群（原著 vs 改编双轨考据）；向听众自身投射（"我们羡慕韦小宝，到底在羡慕什么"）。

### 模板 5：概念工具型（造一把尺子）
结构：①概念溯源（学术权威原文）→②标准升级（自建多维模型）→③直觉投票（嘉宾先盲答再系统评）→④维度逐个展开（每个维度配案例+跑偏）→⑤应用打分（逐个对象过堂）→⑥分层揭榜 →⑦理论升华（升维到更大问题）→⑧配套产品（"评分表发在评论区"）。
要点：听众带走一把可以自己用的尺子；概念辨析制造智力快感（得国≠得位）。

### 模板 6：时事快反型
结构：①新闻时间线（逐日事件+辟谣，穿插梗软化）→②**双层利益分析**（国家利益 × 领导人个人利益矩阵）→③结构分析（基本盘/利益集团如何运作）→④理论纵深（历史框架升维）→⑤落地切身（对听众生活的影响+数据流）。
要点：预测只给可能性清单不给断言（"你准了那是蒙的"）；立场用"同一标准不双标"声明+正面落点自保。

### 模板 7：小切口通史型
结构：①现象切入（日常经验）→②数据流+人物锚点（每个数据配一个"人的故事"）→③通史叙事（纵向贯穿）→④理论升华（学术概念落地）→⑤对垒观点（A vs B，"各有各的道理"）→⑥回扣现象收束。
要点：三段火箭——日常入口→千年叙事→学术落点；"从细节的小点窥见大历史的真实一面"要成为节目自我声明。

### 模板 8：社会议题型（无历史壳，如工作/消费/职场/生活方式）
结构：①问题引擎=**主持人的真实困惑**（亲身经历，如职场创伤、消费焦虑）②主讲用理论接住（"你让我想到一个组织学家……"）→降维三步法展开③案例深挖（企业/事件）④反直觉数据佐证⑤主持人经历再次成为论据（"病例-会诊"镜像：历史型是主讲知识×主持提问，社会议题型是**主持人的真实痛感×主讲的理论武器**——真实痛感替代历史纵深）。
要点：敏感商业/政治话题轻处理（"它内部有很多问题，这是另一回事，我们不详细说"一句话隔离）；挖坑从案例自然长出。

## 四、彩蛋升维收尾（可选但推荐）

在收束段把个案升维成通则（"说起来，中国历史上太宗几乎没正常继位的"——汉唐宋明数一遍），通则天然钩出下期话题。

## 五、全量分析补充的结构技巧（47 期横切验证产出）

### 金句环形 / 预埋钩子
冷开场的混剪片段里可以**预埋结尾金句或后文才回收的梗**（某期开头埋"大老板都善待厨师和司机"，36 分钟后才展开）——听众听到回收瞬间产生"首尾闭环"的爽感。

### 立场对冲双期
争议 IP 连做两期、立场刻意对冲（一期"深扒《鹿鼎记》挑金庸毛病"，隔期"金庸小说中的传统文化"猛夸）——对冲本身就是话题张力，也避免单期站队过狠。

### 及格线打分裁决
评价人物时用"60 分 vs 59 分"的及格线微差制造讨论度（赵匡胤 60 分、赵光义 59 分不及格），且必须**显性公示评分标准**再打分。

### 梗清单目录法
讲"梗很多"的人物（梗王赵光义）时，先快速报一遍全部梗名（高粱河车神/烛影斧声/幸小周后…）当目录，再逐个用正史拆解——梗是入口，机制分析是内容。

### "一期变三期"产能话术
讲不完时坦然说明并当场规划："本来打算一期讲完，讲着讲着发现能讲的太多了，所以要分两期"——把内容溢出转化为系列承诺。

### 系列坐标系命名
给系列装时间坐标系（伊朗三部曲的"前天/昨天/今天"；五代系列的"接力棒"隐喻），并用统一标尺贯穿（土匪两期用"有无政治纲领"作分界标尺）。
