# 08 深度挖掘方法论（选题 → 弹药库的作业流）

> 回答"选题定了之后怎么挖"。目标：把一个题目从"我听说过"挖到"能撑起 50 分钟、每 5 分钟有一个硬点"。以 EP01（王阳明心学）为全程案例。

## 总流程：五步挖掘 → 填进选题卡"内容弹药"栏

```
①误解清单 → ②素材分层挖掘 → ③主线结构假设 → ④概念工具锻造 → ⑤对垒观点
```

### ①误解清单（认知反差的爆破点）

方法：列出大众对这个题目的**三层误解**，每层误解配一个"翻转后的真相"。
自问三遍："普通人听到这个题名，脑子里冒出的第一个念头是什么？这个念头哪里错了？证据是什么？"

EP01 案例：
- 误解1"心学=唯心主义（不看花花就不存在）"→ 翻转：岩中花树的"寂"讲的是意义世界（"没发出去的朋友圈"）
- 误解2"知行合一=知道了就要去做（执行力鸡汤）"→ 翻转："你若做不到，就是不懂"是诊断不是要求
- 误解3"心学=玄学/内心强大学"→ 翻转：事上磨练，功夫在干活里

检验：三层翻转若站不住，这个选题退回重选（比"反差星级"更硬的门槛）。

### ②素材分层挖掘（四层信源，逐层标注出处性质）

| 层 | 挖什么 | EP01 对应 | 出处标注 |
|---|---|---|---|
| 一手文献 | 原典关键句（每期 5-8 句，够冷开场和引用） | 《传习录》格竹/岩中花树/好好色；《年谱》龙场悟道原文；《孟子》孺子入井 | 语录体/准一手 |
| 权威研究 | 学界主流解释与反对意见 | 钱穆"科举民主雏形"vs 制度工具论 | 研究 |
| 轶事与野史 | 戏剧性场景（爽剧素材） | 廷杖四十/伪装投江/石棺/平宁王35天/临终八字 | 正史本传/年谱 |
| 网络讨论 | 大众真实困惑（共鸣素材） | "道理我都懂就是做不到"/收藏夹积灰/熬夜 | 网传 |

挖掘技巧：
- **找"数字与场景"**：每期至少 3 个具象锚点（打多少杖、走多少天、活到几岁、说了几个字）——数字可信，场景可感
- **找"人物对"**：对照组候选（朱熹vs阳明、格竹vs龙场、孙思邈vs嗑药皇帝）——有对照才有论证张力
- **找"未展开的岔路"**：挖掘中遇到的大话题挂路牌（"这仗怎么打的以后专门讲"）——它们是下期的选题

### ③主线结构假设（挖到的素材怎么排）

方法：把素材压进一条**递进逻辑**，而不是时间流水账。问自己："听众听到第 20 分钟时，应该正在获得什么？"

EP01：三个概念递进（心即理→知行合一→致良知）= "方向→诊断→功夫"，人物生平（格竹→龙场→平叛→临终）作副线，每个概念挂在一个人生现场上。
反例警告：若发现素材只是"关于这个题目的 20 个知识点"，说明还没挖出主线——回炉。

### ④概念工具锻造（每期一把"尺子"）

方法：把本期洞察压缩成一个**听众能带走复用的思维工具**，格式最好是"名词+两步用法"。
EP01：真知测试（身体有反应吗？行为自动变了吗？）＋ 良知感应器模型（预装感应器+流氓插件）。
检验：听众明天能用它在生活里做一次判断吗？不能就重造。

### ⑤对垒观点（防止一家之言）

方法：找至少一个"反方"，给平衡收束（"各有各的道理"），但可以表明"哪种体质用哪套"。
EP01：程朱 vs 陆王 = 两套操作系统（知识的/做人的），"道理瘫痪体质，阳明对症"。

## 深度检验（弹药够不够上战场）

- [ ] 三层误解全部有硬证据翻转
- [ ] 一手关键句 ≥5 句（冷开场和金句的原料）
- [ ] 具象锚点（数字/场景）≥3 个
- [ ] 对照组 ≥1 组
- [ ] 概念工具 1 把，两步可用
- [ ] 对垒观点 1 组
- [ ] 挖出的岔路（下期选题）≥2 个——**挖不出岔路说明挖得不够深**
- [ ] 致用挖掘完成：列出听众的 3-4 个日常症状与本期知识的对应关系，每个症状有"处方"（可执行动作）——这是"以古鉴今"的弹药，没有它节目只是讲解而非帮助

## 反向用例：挖掘不足的症状

写到第二幕就"没料"（素材密度下降、开始注水重复）→ 不是写作问题，是挖掘问题，回到①②补弹药。
