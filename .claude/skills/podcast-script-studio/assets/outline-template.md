# 节目大纲模板

```markdown
# 大纲：{标题}（EP{编号}）

> 时长目标：{30-40} 分钟 | 题型：{X 型} | 结构模板：{模板 N}
> 阵容：{主讲} + {主持}（固定双人，不设第三角色）

## 全期时间轴

### [00:00-00:50] 冷开场
- 类型：
- 台词要点：（具体到句子方向，不是"讲个钩子"这种废话）

### [00:50-02:00] 报幕 + 选题缘由
- 缘由话术：
- 人情寒暄（可选）：

### [02:00-XX:XX] 主体（按题型模板分幕，每幕约 7 分钟）

#### 第一幕 {幕名} [02:00-09:00]
- 内容要点：
- 认知反差点：
- 悬念/路牌：
- 梗锚点（2-3 个，标注位置）：
- 主持话轮安排（本幕用到哪些功能）：
- 金句（1-2 句，写出成品方向）：

#### 第二幕 {幕名} [09:00-16:00]
（同上字段）
- 合法跑偏：{位置 + 内容 + 拉回话术}

#### 第三幕 {幕名} [16:00-23:00]
（同上字段）
- 降维三步法执行点：{概念 → 原文 → 吐槽 → 比喻 → 回扣}

#### 第四幕 {幕名} [23:00-30:00]
（同上字段）
- 情怀/理论峰值点：

### [30:00-34:00] 收束
- 一句总结（回扣核心判断）：
- 彩蛋升维（可选）：

### [34:00-36:00] 结尾菜单
1. 总结：
2. 挖坑：
3. 求三连话术：
4. 拉群话术：
5. 告别语：

## 节奏自检
- [ ] 每 3-5 分钟一个梗锚点（全期 ≥10 个）
- [ ] 每 10 分钟左右一次转折/换板块
- [ ] 合法跑偏 1-2 处已就位
- [ ] 路牌预告 ≥2 处
- [ ] 中段回拉设计（开场悬念在中后段被拉回）
- [ ] 概念工具已就位（听众带走的尺子）
- [ ] 降维三步法完整执行 ≥2 次
```
