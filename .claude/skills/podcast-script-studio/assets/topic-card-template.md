# 选题卡模板（每期一张）

```markdown
# 选题卡：{暂定标题}

## 基本信息
- **选题缘由**：（回答"为什么现在听"——热点/节日/群友点播/系列衔接/IP 上映）
- **题型**：（七选一：系列连载/热点快反/节日纪念日/影视IP借势/网感概念/争议站队/群友点播；排名类标注"排名亚型"）
- **系列归属**：（独立单期 / 属于XX系列第N期；如为上下集注明切分点）

## 核心认知反差（生死线）
- **你以为的**：{大众默认认知}
- **实际上的**：{节目要论证的真相}
- **反差的强度自评**：⭐⭐⭐⭐⭐（低于三星退回重选）

## 核心问题（这期节目回答的一句话问题）
{例如："我们羡慕韦小宝，到底在羡慕什么？"}

## 三大基因自检
- [ ] 小切口：{日常经验入口是什么}
- [ ] 大纵深：{最终抵达的宏大落点是什么}
- [ ] 人性内核：{删掉知识点后剩下的关于"人"的问题是什么}

## 标题候选（用九型公式各产 1-2 个，选优）
1. （型）……
2. （型）……
3. （型）……

## 内容弹药
- **主要素材/案例**：（3-6 个，标注每个素材的出处性质：正史/研究/野史/网传/影视）
- **可用的对照组**：（A vs B，用于让规律显影）
- **可交付的概念工具**：（本期听众能带走的"尺子"是什么；没有就要造一把）
- **降维三步法候选点**：（哪 2-3 个概念需要执行 原文→吐槽→比喻→回扣）
- **理论对垒**：（可选：观点A vs 观点B，收束用"各有各的道理"）
- **合法跑偏候选**：（1-2 处，童年记忆/生活吐槽/相邻冷知识）
- **梗与现代映射弹药**：（现代职务映射/游戏语言/影视吐槽素材）

## 阵容配置
- **主讲**：{名字}
- **主持**：{名字}
- **嘉宾**：（可选；专家身份与本选题的知识合法性来源；其"私人经验叙事"点）

## 冷开场方向
- 类型：（金句悬念/论点预告/结论碎片）
- 候选片段：（从内容弹药中预选最"炸"的 1-3 个点）

## 结尾设计
- 收束回扣点：
- 挖坑内容：（下期/未来选题预告）
- 互动设计：（讨论题/排行榜征集/其他）
```
