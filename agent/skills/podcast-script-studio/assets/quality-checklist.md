# 文稿质检清单（阶段 D）

> 逐项记录通过、问题与脚本位置；关键事实有问题必须修订后复核。字数、占比、金句和梗的数量只用于定位异常，不作为通过线。审稿人应主动找反证，不沿用作者的自评结论。

## A. 证据与边界（硬要求）

- [ ] A1 冷开、标题、关键转折、结论、数字与引语都能在证据卡中找到出处和脚本位置。
- [ ] A2 核对原始出处与时间线；不同来源互相冲突时，台词交代分歧，不把单一说法包装成定论。
- [ ] A3 每个重点段落区分可核实事实、依据证据的推断、节目演绎。无证对白、动作、心理活动不以纪实口吻出现。
- [ ] A4 独立反证审稿已找出并处理最强的反对材料；关键主线若证据不足，换主线或降低判断强度。
- [ ] A5 主播亲历、评论区、群聊、听众催更与纠错等说法有真实记录；没有记录就不用拟造反馈。
- [ ] A6 知识解释没有把类比当事实；涉及小说人物或真实人物的诊断、动机判断均限定证据边界。

## B. 故事与吸引力

- [ ] B1 开头提出具体事件或疑问，并留下听下去的理由；钩子本身有证据支撑。
- [ ] B2 各段沿“事件 → 疑问 → 新证据 → 判断变化”推进；时间线、人物关系和因果易听懂。
- [ ] B3 故事有足够的发现空间，强结论与比喻没有提前耗尽后续转折。
- [ ] B4 跑偏、幽默和知识解释帮助理解人物或问题；需要时才使用概念工具、古今类比和可执行建议。
- [ ] B5 结尾由本期材料自然长出，可停在人物余波、未解问题、观点变化或可复用工具；检查近几期是否重复同一种收束。

## C. 双人对话与节目声音

- [ ] C1 全稿仅大开、小李两位说话人；历史人物的话由二人第三人称转述，不写会触发第三音色的引号直接引语。
- [ ] C2 两人各有认识起点；小李在关键节点提出具体证据、误读或不同判断，大开回应其内容，并允许修正自己。
- [ ] C3 每轮对话咬住上一轮的具体内容；删掉只替下一段递词的机械问题和空泛应和。
- [ ] C4 与节目档案和本节目已核实的高光片段对照，保留两人各自的句法、幽默和节奏；外部样本只作参考。
- [ ] C5 亲历、口头重复、接梗和跑偏确有表达作用；没有为了降低“AI 味”而把两人磨成同一种口气。

## D. 语言与编辑保真

- [ ] D1 朗读测试顺口；台词没有“第几幕、伏笔、学术降维三步法”等制作术语或连篇书面句。
- [ ] D2 Humanizer-zh 只在反证审稿之后做局部润稿，处理确有问题的空话、无效重复和机械转场。
- [ ] D3 对照润稿前文本，史实、来源、数字、时间、否定、条件、归因、判断强度、双人分工和引语转述未被改坏。
- [ ] D4 台词修改只写入 `脚本_第N幕.md` 等 Markdown 源稿；未手改时间脚本、字幕或其他生成物。

## E. 文稿反馈

- [ ] E1 请不了解稿件的目标听众盲听开头、中段、结尾的朗读，记录想继续听、听不懂和像背稿的位置；暂时无法盲听时做盲读并说明局限。
- [ ] E2 按反馈回到具体段落修订，不拿个人打分或数字配额代替听感判断。

## 记录格式

| 检查项 | 结果 | 证据或问题位置 | 修订与复核 |
|---|---|---|---|
| A1—E2 | 通过 / 待修 / 不适用 | 文件与行号、来源 | 改动及复核人 |

**优先级**：先处理 A 类事实风险与 C1 双人边界，再处理 B/C 的故事和对话，最后做 D 类润稿。不得用其他项目的通过抵消关键事实错误。
