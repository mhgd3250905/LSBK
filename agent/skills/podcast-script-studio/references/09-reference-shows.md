## 四、选题决策经验法则（从 56 期分布反推）

1. 新节目冷启动：优先**争议站队型+网感概念型**（单期独立、易传播）；系列是留存期再建的
2. 同一 IP/人物可以多刀切（关羽两刀、金庸七期）——好题材值得反复开采，但每刀角度必须不同（历史刀/文化刀/权力刀/情感刀）
3. 热点快反的最佳窗口 3 天内，且要坦白地蹭（人设红利）
4. 系列命名成对呼应（开端/终结）能显著提升追更感
5. 每期至少挖 2 个下期坑——选题库是滚动再生的，不是一次列完的
