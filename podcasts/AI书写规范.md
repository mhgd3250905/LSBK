# 《笑谈历史》文稿写作与去 AI 化规范（唯一汇总）

> 本文件汇总散落在两份审核复盘与工作区 AGENTS.md 中的全部文稿写作 / 去 AI 化规则，是后续所有新单集文稿的**唯一规范入口**。规则修订一律先改本文件；两份历史复盘只作背景与依据，不再增量维护规则。建文件：2026-10-07。
>
> **规则力度分两档**：只有用户明确点名不要的表述（如第三节负面清单各条）才写为零容忍硬禁令；其余一律是取向引导，措辞保持弹性，不写死。（2026-10-07 用户定调）

## 一、硬边界（违反即返工）

1. **事实边界**：不虚构史实、对白、动机、私密场景与听众反应；冷开场、反常识主张、关键转折、数字、引语必须有出处。先锁证据再定故事——关键转折缺证就换主线，不靠润色把不确定写得更动人。
2. **纯双人声线**：全节目只有大开（主讲）× 小李（主持）两个音色；引语一律第三人称转述，**正文直接引号（`“”` `「」`）为 0**。
3. **Markdown 为源稿**：文稿、事实、时间轴以 Markdown 为唯一事实源；单集时长与各幕字数是估算值不是配额，禁止为凑数注水。
4. **不虚报**：不得声称文稿"已朗读 / 盲听 / 试听"除非真的做过；引用旧音频时须注明与当前文稿的差异。
5. **末幕收尾完整性（严禁戛然而止，仅限全集最后一幕，2026-10-14 用户重点纠偏）**：⚠️ **此检查仅且仅在全集最后一幕（通常为第四幕）结尾执行**！前置各幕（第一至三幕）必须保持事件与对话无缝流动，严禁任何形式的提前告别或阶段总结；**仅在最后一幕末尾**，严禁由单人大开陈述或悬念抛出后直接截断，必须严格遵循双人闭环收口结构：① 小李作为独立主持人的全期回扣与情感沉淀；② 大开的一句话深度历史注脚；③ 小李标志性电台收束告别语（“感谢大家收听本期的《笑谈历史》，我们下期接着聊。”）。在启动音频合成前必须人工核验最后一幕最后 3 个话轮，严防废音频重录浪费 API 资源。

## 二、核心叙事宪章：坚决消灭流水账，确立影视化听感（2026-10-14 用户最高指示，主导全节目制作）

> **流水账的致命死穴（零容忍）**：
> 1. **论文式对账**：跨年份罗列史料、比对数字和文献异同（如把篇幅浪费在考证四个版本分别死了多少人），把沉浸式播客变成了枯燥的学术文献综述；
> 2. **碎片化跳跃**：时间轴不断跳跃，缺乏贯穿全篇的情感支柱，段与段之间成了孤立的年份备忘录；
> 3. **听感散漫**：听众无法代入任何一个人的生死悲欢，只感到冰冷的信息轰炸与疲惫，听感极差。

### 创作铁律（二选一必须满足，严禁违背）
- **法则一（主选·大主角命运叙事）**：**必须有一个故事主角**，通过讲述他/她具体血肉丰满的生命经历、戏剧性遭遇与命运起伏，见微知著地折射出整个历史时代的剧烈变局。听众必须能够“穿上主角的鞋”，跟随他一同经历热血、委屈、窒息与壮烈（如 EP28 重构版以戚金二十八年命运串联天下第一铁军的悲壮终局）。
- **法则二（备选·绝对话题中心推演）**：若无单一连续主角，**必须有一个极度聚焦的绝对话题中心**（如一项制度的自我吞噬、一支军队的体制死局、一场审判的司法死斗），通篇围绕一个核心矛盾层层递进推演，每一幕都是一次认知跃迁，严禁写成编年史流水账。

### 影视化听感的三大黄金支柱
1. **开场即高潮**：冷开场必须是影视级的至暗时刻或极具张力的悬念切口（如浑河岸边勒马死战、米脂烈日下的死囚大枷、登州荒舍砍人的现场笔录），开机即抓人，绝不从平铺直叙的背景交代开始；
2. **人性与戏在台前，考据留在幕后**：严谨的历史考据是地基，留在《史料核对.md》中；正文台词必须讲具体人情、权力逻辑、动作白描与心理博弈，绝不让文献考据喧宾夺主；
3. **因果咬合与终极情感回响**：幕与幕之间严密咬合，全篇拥有完整的情感起伏弧线，第四幕结尾必须具备深沉的历史沉淀与双人闭环收口。

## 三、开场与结构

1. **两段式黄金开场（雷打不动）**：
   - `[00:00-01:00]` 纯具象冷开场名场面：不打招呼、不报幕、不寒暄，直接从最荒谬/最激烈/最具悬念的具体历史镜头切入；
   - `[01:00-02:00]` 标志性双人报幕（"大家好，这里是笑谈历史，我是大开。"/"我是小李。"）+ 承接名场面带出人情困惑，大开破题切入正片。
2. **选题三要素（无戏剧主角不立项）**：一个有极致矛盾的血肉主角 + 一个正史有据的黑色幽默名场面（可供影视化还原）+ 一个打穿古今的人性命题。
3. **结尾形态多样化**：不允许每期都以"三把尺子"式分层模型收尾变成培训课；可以停在未解问题、人物余波或真实听众反馈上。

## 三、去 AI 味负面清单（零容忍）

### 表层五禁

1. **句首呼唤**：小李台词首句绝对禁止"大开，"，改用"你说如果……""按常理说……""很多人可能都在琢磨……"等自然带入；
2. **惊悚煽情词**：头皮发麻、让人窒息、脊背发凉、细思极恐、绝了——让具体事实、动作和数字说话，不替听众预设生理反应；
3. **说教式自夸标签**：这就太反常识了、颠覆认知、更绝的是、真正让人不可思议的是；
4. **机械对仗句式**："不是……而是……""既不是……也不是……而是……""从来不是……恰恰是……"，用连贯单句直接陈述事件因果；
5. **暴露剧本结构与制作术语（2026-10-15 用户纠偏）**：这一幕/下一幕/彩蛋/伏笔/板块/环节/大纲/脚本/收束等元词汇不得出现在台词里；**绝对严禁在台词中说“冷开场”**（如“今天冷开场里……”、“这个冷开场……”），开场报幕后指代前面的名场面时，一律用口语自然的“开头 / 刚才开头”，主播绝不知道自己是在做制作，这是真实对谈；
6. **分幕串场与机械设问口癖（2026-10-10 用户纠偏）**：严禁出现“那么接下来发生了什么呢？”“我们继续”“接下来看……”“那后来呢，我们接着说”等主持人串场报幕式设问或机械催促。分幕写作只是工程分工，文稿必须是一个无缝流动的真实对谈，幕与幕、段与段之间必须由具体事件因果、人物下一步动作或前文逻辑自然咬合，主播绝不知道自己活在分幕里。

### 深层四类"AI 口癖"清剿（EP19 沉淀，2026-10-08 S2E01 升级定稿）

| AI 口癖类别 | 典型中毒句式（严禁 ❌） | 真实人类口语 / 具象白描替代（必须 ✅） |
|---|---|---|
| ① 机械排比与宏大对仗 | "在承平时期，他是……；但在绝境中，他是……"；"这不仅是皇权的较量，更是一场……"；"从来不是……恰恰是……" | 讲具体人情与客观权力逻辑："换了任何一个娇生惯养的帝王，谁还顾得上一个手下的小卒子。他倒好，真拿身边人的命当命看。" |
| ② 短视频标签与自卖自夸 | "你会看到更令人唏嘘的一幕"；"这还不算最绝的"；"但真正让人不可思议的是"；"这波操作简直绝了" | 严禁预告和自夸。把镜头直接推到现场，把动作、原话讲出来，惊叹留给听众 |
| ③ 翻译腔与惊悚舞台腔 | "等待着命运的裁决"；"青史难书"；"死神已经追到了脚后跟"；"命运的齿轮开始转动" | 白描写动作："他就安安静静坐在乱石堆里，不跑也不喊"；"瓦剌铁骑的马蹄声已经近在咫尺" |
| ④ 机械接茬与口癖垫话 | "一点都没错 / 一点没错"；"做梦都想不到"；"这组合凑在一块儿就差导火索了"；"这画面想想就……" | 严禁口癖垫话。直接用制度推论接话："皇权最忌讳的就是臣子抱团"；"换谁谁不发懵啊" |

### 开场钩子铁律：严禁预设听众已知（S2E01 用户重点纠偏，2026-10-08）
- **绝不预设听众已知历史背景**：第一幕开场第一句，严禁讲"大家都不知道十年前有一场残酷风暴"，听众压根不知道十年前有风暴，预设已知会导致听众毫无期待；
- **必须从大众最熟悉的课本常识/现实痛点切入**：例如全国初三背《岳阳楼记》"滕子京谪守巴陵郡"，以为只是个人犯错被贬、老友写文安慰，由此层层揭开"全员戴罪在身、大半个文坛被逐出京城"的巨大反差。

## 四、纯故事叙述原则（故事为主，感悟点到为止）

> 本节是**取向引导，不是禁令**：整体往"多讲故事、少讲道理"倾斜即可，除非用户明确点名不要的表述（见第三节负面清单），不设一刀切红线。（2026-10-07 用户澄清）

- **优先用场景推进**：戏剧张力尽量来自正史细节的戏剧性冲撞（如王竑咬马顺的肉、徐珵看星象劝逃被当面拍桌痛骂、杨善凭铁齿铜牙把太上皇白嫖接回）——这是首选手法，不是唯一合法手法；
- **感悟与道理要克制、自然**：不刻意在幕末堆"人生感悟""职场启示录"式的大段抽象总结；但如果一句点题的话是故事自然长出来的、简短贴切的，可以保留——宁可少，不说教；
- **把握不准就倾向故事**：拿捏不定某段该不该讲道理时，默认回到场景与事实，把判断留给听感；
- 双主播定位：大开是茶馆说书人（还原历史现场的波诡云谲与人性格局），小李是好奇听友（追问具体场景细节与常人反应）。

## 五、双人对话真实感（2026-09-24 复盘沉淀）

1. **结论和强度不许先到**：开场就交代惨烈终局、每段都抬到最高音量，听众就失去了自己发现转折的空间；保留最有力的一处形象，其余用具体行动与后果推进；
2. **主持不是提词器**：小李要有自己的误读、证据或不同判断，让对话真的改变至少一个观点；不搞"太对了，接下来是什么"式串题，也不需要每轮制造争辩；
3. **节目方法论不进台词**："学术降维三步法""第一步、第二步"留在创作笔记里，主播只需自然解释概念；
4. **"拟人"不等于虚构经历**：未经核实的评论区催更、微信群讨论、对人物的临床诊断式断言、无出处的私下对白与心理镜头，一律不写。

## 六、单幕文稿写作强约束：每幕写毕必做·五维自检强约束机制（2026-10-14 用户指示升级）

每次在创作、修改或交付任何一幕脚本 Markdown 原稿时，**必须在文稿下方或对话中执行并输出《单幕五维自检卡》，且通过自动化自检脚本无死角扫描**：

### 维度一：大主角命运贯通性（叙事灵魂·绝不偏航）
1. **唯一主角锚定**：明确指出本幕故事的大主角是谁？主角在本幕经历了什么具体的遭遇、戏剧性冲突、委屈、窒息或抗争？
2. **“穿上主角的鞋”**：听众能否自始至终代入主角的第一视角感受时代变局？是否坚决杜绝了“主角失踪”、“多人物跳跃拼盘”或“跨年份流水账”？
3. **戏与人情在台前**：考据证据严格留在幕后，台前只展现具体人情反应、动作白描与权力逻辑。

### 维度二：影视化视听结构
1. **第一幕两段式开场**：纯具象影视级至暗/冲突名场面（不打招呼直接开机）+ 标志性双人报幕 + 大众最熟悉常识痛点切入；
2. **中间幕事件因果咬合**：由具体事件因果自然咬合推进，绝不使用“那么接下来发生了什么呢？”“我们继续”等主持人报幕式口癖；
3. **末幕双人闭环收口（仅限全集最后一幕）**：严格执行末尾三轮闭环（小李主持回扣与情感沉淀 -> 大开深度历史注脚 -> 小李标志性电台告别语）；前置各幕严禁提前告别或阶段总结。

### 维度三：机械零容忍底线（代码级扫描零违规）
- 正文直接引号（`“”` `「」`）为 0（彻底阻断豆包 action=3 触发第三音色）；
- 小李台词句首呼名“大开，”为 0（彻底阻断咪仔音色卡顿重读）；
- 机械八股对仗句式（“不是……而是……”、“既不是……也不是……”、“从来不是……恰恰是……”）为 0；
- 廉价煽情/短视频标签词（“头皮发麻”、“让人窒息”、“细思极恐”、“绝了”、“颠覆认知”、“更绝的是”）为 0；
- 剧本腔结构元词汇（“幕”、“伏笔”、“彩蛋”、“板块”、“环节”、“大纲”、“脚本”、“收束”）除 Markdown 标题外为 0。

### 维度四：真实双人对谈感
1. 小李是具备独立认知的对话者与听众嘴替，带着真实常识发问，绝非机械捧哏；
2. 历史人物话语一律第三人称口语转述。

### 维度五：自动化脚本执行
每幕写完必须运行自动化检查脚本：
```bash
python scripts/verify_act_script.py 幕文件.md [--is-last-act]
```
扫描输出必须全部为 0 违规，否则严禁进入时间脚本转换与音频合成！

## 七、生产流程顺序

1. **先锁证据，再定故事**：对冷开、反常识主张、关键转折、数字和引语做"主张—原始出处—不同解释—脚本位置"小表；
2. **先写全期发现路径，再写台词**：每段只问——听众眼前有什么事件？此处产生了什么疑问？下一条证据怎样改变原来的判断？分幕交付可保留，但不得切断全期弧线；
3. **Humanizer-zh 只做末端局部清理**：适合清空话、重复、机械转场；保留有效的口头重复与两位主播各自的说话方式，不捏造亲历或听众反馈；
4. **质检从自评改成找错**：作者之外做一次证据复核，盲听开头/中段/结尾，记录"哪里想继续听、哪里听不懂、哪里像在背稿"；
5. **合成与元数据底线**：各幕合并前剥离内嵌 ID3、`ffmpeg -v error` 解码零错误、SRT 条数=四幕总话轮数、shownotes 时间轴基于最终 SRT 实测回写（详见《发布SOP与台账.md》踩坑档案）。
