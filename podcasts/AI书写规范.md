# 《笑谈历史》文稿写作与去 AI 化规范（唯一汇总）

> 本文件汇总散落在两份审核复盘与工作区 AGENTS.md 中的全部文稿写作 / 去 AI 化规则，是后续所有新单集文稿的**唯一规范入口**。规则修订一律先改本文件；两份历史复盘只作背景与依据，不再增量维护规则。建文件：2026-10-07。
>
> **规则力度分两档**：只有用户明确点名不要的表述（如第三节负面清单各条）才写为零容忍硬禁令；其余一律是取向引导，措辞保持弹性，不写死。（2026-10-07 用户定调）

## 一、硬边界（违反即返工）

1. **事实边界**：不虚构史实、对白、动机、私密场景与听众反应；冷开场、反常识主张、关键转折、数字、引语必须有出处。先锁证据再定故事——关键转折缺证就换主线，不靠润色把不确定写得更动人。
2. **纯双人声线**：全节目只有大开（主讲）× 小李（主持）两个音色；引语一律第三人称转述，**正文直接引号（`“”` `「」`）为 0**。
3. **Markdown 为源稿**：文稿、事实、时间轴以 Markdown 为唯一事实源；单集时长与各幕字数是估算值不是配额，禁止为凑数注水。
4. **不虚报**：不得声称文稿"已朗读 / 盲听 / 试听"除非真的做过；引用旧音频时须注明与当前文稿的差异。
5. **末幕收尾完整性（严禁戛然而止，仅限全集最后一幕，2026-10-14 用户重点纠偏）**：⚠️ **此检查仅且仅在全集最后一幕（通常为第四幕）结尾执行**！前置各幕（第一至三幕）必须保持事件与对话无缝流动，严禁任何形式的提前告别或阶段总结；**仅在最后一幕末尾**，严禁由单人大开陈述或悬念抛出后直接截断，必须严格遵循双人闭环收口结构：① 小李作为独立主持人的全期回扣与情感沉淀；② 大开的一句话深度历史注脚；③ 小李标志性电台收束告别语（“感谢大家收听本期的《笑谈历史》，我们下期接着聊。”）。在启动音频合成前必须人工核验最后一幕最后 3 个话轮，严防废音频重录浪费 API 资源。

## 二、核心叙事宪章：坚决消灭流水账，确立影视化听感（2026-10-14 用户最高指示，主导全节目制作）

> **流水账的致命死穴（零容忍）**：
> 1. **论文式对账**：跨年份罗列史料、比对数字和文献异同（如把篇幅浪费在考证四个版本分别死了多少人），把沉浸式播客变成了枯燥的学术文献综述；
> 2. **碎片化跳跃**：时间轴不断跳跃，缺乏贯穿全篇的情感支柱，段与段之间成了孤立的年份备忘录；
> 3. **听感散漫**：听众无法代入任何一个人的生死悲欢，只感到冰冷的信息轰炸与疲惫，听感极差。

### 创作铁律（二选一必须满足，严禁违背）
- **法则一（主选·大主角命运叙事）**：**必须有一个故事主角**，通过讲述他/她具体血肉丰满的生命经历、戏剧性遭遇与命运起伏，见微知著地折射出整个历史时代的剧烈变局。听众必须能够“穿上主角的鞋”，跟随他一同经历热血、委屈、窒息与壮烈（如 EP28 重构版戚金、EP30~32 李自成、EP33 史可法、EP34 郑成功、EP35 李定国、番外01 魏忠贤、番外02 朱由校、番外03 张溥、番外04 崇祯朱由检）。
- **法则二（备选·绝对话题中心推演）**：若无单一连续主角，**必须有一个极度聚焦的绝对话题中心**（如一项制度的自我吞噬、一支军队的体制死局、一场审判的司法死斗，如 EP36《1662群星谢幕》），通篇围绕一个核心矛盾层层递进推演，每一幕都是一次认知跃迁，严禁写成编年史流水账。

### 【大主角命运叙事实战操作模型】（全集贯穿实操体系）

经过晚明边防、大明终局与九千岁番外四部曲的反复实战锤炼，全节目确立并固化以下“大主角命运叙事”核心操作法则：

#### 1. 唯一大主角锚定与主观视角沉浸
- **立项先锁大主角**：每集必须锁定一个身处历史风暴漩涡正中心的血肉之人，他必须拥有极端的生存矛盾、强烈的戏剧性冲突或打穿古今的人性共鸣；
- **拒绝碎片拼盘与上帝视角**：严禁写成“前两幕写张三、后两幕写李四”的人物拼盘，也严禁主播站在上帝视角评头论足。全篇必须以大主角的生命主线为骨架，听众“穿上主角的布鞋”，从主角的第一视界去感受时代的刺骨严寒与生死抉择（如番外03以25岁书生张溥的双眼看苏州官民撕裂，番外04以16岁少年朱由检的感官体验深宫密网）。

#### 2. 大主角的标准四幕命运叙事弧线
- **第一幕：深陷死局与至暗时刻（极度紧绷 / 恐惧 / 屈辱）**：冷开场直接推入大主角最凶险或最无助的具象名场面（如信王袖藏麦饼、暗夜要过巡夜短剑握出满手冷汗；米脂烈日下的死囚大枷；浑河岸边的最后冲锋）。不交代任何宏观背景，先让听众感受到主角呼吸的停滞；
- **第二幕：隐忍抗争与深水博弈（暗流涌动 / 抽丝剥茧）**：主角在困局中寻找生机，展现惊人的心智、城府或隐忍抉择（如崇祯温水煮狼假意顺从、客氏出宫火化胎发、叫停生祠碎金身；张溥目睹巡抚钻茅坑与五义士赴死保全城）；考据留幕后，台前只写动作与权力算计；
- **第三幕：正面交锋与命运反杀（戏剧高潮 / 生死决杀）**：大主角与对立力量迎来不可避免的总摊牌（如乾清宫正殿当面念疏十大罪、魏忠贤大惧两腿发软破防；阜城雪夜客店自缢；苏州百姓铁锤怒砸太监生祠）；
- **第四幕：历史闭环与深沉余波（终极审判 / 时代死结）**：由大主角的结局见微知著，折射整个王朝的体制死结（如御案上一整大麻袋颂疏的讽刺现形记，以及晚年刀柄重递太监的历史警示；五人墓碑记化作扇向满朝权贵的耳光）；结尾严格执行三轮双人闭环收口。

#### 3. 角色登场“人情破冰”与零空降铁律（规范第11条）
- **严禁生僻人名轰炸**：严禁在台词中无铺垫直接抛出生僻历史人物，严禁小李以“未卜先知”剧本视角背诵百科履历（如“周顺昌当过吏部郎中……”）；
- **生活常态与人情生态位先行**：凡出场人物，必须先交代他在故事中的生活常态（是退休闲住替街坊平事的长辈？还是卡在夹缝里两头受气的小官？）；
- **听众嘴替发问与具象带活**：小李必须站在听众视角自然追问“这人是谁、为什么要保他”，大开再通过具体生活细节带活人物；
- **非核心人物去姓名化**：非主线推动者的功能性官员，坚决使用“隔壁省巡抚”、“同衙门御史”、“当地同道”替代，杜绝生僻名字打断沉浸感。

#### 4. 历史礼制反戏说与制度边界底线（规范第12条）
- **严禁演义黑话**：严禁受评书古偶剧污染，非皇帝严禁称“万岁”、“万万岁”或“九千九百岁”；魏忠贤生祠最高规格为《明史》定格的“山呼九千岁，恭祝厂臣千秋”；
- **正史规制底线**：逮捕称驾帖、奏疏称厂臣、内阁下发称“朕与厂臣”，展现严谨的正史质感与底线。

#### 5. 语言民间口语化与消灭文言纪年（2026-10-22 用户纠偏）
- **坚决消灭文言生硬纪年**：严禁出现“以明年为崇祯元年”等书面文言套话，必须改用通俗民间口语（如“成了咱们大家都熟悉的崇祯皇帝”、“到了第二年正月”）；
- **民间茶馆说书人基调**：大开是茶馆里讲透世事人情的说书人，小李是带着生活经验与好奇敏锐追问的知己听友，彻底消灭论文答辩腔、作文拔高腔与问卷调查腔。

### 影视化听感的三大黄金支柱
1. **开场即高潮**：冷开场必须是影视级的至暗时刻或极具张力的悬念切口（如浑河岸边勒马死战、米脂烈日下的死囚大枷、登州荒舍砍人的现场笔录），开机即抓人，绝不从平铺直叙的背景交代开始；
2. **人性与戏在台前，考据留在幕后**：严谨的历史考据是地基，留在《史料核对.md》中；正文台词必须讲具体人情、权力逻辑、动作白描与心理博弈，绝不让文献考据喧宾夺主；
3. **因果咬合与终极情感回响**：幕与幕之间严密咬合，全篇拥有完整的情感起伏弧线，第四幕结尾必须具备深沉的历史沉淀与双人闭环收口。

## 三、开场与结构

1. **两段式黄金开场（雷打不动）**：
   - `[00:00-01:00]` 纯具象冷开场名场面：不打招呼、不报幕、不寒暄，直接从最荒谬/最激烈/最具悬念的具体历史镜头切入；
   - `[01:00-02:00]` 标志性双人报幕（"大家好，这里是笑谈历史，我是大开。"/"我是小李。"）+ 承接名场面带出人情困惑，大开破题切入正片。
2. **选题三要素（无戏剧主角不立项）**：一个有极致矛盾的血肉主角 + 一个正史有据的黑色幽默名场面（可供影视化还原）+ 一个打穿古今的人性命题。
3. **结尾形态多样化**：不允许每期都以"三把尺子"式分层模型收尾变成培训课；可以停在未解问题、人物余波或真实听众反馈上。

## 三、去 AI 味负面清单（零容忍）

### 表层五禁

1. **句首呼唤**：小李台词首句绝对禁止"大开，"，改用"你说如果……""按常理说……""很多人可能都在琢磨……"等自然带入；
2. **惊悚煽情词**：头皮发麻、让人窒息、脊背发凉、细思极恐、绝了——让具体事实、动作和数字说话，不替听众预设生理反应；
3. **说教式自夸标签**：这就太反常识了、颠覆认知、更绝的是、真正让人不可思议的是；
4. **机械对仗句式**："不是……而是……""既不是……也不是……而是……""从来不是……恰恰是……"，用连贯单句直接陈述事件因果；
5. **暴露剧本结构与制作术语（2026-10-15 用户纠偏）**：这一幕/下一幕/彩蛋/伏笔/板块/环节/大纲/脚本/收束等元词汇不得出现在台词里；**绝对严禁在台词中说“冷开场”**（如“今天冷开场里……”、“这个冷开场……”），开场报幕后指代前面的名场面时，一律用口语自然的“开头 / 刚才开头”，主播绝不知道自己是在做制作，这是真实对谈；
6. **分幕串场与机械设问口癖（2026-10-10 用户纠偏）**：严禁出现“那么接下来发生了什么呢？”“我们继续”“接下来看……”“那后来呢，我们接着说”等主持人串场报幕式设问或机械催促。分幕写作只是工程分工，文稿必须是一个无缝流动的真实对谈，幕与幕、段与段之间必须由具体事件因果、人物下一步动作或前文逻辑自然咬合，主播绝不知道自己活在分幕里；
7. **做作的预设认知与问卷式垫话（2026-10-15 用户重点纠偏）**：严禁反复套用“在很多人的印象里……”、“在大家的印象里……”、“很多人平时的印象中……”、“很多人总以为……”等做作的调查问卷式垫话。主播不是在宣读社会认知调研报告，而是真实的民间闲聊或场景带入。严禁套路化预设听众印象，改用具体生活化语境或直接切入（如“咱们平时聊起……”、“民间评书总讲……”、“老话常说……”、“要是真以为……可就……”）；
8. **假大空宏大抒情与纪录片/作文解说腔（2026-10-16 用户重点纠偏）**：严禁出现“这正是大明终局历史上最沉重、也最深刻的一场大悲剧”、“最波澜壮阔、也最具戏剧性的历史画卷”、“波澜壮阔的一生”、“谱写了一曲悲歌”、“拉开了……历史大幕”、“敲响了……丧钟”、“轰然倒塌”、“可以说是最廉价也最有效的……”等高考作文式拔高或电视纪录片解说腔。主播是茶馆闲聊的民间说书人，不是给历史定调贴金的思政课教授。严禁自夸历史本身的宏大或强加宏大定性，把台词死死按在具体人情、权力逻辑和动作白描上（如“谁能想到，这几百万饿得只剩一把骨头的穷苦百姓，真能把这大明天下给彻底掀翻了”、“整段历史最让人后背发凉的，其实也就是这个死结。大明朝廷把自己活生生耗死了，而李自成砸烂了旧世道，却根本不知道该怎么建立一个新世道”）。
9. **论文腔过渡与论述假定词（2026-10-16 用户纠偏）**：严禁出现“可以说是”、“不得不面对/不得不说”、“不难看出”、“由此可见”、“换言之”、“综上所述”等论文答辩式连接词。日常口语对谈要用“其实就是”、“但这就带来一个要命的事儿”、“说白了就是”等平实自然的表达；
10. **坚决消灭后置各幕开头的机械回溯/串场口癖（2026-10-19 用户严令·番外01沉淀）**：严禁在后置各幕（第二、三、四幕）开头出现“刚才咱们聊到/说到/提到”、“刚才我们提到”、“前面咱们说到/聊到”、“上一幕讲到”等任何回顾式、复述式、广播串场式机械垫话！整篇文稿必须是一体化、无缝流动的连续真实长对话，听众完全不知道分幕工程的存在。**正确做法**：前一幕结尾抛出悬念、危机或具体疑问，后一幕首句立即由另一位主播直接破题接茬、情绪反应或展开下一现场，如同同一段对话从未中断一样自然流动；
11. **坚决杜绝“人物空降”与“履历背诵式引入”（2026-10-21 用户纠偏·番外03沉淀）**：严禁在台词中无前置铺垫直接扔出生僻历史人物姓名，或由小李以“未卜先知”的剧本视角背诵百科履历（如“周顺昌在朝廷里当过吏部郎中，为人清廉刚正……”）。凡登场人物必须“零门槛破冰”——先交代他在故事中的人情生态位与生活常态（是退休闲住的街坊老大哥？还是卡在夹缝中的地方官？），小李必须站在听众视角自然追问“这人是谁、为什么要保他”，再由大开通过具象生活细节带活。非核心功能性人物坚决“去姓名化”（用“隔壁省巡抚”、“同衙门御史”、“当地同道”替代），严防生僻人名轰炸打断听众沉浸感；
12. **严禁历史礼制僭越与戏说演义黑话（2026-10-21 用户严令·番外03沉淀）**：严禁受评书、戏曲、清宫古偶剧口癖影响，在正史向播客中出现违背朝代礼制与制度常识的荒唐称谓。
   - ① **严禁称非皇帝人物为“万岁”、“万万岁”**：魏忠贤在天启朝最高呼称为“九千岁”（《明史》卷305定格），官员生祠祭拜呼“九千岁”或“恭祝千秋”；“万岁/万万岁”为天子专享绝对禁区，写群臣对太监呼“万岁”属严重史实硬伤；
   - ② **严禁采信无据的民间演义口癖**：如“九千九百岁”（正史无，属评书夸饰）、戏说的“奉天承运皇帝诏曰”等网梗套话；
   - ③ **官职礼制严格依正史边界**：东厂抓人凭“驾帖”，奏折称“厂臣”，内阁票旨称“朕与厂臣”，展现严谨正史质感。

### 开场钩子铁律：严禁预设听众已知（S2E01 用户重点纠偏，2026-10-08）
- **绝不预设听众已知历史背景**：第一幕开场第一句，严禁讲"大家都不知道十年前有一场残酷风暴"，听众压根不知道十年前有风暴，预设已知会导致听众毫无期待；
- **必须从大众最熟悉的课本常识/现实痛点切入**：例如全国初三背《岳阳楼记》"滕子京谪守巴陵郡"，以为只是个人犯错被贬、老友写文安慰，由此层层揭开"全员戴罪在身、大半个文坛被逐出京城"的巨大反差。

## 四、纯故事叙述原则（故事为主，感悟点到为止）

> 本节是**取向引导，不是禁令**：整体往"多讲故事、少讲道理"倾斜即可，除非用户明确点名不要的表述（见第三节负面清单），不设一刀切红线。（2026-10-07 用户澄清）

- **优先用场景推进**：戏剧张力尽量来自正史细节的戏剧性冲撞（如王竑咬马顺的肉、徐珵看星象劝逃被当面拍桌痛骂、杨善凭铁齿铜牙把太上皇白嫖接回）——这是首选手法，不是唯一合法手法；
- **感悟与道理要克制、自然**：不刻意在幕末堆"人生感悟""职场启示录"式的大段抽象总结；但如果一句点题的话是故事自然长出来的、简短贴切的，可以保留——宁可少，不说教；
- **把握不准就倾向故事**：拿捏不定某段该不该讲道理时，默认回到场景与事实，把判断留给听感；
- 双主播定位：大开是茶馆说书人（还原历史现场的波诡云谲与人性格局），小李是好奇听友（追问具体场景细节与常人反应）。

## 五、双人对话真实感（2026-09-24 复盘沉淀）

1. **结论和强度不许先到**：开场就交代惨烈终局、每段都抬到最高音量，听众就失去了自己发现转折的空间；保留最有力的一处形象，其余用具体行动与后果推进；
2. **主持不是提词器**：小李要有自己的误读、证据或不同判断，让对话真的改变至少一个观点；不搞"太对了，接下来是什么"式串题，也不需要每轮制造争辩；
3. **节目方法论不进台词**："学术降维三步法""第一步、第二步"留在创作笔记里，主播只需自然解释概念；
4. **"拟人"不等于虚构经历**：未经核实的评论区催更、微信群讨论、对人物的临床诊断式断言、无出处的私下对白与心理镜头，一律不写。

## 六、单幕文稿写作强约束：每幕写毕必做·五维自检强约束机制（2026-10-14 用户指示升级）

每次在创作、修改或交付任何一幕脚本 Markdown 原稿时，**必须在文稿下方或对话中执行并输出《单幕五维自检卡》，且通过自动化自检脚本无死角扫描**：

### 维度一：大主角命运贯通性与角色零空降（叙事灵魂·绝不偏航）
1. **唯一主角锚定**：明确指出本幕故事的大主角是谁？主角在本幕经历了什么具体的遭遇、戏剧性冲突、委屈、窒息或抗争？
2. **“穿上主角的鞋”**：听众能否自始至终代入主角的第一视角感受时代变局？是否坚决杜绝了“主角失踪”、“多人物跳跃拼盘”或“跨年份流水账”？
3. **戏与人情在台前**：考据证据严格留在幕后，台前只展现具体人情反应、动作白描与权力逻辑；
4. **角色登场人情破冰与零空降（2026-10-21 用户纠偏沉淀）**：
   - 严禁生僻人物无铺垫直接登场，或由小李以“未卜先知”剧本视角背诵履历百科；
   - 凡出场角色必须具备明确的“人情生态位”（如街坊长辈、老轿夫、卡在夹缝中的地方官），其极端行为（点香跪街、自首赴死、修祠磕头）必须具备生活常理的心理底座；
   - 小李必须作为听众视线发问，绝不抢跑剧本；非核心功能性人物坚决“去姓名化”（用“隔壁省巡抚”、“同衙门御史”、“当地同道”替代），杜绝生僻姓名轰炸打断听众沉浸感。

### 维度二：影视化视听结构
1. **第一幕两段式开场**：纯具象影视级至暗/冲突名场面（不打招呼直接开机）+ 标志性双人报幕 + 大众最熟悉常识痛点切入；
2. **中间幕事件因果咬合**：由具体事件因果自然咬合推进，绝不使用“那么接下来发生了什么呢？”“我们继续”等主持人报幕式口癖；
3. **末幕双人闭环收口（仅限全集最后一幕）**：严格执行末尾三轮闭环（小李主持回扣与情感沉淀 -> 大开深度历史注脚 -> 小李标志性电台告别语）；前置各幕严禁提前告别或阶段总结。

### 维度三：机械零容忍底线（代码级扫描零违规）
- 正文直接引号（`“”` `「」`）为 0（彻底阻断豆包 action=3 触发第三音色）；
- 小李台词句首呼名“大开，”为 0（彻底阻断咪仔音色卡顿重读）；
- 机械八股对仗句式（“不是……而是……”、“既不是……也不是……”、“从来不是……恰恰是……”）为 0；
- 廉价煽情/短视频标签词/假大空解说词/政论作文腔（“头皮发麻”、“让人窒息”、“细思极恐”、“绝了”、“颠覆认知”、“更绝的是”、“历史画卷”、“波澜壮阔”、“最具戏剧性”、“历史大幕”、“敲响丧钟”、“轰然倒塌”、“不可一世”、“悄然降临”、“宿命”）为 0；
- 作文式高调定性句式（“这正是……最……也最……”、“可以说是最……也最……”、“不仅……更是拉开了……”）为 0；
- 论文腔论述过渡词（“可以说”、“不得不面对/不得不说”、“不难看出”、“由此可见”、“换言之”、“综上所述”）为 0；
- 做作问卷式与预设认知垫话（“在很多人的印象里/中”、“大家的印象里/中”、“很多人平时的印象”、“很多人总以为”）为 0；
- 后置幕开头机械回溯与复述口癖（“刚才咱们/我们提到/聊到/说到/讲到”、“前面咱们说到/提到”）为 0；
- 剧本腔结构元词汇（“幕”、“伏笔”、“彩蛋”、“板块”、“环节”、“大纲”、“脚本”、“收束”）除 Markdown 标题外为 0；
- 历史礼制与称谓演义化戏说（对非皇帝人物出现“万岁”、“万万岁”、“九千九百岁”、“喊万岁”）为 0。

### 维度四：真实双人对谈感
1. 小李是具备独立认知的对话者与听众嘴替，带着真实常识发问，绝非机械捧哏；
2. 历史人物话语一律第三人称口语转述。

## 七、生产流程顺序

1. **先锁证据，再定故事**：对冷开、反常识主张、关键转折、数字和引语做"主张—原始出处—不同解释—脚本位置"小表；
2. **先写全期发现路径，再写台词**：每段只问——听众眼前有什么事件？此处产生了什么疑问？下一条证据怎样改变原来的判断？分幕交付可保留，但不得切断全期弧线；
3. **Humanizer-zh 只做末端局部清理**：适合清空话、重复、机械转场；保留有效的口头重复与两位主播各自的说话方式，不捏造亲历或听众反馈；
4. **质检从自评改成找错**：作者之外做一次证据复核，盲听开头/中段/结尾，记录"哪里想继续听、哪里听不懂、哪里像在背稿"；
5. **合成与元数据底线**：各幕合并前剥离内嵌 ID3、`ffmpeg -v error` 解码零错误、SRT 条数=四幕总话轮数、shownotes 时间轴基于最终 SRT 实测回写（详见《发布SOP与台账.md》踩坑档案）。
