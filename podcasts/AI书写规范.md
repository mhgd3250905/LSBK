## 一、硬边界（违反即返工）

1. **事实边界**：不虚构史实、对白、动机、私密场景与听众反应；冷开场、反常识主张、关键转折、数字、引语必须有出处。先锁证据再定故事——关键转折缺证就换主线，不靠润色把不确定写得更动人。
2. **纯双人声线**：全节目只有大开（主讲）× 小李（主持）两个音色；引语一律第三人称转述，**正文直接引号（`“”` `「」`）为 0**。
3. **Markdown 为源稿**：文稿、事实、时间轴以 Markdown 为唯一事实源；单集时长与各幕字数是估算值不是配额，禁止为凑数注水。
4. **不虚报**：不得声称文稿"已朗读 / 盲听 / 试听"除非真的做过；引用旧音频时须注明与当前文稿的差异。
5. **末幕收尾完整性（严禁戛然而止，仅限全集最后一幕，2026-10-14 用户重点纠偏）**：⚠️ **此检查仅且仅在全集最后一幕（通常为第四幕）结尾执行**！前置各幕（第一至三幕）必须保持事件与对话无缝流动，严禁任何形式的提前告别或阶段总结；**仅在最后一幕末尾**，严禁由单人大开陈述或悬念抛出后直接截断，必须严格遵循双人闭环收口结构：① 小李作为独立主持人的全期回扣与情感沉淀；② 大开的一句话深度历史注脚；③ 小李标志性电台收束告别语（“感谢大家收听本期的《笑谈历史》，我们下期接着聊。”）。在启动音频合成前必须人工核验最后一幕最后 3 个话轮，严防废音频重录浪费 API 资源。

## 二、核心叙事宪章：坚决消灭流水账，确立影视化听感（2026-10-14 用户最高指示，主导全节目制作）

> **流水账的致命死穴（零容忍）**：
> 1. **论文式对账**：跨年份罗列史料、比对数字和文献异同（如把篇幅浪费在考证四个版本分别死了多少人），把沉浸式播客变成了枯燥的学术文献综述；
> 2. **碎片化跳跃**：时间轴不断跳跃，缺乏贯穿全篇的情感支柱，段与段之间成了孤立的年份备忘录；
> 3. **听感散漫**：听众无法代入任何一个人的生死悲欢，只感到冰冷的信息轰炸与疲惫，听感极差。

### 创作铁律（二选一必须满足，严禁违背）
- **法则一（主选·大主角命运叙事）**：**必须有一个故事主角**，通过讲述他/她具体血肉丰满的生命经历、戏剧性遭遇与命运起伏，见微知著地折射出整个历史时代的剧烈变局。听众必须能够“穿上主角的鞋”，跟随他一同经历热血、委屈、窒息与壮烈（如 EP28 重构版戚金、EP30~32 李自成、EP33 史可法、EP34 郑成功、EP35 李定国、番外01 魏忠贤、番外02 朱由校、番外03 张溥、番外04 崇祯朱由检）。
- **法则二（备选·绝对话题中心推演）**：若无单一连续主角，**必须有一个极度聚焦的绝对话题中心**（如一项制度的自我吞噬、一支军队的体制死局、一场审判的司法死斗，如 EP36《1662群星谢幕》），通篇围绕一个核心矛盾层层递进推演，每一幕都是一次认知跃迁，严禁写成编年史流水账。

#### 2. 大主角的标准四幕命运叙事弧线

### 影视化听感的三大黄金支柱
1. **开场即高潮**：冷开场必须是影视级的至暗时刻或极具张力的悬念切口（如浑河岸边勒马死战、米脂烈日下的死囚大枷、登州荒舍砍人的现场笔录），开机即抓人，绝不从平铺直叙的背景交代开始；
2. **人性与戏在台前，考据留在幕后**：严谨的历史考据是地基，留在《史料核对.md》中；正文台词必须讲具体人情、权力逻辑、动作白描与心理博弈，绝不让文献考据喧宾夺主；
3. **因果咬合与终极情感回响**：幕与幕之间严密咬合，全篇拥有完整的情感起伏弧线，第四幕结尾必须具备深沉的历史沉淀与双人闭环收口。

## 三、去 AI 味负面清单（零容忍）

### 表层五禁

1. **句首呼唤**：小李台词首句绝对禁止"大开，"，改用"你说如果……""按常理说……""很多人可能都在琢磨……"等自然带入；
2. **惊悚煽情词**：头皮发麻、让人窒息、脊背发凉、细思极恐、绝了——让具体事实、动作和数字说话，不替听众预设生理反应；

- 历史礼制与称谓演义化戏说（对非皇帝人物出现“万岁”、“万万岁”、“九千九百岁”、“喊万岁”）为 0。

### 维度四：真实双人对谈感与反机械复读（2026-10-24 升级，2026-10-30 用户第17条升级）
1. 小李是具备独立认知的对话者与听众嘴替，带着真实常识发问，绝非机械捧哏；
2. **严禁复读上一轮要点**：小李绝不复读大开刚交代过的事实，大开绝不用“苦到了极点”、“惨到不行”等空洞形容词接茬；台词推进全部依靠动作、场景与权力逻辑，杜绝“形容词打乒乓球”；
3. **重点排查“无前件的旁白式跨越”（2026-10-28 用户纠偏沉淀）**：
   - 严禁一刀切误伤合法表述，但遇到诸如“这一等，就是整整……”、“这一看，就是……”、“这一走，就是……”、“这一坐，就是……”等跨度句式时，**必须列为重点排查词汇，人工核实其前因后果是否合理**；
   - **排查要点**：看前文是否有对应的主语和动作前件。如果前文根本没有人在“等/看/走”，大开只是在被动接小李的话，就绝对不能脱离对话情境自言自语冒出旁白，大开首句必须先正面回应小李的疑问或情绪，再由具体事实自然推移。
4. **严禁小李“全知剧透开天眼”，确立“听众直觉猜想与戏剧反转”（规范第17条）**：
   - 大开抛出危机悬念时，小李绝不未卜先知直接命中历史谜底，必须依常人直觉提出合理猜想，由大开否定猜想后反差揭晓真相；
   - 冷门奏折文句与正史卷帙定谳一律由大开引出，小李专注常理质疑与情感共鸣。
5. 历史人物话语一律第三人称口语转述。

### 维度五：自动化脚本执行
每幕写完必须运行自动化检查脚本：
```bash
python scripts/verify_act_script.py 幕文件.md [--is-last-act]
```
扫描输出必须全部为 0 违规，否则严禁进入时间脚本转换与音频合成！

## 七、生产流程顺序

1. **先锁证据，再定故事**：对冷开、反常识主张、关键转折、数字和引语做"主张—原始出处—不同解释—脚本位置"小表；
2. **先写全期发现路径，再写台词**：每段只问——听众眼前有什么事件？此处产生了什么疑问？下一条证据怎样改变原来的判断？分幕交付可保留，但不得切断全期弧线；
3. **Humanizer-zh 只做末端局部清理**：适合清空话、重复、机械转场；保留有效的口头重复与两位主播各自的说话方式，不捏造亲历或听众反馈；
4. **质检从自评改成找错**：作者之外做一次证据复核，盲听开头/中段/结尾，记录"哪里想继续听、哪里听不懂、哪里像在背稿"；
5. **合成与元数据底线**：各幕合并前剥离内嵌 ID3、`ffmpeg -v error` 解码零错误、SRT 条数=四幕总话轮数、shownotes 时间轴基于最终 SRT 实测回写（详见《发布SOP与台账.md》踩坑档案）。
