# 大纲：王阳明的"知行合一"，根本不是"知道了就要去做"（EP01）

> 时长目标：60 分钟 | 题型：概念工具型×人物叙事 | 模板：5（概念工具型）为主体，人物线穿插
> 阵容：周老师（主讲）+ 阿灿（主持） | 结构：三概念递进（心即理→知行合一→致良知）+ 生平关键场景作"悟道现场"

## 全期时间轴

### [00:00-00:55] 冷开场（论点预告式·双金句）
- 金句①（周）："道理我都懂，就是做不到——这句话要是让王阳明听见，他会告诉你：你若做不到，就是不懂。"
- 金句②（灿）："你未看此花时，此花与汝心同归于寂——被当成唯心主义笑话批了一百年的话，可能是中国哲学史上被误读最深的一句。"

### [00:55-02:30] 报幕 + 选题缘由
- 缘由：书店畅销架与短视频的心学热观察（"知行合一王阳明""心学教你内心强大"）——"概念人人会念，意思没人说对"
- 寒暄：阿灿自曝买了心学畅销书没读完（人设即论据，为第一幕跑偏埋线）

### 第一幕：病与病人【02:30-15:00】（12.5分钟）
> 主线：现代人的"道理瘫痪" + 王阳明是谁（爽剧人生速览）
- 内容要点：
  1. 病：信息过载时代的"道理瘫痪"——收藏的干货、办的健身卡、明知熬夜伤身还熬（阿灿病例展示）
  2. 人：王阳明速览——状元之子（起点）→ 青年格竹失败（方法破产）→ 上疏救人被廷杖四十下狱（理想主义碰壁）→ 贬龙场、途中遭追杀伪装投江（跌到谷底）→ 龙场悟道（绝境翻转）→ 书生带兵 35 天平宁王（巅峰）→ 临终"此心光明"（收束）
  3. 龙场场景化：石棺自问"圣人处此，更有何道？"——顿悟那晚发生了什么
- 反差点：临终遗言天花板——"此心光明，亦复何言"对比现代人临终大概率的"还有好多事没干"
- 悬念/路牌：他到底悟出了什么？——三个概念逐一拆（路牌预告）
- **合法跑偏①**（约[06:00]处，3分钟内）：阿灿聊自己的道理瘫痪（收藏夹上千篇、健身卡去了三次、一点半还在刷手机"就看最后一个"）→ 周接住升维："你这个状态，五百年前有个专门的诊断……"
- 梗锚点：鸡汤书封面吐槽（"内心强大"型封面）；龙场=明代地图边缘的"有去无回"驿站；廷杖四十的具象化（打完趴着写诗）
- 金句：①"王阳明的人生，比爽剧离谱，因为它是真的。"②"圣人处此，更有何道——把问题从'世界为什么这样对我'换成了'如果是圣人，接下来怎么办'。"
- 主持功能：个人叙事（道理瘫痪自曝）/复述确认/代听众发问（"所以龙场悟道到底悟了个啥？"）

### 第二幕：心即理——从格竹破产说起【15:00-28:00】（13分钟）
> 主线：概念①"心即理"，对照程朱理学
- 内容要点：
  1. 朱熹方案：即物穷理——理在事物之中，今日格一物、明日格一物，积累贯通（《大学章句》格物补传）
  2. 实践破产：青年阳明与友人格竹（友三日病、己七日病，《传习录》自述）——"实验失败"叙事
  3. 龙场翻转："圣人之道，吾性自足，向之求理于事物者误也"——方向调转
  4. 岩中花树正读：原文完整引用 → "寂"不是"不存在"而是"无意义状态"——他谈的是**意义世界**不是物理世界
- **降维三步法①**："心即理"——朱熹原文 → 吐槽（格竹格出病，"这实验搁今天科研伦理都过不了"）→ 比喻（朋友圈没发的照片存在吗？物理上存在，意义上对别人"归于寂"；竹子在深山自长，格不格它都在，但"竹子之理"只对格它的人存在）→ 回扣
- 对照组：朱熹 vs 阳明（外求/内求；积累式/当下式——"两套操作系统"）
- 数据/细节锚点：廷杖四十后的贬谪路线（北京→贵州龙场，明代地图边缘）；"理"字在朱熹体系里的分量
- 梗锚点：格竹=科研民工崩溃现场；"意义世界"的现代翻译
- 金句：①"竹子自会长，但'竹子之理'只对看它的人存在。"②"朱熹让你带着笔记本出门找真理，阳明说罗盘在你兜里揣着呢。"
- 主持功能：代听众发问（"这不就是唯心主义吗？花不看就不存在？"——替中学政治课发问）/复述确认/争议逼问

### 第三幕：知行合一——被鸡汤化的最强概念【28:00-42:00】（14分钟）
> 主线：概念②"知行合一"（用户诉求的核心），全期最长最重
- 内容要点：
  1. 鸡汤版批判："知道了就要做到""执行力""知行合一教你成功"——全部读反了
  2. 原文正读："知是行之始，行是知之成"；"知而不行，只是未知"
  3. 好好色恶恶臭论证：《传习录》释《大学》——"见好色属知，好好色属行，只见那好色时已自好了……不是见了后又立个心去好"——真知是即时的、无"决定"环节的
  4. 反证：熬夜案例——"明知熬夜伤身还天天熬"说明"熬夜伤身"对你只是信息不是知；收藏夹的一百篇干货 vs 真正改变行为的那一篇
  5. **真知测试**（尺子交付）：身体有没有即时反应？
- **降维三步法②**："知行合一"——原文 → 吐槽（听起来像正确的废话）→ 比喻（看到美食流口水不需要"执行"环节；闻到臭味皱眉不需要决策——而知行分裂就是"闻到臭味、讨论完臭味的化学成分、然后决定继续闻"）→ 回扣
- **合法跑偏②**（约[36:00]处）：阿灿"第一反应 vs 想了一夜"的生活共鸣（有没有过第一反应是对的、想了一夜被自己说服改错了）→ 周接住：这其实通向下一个概念（转场式跑偏）
- 对照组：信息 vs 知；"听懂了" vs "做到了"
- 梗锚点：鸡汤书再吐槽（回收第二幕的书封面梗，金句环形）；"道理瘫痪"回扣第一幕的病
- 金句：①"你若做不到，就是不懂——这不是骂人，是诊断。"②"收藏夹里的一百篇干货是信息，真正改变了你行为的那一篇，才叫知。"
- 主持功能：复述确认（核心，多次）/个人叙事/金句接梗/代听众发问

### 第四幕：致良知与事上磨练——功夫在哪【42:00-53:00】（11分钟）
> 主线：概念③"致良知" + 方法论收束 + 生平收束
- 内容要点：
  1. 良知是什么：孟子"乍见孺子将入于井，皆有怵惕恻隐之心"——来不及算计的 0.1 秒反应就是良知；人人预装
  2. "致"才是功夫：感应器出厂自带，难在校准与执行——私欲是流氓插件，屏蔽了预装系统
  3. 事上磨练："人须在事上磨，方立得住，方能静亦定，动亦定"——不是打坐想出来的，是剿匪、平叛、断案里干出来的（平宁王 35 天作证据）
  4. 临终收束："此心光明，亦复何言"——一生的答案
  5. 现代回响轻带（一句带过不展开）：心学东传日本，明治志士人手一册《传习录》（挖坑）
- **降维三步法③**："致良知"——四句教选句/孟子原文 → 吐槽（听起来玄乎像气功）→ 比喻（预装杀毒软件，功夫是别让流氓插件屏蔽它；游泳看一百个教程不如下水一次）→ 回扣
- 对照组：事上磨练 vs 打坐悟道；阳明格竹 vs 龙场悟道（回收第二幕，环形）
- 情怀/峰值点：此心光明段的收梗处理——朴素句，不加梗
- 梗锚点：书生带兵"文科生空降指挥千军万马"；游泳教程梗
- 金句：①"良知不用学，学的是别挡着它。"②"功夫不在悟的那一晚，在悟后的每一天。"
- 主持功能：争议逼问（"照这么说，是非对错我自己说了算？那还得了？"——引出边界：良知不是任性，是经过事上磨练校准的）／复述确认

### [53:00-60:00] 收束 + 结尾菜单（7分钟）
