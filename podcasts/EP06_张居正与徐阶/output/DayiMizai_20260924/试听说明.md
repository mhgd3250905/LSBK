# EP06 豆包默认推荐配对试听

本版沿用项目当前四幕文稿，改用豆包播客 API 文档中的默认推荐配对：大开 → `zh_male_dayixiansheng_v2_saturn_bigtts`（大壹先生），小李 → `zh_female_mizaitongxue_v2_saturn_bigtts`（咪仔）。目标是让偶发回退到默认男声时更接近大开；API 文档并未保证所有异常都只会回退到这两种音色。

流水线原先按音色 ID 字母排序 `speaker_info.speakers`，会把女声排在男声之前。本次调整为按角色映射顺序发送，先 Dayi、再 Mizai；每句 `nlp_texts` 仍明确指定说话人，`random_order` 保持关闭。

成品：

- `EP06_豆包默认配对版.mp3`：34 分 16.56 秒，四幕合成后剥离了各幕内嵌 ID3 标签，ffmpeg 解码检查通过。
- `EP06_豆包默认配对版.srt`：131 条字幕，按剥离标签后的各幕实测时长偏移。
- `疑似回退女声试听_12m38s.mp3`：含小李“那高拱听进去了吗？”一轮及其前后对话，供检查女声是否出现低音色偏移。
- `EP06_豆包默认配对版_音色体检.json`：完整逐句基频体检报告。

体检报告找到 5 句基频偏离角色全局中位的候选段：小李 12:38（148.3 Hz）；大开 20:41（235.3 Hz）、25:13（246.2 Hz）、33:50（280.7 Hz）；小李 34:01（421.1 Hz）。部分偏离可能来自短句、语气上扬或分段边界；仅凭基频不能判定实际音色，需人耳复核。报告中的大量“段内双声部”标记多为谐波误报，不等同于额外说话人。

本版尚待试听，不覆盖原成品，也未发布。
