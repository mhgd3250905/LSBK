# EP06 第三、四幕史料笔记

脚本台词保持口语，出处集中在这里。下表的“可说”说明证据能支持的范围；两位主播的立场分歧是节目讨论，不代表史料记有他们的判断。

|---|---|---|
| 考成法 | 张居正《请稽查章奏随事考成以修实政疏》指出章奏获批、发出后缺少执行追踪，提出按路途和缓急定程期、设簿、月注销、上下层级稽查。所附皇帝批复允许某些积年难办之事说明后开除。它是整顿和强化既有稽查办法，不宜说张发明全部文簿制度；也不宜虚构现代式指标和即时惩罚数字。 | [张居正奏疏](https://zh.wikisource.org/zh-hans/請稽查章奏隨事考成以修實政疏)；[《明史》卷20](https://zh.wikisource.org/zh-hans/明史/卷20)万历元年十一月；[《明史》卷213](https://zh.wikisource.org/zh-hans/明史/卷213)张居正传 |

| 书院 | 张居正万历三年奏疏有不许提学官另创书院之规定，缘由在其所述官学职掌、士人结党与请托。学术研究区分1575年学政整顿与1579年禁毁书院。书院活动并非全部一夜消失；不能把张的内心动机写成单一确定答案。 | [张居正《请申旧章饬学政以振兴人才疏》](https://zh.wikisource.org/zh-hans/請申舊章飭學政以振興人才疏)；[《明代提学官的书院建设与张居正的学政改革》](https://www.gdwsw.gov.cn/wsbl/content/post_37693.html) |
| 万历与张居正 | 《明史》记万历年幼时慈圣太后以张先生的督促规劝，皇帝敬畏；年长后厌其约束，也记张编古代治乱故事、配图俗语教授皇帝。可讲师生关系变化，不能编皇帝私下心理与夜谈。 | [《明史》卷213](https://zh.wikisource.org/zh-hans/明史/卷213)张居正传 |
| 身后清算 | 万历十年六月张居正卒，十一年三月追夺官阶，十二年四月籍家；《明史》张传记搜家前闭门、开门后十余人饿死、长子敬修自缢，也记官员为其家求缓。徐阶万历十一年去世，未见万历十二年籍家。不要写徐阶亲闻清算、张死后数月即抄家。 | [《明史》卷20](https://zh.wikisource.org/zh-hans/明史/卷20)万历十至十二年；[卷213](https://zh.wikisource.org/zh-hans/明史/卷213)徐阶、张居正两传 |

## 写作时保留的解释边界

- “张居正护徐阶”依据张曾劝高拱缓追徐家、高拱去后徐家事解；“逐高主要是救徐阶”缺直接证据，不能定为动机。
- “压制异见削弱纠错”是根据多起处罚与学政措施作的节目判断；不能宣称它单独导致万历帝后来清算。
- 《明史》为后出史书，能够提供事件记载，也含清代史官评价。节目引其评论时应说明是史书的判断，尤其是“夺情后益偏恣”。
