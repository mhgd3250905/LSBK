## 严守之边界与禁区
1. **纯双人转述**：全文只有大开与小李两人说话；历史人物台词一律用第三人称转述（“高拱跟同僚说……”），严禁双引号直接引语，防范豆包 API 自主触发戏剧化第三音色。
2. **拒绝动机全知**：张居正联合冯保究竟出于权欲还是理念自保，史学界尚有分歧，稿中摆出双方行为与证据事实，不妄断个人灵魂黑化。
3. **禁止剧本腔与虚构互动**：绝不出现“这一幕、伏笔、彩蛋、环节、大纲、四幕”等字眼；不捏造未发生的听众留言或社群讨论。
4. **数字严谨**：俺答封贡、边贸口岸数量按正史（如十一处互市），不随意夸大或含糊其辞。
