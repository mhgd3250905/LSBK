|---|---|---|
| **朱元璋海禁与大明宝钞贬值** | 《明太祖实录》洪武四年十二月“禁濒海军民不得私出海”；《明史·食货志五》载宝钞法废弛，万历间民间全不用钞；彭信威《中国货币史》 | 讲清朱元璋出于防范张士诚余部与理想化农耕自足而厉行海禁。交代宝钞因为缺乏准备金与无限超发迅速贬值为废纸，导致国内长期陷入通货紧缩和“钱荒”，民间被迫倒退到以物易物或偷偷用碎银。 |
| **嘉靖朝倭患本质为武装走私** | 《明史·日本传》：“大抵真倭十之三，从倭者十之七”；郑若曾《筹海图编》；采九德《倭变事略》；徽商王直自称“徽王”，求开市未果被诱杀 | 还原所谓“倭乱”背后的经济驱动力。沿海百姓“市通则寇转为商，市禁则商转为寇”。大开与小李借此打破非黑即白的叙事，指出厉行海禁反而是制造倭乱的制度根源。 |
| **隆庆开关的时间、地点与奏准过程** | 《明穆宗实录》卷四隆庆元年二月：福建巡抚涂泽民请开市舡；万历《漳州府志》卷五《兵防志》；张燮《东西洋考》卷七《饷税考》 | 准确指出隆庆开关并非全国全面开放，而是在福建漳州海澄县（今龙海区）的“月港”准许民间商船出海贸易，发放“引票”，实行配额和收税制。虽是局部开口，却成为连接全球的咽喉要道。 |
| **美洲波托西银矿与日本石见银山** | 贡德·弗兰克《白银资本》；全汉昇《美洲白银与明清中国国际贸易》、《明代中叶后白银的输出入》；布罗代尔《15至18世纪的物质文明、经济和资本主义》；德·弗里斯《白银的力量》 | 交代世界白银开采的技术背景（水银混汞法/灰吹法）。明确指出美洲银矿与日本银山在16世纪后半叶产银暴增，而大明凭借生丝、丝绸、瓷器、茶叶的绝对贸易顺差，成为全球白银的终极归宿（吸入量占世界流通量三分之一至二分之一）。 |
| **马尼拉大帆船（Manila Galleon）航线** | 舒尔茨（William L. Schurz）《马尼拉大帆船》；林仁川《明末清初私人海上贸易》 | 厘清贸易链路：西班牙大帆船满载美洲白银自阿卡普尔科（墨西哥）横渡太平洋抵达马尼拉；中国月港海商满载丝茶等货物抵达马尼拉与西班牙人交易白银运回漳州。 |
| **张居正一条鞭法与税收折银** | 《明史·食货志一》；张居正《张太岳集·答福建巡抚谈海禁》；黄仁宇《十六世纪明代中国之财政与税收》 | 讲明张居正推行一条鞭法的客观基础，正是隆庆开关后大量白银流入东南，为货币化提供了可能。指出改革简化了征税、充实了国库，但把赋税硬性折银推向全国（包括不产银、不通商的北方内地），为后来的系统性风险埋下了地雷。 |
| **17世纪前期全球银根紧缩与输入型通缩** | 万志英（Richard von Glahn）《财富之泉：中国的货币与货币政策》；岸本美绪《明清交替与江南社会》；全汉昇《明季白银流出与明代灭亡》；艾伦《明清经济史研究》 | 审慎呈现学术界关于“明亡与白银危机”的前沿讨论：美洲富矿脉枯竭、西班牙腓力四世贸易管制、日本宽永锁国限银，确实导致了1630-1640年代流入中国的白银急剧减少。文稿需讲明：白银危机不是明亡的唯一原因，而是与天灾、兵祸叠加的最致命催化剂。 |
| **“银贵钱贱”逼死北方农民与朝廷财政瘫痪** | 顾炎武《日知录》卷十一“钱法”；崇祯朝户部档案与《崇祯实录》；毕自严《度支奏议》；文秉《烈皇小识》 | 解释“银贵钱贱”机制：白银稀缺导致银价暴涨，铜钱暴跌。农民卖粮换银交税，粮价被压到极低，一石米换不来几分银子，实质赋税暴增数倍。崇祯无法向江南豪绅收税，北方自耕农破产成为李自成主力；前线军饷只认白银，发不出银子导致兵变溃败。 |

## 创作纪律与禁区
1. **纯双人转述**：全篇仅大开与小李两个人发声；历史人物的话全部转为第三人称间接引述，**绝对不使用直接引号**，杜绝豆包 API 自主触发第三方声线。
2. **拒绝剧本腔**：严禁出现“第X幕/这一幕/下一幕/彩蛋/伏笔/板块/环节/回收/大纲/脚本”等词汇。转场全靠内容自身的因果关系推动。
3. **分清事实与推断**：
   - 确凿史实：月港开放、马尼拉航线、波托西与石见银山、一条鞭法折银、崇祯朝银贵钱贱。
   - 经济学解释：输入型通货紧缩、货币主权外包的现代金融对照，必须以“从现代经济学的角度看”、“很多经济史学家分析”等口吻清晰界定，不可让古人穿越说现代金融学术黑话。
