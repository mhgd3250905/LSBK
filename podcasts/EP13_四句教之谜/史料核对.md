| **四句教原文与钱德洪王畿争辩焦点** | 《传习录》卷下第315条（钱德洪记录）、《王龙溪先生全集》卷一《天泉证道纪》；黄宗羲《明儒学案》卷十、卷十一 | 准确引用三十二字四句教：无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物。精准界定两派分野：钱德洪持“四有”，主张从意念、良知、事物处扎实为善去恶（渐修）；王畿持“四无”，认为若心体无善恶，则意、知、物皆无善恶，本体顿悟超脱善恶分别（顿悟）。不将二人争执庸俗化为人身攻击，而是严肃的义理探讨。 |
| **王阳明深夜登楼裁决与“教法二门”** | 《传习录》卷下第315条；《王阳明全集·语录三》；陈荣捷《王阳明传习录详注集评》 | 还原王阳明对两徒观点的裁定：称二人“互有发明，不可偏废”。明确指出“四无”接引上根利智之人，“四有”接引中下根人。重点交代王阳明的核心告诫：若以四无妄授中人，必使人流于“狂禅”，虚无放浪、荡检逾闲，反成大害；但若固执四有，又易使人拘泥胶滞。二人须互取所长，本体与工夫合一。 |
| **王阳明南行病逝与心学无最高裁判** | 《王阳明全集·年谱三》嘉靖七年戊子十一月二十九日；《明史·王守仁传》；门人周积记录 | 交代嘉靖七年十一月王阳明平定两广叛乱后病笃返乡，在江西南安青龙铺舟中病逝。门人周积问有何遗言，阳明答复“此心光明，亦复何言”，瞑目而逝。自此心学失去定海神针，两派门人失去最高仲裁，分化迅速表面化。 |
| **江右王门与徐阶的稳健治国实践** | 黄宗羲《明儒学案·江右王门学案》；《明史·徐阶传》卷213；沈德符《万历野获编》 | 讲明钱德洪、邹守益、聂豹（徐阶之师）一系继承了注重“戒慎恐惧、实地做工”的端正学风。徐阶早年师从聂豹，在嘉靖隆庆年间以极强的心学定力与隐忍功夫扳倒严嵩、辅政大明，体现了心学在政治实践中的经世致用价值。 |
| **泰州学派兴起与“百姓日用即道”** | 黄宗羲《明儒学案·泰州学案》；王艮《心斋先生全集》；嵇文甫《晚明思想史论》 | 客观呈现王艮创立泰州学派的平民思想解放意义。王艮出身泰州灶丁（盐民），提出“百姓日用即道”，主张挑水、劈柴、经商、农耕皆含大道，农夫樵夫陶工皆可成圣。这打破了士大夫对道德真理的垄断，是中国历史上罕见的平民启蒙运动。 |
| **心学末流狂禅与李贽的社会冲击** | 李贽《焚书》《藏书》；沈德符《万历野获编·李贽》；《明史·李贽传》；容肇祖《李贽年谱》 | 呈现晚明心学末流走向极端的客观史实：部分士人将心学解构为“任情放荡、目无三纲”。李贽作为晚明狂士巅峰，倡导“童心说”，挑战孔孟教条，主张“穿衣吃饭即是人伦物理”，最终以“敢倡乱道、惑世诬民”被逮下狱，自刎死于狱中。既展现其思想锐度，也客观点明其对当时社会伦理秩序的颠覆性冲击。 |
| **东林学人反思与清初顾炎武的痛斥** | 顾宪成《小心斋札记》；高攀龙《高子遗书》；顾炎武《日知录》卷七《夫子之言性与天道》；钱穆《国学概论》 | 讲清明末文人对心学末流的深刻反弹：东林书院顾宪成高攀龙倡导重回规矩实学，痛斥狂禅空谈；明亡后，清初大儒顾炎武总结亡国教训，在《日知录》中写下名言：“以明心见性之空言，代修己治人之实学。神州荡覆，宗庙丘墟……平日袖手谈心性，临危一死报君王，即此之谓也！” |

1. **纯双人转述**：全篇只有大开与小李两位说话人；历史人物话语一律第三人称间接叙述，**正文严禁使用双引号（`“”`）或角标引号（`「」`）**，彻底避免触发豆包 API 第三方声线。
2. **拒绝剧本腔**：严禁出现“第X幕/这一幕/下一幕/彩蛋/伏笔/板块/环节/回收/大纲/脚本”等词汇。
3. **拒绝概念空转**：哲学探讨必须紧密咬合历史人物的具体命运（钱德洪、王畿、王阳明、王艮、李贽、顾炎武）与现代人的生活心理困境，绝不陷入咬文嚼字的学究式掉书袋。
