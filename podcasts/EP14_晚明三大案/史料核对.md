| **朱常洛登基纵欲与病倒** | 《明史·光宗本纪》卷21；《明史·方从哲传》卷218；《明季北略》卷一；文秉《定陵注略》 | 真实记录泰昌元年（1620年）八月初一朱常洛即位，免矿税、发内帑犒劳辽东将士，士林一度欢欣。但郑贵妃进献八名美女，朱常洛本就体弱多病，登基数日即重病卧床。客观陈述事实，不作低俗戏谑渲染。 |

| **红丸案政治大撕裂与孙慎行弹劾** | 《明史·孙慎行传》卷243；《明史·方从哲传》；孟森《明史讲义·泰昌天启之争》 | 讲清红丸案对文官集团的撕裂效应：东林党礼部尚书孙慎行上疏直指首辅方从哲弑君，要求严惩方从哲与李可灼；而齐楚浙党官员力保方从哲，辩称李可灼系医官误投。两派借皇帝死因进行生死搏杀，彻底关死了妥协大门。 |
| **移宫案当场交锋与杨涟抢皇帝** | 《明史·熹宗本纪》卷22；《明史·杨涟传》卷244；《明史·左光斗传》；文秉《先拨志始》卷中 | 还原九月初一泰昌驾崩当天，朱常洛宠妃李选侍（西李）居乾清宫不肯搬离，并将皇长子朱由校扣在后宫企图垂帘听政。东林党人杨涟、左光斗、刘一燝等群臣直闯乾清宫，强行从内侍宫女手中迎出朱由校，拥至文华殿登基，随后严令李选侍迁往仁寿殿。 |
| **移宫案后遗症与魏忠贤全面翻案** | 《明史·魏忠贤传》卷305；《明史·杨涟传》；谈迁《国榷》；计六奇《明季北略》 | 交代移宫案的权力伏笔：李选侍亲信太监魏忠贤与朱由校乳母客氏怀恨在心。天启中后期魏忠贤得势后，伙同阉党文官编写《三朝要典》，全面推翻三大案旧案，将杨涟等东林党人定性为逼宫谋逆，作为天启五年诏狱血洗东林六君子的核心借口。 |

## 创作纪律与禁区
1. **纯双人转述**：全篇只有大开与小李两位说话人；历史人物话语一律第三人称间接叙述，**正文严禁使用双引号（`“”`）或角标引号（`「」`）**，彻底避免触发豆包 API 第三方声线。
2. **拒绝剧本腔**：严禁出现“第X幕/这一幕/下一幕/彩蛋/伏笔/板块/环节/回收/大纲/脚本”等词汇。
3. **拒绝脸谱化阴谋论**：三大案中充斥着真实的误会、巧合、恐慌与草台班子操作，深入制度瘫痪与互疑机制，不将其简化为单方面的宫斗下毒爽文。
