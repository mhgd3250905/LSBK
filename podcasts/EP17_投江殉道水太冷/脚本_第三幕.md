# EP17 脚本·第三幕｜水缸练憋气与换双靴子再来死

**小李**（15:00）：
刚才听完钱谦益嫌水冷、龚鼎孳怪小妾，我已经觉得人类的借口库被他们开发到了极致。大开，还有比这二位更离谱的名士吗？

**大开**（15:15）：
当然有！钱谦益和龚鼎孳好歹还是在事后找补，但接下来要登场的这两位复社顶流名士，那可是在殉国进行时，公然把自杀现场搞成了一场让人哭笑不得的行为艺术展！第一位叫周钟，也是崇祯朝的进士、江南复社的核心骨干。

**小李**（15:40）：
这位周大才子又有什么惊天动地的表演？

**大开**（15:45）：
周钟平日里自命清高，在文人聚会上一杯酒下肚，就拍着胸脯痛陈时局，发誓说只要国家有难，自己必当以死报国，绝不苟且偷生。崇祯十七年三月十九日，李自成的大军攻陷北京，崇祯皇帝自缢殉国。消息传开，周钟平时的几位好友同僚抱头痛哭，心想以周兄那刚烈不屈的脾气，现在肯定已经在家里悬梁自尽了！

**小李**（16:21）：
朋友们这是赶紧跑去他家里给他收尸营葬吧？

**大开**（16:26）：
明季北略和甲申殉难纪略里记载得清清楚楚。几个朋友抹着眼泪推开周钟家的院门，一进院子，所有人都当场愣住了。只见院子正中间摆着一口盛满水的大水缸，周钟挽着袖子、撅着屁股趴在缸沿上，把整个脑袋死死扎进水缸里，憋了一阵气，憋不住了猛地拔出脑袋大口喘气，抹一把脸上的水珠，然后再扎进去继续憋！

**小李**（17:02）：
趴在水缸里反复把脑袋浸水里？他这是在练杂技还是在练自由潜水啊？！

**大开**（17:10）：
几个朋友惊得眼珠子都快掉下来了，赶紧冲上去扶住他大喊，周兄，你这是在干什么啊？！周钟擦了擦满脸的凉水，满脸严肃、一本正经地回答说，我正想投水自尽，先在这水缸里试试看，看这水淹窒息的滋味我到底受不受得了！

**小李**（17:36）：
我的妈呀，自杀科目一模拟考试？！他还真在水缸里做起了模拟测试！那他最后测试及格了吗？

**大开**（17:46）：
测试结果是极其不及格！周钟试了几次之后得出结论，这水淹进肺里的感觉实在太难受了，根本不是人受的罪，所以这节还是别殉了！就在第二天清晨，一份辞藻极其华丽、极尽谄媚阿谀的贺表，就工工整整送到了大顺军大顺皇帝李自成的案头，这就是文学史上臭名昭著的从贼疏！

**小李**（18:19）：
前一天还在水缸里试憋气，后一天就成了李自成的大顺忠臣！这应变速度真是让人叹为观止。

**大开**（18:29）：
别急，还有另一位更讲究仪式感的，叫陈名夏。陈名夏是晚明天崇年间的复社领袖，南明弘光朝任吏部侍郎，在江南士林名望极高。清军打过长江逼近南京的时候，陈名夏也觉得自己作为天下名士，必须得有所表示。于是他带着一帮门生和仆从，浩浩荡荡跑到长江边上，迎着江风放声大哭，作势就要往江水里跳！

**小李**（19:02）：
这回总算是真跳江了吧？

**大开**（19:05）：
家丁仆人赶紧上前拼命拽住他的衣服，哭着劝他不要想不开。陈名夏一边用力挣扎，一边高喊不要拦我，让我为大明死节！结果家丁看他挣扎得这么厉害，手突然一滑松开了。陈名夏往前冲了一步，一脚深深踩进了江滩的烂泥塘里。

**小李**（19:30）：
然后整个人顺势扑进江里了？

**大开**（19:33）：
明季南略记载，陈名夏低头一看，只见自己脚上那双崭新的官靴沾满了黑泥。他整个人瞬间僵住了，默默收回了脚步，满脸严肃地转头对仆人说，靴子脏了，容我回府换双干净靴子，再来赴死！

**小李**（19:57）：
靴子脏了，容我换双靴子再来死？！这是什么处女座强迫症的顶级借口啊！

**大开**（20:06）：
结果陈名夏回府之后，换下了脏靴子，顺便让仆人把自己的头发给剃了，换上一身新行头，欢天喜地出门迎接清军去了！后来陈名夏在清朝甚至当上了大学士和吏部尚书。

**小李**（20:25）：
水缸练憋气、沾泥换官靴、水太冷、小妾不肯……大开，你把这几个人放在一起看，他们到底图什么啊？他们要是真怕死，直接投降不就完了吗，为什么非要在死之前搞这么一出出让人笑掉大牙的滑稽戏？

**大开**（20:47）：
这就是晚明士大夫最可怕的剧场型人格！他们骨子里既想要贪图崇高的忠烈名声，又绝对舍不得放弃自己的荣华富贵和身家性命。所以他们必须在天下人面前表演出一副我极力想去死、但我因为一些客观不可抗力没死成的假象！晚明文官制度最大的漏洞，就是把道德变成了一种毫无违约成本的政治表演。只要你口号喊得响，你就能名利双收；真到了大难临头，换一身衣服，他们依然能接着当官！
