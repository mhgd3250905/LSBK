# EP18 Shownotes｜《孔子的加密代码：春秋公羊学与两千年的改制狂人》

“如果有人告诉你，在以温良恭俭让著称的儒家内部，其实藏着一本两千年前的‘官方造反说明书’，只要翻开它，就能合法国战复仇、合法激进变法、甚至合法改朝换代，你敢信吗？”

在大众的刻板印象里，儒家向来是循规蹈矩、劝人听话的守旧代名词。然而在中国思想史的隐秘地壳深处，却潜伏着一套极度危险、杀气腾腾的“官方黑客操作系统”——**春秋公羊学派**！

他们坚信圣人孔子在《春秋》里玩了一整套“微言大义”的密电码。两千年来，每当中国陷入生死绝境，这帮绝顶聪明的大脑就会从地底下拔出这把宝剑，掀翻整个旧世界的棋盘：

• **“九世之仇，虽百世可也！”：颠覆儒家文弱刻板印象的战狼之祖**
汉武帝十六岁登基，面对北方匈奴数十年的耻辱和亲与满朝老臣的因循守旧，董仲舒带着《公羊春秋》进京对策！董仲舒掏出公羊判例：齐襄公隔了九代灭纪国报仇，孔子大加赞赏！九世之仇犹可报乎？虽百世可也！公羊学者直接给大汉帝国远征匈奴提供了最暴烈的法理武器！

• **东汉何休的“张三世”：两千年前中国本土的社会进化论**
你以为古人总觉得“一代不如一代”？东汉公羊大师何休在《解诂》中破天荒提出了“张三世”社会进化论：据乱世（丛林法则）→ 升平世（小康秩序）→ 太平世（远近大小若一，天下大同）！还有让历代帝王冷汗直流的“通三统”：天命流转，没有万世不灭之朝！为什么历代皇帝后来要把公羊学悄悄雪藏两千年？

• **常州学派惊天还魂：龚自珍发疯与魏源开眼**
乾嘉考据学万马齐喑的死水里，常州刘逢禄重新刨出了公羊学。狂生龚自珍拿公羊学直接痛骂大清是“一只脚踏进棺材的衰世”，写下“我劝天公重抖擞，不拘一格降人材”；同门师弟魏源以“制度因时而变”写出《海国图志》，首倡“师夷长技以制夷”！

• **终极大魔王康有为的魔幻狂飙：把孔子包装成“变法教皇”**
晚清大变局下，康有为连续扔出两颗思想氢弹：《新学伪经考》宣称两千年来全天下读的正统儒家经典全是刘歆伪造的；《孔子改制考》声称孔子其实是带头革命的改革教皇，吹尧舜禹完全是“托古改制”卖私货！带着这套理论，康有为忽悠光绪帝引爆了戊戌变法！

1. **警惕表象的教条主义**：看起来最保守、最不可撼动的神圣权威，内部往往包含着颠覆它自身的最激进种子；
2. **制度变革的动力学**：历史从来不是机械复古，而是必须根据时代演进（张三世）；任何妄图“万世不移”的体制最终都会迎来公羊学的无情审判；
