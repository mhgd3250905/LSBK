# 选题卡：EP22《张璁：七次落榜，47岁中进士，六年干到内阁首辅》

> 2026-10-07 正式立项。事实依据与原文出处见同目录 `史料核对.md`。

## 基本信息
- **选题缘由**：《笑谈历史》大明权谋线核心人物篇。EP08《嘉靖大礼议》讲了大礼议的冲突，EP07 讲了高拱，EP05/06 讲了徐阶与张居正。但很多人不知道，嘉靖朝第一位权臣、明代打破内阁百年成规的火箭升迁奇迹、以及后来张居正能够权倾天下的内阁首辅专权体制，源头全在一个叫张璁的人身上。张璁47岁才考中进士，实习期一封奏疏对抗整个内阁文官集团，短短六年直登相位。这是一个极具张力的小人物绝地博弈与职场登顶样本。
- **题型**：人物深度传记型 / 政治博弈型
- **系列归属**：《笑谈历史》大明权谋线·特别人物篇（嘉靖大礼议前传与首辅体制源头）
- **时间跨度**：成化十一年（1475）出生 → 正德十六年（1521）47岁登第、上大礼议疏 → 嘉靖三年（1524）左顺门之变 → 嘉靖六年（1527）入阁拜相 → 嘉靖十八年（1539）病逝

## 核心认知反差（生死线）
- **你以为的**：
  1. 明朝能当上内阁首辅的，都是二十多岁少年得志、从翰林院修撰一步一步熬资历熬出来的清流精英；
  2. 嘉靖大礼议只是文官和年轻皇帝意气用事的礼仪争执，跟普通官员没什么关系；
  3. 张璁靠钻营迎合皇帝上位，必定是个祸国殃民的大奸相。
- **实际上的**：
  1. 张璁七次会试落第，直到47岁白发苍苍才考中三甲进士，入职还是部观政（实习期公务员）；
  2. 当满朝文官数百人全部听从首辅杨廷和、逼十五岁的嘉靖认伯父为爹的时候，实习生张璁敏锐抓住礼制法理，一封奏疏直戳文官集团痛处，嘉靖在深宫痛哭拍案直呼我的父子亲情终于保住了；
  3. 杨廷和表面升官、暗中发配，张璁在南京集结同盟；三年后左顺门大流血，张璁杀回北京，打破明代非翰林不入阁的百年铁律，六年登顶首辅；
  4. 掌权后他刚明峻洁、一心奉公，整顿吏治、清丈庄田、打压六部尚书，把权力收归内阁首辅，成了张居正改革的制度源头；但他性格孤傲狠厉，得罪了整个文官集团，举朝嫉之如仇，一生在伴君如伴虎的帝王心术中三起三落。
- **反差的强度自评**：⭐⭐⭐⭐⭐（五星满格：47岁老考生逆袭+六年拜相神话+孤臣改革悲歌）

## 核心问题（这期节目回答的一句话问题）
一个47岁才上岸、七次落榜的老考生，凭什么六年干到大明内阁首辅？当他把站队这门手艺做到极致，背后的代价到底有多大？

## 三大基因自检
- [x] **小切口**：正德十六年（1521）七月，工部观政实习生张璁写下《大礼或问》，紫禁城深宫里的十五岁少年皇帝抱疏痛哭，内阁首辅杨廷和冷笑着批了一纸调令——南京刑部主事。
- [x] **大纵深**：从大礼议、南京暗流、左顺门134人入狱16人杖死，到打破翰林垄断登顶首辅，再到首开首辅专权体制，奠定日后张居正改革的制度基础。
- [x] **人性内核**：小人物在体制铁板面前的生死一搏，以及孤臣在权力巅峰时的孤独与代价。
