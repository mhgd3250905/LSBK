## 二、存疑与冲突（两说并陈）

1. **皇帝知不知道**：《明史·后妃传》说帝不知；尹直《謇斋琐缀录》（据《野获编》转引）说宪宗亲自安排托病、嘱门官照管，甲午冬已知西宫有一子。《明史·商辂传》称左右畏万贵妃莫敢言，久之乃闻于帝，介于两者之间。节目处理：两说都讲，大开说明自己更倾向哪边、为什么，小李保留不同看法。
2. **《明史》叙事的来源**：于慎行称得自万历甲戌一老中官；沈德符明确不信。学界常说《明史》此段与毛奇龄《胜朝彤史拾遗记》文字几乎相同、毛奇龄曾参修《明史》（二手，据维基百科《万贵妃（明朝）》条，未见原书）。台词只说“有学者指出”，不点毛奇龄负责哪几卷。乾隆曾撰文驳斥万贵妃逼堕胎之说（二手，同上），不入台词。用户简报提到孟森亦有怀疑，本次未能查到孟森原文，台词不点孟森之名。
3. **张敏结局**：《明史·后妃传》称成化十一年吞金死；维基百科转引《金门县志》称张敏卒于成化二十一年，且立太子后数年仍见于记载（二手）。尹直版中张敏还在为皇子奔走。台词说法：《明史》说他吞金而死，但也有地方志记他多活了十年，存疑。
4. **纪氏死因**：《明史》并列万贵妃致死、自缢两说；《孝宗实录》称孝穆太后以疾逊于西宫（二手，转引自网络文章引《明孝宗实录》卷一，未核原书，台词不引）。沈德符认为暧昧必有。节目不下结论。
5. **谁抚养太子**：《后妃传》《本纪》称周太后宫中；商辂疏称贵妃抚育。可能是不同阶段，也可能是疏中客套。节目当证据矛盾讲。
6. **头发**：胎发披地 vs 顶寸许无发、或曰药所中。并陈，不作推断。

## 三、证据禁区

1. 不把万贵妃写成猎奇的毒妇或把宪宗写成荒淫昏君；堕胎、毒杀只作为《明史》说法转述一次并交代来源问题，不描写过程。
2. 不虚构纪氏、张敏、吴废后的心理活动与私下对话；唯一可用的“话”是史书记下的那几句，一律第三人称转述并注明出自哪本书。
3. 不说孝宗“完全宽恕万家”：他撤了万喜等人的官、追回赏赐。
4. 不把“一夫一妻”说成现代爱情观的自觉选择；只说史书中无妃嫔记载及大臣劝选未果的经过。
5. 不说“藏了整整六年皇帝毫不知情”是定论。

## 四、关键引语（全部第三人称转述）

- 宪宗照镜叹老将至而无子 → 他对着镜子叹气，说自己快老了，还没有儿子。
- 张敏：死罪，万岁已有子也 → 张敏跪下说自己该死，万岁其实已经有儿子了。
- 纪氏：儿去，吾不得生；儿见黄袍有须者，即儿父也 → 她抱着孩子说，你这一走我活不成了；看见穿黄袍、有胡子的人，就是你爹。
- 宪宗：我子也，类我 → 他说这是我的儿子，长得像我。
- 周太后：儿去，无食也 → 周太后叮嘱孩子，去了什么也别吃。
- 孝宗：宁受百欺，冀获一是 → 他说宁可被骗一百次，只盼有一次是真的。
- 尹直版：果有一子在西宫，俟再打听 → 宪宗回话说，西宫确实有个儿子，等再打听打听。

## 五、给写稿者的说明

- 全期主线：一个被藏起来的孩子 → 同一个故事的两个版本 → 他被谁护着长大 → 他当了皇帝怎么还债、怎么不报仇。
- 小李的独立立场：她自己算出张敏那句话的时间破绽；她认为如果皇帝知情却让儿子在冷宫长到五岁，比不知情更冷；她在结尾指出孝宗对吴废后的回报其实不算厚（沈德符也这么说）。
- 与 EP04 的口径：EP04 已表达对万贵妃堕胎说的怀疑，本期更完整，但不推翻 EP04，也不提 EP04 中关于鸡缸杯的说法。
