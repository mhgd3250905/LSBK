6. **谁让胡惟庸去探病**：胡惟庸自己来（行状、实录卷99、明史刘基传）与皇帝下诏派去（实录卷129、明史胡惟庸传）（#26、#32、#33）。

## 五、证据禁区

1. 不说刘基“肯定是被胡惟庸毒死的”，也不说“肯定是朱元璋指使的”；三说并陈。
2. 不描写药的成分、不作临床式推断（如“慢性砒霜”“肝癌”之类），症状只按《行状》《实录》《遇恩录》原文转述。
3. 不虚构胡惟庸探病时两人的对话、表情、心理；冷开场只用史书记下的动作。
4. 不把《烧饼歌》任何句子当刘基作品引用；不说“刘伯温预言了清朝”。
5. 不把神算故事当史实讲；凡讲必说出处（行状、实录、明史、笔记、小说各是什么性质）。
6. 胡惟庸案不铺陈屠杀细节、不列名单；只说三万余人和李善长一家七十余口。空印案不展开。
7. 不写“刘基是开国第一谋臣”这种定论；可说朱元璋称他为子房、《明史》说中原大计多出于他，同时交代实录的不同写法。
8. 不点名钱谦益暗示朱元璋授意（未核原文）；网上关于《烧饼歌》康熙本、天启本的说法不用。

## 六、关键引语（全部第三人称转述）

- 刘基评杨宪：宪有相才无相器……持心如水 → 他说杨宪有当宰相的才干，没有当宰相的器量；宰相的心要像水一样平，拿义理当秤，自己不掺进去。
- 评胡惟庸：譬之驾，惧其偾辕也 → 他说用胡惟庸，就像套一头会把车辕掀翻的牲口拉车。
- 自评：臣疾惡太甚，又不耐繁劇 → 他说自己太嫉恶如仇，又耐不住繁杂公务。
- 闻胡惟庸拜相：使吾言不驗，蒼生福也 → 他说但愿自己的话不应验，那才是天下人的福气。
- 朱元璋御制文：但奪其祿而不奪其名……時顧舊巢 → 皇帝在文里说，只夺你的俸禄，不夺你的名分；鸟飞走了还会回头看旧巢，你回乡养老吧。
- 刘基临终：亟上之，毋令後人習也 → 他让长子赶紧把天文书交上去，别让后人学这个。
- 朱元璋对刘璟：我只道他老病，原來吃蠱了 → 皇帝说，我原来只当他是老病，原来是中了蛊。
- 朱元璋转述刘基：臣如今肚內一塊硬結，怛諒著不好 → 皇帝回忆刘基对他说，肚子里有一块硬结，怕是不好了。
- 洪武二十八年敕谕：臣下有奏請設立者，論以極刑 → 皇帝说，以后哪个臣子敢奏请设丞相，处死。

## 七、给写稿者的说明

- 全期主线：一个被传成神仙的人 → 神仙形象是谁写出来的 → 去掉神话后的真实官运 → 那碗药与死后四年才出现的毒死说 → 皇帝借这件事拿掉了丞相这个位置。
- 小李的独立立场：①自己算封爵账（#14）；②发现《实录》和《明史》把伏兵之计记在不同人头上（#4）；③抓出“看人准”那段话写在三人都倒台之后（#20）；④在死因上倾向认为皇帝至少是默许的（依据 #32、#33），和大开的看法不同，最后不统一。
- 大开的立场：毒死说证据链从洪武十二年才开始，皇帝自己说过原以为是老病，所以他认为“毒杀”无法证实；但他承认刘基服药后病重这一事实确凿。
- 与已做节目的口径：接张居正、徐阶、高拱各期（废相是内阁首辅“无相之名”的前因），只点一句，不展开；接 EP18 姚广孝（刘璟与朱棣），备用。
