# 选题卡：EP25《刘伯温看人那么准，为什么还是躲不过胡惟庸那碗药？》

> 2026-10-13 明朝篇批量选题中，经红队评审（C01 刘伯温 7 分，建议并入 C02 胡惟庸案与废丞相）后由主代理裁决立项，编为 EP25（原 EP25 宋濂题已被用户否决，PR #6 关闭）。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：大明篇已从永乐靖难（EP18 姚广孝）一路做到崇祯，但洪武朝一期都没有。刘伯温是大众最熟的明初面孔，而节目已经做过的张居正、徐阶、高拱几期，反复在讲“没有丞相名分的首辅”，丞相是怎么没的一直没交代。这期用刘伯温的死，把胡惟庸案和废丞相带出来，算是给内阁那几期补前因。
- **题型**：人物反差型 + 传说溯源 + 疑案辨析（毒死说各方史料并陈）
- **系列归属**：《笑谈历史》第一季·大明篇，洪武篇
- **时间跨度**：约至正二十年（1360）刘基应聘到应天 → 洪武三年（1370）封诚意伯、禄二百四十石 → 洪武四年回乡 → 约洪武六年谈洋案夺禄、留京 → 洪武八年（1375）正月胡惟庸带医探病，四月十六日卒于青田 → 洪武十二年十二月涂节首提“遇毒死” → 洪武十三年（1380）正月诛胡惟庸、罢中书省 → 洪武二十三年李善长案、坐诛三万余人 → 洪武二十八年（1395）敕谕永不设相

## 核心认知反差（生死线）
- **你以为的**：
  1. 刘伯温是“前知五百年、后知五百年”的半仙，《烧饼歌》算尽了明清两朝的国运；
  2. 开国第一军师，朱元璋最信任的人，封赏自然最厚；
  3. 他被胡惟庸毒死，是板上钉钉的奸臣害忠良。
- **实际上的**：
  1. 《烧饼歌》要到清代中晚期才挂到他名下，明代“吃饼预言”的主角是铁冠道人张中；清初《罪惟录》甚至说论预言，刘基不值一提。不过“会看天象”的种子，早在刘家请人写的《行状》和官修《实录》里就种下了；
  2. 封诚意伯，禄二百四十石，不到李善长的十六分之一，连同批另一位伯爵汪广洋都不如；爵位起初不世袭，入明后实际任职不到两年半，后来连这点俸禄也被夺了；
  3. 现存他死时的文字里没有一处说是毒，皇帝亲撰的送别文说他是年老病侵；毒死之说是四年半后，在皇帝清算胡惟庸和中书省时才出现的，皇帝后来还亲口说过“我原来只当他是老病”。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 传说溯源 + 同一部官书前后打架 + 一个制度在五天之内被拿掉）

## 核心问题（这期节目回答的一句话问题）
一个被后人传成神仙的谋臣，在洪武朝的真实处境是什么？他死后四年才冒出来的“毒死说”，又被谁、拿来做了什么？（答案的后半：它先后扳倒了当时中书省的两位丞相，五天后丞相这个位置也没了。）

## 三大基因自检
- [x] **小切口**：洪武八年正月，南京，当朝丞相带着医生来探一位失势老臣的病；老人喝了两服药，觉得肚子里像压着一块拳头大的石头，去告诉皇帝，皇帝没当回事。
- [x] **大纵深**：一个神算形象如何从行状、实录、小说、谶书一路被叠加出来；浙东文人在淮西功臣圈子里的位置；一桩死因如何在政治清算中被定性，最后连丞相制度一起被拿掉。
- [x] **人性内核**：看得清别人、也看得清自己（他说自己疾恶太甚、不耐繁剧），却还是没能脱身；死前把天文书交出去、叮嘱后人别学，身后却被安上了一整本预言书。

## 印章拟定
- **印章四字**：`持心如水`（出自《明史·刘基传》与《行状》中刘基论宰相：宰相要持心如水，以义理为权衡而己无与；既是他看人的尺子，也呼应全期落点：朱元璋最后的办法是干脆不要宰相）
- 古法排列：右列“持 心”，左列“如 水”，自上而下。
