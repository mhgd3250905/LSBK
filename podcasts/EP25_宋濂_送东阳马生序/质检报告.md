## 四、故事与对话（B/C 类）

- **两段式开场**：`[00:00-00:48]` 饭桌素食冷开（不报幕）→ `[00:48]` 标志性报幕 → 小李背课文作课本钩子（沿用宋朝系列"课本常识切入"）。
- **发现路径**：课本少年 → 课文写于宠光最盛时、文末自料被说炫耀 → 十九年满分伴君术 → 百岁衣与儿孙扶掖 → 胡惟庸案连坐 → 皇后两步求情、儿孙被杀、夔州两种死法 → 回到课文最后一句。
- **小李的独立立场**：中段主动下判断"满分卷子"；第三幕提出"罪名在孙子身上与爷爷何干"；第四幕坚持"怪不到他头上"。大开同意但补"怪不到他，他也没躲过"，分歧保留，不强行统一。
- **轻松段落**：喝酒查岗、茹太素"写太长挨打"、强灌三杯醉学士诗，均为正史。
- **呼应**：宋璲、宋慎扶掖（第三幕）→ 二人被杀（第四幕）；百岁衣三十二年 → 七十二岁；冷开饭桌 → 第四幕重述；课文末句（第一幕）→ 结尾。均为正史/本人文，无虚构。
- **结尾**：停在人物余波与课文原句，未做"三把尺子"式总结；胡惟庸案后续一句带过，不做预告式串场。

## 六、存疑与待核

1. 宋濂卒日"洪武十四年五月二十日"与死因两说（行状/《名山藏》/《国榷》）均为二手转引（维基百科宋濂条注6、百度百科引行状），未核原书；台词只说"洪武十四年五月"与两说并列。
2. 郑晓《皇明名臣记》"开国文臣之首"为朱元璋原话一说为二手转引。
3. 太子投水另有王鏊笔记挂在他事上的说法，仅见现代转引；台词只说"不同笔记说法对不上"。
4. 《明史·太祖本纪》把"安置宋濂于茂州，道卒"系于洪武十三年九月条下，与本传"其明年卒于夔"在叙述上有出入（本纪属连带书写）；台词采用本传。
5. 《送东阳马生序》写于 1378 为教材通行系年，文中未自书年份。
