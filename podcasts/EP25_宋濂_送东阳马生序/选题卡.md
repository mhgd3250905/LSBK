# 选题卡：EP25《课本里冻着手抄书的宋濂，为什么七十一岁差点被朱元璋砍头？》

> 2026-10-12 立项（开哥批准选题）。事实依据与原文出处见同目录 `史料核对.md`；凡标"笔记"者为野史杂录，台词中一律按"有这么一种说法"处理。

## 基本信息
- **选题缘由**：全国初三都背过《送东阳马生序》（统编版九年级下册第三单元第11课），印象里的宋濂是那个天大寒、砚冰坚还在抄书的勤学少年，后来成了"开国文臣之首"、太子的老师，功成名就。可这篇课文写于洪武十一年（1378），宋濂在文里还提到自己"承天子之宠光"；两年后，长孙宋慎被卷进胡惟庸案，朱元璋要杀这位七十一岁的老先生，靠马皇后、太子朱标力救才改为全家流放茂州，第二年他死在夔州，次子宋璲、长孙宋慎被杀。课本人设与人生结局反差极大，而且主线全部在《明史》本传、后妃传、本纪里有据。
- **题型**：课本名人真脸型 / 人物传记型 / 伴君之道
- **系列归属**：《笑谈历史》第一季大明篇·洪武线开篇（可挖"洪武大案"系列坑）
- **时间跨度**：元至大三年（1310）生 → 至正二十年（1360）应召至应天 → 洪武二年（1369）总裁《元史》 → 洪武十年（1377）致仕 → 洪武十一年（1378）来朝、作《送东阳马生序》 → 洪武十三年（1380）胡惟庸案、宋慎坐党 → 洪武十四年（1381）卒于夔州
- **避重说明**：EP16《诗词人设崩塌》讲元稹、宋之问、汪精卫、冯道，人物无重叠；EP16 的落点是"文如其人"破灭，本期宋濂人品无亏，落点是"人品无亏也护不住家人"，方向相反。

## 核心认知反差（生死线）
- **你以为的**：
  1. 宋濂是勤学成才的励志模板，苦尽甘来，晚年荣归故里；
  2. 朱元璋杀功臣杀的是武将、是贪官、是跋扈的人；一个只写文章、从不揽权、连别人坏话都不说的老学者，总该是安全的；
  3. 《送东阳马生序》就是一篇劝学文。
- **实际上的**：
  1. 《明史》本传记朱元璋亲口评价他：事朕十九年，未尝有一言之伪，诮一人之短；喝了什么酒、请了谁、吃了什么菜，朱元璋派人暗中盯着，第二天一问，他句句照实说；
  2. 他一再推掉实权官职，退休时朱元璋还送他绸缎，说留三十二年做百岁衣；结果两年后长孙宋慎坐胡惟庸党，朱元璋要杀他，马皇后陪皇帝吃饭不沾酒肉，说是替宋先生作福事，才换来免死、流放茂州（《明史·后妃传》）；
  3. 劝学文最后一句，宋濂自己预料到有人会说他在炫耀"际遇之盛"——这份际遇只剩两年。
- **反差强度自评**：⭐⭐⭐⭐⭐（课本熟悉度满格 + 正史有据的饭桌救命名场面 + 结局两种死法说法）

## 核心问题（一句话）
一个在朱元璋身边十九年、从不说假话、从不说人短处的老实人，为什么最后连自己的儿孙都护不住？伴君的本事，到底能护住多大一圈人？

## 三大基因自检
- [x] **小切口**：洪武十三年，宫中饭桌上马皇后不碰酒肉，说是为宋先生作福事，朱元璋扔下筷子起身，第二天赦宋濂死（《明史·后妃传》）。
- [x] **大纵深**：从元末龙门山隐居、应召"四先生"，到修《元史》、教太子十余年、定一代礼乐，再到胡惟庸案罢中书省废丞相，洪武朝第一桩大案的连坐逻辑。
- [x] **人性内核**：个人的诚与慎能换来皇帝的信任，但换不来连坐制度下家人的安全；"伴君之道"的边界在哪里。
