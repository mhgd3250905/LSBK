## 二、存疑与冲突（两说并陈）

1. **“一仗没打”是不是真的**：不是。见 #17–#20。标题用“没打出一场名战”。
2. **为什么没打大仗**：四种解释并存，本期比旧包多一种。
   - 方针：督臣谭纶一到就定下“南宜战、北宜守”（#25）——这是本期新增，最硬；
   - 《明史》：守得太固，敌人转去辽东（#24）；
   - 张居正：拒守为主，贼不得入即为上功，援辽非急（#26）；
   - 戚继光本人和戚家：想出塞援辽，朝廷不批（#27、#28）。
   大开可以说倾向，小李追问“是不能打还是不让打”。
3. **敌台数字**：戚传“先建千二百座”vs 谭传“筑敌台三千”（#8、#9）；儿子跋语说一千二百座（#52）。最终建成总数未核，台词不报。
4. **送礼争议**：
   - 有据的“近”：张居正书信嘱托、夜信、自称（#36–#38）——书信是一手；自称是笔记。
   - 存疑的“送”：千金姬（王世贞，C）、名姝瑰异（沈德符，C，与王世贞高度重合，疑同源）、海狗肾（沈德符，C）。
   - 反证：张居正退礼信（#35，一次）。
   - 同框：王世贞、沈德符、《明史·张居正传》都把戚继光和李成梁并提（#56），送礼在当时是门下边帅的共同处境，不是戚继光独有。
   - 节目口径：依附是实的；送了什么、送了多少，只有与张居正不睦的私家记载，正史不采；不判他“行贿”，也不替他洗白。
5. **调广东的推手**：《明史》说张鼎思上言、当国者遽改（#41）；《年谱》《墓志铭》说是受恩裨将散布流言（#42）；沈德符陈文治条是可能的旁证但对不上（#43）。
6. **在镇年数**：“十六年”虚算（#29）。
7. **去世日期**：蜡日两解（#50）。
8. **雨中站立的年份**：未系年（#10）。
9. **浙兵数目**：最初三千、说好三年遣还（#5）；台成后增募九千余（#9）；本传说“浙兵止弗调”曾一度叫停（#7）。三条时间不同，不矛盾，但台词不要把“三千”说成全部南兵。

## 三、传说溯源

1. **怕老婆段子**（请夫人阅兵、杀鸡炖汤、提刀闯军营、王氏守城）：能落到原始出处的只有沈德符“为其妻所制”（#53）与墓志拿刀一段（#49）；其余未找到出处，不用。
2. **“王氏休夫”**：现代网文说法，原文只是把积蓄装车运回王家。
3. **“张居正把弹劾戚继光的奏折全扣下”“戚继光开放互市、蒙古心服”**（见于本节目 EP06 台词）：本次未找到史料；互市是隆庆五年俺答封贡，宣大以西的事，与戚继光无直接关系（《明史·戚继光传》“俺答已通贡，宣、大以西，烽火寂然”）。本期不重复，也不在台词里点名纠正 EP06，正面按 #30 讲“欲为继光难者，辄徙之去”即可。
4. **“戚继光修了长城”**：今天常见的金山岭、慕田峪等段落敌楼多与他的蓟镇工程相关，但具体哪段哪座是他修的，本表未核，台词只说“蓟镇这二千里边墙上跨墙修敌台”，不点今天景区名。
5. **“猴子放铳”**：沈德符《奇兵不可再》说他在江南曾让猴子学放鸟铳火鼠，用来惊倭；沈德符自己评“真堪大噱”。属东南时期笑谈，归 EP25，且可信度低，本期不用。

## 四、证据禁区

1. 不说“戚继光在北方一仗没打”；不说他“被张居正雪藏”。
2. 不说“戚继光行贿张居正”是定论；送姬、海狗肾各最多一句，标明笔记、存疑。
3. 不虚构王氏、戚继光、张居正的心理活动与私下对话。
4. 不把贫困全归咎朝廷或王氏。
5. 不说敌台最终建成多少座，不点今天景区名。

## 五、关键引语（全部第三人称转述）

- 蓟门之兵，虽多亦少 → 他到任就上疏说，蓟门的兵看着多，其实等于少。
- 臣官为创设，诸将视为缀疣 → 这个官是新设的，下面的将领把他当成身上多长的一块肉。
- 一瑕则百坚皆瑕 → 二千里边墙，一处有破绽，其余修得再结实也白搭。
- 秣马厉兵……宜于南；坚壁清野……宜于北 → 谭纶说，在南方是喂饱马、磨快刀，一口气定胜负；在北方是把墙修坚、把野外清空，坐在原地让对方进不来。
- 贼不得入，即为上功；援辽非其所急 → 张居正写信说，敌人进不来就是头功；去辽东帮忙，不是你的急事。
- 徒有封拜之具，无可措手之会 → 他晚年写给祖宗：手里攥着能换封爵的本事，等不到下手的机会。
- 时时搆千金姬进之居正 → 王世贞的书里说，他常常花大价钱买美女送给张居正（私家记载，存疑）。
- 门下沐恩小的某万叩头跪禀 → 沈德符说，他和李成梁给张居正写禀帖，都自称门下受恩的小人，叩头跪禀。
- 边烽警急，宰相或不得坚卧 → 张居正的儿子答审官：边关告急，宰相有时也睡不了安稳觉。
- 尽转而之辽，故成梁擅战功 → 《明史》说，蓟门守得太死，敌人只好全都绕去辽东，所以战功都归了李成梁。
- 倭勣乃横草熟釜之功，边勣乃曲突徙薪之业 → 他儿子写道，打倭寇是踩倒一棵草、煮熟一锅饭的工夫；北边的功劳是把烟囱改弯、把柴火挪开，让火根本烧不起来。
- 囊括其所蓄，辇而归诸王 → 她把家里的积蓄收拾起来，装上车，运回了王家。
- 今国家太平……安所事武臣哉 → 他回到老家说，如今天下太平，哪里还用得着武将。

## 七、对抗自审记录（2026-10-13）

本次以“找错”为目标逐条复核，已直接修订如下：
1. **送礼“双源”过头**：初稿把王世贞（#32）与沈德符《边材》（#33）当作两条独立证据。复核原文后发现两者都写“谭纶御女术进之江陵而验”，措辞与情节高度重合，沈德符晚一代，疑袭用王世贞。已改为“疑同源，不能算两条独立证据”。
2. **“照抄”措辞**：大纲初稿写“《明史》那句几乎照抄王世贞”，与旧包审稿口径冲突，已改为“措辞高度相近、应是取材于它”。
3. **敌台数字**：戚传“先建千二百座”与谭传“筑敌台三千”并存，初稿险些把“三千”写成建成数，已改为“规划里写到三千、最终总数未核”（#9）。
4. **李成梁封伯年月**：《明史》只把封伯叙于万历六年十二月圜山之战之后，未给授封月份；选题卡时间轴已改为“此后以功封宁远伯（授封月份未核）”。
5. **陈文治 = 流言裨将？**：沈德符《同邑二役》情节与年谱相似，但“东协/西部”对不上，且沈德符未将其与戚继光去职挂钩，已降级为“可能是同一人”，台词不点名（#43）。
6. **结尾改向**：旧包以 1629 年大安口收尾，属本系列 EP29 的时间段，且容易被听成“戚继光一走长城就破”；已改为以《明史》“尽转而之辽，故成梁擅战功”引出 EP27。
7. **籍贯小错**：沈德符称“登之文登人”，与《明史》登州卫、《年谱》蓬莱不尽一致，已在 #34 标注，不展开。
8. 仍未补的缺口：《年谱》卷一至卷十一未核；《墓志铭》用录入本；《明神宗实录》未核调粤、罢归的实录日期（以《年谱》为准）；敌台最终建成总数未核。
