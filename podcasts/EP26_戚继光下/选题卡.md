# 选题卡：EP26《打遍东南的戚继光，为什么在长城上守了十六年，没打出一场名战？》

> 2026-10-13 立项，晚明边防系列第 2/5 期（戚继光下）。事实依据与原文出处见同目录 `史料核对.md`（下称“核对表”，#编号对应），凡冲突以核对表为准。本期复用旧包 EP30_戚继光（PR #8）的史料，按系列定位重写：结尾不再停在 1629 年大安口，改为引出同时代辽东的李成梁。

## 基本信息
- **选题缘由**：课本里的戚继光停在台州、福建。上期讲完他在东南为了练兵、打仗依附胡宗宪，背上了第一层名声争议；这期讲他后半生最长的一份差事：北京东北的蓟镇，十六年（虚算）。用户对戚继光的判断是“一个为了目标可以牺牲世俗名声的优秀将领，存在争议”，这一期正是争议最集中的一段：他和张居正近到什么程度，送没送礼，换来了什么，又付了什么代价。
- **题型**：人物反差型（前半生名战 vs 后半生无名战）+ 证据链辨析（正史、书信、墓志、年谱、笔记并陈）
- **系列归属**：《笑谈历史》大明篇·晚明边防系列（5期）第 2 期。系列两条线：戚家军一条线 + 火器一条线。
- **时间跨度**：隆庆二年（1568）五月总理蓟州练兵 → 隆庆五年（1571）秋敌台工成 → 万历元年至二年（1573–1574）喜峰口与董狐狸、长秃 → 万历六年（1578）张居正葬父前的嘱托信；同年十二月辽东李成梁圜山之战，此后以功封宁远伯（授封月份未核） → 万历七年（1579）十月援辽 → 万历十年（1582）六月张居正卒 → 万历十一年（1583）二月调广东 → 万历十三年（1585）罢归蓬莱 → 万历十五年（1587）腊月卒 → 余波：1620 年幼子作跋。

## 核心认知反差（生死线）
- **你以为的**：
  1. 戚继光就是抗倭英雄，名将的价值看打赢了几场大仗；
  2. 他和张居正是一段将相佳话，晚年凄凉只是被小人陷害；
  3. 北方的长城是“修好了就守住了”的死物。
- **实际上的**：
  1. 他人生最长的一段差事在北方，修敌台、练车营、用火器，做的是一套让仗打不起来的系统；北方没有名战，一半是督臣谭纶和首辅张居正定下的方针（南宜战、北宜守；贼不得入即为上功），一半是他自己晚年说的“手里有封爵的本事，等不到下手的机会”；
  2. 他和张居正近到自称门下小的、半夜递信；王世贞、沈德符说他给张居正送美女、送海狗肾，正史不采，真伪存疑，可同一句话里也写着李成梁和两广督抚的贿赂接踵而至——这是当时边帅的共同处境；靠山一倒，他半年后被调走，再两年罢官，最后连请医生都没钱；
  3. 敌人没进蓟门，是转去了辽东；战功也跟着去了辽东，归了同时代另一位名将李成梁，他封了伯。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 什么都没发生才是战绩 + 依附的代价 + 隔壁那位封了伯）

## 核心问题（一句话）
一个最会打仗的将领，为什么把后半辈子最好的成绩做成了“什么都没发生”？为了做成这件事，他把自己的名声押给了谁？

## 三大基因自检
- [x] **小切口**：三千浙兵在蓟镇城外的大雨里，从早上站到过了中午，一动不动（核对表 #10）。
- [x] **大纵深**：庚戌之变后的京畿防务、十七年十将的困局、敌台车营与火器、明代考核武将的八事账本、文官节制武将、首辅倒台后的清算。
- [x] **人性内核**：做成了预防的人怎么证明自己的功劳；为了做成事，名声可以押出去多少；靠一个人才能做成事，代价由谁付。
