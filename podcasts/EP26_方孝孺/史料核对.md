## 二、存疑与冲突（两说并陈）

1. **城破那一刻：哭骂还是叩头？**《明史》（#18）写悲恸、辩周公、投笔哭骂；《太宗实录》（#25）写叩头祈哀。可信度：实录是永乐方立场的官修（城破细节与《奉天靖难记》同源，据知猫论文转述，二手），把对手写成“奸臣”求饶有明确动机，且同书说他献计拆民房致死者相枕（#15）；《明史》的对话细节则来自正德以后私史层层增补（#32、#36）。两边都不是现场记录。节目处理：大开说更倾向“他没有屈服”这一底线（理由：实录也承认他最终“戮于市”，若真叩头求饶，朱棣有理由留他草诏；连《天顺日录》都写他投笔），但承认辩论对白是后来补出来的。
2. **株连多少人：数百、847、870、873。**正史本传“数百人”（#23）；本纪“夷其族”（#24）；《姜氏秘史》《明儒学案》847（#36、#40，指宗亲）；《明史纪事本末》正文 873、论赞 870（#39）；《立斋闲录》两种说法（#44，禁用）。节目处理：数字是越写越具体的，但“数百人被杀、上千人谪戍”（#23、#29）是正史底线。
3. **“十族”是谁说的。**《野记》是孝孺说九族、朱棣说十族（#33）；《姜氏秘史》只说“有滅十族等语”（#36）；最晚到清初《明史纪事本末》，已变成朱棣说九族、孝孺答十族（#39；据李谷悦，这一版与崇祯五年《宁海县志》基本一致，最早由谁调转本组未核）。豪言的主人在一百多年里换了人，但不能说是谷应泰换的。
4. **有没有后人。**《明史》说绝无后、嘉靖俞斌冒认（#30）；《熹宗实录》说幼子德宗藏到松江、改姓余、十世孙来京获恤（#31）。两条都和松江有关。节目并陈，不判。
5. **姚广孝在不在南京举荐（冷开场与笔记版的关键冲突）。**把姚广孝放到南京现场、朱棣问他谁可草诏的，是《天顺日录》（#32）、《野记》（#33）、《姜氏秘史》方孝孺条（#36）三种笔记私史。《明史·姚广孝传》（S6）写建文元年起兵时他“辅世子居守”北平，建文二年仍从北平“驰书”劝班师，**此后何时到南京传中没有写**；《明史·方孝孺传》（#17）把他的托付放在“成祖发北平”之时，城破后谁举荐方孝孺草诏则不写；《明史纪事本末》（#39）同样把托付放在出发时，现场改为“皆举孝孺”。也就是说，后出的两部史书都没有沿用“姚广孝在南京举荐”的情节。处理：①冷开场只用《明史》版（#18），**不得加入“朱棣问姚广孝谁能写诏书”**；②小李的发现只能说成“《姚广孝传》说他起兵时留守北平，没写他什么时候到的南京，笔记却让他站在南京的殿上举荐，这一点对不上、存疑”，不能说成“姚广孝那时肯定在北平”；③不推断后来史家删掉的原因。
6. **草诏的时间。**乙丑城破当日被执，己巳即位，丁丑处死（#16、#24）。草的是否“即位诏”、发生在即位前还是后，诸书不一，台词不给具体日期，只说“城破后的那几天”。
7. **谥号年份**：见 #43，存疑。

## 四、证据禁区

1. 不复述凌迟、抉口至耳、逐个示之等刑罚过程，只说“后来的书里加进了更残酷的细节”。
2. 不说“朱棣无罪”“十族是清朝人黑明朝”。十族的加码者主要是明朝人自己（#33–#38），《明史》反而删了。
3. 不把“东林党为了宣传编造十族”当事实：只能说有研究者认为，十族在天启年间进入官方叙事，与当时士大夫标榜气节的需要有关（李谷悦观点，二手）。
4. 不编方孝孺、朱棣、姚广孝的心理活动与私下对话。可用的话只有史书记下的那几句，一律转述并说明出自哪本书。
5. 网传“红蛇 873 条”“方孝孺舌如蛇形”“写下燕贼篡位四字”等，均无本表出处，禁用。
6. 不展开靖难战事（EP18 已讲），不展开建文帝出亡传说。

- 成祖：予欲法周公輔成王耳 → 朱棣说，我不过是学周公辅佐成王。
- 孝孺：成王安在 → 方孝孺反问，那成王在哪里？
- 成祖：此朕家事 → 朱棣说，这是我家里的事。
- 孝孺：死即死耳，詔不可草 → 他说死就死，这诏书我不写。
- 《野记》：不過夷我九族耳／吾夷汝十族／朋友亦族也 → 方孝孺说大不了灭我九族；朱棣说我灭你十族；身边人问哪来第十族，朱棣说朋友也算一族。
- 《纪事本末》：便十族奈我何 → 到了清初的书里，这句豪言变成方孝孺说的：就算十族又能把我怎样。
- 李贤：忠而過者 → 李贤说，他的死是忠，但忠得过了头。
- 朱彝尊：三家村夫子之說 → 朱彝尊说，十族是乡下教书先生编出来的说法。

## 六、给写稿者的说明

- 全期主线：一个人人都知道的数字 → 这个人是谁、他想干什么 → 城破那天的两种写法 → 十族这两个字是谁、在哪一年加上去的 → 为什么后人需要它。
- 小李的独立立场：她自己算出 847 与 873、870 的差，自己发现《姚广孝传》没写他何时到南京、笔记却让他在南京殿上举荐（存疑，见第二节第 5 条）；她更同意李贤的看法，认为方孝孺本可以不把话说绝（大开引黄宗羲反驳），两人不统一。
