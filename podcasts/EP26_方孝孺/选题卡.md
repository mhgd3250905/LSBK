# 选题卡：EP26《方孝孺真的被诛了十族吗？这个故事是谁一笔一笔写出来的？》

> 2026-10-13 明朝篇批量立项（红队评审 C03，9 分，已核）。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：EP18 讲完姚广孝和靖难之役，城破以后的事没有讲。方孝孺“诛十族、八百七十三人”是大众最熟的明初故事之一，但很少有人追过这个数字是从哪本书来的。本期顺着时间把这条出处链走一遍，同时讲清方孝孺本人：他在建文朝想做什么，城破那天又做了什么。
- **题型**：传说溯源型（正史、实录、笔记、私史并陈）+ 人物传记
- **系列归属**：《笑谈历史》第一季·大明篇，建文—永乐过渡篇（上接 EP18 姚广孝，下接 EP27 朱棣迁都）
- **时间跨度**：洪武十五年（1382）初见太祖 → 建文元年至四年（1399—1402）改制与靖难 → 建文四年六月城破、方孝孺被杀 → 永乐二十二年（1424）仁宗宽宥家属 → 天顺（约 1460 年代）《天顺日录》 → 正德年间《野记》首见“十族” → 万历十三年（1585）释放谪戍后裔 → 天启二年（1622）《熹宗实录》写“致夷十族” → 清初《明史纪事本末》“八百七十三人” → 乾隆初《明史》只写“数百人”

## 核心认知反差（生死线）
- **你以为的**：
  1. 方孝孺被朱棣诛了十族，第十族是他的学生朋友，一共杀了八百七十三人，这是史书写明的；
  2. 那句“就算诛十族又怎样”是方孝孺当着朱棣的面喊出来的；
  3. 方孝孺就是个只会骂人的书呆子忠臣。
- **实际上的**：
  1. 清朝官修的《明史》里没有“十族”，只写宗族亲友前后坐诛者数百人；目前能找到最早写“十族”的，是方孝孺死后一百年左右祝允明的笔记《野记》，同一本书里还配了一个蟒蛇报复方家的因果故事；“八百七十三人”这个数，本期能核到的出处是清初的《明史纪事本末》，而这本书自己的论赞里写的是八百七十人（873 是否更早已有，未核）；
  2. 在《野记》里，说“九族”的是方孝孺，说“十族”的是朱棣；最晚到清初的书里，这句豪言已经换到了方孝孺嘴里；
  3. 他是建文朝最受信任的文臣，参与了一套复古改制，把宫殿门都改成了周礼的名字；朱棣即位后第二天就全部改回去。株连数百人、上千人谪戍是真的，十族这个数字是一层层加上去的。
- **反差的强度自评**：⭐⭐⭐⭐⭐（家喻户晓的数字 + 出处链清楚可讲 + 正史与笔记互相拆台）

## 核心问题（这期节目回答的一句话问题）
方孝孺被杀是真的，株连数百人也是真的，那“十族”和“八百七十三”这两个数字，是谁在哪一年一笔一笔加上去的？后人为什么需要这个故事？

## 三大基因自检
- [x] **小切口**：一个人在新皇帝面前把笔扔到地上，说死就死，诏书不写。
- [x] **大纵深**：一个故事从永乐到乾隆三百多年的写法变化，每一次加码都对应一个时代的需要：永乐要他是奸臣，仁宗要宽宥，正德的笔记要因果报应，天启要气节，清初要反思，康熙修史要删。
- [x] **人性内核**：一个人的死，被后人反复讲、反复加码；讲故事的人各有各的需要。另一面，真正替他收尸、偷偷抄下他文章的，恰恰是按十族逻辑最该被杀的门生。
