# 选题卡：EP27《朱棣为什么非要把首都搬到离蒙古人最近的地方？》

> 2026-10-13 编写。选题来自明朝篇红队评审新增候选 N1（8 分），并列入推荐十期第 3 位。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突的，以史料核对为准。

## 基本信息
- **选题缘由**：大明篇已经做了土木堡（EP19）、北京保卫战（EP20）、夺门之变（EP21），三期都绕不开同一个前提：北京就在前线。这个前提是谁造成的、为什么要这么做、花了多少代价，还没有讲过。EP18 讲姚广孝时讲到燕王起兵，本期接着讲燕王当了皇帝以后，怎么把首都搬回了自己的老家。
- **题型**：帝王决策 / 制度必然性型，另带一节传说溯源（“天子守国门”）
- **系列归属**：《笑谈历史》第一季·大明篇，永乐朝
- **时间跨度**：洪武十三年（1380）燕王就藩北平 → 永乐元年（1403）改北平为北京 → 永乐四年（1406）诏建北京宫殿、五省采木 → 永乐九年（1411）开会通河 → 永乐十八年（1420）诏迁都 → 永乐十九年（1421）正月初一御奉天殿，四月初八三殿起火，下诏求直言，萧仪被杀 → 永乐二十二年（1424）死于榆木川 → 洪熙元年（1425）仁宗准备还都南京，五月去世 → 正统六年（1441）三殿重建落成，北京去掉“行在”，正式定都 → 正统十四年（1449）土木之变、于谦拒绝南迁（只做余波）

## 核心认知反差（生死线）
- **你以为的**：
  1. 朱棣迁都是为了“天子守国门”，这是他亲口说的豪言，甚至是明朝祖训；
  2. 皇帝一声令下就搬了，北京紫禁城盖好，事情就结束了；
  3. 北京从此一直是首都，大家都服气。
- **实际上的**：
  1. 当事人留下的迁都诏和群臣联名疏里，讲的是龙兴之地、山川巩固、四方路程适中、方便巡狩驻守，没有一个字提到守国门；“天子守国门”目前能找到的较早书面文字之一，是2004年一本讲清朝皇帝的书（书里本身给这句话打了引号，谁最先说的查不到）。明末倒是有人说过“天子自守边”，王夫之一本书里夸，另一本书里骂；
  2. 从改名北京到正式定都，前后拖了三十八年：盖宫殿用了十几年，五省进山砍木，三十万民夫挖运河；新宫殿启用才三个月就烧掉了三座大殿，皇帝下诏求大家提意见，大臣们说迁都不便，结果一个主事被杀，几个人下狱、发配；
  3. 朱棣死后第二年春天，儿子仁宗就下令北京各衙门改回“行在”，准备搬回南京，可是下令后两个月他就去世了，在位不到一年；北京衙门的公文印章，直到正统六年（1441）才去掉“行在”两个字。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 一句流行语辟谣 + 一笔算得出来的账）

## 核心问题（这期节目回答的一句话问题）
朱棣为什么要把首都搬到离蒙古人最近的北京？这件事到底花了多少代价，又为什么差一点被他儿子搬回去？

## 三大基因自检
- [x] **小切口**：1421年正月初一，六十出头的朱棣坐进刚落成的奉天殿接受朝贺；九十六天后，这座大殿连同华盖殿、谨身殿一起被烧光。
- [x] **大纵深**：从洪武年间就没想清楚的定都问题，到永乐朝砍木、修河、迁民、迁官的巨型工程，再到仁宗想迁回南京、英宗才正名，最后接上土木堡与北京保卫战。
- [x] **人性内核**：一个皇帝自己下诏请大家批评，等批评真的来了又受不了；一群大臣当初联名说好，出事后又说不好；他的儿子在南京监国被谗十几年，即位后求直言、废诽谤禁、下令搬回南京，却也把上书的李时勉打断了肋骨；一句豪言是怎么在几百年后被安到他头上的。（审稿补：人物线见大纲）

## 印章拟定
- **印章四字**：`京师根本`（出自《明史·邹缉传》卷164 邹缉上疏“夫京师天下根本，人民安则京师安”，以及《明史·于谦传》卷170 于谦“京师天下根本，一动则大事去矣”。同一句话，1421年邹缉接的是“民安”，同一道奏疏末尾请求还都南京；1449年于谦接的是“一动则大事去矣”，用来阻止朝廷逃回南京，正好是本期的落点。审稿订正：邹缉并非直接用这句话论证还都）
- 古法排列：右列“京、师”，左列“根、本”，自上而下。

## 内容弹药
- **主要素材**：《明史》成祖本纪（卷5~7）、仁宗本纪（卷8）、宣宗本纪（卷9）、英宗前纪（卷10）；夏原吉传（卷149，萧仪被杀）、邹缉传（卷164，营建成本与言事者获罪）、李时勉传（卷163）、宋礼陈瑄传（卷153，会通河与海运账）、李至刚传（卷151）、于谦传（卷170）；食货志漕运（卷79）与采木（卷82）、兵志边防（卷91）、职官志南京（卷75）、地理志京师（卷40）；《日下旧闻考》卷4、卷34转录的成祖实录、英宗实录（群臣联名疏、迁都诏、三殿重建）；《纲目三编》卷7（求直言诏全文、萧仪籍贯）。
- **传说溯源**：刘侗《帝京景物略》自序（1635，“天子自守边之略”）；王夫之《黄书》（赞“天子守边”）与《思问录》（骂“天子自守边”为悖）；阎崇年《正说清朝十二帝》（2004，“天子守国门”）。
- **对照组**：邹缉的“京师天下根本，人民安则京师安”与奏疏末尾的“当还都南京”（1421，两句不相连） vs 于谦的“京师天下根本，一动则大事去矣”（1449）；永乐十四年群臣联名说北京好 vs 永乐十九年言者多说北京不便；黄宗羲“皆都燕之为害” vs 北京保卫战守住了。
- **合法跑偏**：①宋礼报告大木头自己从山里漂出来，朝廷把那座山封为神木山；②李时勉的奏疏被朱棣扔在地上，又捡起来看了两遍；③大青颜料一斤一万六千贯，不够刷一根柱子；④三殿烧了二十年没修，上朝改在奉天门；⑤《明卓异记》里预言起火的漏刻博士（注明是笔记奇闻，一句带过）。
