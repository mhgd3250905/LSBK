# 选题卡：EP27《二百年来战功第一的明朝大将，为什么被说成养大了努尔哈赤？》

> 2026-10-13 按用户定下的“晚明边防系列”（戚家军线 + 火器线，共 5 期，EP25–EP29）立项，本期为第 3 期。事实依据与原文出处见同目录 `史料核对.md`（以下 #编号均指该表），凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：上一期（EP26）讲完戚继光在蓟镇十六年，《明史》给“没有名战”的解释是：蓟门守得太固，敌人进不来，全转去了辽东，所以战功归了李成梁（#14）。这一期就去辽东，看拿走那些战功的人是谁、战功是怎么来的、又留下了什么。大众对李成梁几乎只知道一句网络说法“他养大了努尔哈赤”，本期把这句话拆开验一遍。
- **题型**：人物对照型（同时代、同一个靠山、两种名将）+ 证据链辨析（明史、清史稿、实录、明末私史四方说法并陈）
- **系列归属**：《笑谈历史》大明篇·晚明边防系列 3/5（EP25 戚继光·东南 → EP26 戚继光·蓟镇 → **EP27 李成梁** → EP28 戚家军的结局 → EP29 大炮）
- **时间跨度**：嘉靖四十五年前后（约1566），四十岁的生员李成梁靠巡按资助进京袭职 → 隆庆四年（1570）接手三大将战死后的辽东 → 万历六年（1578）封宁远伯 → 万历七年（1579）戚继光赴援辽东 → 万历十一年（1583）古勒寨，努尔哈赤祖父与父亲死于兵火 → 万历十七年（1589）明授努尔哈赤都督佥事 → 万历十九年（1591）解任 → 万历二十一年（1593）长子李如松平壤大捷 → 万历二十九年（1601）七十六岁再镇辽东 → 万历三十四年（1606）弃宽甸、驱民内徙 → 1615 年九十岁卒 → 1618 七大恨 → 1619 萨尔浒李如柏自裁、铁岭失陷

## 核心认知反差（生死线）
- **你以为的**：
  1. 李成梁就是“养虎为患”的那个人，把努尔哈赤当干儿子养大；
  2. 名将就是打胜仗多的将军，战功越多越可靠；
  3. 戚继光和李成梁是一对“南戚北李”的明朝双子星，差不多的人。
- **实际上的**：
  1. “养子”这件事，《明史》一个字没提，清朝自己的记载说是李成梁的妻子放走了他，明朝晚期的三种私家说法岁数互相对不上（四岁、十五六岁、“方幼”），“谊同父子”四个字是言官弹劾他的话（#37–#43）。能坐实的是另一层：他打古勒寨时努尔哈赤的祖父和父亲死于兵火；他在任时明朝给了努尔哈赤都督佥事；他第二次镇辽那几年辽东“少事”，建州却吞了哈达、拿了龙虎将军（#35、#44）。
  2. 《明史》一边说他“边帅武功之盛，二百年来未有”，一边自己翻账：战功在塞外，容易粉饰；有一仗死了一千人，报上去是斩首二百八十（#13、#19、#21）。
  3. 同一个张居正撑腰，同一种“门下沐恩小的”的禀帖（#17），戚继光练的是制度兵、主守、没名战；李成梁养的是私家健儿、出塞捣巢、十大捷（#6、#22）。张居正死后，戚继光半年就被调走，李成梁又干了九年（#23）。
- **反差的强度自评**：⭐⭐⭐⭐（熟脸努尔哈赤 + 一句流行说法被拆开 + 与上期戚继光直接对照）

## 核心问题（这期节目回答的一句话问题）
一个在辽东打了三十年、战功被《明史》称为二百年来第一的将军，为什么最后留给明朝的，是一个他亲手开拓又亲手放弃的宽甸，和一个后来叫努尔哈赤的邻居？

## 三大基因自检
- [x] **小切口**：万历三十四年，八十一岁的李成梁与总督、巡抚一起提议放弃三十多年前自己献议开拓的宽甸，六万四千多户居民不肯走，大军赶着走，死了很多人；事后他还因为“招回逃人”加了官（#28、#30）。
- [x] **大纵深**：明代边将的考核与首级账本、私兵化的家丁体制、以夷制夷扶一部压一部、言官与阁臣的庇护网、清修《明史》对清室先世的讳言。
- [x] **人性内核**：功劳越大越没人敢查；一个人既是辽东的屏障也是辽东的病根；后人找“罪人”时，最方便的就是那个和对手走得最近的人。

- **主要素材**：《明史·李成梁传》卷238（含子如松、如柏、如桢、如梅传与赞）；《明史·戚继光传》卷212、《张居正传》卷213、《张学颜传》卷222、《熊廷弼传》《杨镐传》卷259、《朝鲜传》卷320；《清史稿·太祖本纪》卷1；姚希孟《建夷授官始末》（《皇明经世文编》卷501）；黄道周《博物典汇》卷二十；茅瑞征《东夷考略》；《明神宗实录》卷462；沈德符《万历野获编》卷十七；《七大恨》。
