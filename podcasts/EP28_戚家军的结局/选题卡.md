# 选题卡：EP28《戚继光死后，戚家军是怎么一步步没的？》

> 2026-10-13 按“晚明边防系列”（用户 2026-10-13 定，共 5 期，本期为第 4 期）立项。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：戚家军在课本里停在台州、福建的抗倭大捷；戚继光死后这支军队的下落，大众只知道网上一句“被自己人坑杀了三千”。这期顺着戚继光留在蓟镇的南兵往下走：他们去朝鲜打了平壤，回国后在石门寨闹出一场兵变，最后一批浙兵死在沈阳城外的浑河。每一站都绕不开同一个问题：功劳记在谁的账上。
- **题型**：群像结局型（一支军队三十年的下落）+ 证据链辨析（明朝正史、明实录、朝鲜实录、审讯档案、家谱并陈）
- **系列归属**：《笑谈历史》大明篇·晚明边防系列 4/5（EP25 戚继光上 → EP26 戚继光下 → EP27 李成梁 → **EP28 戚家军的结局** → EP29 大炮）
- **时间跨度**：万历十五年腊月（1588 年初）戚继光卒 → 万历二十年（1592）南兵东征朝鲜 → 万历二十一年正月（1593）平壤之战 → 万历二十二年（1594）南兵撤回蓟镇石门寨 → 万历二十三年十月（1595）石门寨兵变 → 万历二十五年（1597）浙兵再征朝鲜 → 万历四十七年（1619）萨尔浒 → 天启元年三月（1621）浑河之战

## 核心认知反差（生死线）
- **你以为的**：
  1. 戚家军跟着戚继光退场了，或者像网上说的，从朝鲜凯旋后被总兵王保骗进校场，三千人一次杀光；
  2. 平壤大捷是李如松的功劳，打赢了大家一起领赏；
  3. 浑河那三千浙兵就是戚继光的戚家军，打出了最后的荣光。
- **实际上的**：
  1. 戚继光死后，他在蓟镇募练的南兵还在；吴惟忠带着这支以戚家军为底子、又新招了两千多义乌一带青年的队伍去了朝鲜。平壤城下，朝鲜官方记载里第一个爬上城头的是南兵将领骆尚志，“浙兵先登”；《明史》却把先登记在北方将领杨元名下（史料核对 #12、#13）；
  2. 打完仗论功，朝鲜大臣柳成龙说提督攻城全用南军，论功北军居上；首功给了张世爵；先登的赏银，各家记载从五十两到一万两都有，南兵回国后在审讯记录里要的是“平壤先登城银十万两平分”（#11、#17、#18、#28）；
  3. 石门寨这件事有四种写法：《明史》说王保诱杀数百人；《两朝平攘录》说一千三百；朝鲜使臣转述传闻说三千三百；研究者翻出的刑部审讯档案和平叛官员自记，说南兵先自己聚众歃血、扣了将官，死了一百五十人上下，但这些材料也出自镇压的一方（#24~#30）。浙兵此后还在被征调（#34）；
  4. 二十六年后浑河边的三千浙兵，统兵的戚金在平壤城下就在场；他是不是戚继光的侄子，只有后来的家谱这么说。浙营用火器打到火药用尽才溃，兵部尚书报功，首功又记在了川兵头上（#39~#43）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 网传“坑杀三千”被几层史料拆开 + 一条“记功的账本”从平壤串到浑河）

## 核心问题（这期节目回答的一句话问题）
戚继光留下的这支兵，后来是怎么一步步没的？谁替他们记功，谁替他们记账？

## 三大基因自检
- [x] **小切口**：平壤城下，李如松斩了一个后退的兵，喊先登者有赏；骆尚志扛着长戟、背着盾牌往城墙上爬，石头砸伤了脚还在爬（#10、#12）。
- [x] **大纵深**：募兵制下军饷与赏银怎么发；南兵与北兵、文臣经略与将门提督怎么争；朝鲜怎样照着戚继光的书练兵；石门寨档案与史书的出入；从壬辰到萨尔浒的同一批人。
- [x] **人性内核**：功劳由谁来记；一支军队靠钱和名分维系，二者都欠下的时候会发生什么；同一件事，镇压者、弹劾者、远方传话者各写一个数。

## 标题候选（课本熟脸 + 认知反转问句）
1. 《戚继光死后，戚家军是怎么一步步没的？》（**主选**。“一步步”对应平壤论功、石门寨、浑河三站，不坐实“一次屠杀”）

3. 《戚家军的最后一仗，为什么打在沈阳城外的浑河边？》（备选）

## 印章拟定
- **印章四字**：`浙兵先登`（出自《朝鲜宣祖实录》宣祖二十六年正月丙寅条“浙兵先登，拔贼帜，立天兵旗麾”。用朝鲜一方的记载作印，本身就是本期的立场提示：这四个字在明朝自己的正史里没有）
