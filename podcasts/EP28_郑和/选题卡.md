# 选题卡：EP28《郑和的航海档案，真是被一位清官一把火烧掉的吗？》

> 2026-10-13 明朝篇十期批量立项（红队评审 C05，8 分，史料已核），编号按历史时间顺序排在 EP27 迁都之后。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：大明篇已经讲过姚广孝（EP18）、土木堡三部曲（EP19~EP21）、隆庆开关（EP11），郑和一直没有正面出场。“为什么不下西洋了”课本有标准答案（花钱太多），老生常谈；真正冷门、又能翻出新东西的，是“刘大夏烧毁郑和档案”这个流传极广的说法怎么一步步长出来的。这期用一个传说溯源，把郑和其人、七次航行、仁宣停航和成化年间重提下西洋串成一条线。
- **题型**：传说溯源型 / 正史与笔记并陈型
- **系列归属**：《笑谈历史》第一季·大明篇，永乐—宣德—成化跨朝篇
- **时间跨度**：永乐三年（1405）六月第一次出航 → 永乐二十二年（1424）仁宗即位诏停罢宝船 → 宣德五年至八年（1430–1433）第七次 → 成化十五、十六年（1479–1480）汪直谋取安南、刘大夏匿档 → 嘉靖初（约1530）西洋版初见 → 万历二年（1574）严从简两说并列 → 万历末（约1617）顾起元写成“取而焚之”

## 核心认知反差（生死线）
- **你以为的**：
  1. 郑和下西洋是一场探险，后来不去了，是因为朝廷保守、怕花钱，慢慢就不去了；
  2. 清官刘大夏一把火烧了郑和的航海档案，中国从此造不出、开不出远洋船队；
  3. 这个说法出自正史，有板有眼。
- **实际上的**：
  1. 船队是带着钱帛、兵马的武装使团，《明史》说为了找建文帝加耀兵，碑上说为了宣德化柔远人，当时人叫它取宝船；停航是仁宗即位诏书里的一条公开命令，船队直接改编成南京守备部队；
  2. 《明史·刘大夏传》和官方实录里，刘大夏藏起来的是永乐年间征安南的调兵档案，为的是不让汪直去打安南，全传一个字没提郑和；
  3. 西洋版最早见于嘉靖初的私家笔记，记录它的严从简自己就把两个版本并排放、说留待后考；“烧”这个字要到刘大夏死后约一百年，才在顾起元笔下第一次出现。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 一个清官背了五百年的锅 + 作者自己写下“俟考”的证据现场）

## 核心问题（这期节目回答的一句话问题）
七下西洋为什么戛然而止？刘大夏烧掉郑和档案的故事，是怎么从“藏一份安南档案”长成“一把火烧掉大航海”的？

## 三大基因自检
- [x] **小切口**：兵部库房里一份找了三天没找到的旧档，和严从简书里的一句“因附记以俟考”。
- [x] **大纵深**：永乐的远航、仁宣的收缩、成化的边功之争；一个故事在一百年里如何换地点、换人物、换动作、换数字。
- [x] **人性内核**：一个官员用“拖”去拦一场仗，后人却把他写成烧掉大航海的人；我们为什么需要一个可以怪罪的人。
