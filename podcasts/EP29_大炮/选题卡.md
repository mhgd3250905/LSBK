# 选题卡：EP29《宁远大捷之后，明朝最好的大炮怎么到了皇太极手里？》

> 2026-10-13 编写。晚明边防系列（戚家军一条线 + 火器一条线）第 5 期，系列终篇。事实依据见同目录 `史料核对.md`（#1–#48），凡冲突以史料核对为准。史料大量复用 EP33_徐光启 旧包（分支 ming/ep33-xuguangqi），但定位从“徐光启这个人”改为“明朝的大炮这条线”：一条从浑河的火药一直走到浑河的金杯的线。

## 基本信息
- **选题缘由**：用户定下的系列结局是“明朝怎么输掉技术与军队”。课本里的晚明火器只有两张卡片：宁远大捷、红衣大炮。大众不熟的切入角度是：明朝其实买到了炮、学会了造炮、练成了炮兵，最后连炮带人送到了对面。这条线从 1621 年浑河边浙兵打光火药（EP28 结尾）开始，经过徐光启练兵买炮、宁远城头开炮、后金自己铸炮、孙元化登州练兵，到吴桥一只鸡引出的兵变、登州一夜易手、皇太极在浑河岸边亲手斟酒为止。
- **题型**：证据链拼接（正史、实录转引、当事人奏疏、今人档案研究分层交代）＋ 系列收束型（回扣戚家军的南兵、登州、车营、军法）
- **系列归属**：《笑谈历史》大明篇·晚明边防系列 5/5（EP25 戚继光上 → EP26 戚继光下 → EP27 李成梁 → EP28 戚家军的结局 → **EP29 大炮**）
- **时间跨度**：天启元年（1621）三月浑河之战、辽阳失陷 → （回溯）万历四十七年（1619）萨尔浒后徐光启请练兵 → 泰昌元年（1620）李之藻、杨廷筠捐资从澳门买回四门炮 → 天启元年徐光启力请多铸西洋大炮、去职 → 天启六年（1626）正月宁远 → 天启七年徐光启致友人信“仅得一二大炮置之边城” → 崇祯三年（1630）澳门炮师进京、孙元化任登莱巡抚 → 崇祯四年（1631）正月后金铸成红衣大炮、八月大凌河、同年徐光启疏“贼反用之”、闰十一月吴桥兵变 → 崇祯五年（1632）正月登州陷、四月徐从治在莱州中炮死、七月孙元化弃市 → 崇祯六年（1633）孔有德、耿仲明降金，皇太极浑河岸迎降；旅顺陷、黄龙死；十月徐光启卒 → 崇德元年（1636）三顺王

## 核心认知反差（生死线）
- **你以为的**：
  1. 明朝输给清朝，是因为技术落后，八旗骑兵打火器不行的明军；
  2. 宁远大捷说明明朝的红衣大炮管用，后来是袁崇焕死了才不行；
  3. 红衣大炮是清朝的东西（课本上“红衣大炮”是清朝叫法）。
- **实际上的**：
  1. 明朝的问题不是没有火器。1621 年浑河边，浙兵营火器打到火药用尽（#1）；徐光启当年就说，明朝把里外大小火器全送给了对方（#3）；
  2. 宁远之后，明朝把西洋炮、澳门教官、会造炮的人都凑齐了，在登州练出了一支当时人说的精兵（#27、#30），毁掉它的是欠饷、罢市、一只鸡、一次贯耳、一场主抚误判（#31–#34）；
  3. “红衣大炮”的“红衣”是清朝人的写法（通行说法，传说溯源 2）；后金 1631 年就自己铸成了“天祐助威大将军”（#21），1633 年孔有德又把十来门炮和一整套受过澳门教官调教的炮兵带了过去（#43），皇太极出城十里亲手斟酒（#42）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸“宁远大捷/红衣大炮” × 被忽略的十二年 × 首尾都在浑河的结构；扣一星是宁远一环要靠拼接、门数只能用约数）

## 核心问题（这期节目回答的一句话问题）
宁远城头的西洋大炮打赢过，明朝也学会了造炮、练成了炮兵；为什么短短六七年后，最好的炮和最会用炮的人都到了皇太极手里？

## 三大基因自检
- [x] **小切口**：崇祯五年春，莱州城下，叛军拉着孙元化造的西洋大炮日夜轰城；守城的山东巡抚徐从治留下文字说，从古到今没见过这么狠的红夷炮攻城，这些炮都是孙元化留给叛军的；四月，他在城上中炮身亡（#37、#38）。
- [x] **大纵深**：戚继光的南兵、车营、军法、登州卫，七八十年后在登州全部以另一种面目出现（#26、#29、#33、#36）；萨尔浒以后明廷的火器转向；澳门与白银时代（EP11 讲月港—马尼拉，未讲澳门，只作时代呼应）；后金的汉人工匠与汉军炮队；明清鼎革的一条导火线（#46）。
- [x] **人性内核**：一群人用十几年凑齐了人、炮、钱和教官，最后发现真正缺的是一支发得出饷、南北兵不互相拆台、上面拿得定主意的军队；而对面的人什么都不必发明，只需要在河边摆一桌酒。

## 内容弹药
- **主要素材**：《明史》卷23、92、212、248、251、259、270、271、326；《清史稿》卷2、231、234（正史，A）；徐光启奏疏书信、李之藻疏、徐从治文集、孙元化疏（《徐光启全集》《李之藻集》《徐忠烈公集》《明熹宗实录》《崇祯长编》，经肖清和 2024、黄一农 2012/2022 转引，B）；黄一农《吴桥兵变》（2012）、《红夷大炮与明清战争》（2022）；肖清和《徐光启练兵史论》（2024）（今人研究，B）；瞿式耜奏疏、柏应理《徐光启行略》（二手，C）。
- **两条系列暗线**：
  1. **戚家军线**：浑河浙兵打光火药（#1）→ 徐光启主张南兵守城、选兵标准被学者认为与戚继光相似（#8、#9）→ 车营思路（#26）→ 登州城下又是辽兵与南兵，辽兵一退南兵即败（#29、#34）→ 吴桥那次贯耳之刑写在戚继光的《练兵实纪》里（#33，限定说法）→ 登州本是戚继光世袭的卫所（#36）。
  2. **张焘线**（继承旧包）：替李之藻、徐光启去澳门买回第一批四门炮的人，十二年后在登州城外带的辽兵投了叛军，最后与孙元化同日被斩（#40，据学者考证）。
- **对照组**：1621 浑河边浙兵火药用尽战死（#1） vs 1633 浑河岸皇太极亲手斟酒迎降（#42）；徐光启练兵时“各部实无所出”（#7、#12） vs 皇太极让孔有德“号令、鼓吹、仪卫皆如旧”（#42）、三年后封王（#45）。
- **合法跑偏**：①红夷炮多是从广东沿海沉船里捞的（传说溯源 1）；②“红衣大炮”是清人写法（传说溯源 2）；③吴桥兵变的导火线据清代记载是一只鸡（#32）；④第一批四门炮买到了却停在广东，因为练兵衙门已经撤了（#10）。
- **梗与现代映射**：自掏腰包买设备、请外籍顾问，好不容易练出一个团队，结果因为欠薪和一次处罚整队跳槽，还带着设备去了竞争对手那边（只作比喻，不代替史实）。
