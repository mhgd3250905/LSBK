## 二、存疑与冲突（两说并陈）

1. **《杂事秘辛》是不是杨慎伪造**：沈德符（《野获编》卷23、《敝帚轩剩语》）、《四库提要》卷143 认定是杨慎伪作；胡震亨、姚士粦只证明它不是汉代作品；朱国伟（2012）认为是中晚唐小说。节目处理：沈德符、四库一方是“后辈判断 + 官方书目”，有动机证据（跋文刚好解决了他考不出的缠足问题），但没有直接证据（手稿、自承）；反方是今人研究，本组只见摘要。**不下定论**，大开说倾向，小李保留。
2. **得书来源的记载不一**：杨跋作“安宁州土知州董氏”，《提要》作“万氏”，沈德符作“托名王忠文得之土酋家”。三处说法不完全一致，作为小破绽可用，不作推论。
3. **他到底想证明什么**：杨慎自己的跋说东汉已有缠足；鲁迅说他是为了证明汉人的脚“底平趾敛”。原文并列，不判对错。
4. **出错是记性问题还是故意**：《提要》对同一个人同时给了两种解释——“恃其强识，不及检核原书”（疏忽）和“每说有窒碍，辄造古书以实之”（故意）；《正杨》提要又替他说“晚谪永昌，无书可检，惟凭记忆”。但 #26《石鼓文音释》自序在正德十六年，早于流放，所以“无书可检”解释不了全部。
5. **《廿一史弹词》写作年代**：通行说法是谪戍云南期间，未见可靠系年；江陵渔樵的创作故事无早期出处。
6. **晚年死所**：《明史》只记卒年；《尧山堂外纪》说病寓禅寺而没，属笔记，不用。

## 四、证据禁区

1. 不说“杨慎伪造了岣嵝碑”，不说《南诏野史》是他写的。
2. 不把《杂事秘辛》说成“已证实是杨慎伪造”，也不说“已证明清白”。
3. 不描写《杂事秘辛》的验身内容，不复述书中身体细节。
4. 不描写廷杖受刑细节，大礼议总时长压在 3 分钟以内，不重述 EP08 的君臣交锋。
5. 不编杨慎的心理活动和私下对话；王世贞对他纵酒的解读，只能作为王世贞的看法转述。
6. 不说《临江仙》是杨慎为三国写的，不说罗贯中写了这首词；不讲江陵渔樵故事为史实。
7. 不把“明代三大才子”“明朝第一才子”说成史书封号；《明史》原话是“记诵之博、著作之富，推慎为第一”。

## 五、关键引语（全部第三人称转述）

- 杨慎答注张 → 他说注张就是柳星，随手抄了《史记》《汉书》两条给内使带回去。
- 同僚玩笑 → 同事打趣他：说得这么博，不怕犯了私下钻研天文的禁令？
- 国家养士百五十年，仗节死义正在今日 → 他说朝廷养了读书人一百五十年，为气节去死，就在今天。
- 资性不足恃，日新德业当自学问中来 → 他说天分靠不住，长进只能从读书里来。
- 《提要》：每说有窒碍，辄造古书以实之 → 四库馆臣说，他的说法一旦卡住，就造一本古书出来给自己作证。
- 《提要》：铁中铮铮者 → 同一批馆臣也说，放在明朝，他仍是铁块里响当当的那一块。
- 沈德符：杨不过一时游戏，后人信书太真 → 沈德符说，杨慎不过是一时玩笑，倒是后来人太把书当真。
- 杨慎跋：言脱于口，追驷不及 → 他在跋里说，话一出口驷马难追，先记在这里，免得别人笑我疏漏。
- 草书百韵歌 → 他说孔子既然没写过《四书活套》，王羲之又哪来的《草书百韵》。

## 六、给写稿者的说明

- 全期主线：一首被搬了家的词 → 一个记性好到吓人的状元 → 一顿廷杖把他送到没有藏书楼的云南 → 四库馆臣给他的造假档案，分成记错、造书作证、说不清、被冤枉四层 → 一辈子跟他较劲的人和他自己的玩笑 → 七十岁被押回去、丹铅这个书名。
- 小李的独立立场：她自己算出《三国演义》和这首词差了一百多年；她抓住《石鼓文音释》自序早于流放，反驳“没书可查才出错”；她发现鲁迅和杨慎自己的跋方向相反；她坚持造假就是造假，不因为人惨就打折。
- 与 EP08、EP22 的口径：左顺门的人数、死伤沿用正史数字，与两期一致；EP08 台词里“滚滚长江是在发配云南的荒山野岭里写下”的说法本期不重复、不点名纠正，只按 #22 讲“系年不可考”。
