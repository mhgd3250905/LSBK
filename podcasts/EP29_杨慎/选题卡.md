# 选题卡：EP29《写出“滚滚长江东逝水”的明朝第一才子，为什么也是造假高手？》

> 2026-10-13 编写，依据明朝篇候选红队评审 C08（8 分，已核）。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：杨慎在 EP08《嘉靖大礼议》、EP22《张璁》里都以左顺门领头人的身份出场，但只是配角，观众对他的印象停在“被打、被流放的硬骨头”。红队指出两个风险：一是原切口（大礼议 + 流放）等于重播 EP08 的高潮；二是“三国开篇词不是罗贯中写的”知道的人已经不少，单靠它撑不起一期。真正冷门的是他另一张脸：明代记诵最博的人，同时被《四库提要》点名“每说有窒碍，辄造古书以实之”。
- **题型**：人物反差型 + 传说溯源（一首词的搬家史）+ 证据分级（造假指控的定论、存疑、冤枉分开讲）
- **系列归属**：《笑谈历史》第一季·大明篇，正德—嘉靖人物侧写
- **时间跨度**：弘治元年（1488）生 → 正德六年（1511）状元 → 正德十二年（1517）答“注张”、谏武宗出关 → 嘉靖三年（1524）左顺门、两次廷杖、戍永昌卫 → 谪戍三十五年 → 嘉靖三十八年（1559）卒 → 隆庆己巳（1569）陈耀文《正杨》→ 清初毛本《三国演义》把他的词放到卷首 → 乾隆《四库提要》下评语 → 1994 电视剧片头曲

## 核心认知反差（生死线）
- **你以为的**：
  1. “滚滚长江东逝水”是写三国的，可能就是罗贯中写的；
  2. 杨慎是大礼议里的忠臣、受害者，才子加硬骨头，人设干净；
  3. 古代大学者就算错，也只是记错。
- **实际上的**：
  1. 词是杨慎写的，原本是《廿一史弹词》第三段《说秦汉》的开场词，跟三国无关；一百多年后毛宗岗父子把它搬到了《三国演义》卷首；
  2. 同一个人，被《四库提要》写进评语：记性好、懒得翻原书，所以错得多；又好胜，说法卡住了就造一本古书来作证。最硬的一例是《石鼓文》七百零二字“全本”，而且时间在流放之前；
  3. 但指控要分层：《石鼓文》全本，四库认定是伪托；《杂事秘辛》是沈德符和四库认定、今人有反驳的存疑案；《南诏野史》则是别人借他的名字，他反倒是被冤枉的一方。
- **反差的强度自评**：⭐⭐⭐⭐（课本级熟脸词作 + 学术造假档案 + 证据分级的反转）

## 核心问题（这期节目回答的一句话问题）
一个记性好到能当场答出冷僻星名的状元，为什么会被后人记成明朝最会造假古书的人？这些指控里，哪些站得住，哪些是冤枉？

## 三大基因自检
- [x] **小切口**：正德十二年，皇帝看书看到一个叫“注张”的星名，钦天监答不出，翰林院面面相觑，杨慎随口说是柳星，还顺手抄了两条《史记》《汉书》。
- [x] **大纵深**：一首词从弹词到小说卷首再到电视片头的搬家史；明代考据学的竞争（《正杨》《正正杨》）；四库馆臣怎样给前朝学者下评语。
- [x] **人性内核**：记性、好胜和孤独怎样一起把一个人推向造假；被押回云南的七十岁老人，给自己的读书笔记起名叫“丹铅”。

## 内容弹药
- **主要素材**：《明史》卷192 杨慎传及赞、卷191 何孟春传、卷17 世宗本纪、卷190 杨廷和传（正史）；《四库全书总目提要》卷043、066、078、087、119、123、143、172（官修书目评语）；杨慎《廿一史弹词》、《杂事秘辛》跋（原书）；沈德符《万历野获编》卷23、焦竑《玉堂丛语》卷1、王世贞《艺苑卮言》卷6、蒋一葵《尧山堂外纪》卷95（笔记）；鲁迅 1933 杂文；朱国伟 2012 论文（今人研究）。
- **对照组**：①造假指控的三层（四库认定的《石鼓文》全本 / 有争议的《杂事秘辛》/ 被借名的《南诏野史》）；②《提要》同时给出的两种解释（记性靠不住 vs 故意造书作证）；③杨慎跋与鲁迅对《杂事秘辛》动机的两种说法方向相反。
- **合法跑偏**：①同僚打趣他答得这么博，不怕犯私习天文之禁；②《草书百韵歌》的玩笑：孔子既没写《四书活套》，王羲之哪来的《草书百韵》；③《正杨》之后还有《正正杨》；④电视剧片头曲的作曲、演唱一句带过。
