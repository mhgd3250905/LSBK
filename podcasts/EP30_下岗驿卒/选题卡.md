# 选题卡：EP30《李自成真是因为“下岗”才造反的吗？》

> 2026-10-13 立项，明朝篇·闯王李自成系列第 1 期（共 5 期）。事实依据与原文出处见同目录 `史料核对.md`（下称“核对表”，#编号对应），凡与之冲突处以核对表为准。

## 基本信息
- **选题缘由**：用户 2026-10-13 定下长线：李自成作为绝对主角，按他的人生顺着讲；要史诗感、趣味性、跌宕起伏；不必和课本强关联；张献忠只作穿插对照。本期是起点：一个陕北驿卒怎么成了“闯将”，又怎么一次次从必死的局面里活下来，直到上一任“闯王”被擒。
- **题型**：熟脸反差型（“下岗驿卒李自成”是课本和 EP15 里的熟脸）+ 证据链拆解（一个人的“下岗”，五本书五个版本）+ 绝境求生的连续剧
- **系列归属**：《笑谈历史》明朝篇·闯王系列 1/5（EP30 下岗驿卒的五次死而复生 → EP31 闯王的谷底 → EP32 河南一呼百万 → EP33 四十二天 → EP34 一片石到九宫山；之后接南明十八年长线）
- **时间跨度**：万历三十四年（1606）生于米脂 → 银川驿驿卒 → 崇祯初年米脂枷号、出逃、入伙（年份各书不一）→ 崇祯三四年号“闯将”→ 崇祯六年十一月武安诈降、黄河冰渡 → 七年车箱峡（汉中）诈降 → 八年正月荥阳“大会”（存疑）、凤阳、与张献忠结怨 → 八年渭南临潼大败、邢氏随高杰投敌 → 九年春朱龙桥大败、回米脂 → 九年七月高迎祥在盩厔被擒，闯王名号空出

## 核心认知反差（生死线）
- **你以为的**：
  1. 李自成是崇祯裁驿站裁下来的驿卒，丢了饭碗就造反了，一条线清清楚楚；
  2. “闯王”一开始就是李自成，他是高迎祥手下的大将；
  3. 起义军是一路打出来的，开过“荥阳大会”定下战略，凤阳挖祖坟是李自成干的。
- **实际上的**：
  1. 《明史》本传里根本没写他被裁，只写他犯法被知县抓了、差点处死、逃出去当了屠户（#6）；“丢公文”只是家乡县志里的一句（#8）；他怎么走上造反路，清初几部书有五个版本，有的说烈日下戴枷被乡亲救走（#12），有的说杀了与妻子私通的人跑去甘州当兵（#14、#18），史学家顾诚考证认为甘州兵变跟他毫无关系（#20）；
  2. 这时的“闯王”是他舅舅高迎祥，他叫“闯将”，按顾诚的研究两人各带一支、互不隶属（#21—#23）；
  3. 他前四次活命，至少两次靠的是“诈降”：黄河北岸跪地说“我们都是良民”，转身踏冰过河（#26、#27）；车箱峡（汉中）据《烈皇小识》按人头给总督送银子（《明史》作贿赂总督左右），出了栈道一夜把押送官全绑了（#30—#33）。“荥阳大会”只有一部书记载，主流认为是虚构（#37、#38）；凤阳那把火他在场，但谁领的头说不清（#42）。
  4. 双雄第一次翻脸，是为了一班会吹鼓手的小太监（#44）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸“下岗驿卒” + 五本书五个版本的悬疑 + 两次诈降的黑色幽默 + 闯王原来是另一个人）

## 核心问题（这期节目回答的一句话问题）
一个连自己怎么造反都说不清的陕北驿卒，凭什么在七八年里一次次死里逃生，活到了“闯王”这个名号空出来的那一天？

## 三大基因自检
- [x] **小切口**：米脂街头烈日下的一副枷，他自己扛着枷又坐回太阳里（#12）；黄河结冰的那一夜（#27）；一班吹鼓手小太监（#44）。
- [x] **大纵深**：裁驿与陕北大旱的结构背景（#7、#17）；明廷剿抚两手、招安制度的漏洞（每百人一个安抚官、皇帝亲批，#33、#34）；史料怎么生成：清初文人把传闻写进私史，再被《明史》采入（#37）。
- [x] **人性内核**：一个人在绝境里能屈到什么程度——跪地称良民、按人头送钱、家里人被自己的部将带走，第二天照样上马。
