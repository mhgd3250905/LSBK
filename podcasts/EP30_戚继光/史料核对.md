## 二、存疑与冲突（两说并陈）

1. **“一仗没打”是不是真的**：不是。《明史》记了万历元年喜峰口掩击董狐狸、擒长秃、炒蛮入犯汤克宽战死、援辽等（#15、#16）。准确说法：北方十六年没有大会战，《明史》原话是“北则专主守”（#17）。标题可以用，台词必须修正它。
2. **为什么没打大仗**：三种解释并存。
   - 《明史》：守得太固，敌人改去辽东（#17）；
   - 张居正：上级本来就要求拒守为主，贼不得入即为上功（#21）；
   - 戚继光自己和戚家：他想出塞、想援辽，是朝廷（政府）不批（#22、#23）。
   三者并不矛盾，但侧重不同。大开可以说自己的倾向，小李可以抓住“到底是不能打还是不让打”追问。
3. **戚继光和张居正的关系**：正史说倚任与庇护（#24）；王世贞说送千金姬（#25）；沈德符说岁献海狗肾、禀帖自称门下小的（#26、#27）；张居正书信里有退礼（#28）。送姬、送药两条都是与张居正有过节或隔代的晚明笔记，《明史》修史者显然读过王世贞却没采送姬一句。节目处理：依附关系是实的（书信、自称、半夜递信都有据），送姬送药存疑，各说一句不展开。
4. **王氏离去的出处**：红队复核点“出处是年谱还是笔记”——**答：出自汪道昆《墓志铭》**，属同时代老友所撰墓志，不是笔记，可信度较高；家属所编《年谱》卷十二对此只字未提，只有戚继光本人一句“乃出奇计，苦心万状”隐约对应（#22、#36）。网传“王氏休夫”“提刀闯军营”“戚继光跪地请夫人阅兵”“杀鸡炖汤”等细节，在《墓志铭》《年谱》卷十二、《野获编》中都没有找到，见第三节。
5. **晚年贫病的原因**：《明史》只说罢归、被荐反夺俸、遂卒；《墓志铭》说他岁散千金给门客，家计骤衰，延医无资（#37）。“两袖清风、无私报国”的说法见山东地方志网站引董承诏《戚大将军孟诸公小传》“四提将印……囊无宿镪，惟集书数千卷”（二手，未见原书）。节目说法：穷是真的，原因里有他自己好客散财的一部分。
6. **在镇年数**：《明史》《年谱》都说十六年，实际约十四年九个月（#24），按年号首尾虚算。
7. **去世日期**：蜡日两解，相差十二天（#38）；维基百科作十二月二十日（1588年1月17日），山东地情网取腊月初八（1588年1月5日）。台词只说腊月。
8. **雨中站立的年份**：两书未系年（#11）。
9. **调广东的推手**：《明史》只说张鼎思上言、当国者遽改；《年谱》《墓志铭》说是受过恩惠的裨将散布流言（#30、#31）。后者是戚家一方说法。

## 三、传说溯源

1. **“戚继光怕老婆”系列段子**（被部下撺掇召夫人进营示威、反而跪下说请夫人阅兵；拔剑闯卧室被喝问，改口说要杀鸡给夫人炖汤；提刀闯军营；王氏带兵守城）：
   - 能落到原始出处的只有两条：沈德符《野获编》卷五说他“为其妻所制”（#42）；汪道昆《墓志铭》的拿刀、穿甲、抱头痛哭（#36）。
   - 阅兵、杀鸡两个段子在已核材料中均未找到，最早出处不明，网文多称“野史”。台词**不用**，最多说一句网上流传的段子大多找不到出处。
   - 王氏守城一说（维基百科称1561年率兵守卫要塞）可能出自《年谱》前几卷，本次未核到，**不用**。
2. **“王氏只吃鱼头鱼尾”**：网文版本说她把鱼身留给丈夫、自己吃鱼头鱼尾。《墓志铭》原文是早上给丈夫鱼头、中午给鱼尾、晚上给鱼腹，她自己一直空着肚子，戚继光发现后才有“甘苦可无同乎”的对话（#35）。台词按墓志讲。
3. **“王氏休夫”**：这是现代网文的说法。原文只说她把积蓄装车运回娘家，没有休书、离婚的记载，台词不用“休夫”“离婚”这类词，说“带着家财回了娘家”。
4. **海狗肾、千金姬**：见第二节第3条，晚明笔记。

## 四、证据禁区

1. 不说“戚继光在北方一仗没打”是事实；不说他“被张居正雪藏”。
2. 不铺陈送姬、海狗肾、房中药；各一句、标明笔记、真伪存疑。
3. 不虚构王氏、戚继光的心理活动和私下对话；鱼的对话、拿刀的场面只能按墓志转述，并点明出自墓志。
4. 不把他的贫困全部归咎于朝廷；墓志自己写了散财。
5. 不把1629年大安口之变说成戚继光离任的直接后果。
6. 不重讲张居正的改革、夺情、抄家（EP06已讲），只用一两句交代张居正之死和清算的背景。
7. EP06第三幕台词里“言官弹劾戚继光、张居正把奏折全扣下”“戚继光开放互市、蒙古各部心服口服”两处，本次未找到对应史料（互市是隆庆五年俺答封贡，与戚继光无直接关系）。本期**不重复这两种说法**，也不在台词里点名纠正EP06，正面按本表讲即可。

## 五、关键引语（全部第三人称转述）

- 蓟门之兵，虽多亦少 → 他到任就上疏说，蓟门的兵看着多，其实等于少。
- 臣官为创设，诸将视为缀疣 → 他说自己这个官是新设的，下面的将领把他当成身上多长的一块肉。
- 一瑕则百坚皆瑕 → 二千里长的边墙，一处有破绽，其余一百处修得再结实也白搭。
- 贼不得入，即为上功；蓟门无事，则足下之事已毕 → 张居正写信说，敌人进不来就是头功；蓟门没事，你的差事就算办完了。
- 徒有封拜之具，无可措手之会 → 他晚年写给祖宗的祝文里说，自己手里攥着能换封爵的本事，却始终等不到下手的机会。
- 倭勣乃横草熟釜之功，边勣乃曲突徙薪之业 → 他儿子写道，打倭寇的功劳是踩倒一棵草、一锅饭工夫的事；北边的功劳是把烟囱改弯、把柴火挪开，让火根本烧不起来。
- 甘苦可无同乎 / 妾佚君劳，君良妾苦，礼也 → 他问妻子，你空着肚子成全我，甘苦怎么能不一起担；妻子说你辛苦我清闲，你吃好的我受苦，本来就是礼数。
- 囊括其所蓄，辇而归诸王 → 她把家里的积蓄全收拾起来，装上车，回了王家。
- 今国家太平……安所事武臣哉 → 回到老家，他对亲友说，如今天下太平，哪里还用得着武将。

## 六、给写稿者的说明

- 全期主线：课本里打倭寇的戚继光 → 后半生守在北京东北的蓟镇 → 他修台练车、敌人不来，战功跑去了辽东 → 不让打还是不能打 → 他的靠山张居正一死，他被调走、罢官 → 家里人也走了，穷病而终 → 儿子说父亲的功劳是曲突徙薪。
- 小李的独立立场：她自己掐出“十六年”是虚算；她算出李成梁封了伯、戚继光没有；她认为戚继光自称“门下小的”、半夜递信，是自己把自己绑在了张居正身上；她在王氏的事上站王氏一边。
- 大开的立场：在明代文官节制武将的体制里，武将要做事就得找靠山，十七年十将率以罪去就是不找靠山的下场；但他承认依附的代价是戚继光自己付的。两人在这一点上最后不统一。
- 与EP06的口径：EP06讲张居正支持戚继光守蓟门，本期从戚继光这边看同一段关系，侧重依附的代价，不重复张居正的改革内容。
