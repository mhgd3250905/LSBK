# 选题卡：EP30《打遍东南的戚继光，为什么在北方十六年没打出一场名战？》

> 2026-10-13 按明朝篇批量选题（红队评审 C11，8 分）立项。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：课本里的戚继光停在嘉靖年间的台州、福建；他后半生在北京东北的蓟镇守了十六年，这段大众几乎不知道。EP06 讲张居正时只用一句话带过“全力支持戚继光守边”，这期从戚继光这一边，把这段将相关系和它的代价讲完整。
- **题型**：人物反差型（前半生名战 vs 后半生无名战）+ 证据链辨析（正史、墓志、年谱、笔记并陈）
- **系列归属**：《笑谈历史》第一季·大明篇，嘉靖—万历武将侧写
- **时间跨度**：嘉靖二十九年（1550）庚戌之变，二十出头的戚继光在京城应武举 → 隆庆二年（1568）五月总理蓟州练兵 → 隆庆五年（1571）秋敌台工成 → 万历元年（1573）喜峰口掩击董狐狸 → 万历十年（1582）六月张居正卒 → 万历十一年（1583）二月调广东 → 万历十三年（1585）罢归登州 → 万历十五年（1587）腊月卒 → 余波：1620年幼子作跋；1629年大安口

## 核心认知反差（生死线）
- **你以为的**：
  1. 戚继光就是抗倭英雄，一辈子在海边打仗；
  2. 名将的价值看打赢了几场大仗；
  3. 他和张居正是一段将相佳话，晚年凄凉只是被小人陷害。
- **实际上的**：
  1. 他人生最长的一段差事在北方：十六年（虚算）守蓟镇，修敌台、练车营；
  2. 这十六年没有一场名战，《明史》的解释是守得太固，敌人改去了辽东，战功归了李成梁；张居正写信说，贼进不来就是头功；戚继光自己晚年却说，他有封侯的本事，没有下手的机会；
  3. 他和张居正的关系近到禀帖自称门下小的、半夜递信；靠山一倒，他半年后就被调走，再两年罢官。家里，据汪道昆墓志铭，妻子王氏在过继的儿子夭折后，把家中积蓄装车运回了娘家；墓志接着写他每年散千金给门客、罢归后家计骤衰，到请医生都没钱（墓志把这段放在罢归登州之后叙述，确切年份不详）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 什么都没发生才是战绩 + 依附的代价）

## 核心问题（这期节目回答的一句话问题）
一个最会打仗的将领，为什么把后半辈子最好的成绩，做成了“什么都没发生”？这份成绩又为什么换不来他想要的东西？

## 三大基因自检
- [x] **小切口**：三千浙兵在蓟镇城外的大雨里，从早上站到过了中午，一动不动。
- [x] **大纵深**：庚戌之变后的京畿防务、十七年十将的困局、敌台与车营、明代考核武将的账本、文官节制武将的体制、首辅倒台后的清算。
- [x] **人性内核**：做成了预防的人怎么证明自己的功劳；靠一个人才能做成事，代价由谁付；英雄回到家里也有欠下的账。

## 内容弹药
- **主要素材**：《明史·戚继光传》卷212（含赞）；《明史·张居正传》卷213、《谭纶传》卷222；汪道昆《孟诸戚公墓志铭》；戚祚国等《戚少保年谱耆编》卷十二（含孝思祠祝文、戚兴国跋）；张居正书牍《答总兵戚南塘授击土蛮之策》（附张懋修按语）、《答蓟镇总兵戚南塘计边事》、《答总兵戚南塘》；王世贞《嘉靖以来首辅传》卷七；沈德符《万历野获编》卷五、十七、二十一。
- **对照组**：戚继光（守住了，没首级）vs 李成梁（敌人转去辽东，封了伯）；他到任前十七年十位大将率以罪去 vs 他在镇十六年；《明史》删掉的王世贞半句话。
- **合法跑偏**：①“封侯非我意，但愿海波平”这句课本诗，他后来真的没封侯；②戚兴国把父亲的北边功劳比作曲突徙薪（劝人把烟囱改弯的人没被请上酒席的典故）；③沈德符把戚继光列进晚明“惧内”名人榜，和王阳明并列；④网传怕老婆段子大多找不到出处。
