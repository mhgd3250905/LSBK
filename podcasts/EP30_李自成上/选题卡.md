# 选题卡：EP30《李自成上：戴死囚大枷、破窑拔刀杀人，一个穷汉是如何熬死大明十面罗网的？》

## 基本信息
- **选题缘由**：承接晚明边防系列（EP25~EP29）之后明朝精锐与防线崩溃的大背景。作为第一季明朝篇终局大戏的开篇，以李自成为第一视角的绝对主角。本期不神化也不丑化，以“底层小人物在死局里一次次死而复生”为主线，彻底解构民间文学编织的“下岗起义”与“十八骑”神话。
- **题型**：熟脸认知反差型（课本下岗驿卒 vs 正史从无记载、清初五部书五种传说；悲壮十八骑 vs 档案里一路掉队的一千人）+ 绝境求生辨析
- **系列归属**：《笑谈历史》大明篇·闯王三部曲 1/3（EP30 起家与谷底 → EP31 河南一呼百万 → EP32 登顶与覆灭；后续衔接南明四重奏 EP33~EP36）
- **时间跨度**：万历三十四年（1606）米脂出生 → 崇祯初年枷号出逃 → 崇祯四年号闯将 → 崇祯六年十一月武安诈降黄河冰渡 → 崇祯七年车箱峡受抚突围 → 崇祯八年凤阳大火与张献忠为吹鼓手翻脸 → 崇祯九年七月高迎祥在盩厔被擒，闯王名号空出 → 崇祯十一年杨嗣昌十面之网与孙传庭真聋下狱 → 崇祯十三年小庙三卜，轻骑入豫。

## 核心认知反差（生死线）
- **你以为的**：
  1. 李自成是崇祯裁撤驿站被下岗的失业职工，丢了铁饭碗走投无路才揭竿而起；
  2. 李自成一开始就是“闯王”，带着兄弟们所向披靡；
  3. 起义军靠战无不胜打天下，潼关战败后“十八骑入商洛山”卧薪尝胆。
- **实际上的**：
  1. 《明史》本传里压根没写他“被裁员下岗”，只写他犯法被捕、险些处死、逃亡当了屠户；清初五部书记载了五个不同版本（县志丢公文 / 《荒书》骑死驿马 / 《绥寇纪略》欠债通奸 / 《明史》屠户 / 顾诚考证的大旱饥民裹挟）；
  2. 此时真正的闯王是舅舅高迎祥，李自成只是“八队闯将”，各带各的兵，互不隶属；
  3. 他前期活下来至少两次靠“诈降”黑色幽默：武安跪在黄河北岸高呼“我们都是良民”，趁夜踏冰过河；车箱峡按人头送五十两银子给官军，出了栈道一夜把押送官全绑了；
  4. “十八骑入商洛山”纯属清初文人小说演义，作家姚雪垠坦承小说沿用了民间传说，明朝兵部档案里实际是他带了一千多人一路被追杀、一路掉队；
  5. 最终救了他的不是深山练兵，而是清军入塞逼得明朝两线作战、崇祯自己把十面之网给撤了。

## 核心问题（这期节目回答的一句话问题）
一个连自己怎么造反都说不清的底层驿卒，凭什么在整整十二年里一次次死里逃生，活成了明朝官僚系统怎么也掐不死的梦魇？

## 三大基因自检
- [x] **小切口**：米脂街头烈日下的一副木枷，他自己扛着枷又坐回太阳底下；黄河结冰那一夜的“我们都是良民”；一班吹鼓手小太监让双雄彻底决裂；路边荒庙里的三卜三吉。
- [x] **大纵深**：明末陕北旱荒与流民机制；明朝“剿抚两手”在官僚执行中的巨大漏洞（按人头给总督送银子、每百人派一个文官）；杨嗣昌四正六隅十面网的理想主义与财政死穴；明朝两线作战自己松手。
- [x] **人性内核**：一个人为了活命能屈伸到何种地步——跪地称良民、按人头买路、妻子部将背叛投敌，第二天照样骑马上路。
