## 二、存疑与冲突（两说并陈）

1. **落榜与拒绝的因果**：《明史》把“谢弗往”与“懋学遂与居正子嗣修偕及第”“显祖至万历十一年始成进士”连写，读来像因果，但没有写“因此被黜”；邹迪光、钱谦益也只写拒绝和名声更大，没写考官受命压他。张居正是否真的干预了汤显祖的卷子，**没有任何直接证据**。节目说法：拒绝是真的，落榜也是真的，两件事之间的线是后人（包括《明史》的写法）连起来的。小李可以抓这一点。审稿补：《明史》原句“显祖谢弗往，懋学遂与居正子嗣修偕及第。显祖至万历十一年始成进士”，“遂”字只管沈懋学，不管汤显祖落榜；汤显祖本人《寄江陵张幼君》对张家毫无怨言，也从没说过自己被张居正黜落。
2. **奏疏年份**：《明史·汤显祖传》系于万历十八年；《神宗本纪》彗星敕修省、夺言官俸一年在十九年闰三月；进士同年录（二手）记辛卯（十九年）降徐闻；疏中自称“陛下御天下二十年”，十九年更接近。**审稿补两条本人旁证**：诗集卷十四《漫书所闻答唐观察》有“一疏春浮瘅海涯”（疏上在春天，与十九年闰三月合）；《寄江陵张幼君》说“辛卯中冬……握语雷阳”（十九年冬已在雷州）。节目用**万历十九年（1591）**，不提“十八年”。
3. **第二次拒绝（庚辰）与拒张四维、申时行**：“拒”只见邹迪光、钱谦益（钱多半采邹或同源），《明史》不载。说法必须带出处。正史与本人旁证只能证明背景：张家公子庚辰两次登门（本人尺牍 #8）；张、申两相之子确为癸未同年（《魏允贞传》#15a）。
4. **陪考的是哪个儿子**：钱谦益说沈懋学与懋修同榜，错；《明史》《选举志》《状元图考》均为嗣修（丁丑）、懋修（庚辰）。
5. **张家那位亲戚**：钱谦益作“叔”，今人研究认为是张居谦（二手）。台词说“张家一位亲戚”。
6. **纵囚年份与人数**：本人诗文没有年份。诗集卷十四的排列是《平昌河桥纵囚观灯》《平昌君子堂》《除夕遣囚》，后接“甲午秋”一首，推测在万历二十一至二十二年（1593–1594）前后，**存疑**，台词说“在遂昌的某一年”。“放了三十多个”“正月初四全部回来、无一人逃”是今人通俗文章说法，未见原始出处，见第三节，**不用**。
7. **被夺官的年份**：《明史》“又明年大计”字面不清；邹、钱作辛丑（1601）。用1601。
8. **享年**：钱谦益六十八；按生卒推算虚岁六十七。不报。

## 四、证据禁区

1. 不说“张居正下令黜落汤显祖”。
2. 不虚构汤显祖与张家使者、与申时行父子、与囚犯的对话或心理活动；唯一可用的“话”是传记和本人诗文里记下的那几句，一律第三人称转述并说出处。
3. 不说申时行是被汤显祖一道奏疏扳倒的。
4. 不把纵囚写成“全县轰动、朝廷震动、无一人逃跑”；不写囚犯人数。
5. 不把《牡丹亭》剧情硬套到汤显祖的仕途上（比如说杜丽娘就是他自己），可以由小李提出一个类比，大开说这是读法而非史实。
6. 莎士比亚只说一句，不做中西比较。
7. 张居正、申时行不脸谱化：张居正的改革功过以 EP06 为准，本期只看他作为父亲安排儿子科举这一件；申时行“柔而多欲”是汤显祖的指控，不是史家定论。

## 五、关键引语（全部第三人称转述）

- 邹迪光：吾不敢从处女子失身也 → 他说，让我去依附，就像让一个姑娘失身，这种事我不敢。
- 邹迪光：假令予以依附起，不以依附败乎 → 他感叹，我要是当年靠攀附爬上去，现在不也跟着一起倒了吗。
- 奏疏：前十年之政，张居正刚而多欲……后十年之政，时行柔而多欲 → 他说皇上在位二十年，前十年被张居正弄坏了，那是个强硬又贪心的人；后十年被申时行弄坏了，这是个软和又贪心的人。
- 寄姜耀先：兄谓纵囚观灯，恐有得间者，良然 → 朋友担心放囚犯看灯会有人趁机溜走，他回信说你说得有道理，然后反问对方肯不肯也放开一点。
- 除夕遣囚：须归拜朔迟三日 → 回去拜年，晚三天再回来。
- 辛丑大计主者：正欲成此君之高耳 → 主事的人说，我们正是想成全他的清高。
- 谢李三才：身与公等比肩事主，老而为客，所不能也 → 他说我跟你们一样都是给皇上做事的人，老了跑去给人当门客，我做不到。
- 题词：情不知所起，一往而深 → 课本名句，可原样说出这八个字（不加引号），其余转述。

## 六、给写稿者的说明

- 全期主线：一个写情最深的人 → 二十多岁连拒首辅之子的邀请，落榜 → 首辅死了，他中了，后来的首辅又来拉，他又不去 → 一道奏疏把两任首辅一起点名，被扔到天涯海角 → 在遂昌放囚犯回家过年 → 弃官、写《牡丹亭》、被正式夺官 → 草鞋麻衣入殓。
- 小李的独立立场：她抓出“拒绝”和“落榜”之间没有直接证据；她认为不去应酬不一定是气节，也可能是他算准了（汤显祖自己那句“以依附起，以依附败”就是证据）；她觉得放囚观灯是拿全县安全冒险，朋友姜耀先也这么担心。
- 大开的立场：1577 年张居正如日中天，没人能算到五年后的抄家，所以第一次拒绝很难说是算计；但他承认后几次拒绝里有“看清了”的成分。
- 与 EP06 张居正篇、EP23 唐伯虎科场案的口径：张居正夺情、吴中行赵用贤廷杖见 EP06；“首辅之子中第”与 EP23“大臣与举子走动”可遥相呼应，只点一句，不复述。
