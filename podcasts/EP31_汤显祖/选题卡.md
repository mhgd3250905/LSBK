# 选题卡：EP31《写出“情不知所起”的汤显祖，为什么敢连拒三位首辅？》

> 2026-10-13 依明朝篇红队评审 C14（8 分，推荐 10 期之第 7 期）立项编写。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：大明篇已用 EP05~EP07 讲透徐阶、张居正、高拱三任首辅，EP06 从正面讲张居正的十年。万历朝缺一个“从下往上看首辅”的视角。汤显祖是高中课本里的熟脸（《牡丹亭·游园》、情不知所起一往而深），他的科场和官场又恰好撞上张居正、张四维、申时行三位首辅，正合“名人之间的交互和斗争”。
- **题型**：人物反差型 / 名场面辨析型（正史、同时代传记、本人诗文三方对照）
- **系列归属**：《笑谈历史》第一季·大明篇，万历篇（文人侧写）
- **时间跨度**：隆庆四年（1570）中举 → 万历五年（1577）丁丑、八年（1580）庚辰两次拒张家邀请、落第 → 万历十年（1582）张居正卒 → 万历十一年（1583）中进士、拒张四维申时行两相之招 → 万历十九年（1591）《论辅臣科臣疏》、谪徐闻 → 万历二十一年（1593）知遂昌、除夕遣囚元宵纵囚 → 万历二十六年（1598）投劾归、《牡丹亭》题词 → 万历二十九年（1601）辛丑大计被夺官 → 万历四十四年（1616）卒于临川

## 核心认知反差（生死线）
- **你以为的**：
  1. 写《牡丹亭》的人，是个柔情才子、恋爱专家；
  2. 才子考不上，是文章不合考官口味，或者运气不好；
  3. 敢跟首辅对着干的，都是海瑞那样的言官铁头，跟写戏的文人不沾边。
- **实际上的**：
  1. 二十多岁名满天下的举人，被当朝首辅张居正派人请去给儿子“陪考”，他不去；三年后张家三公子亲自带人来，他还是不去，说这跟姑娘失身一个道理（邹迪光）；
  2. 他两次落榜、首辅一死就考中——但《明史》只把这几件事写在一起，从没说张居正动了他的卷子。因果是后人连上的；
  3. 首辅死了，他中了进士，新的两位宰相通过儿子来拉他入幕、许他进翰林，他又不去；八年后一道奏疏，把前十年的张居正和后十年的申时行一起点名，说一个强硬而贪心、一个软和而贪心，被皇帝扔到雷州半岛当典史；后来当县令，除夕把犯人放回家过年。写“情不知所起”的人，官场上最硬。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 三位首辅 + 一个可以拍成电影的除夕监狱）

## 核心问题（这期节目回答的一句话问题）
一个只想好好考试、好好做官的才子，为什么一次次把首辅递过来的梯子推开？他推开之后，又拿自己这一辈子换来了什么？

## 三大基因自检
- [x] **小切口**：遂昌县衙，除夕夜，知县把犯人放回家过年，写诗说拜完年晚三天回来；元宵又把他们放出来上河桥看灯，朋友写信担心有人趁机跑掉。
- [x] **大纵深**：张居正时代首辅之子连中榜眼状元、御史因此被贬；张居正死后的清算；申时行时代“柔”的官场生态和一批言官相继被贬（《明史》卷230 整卷几乎都是弹劾申时行的人）。
- [x] **人性内核**：拒绝的代价有多大、拒绝里有没有算计；一个人在官场越硬，在戏里为什么越软。

## 标题候选（九型公式选优）
1. （熟脸 + 反转问句）《写出“情不知所起”的汤显祖，为什么敢连拒三位首辅？》（**主选**）
2. （红队原方向）《写出“情不知所起”的汤显祖，为什么敢连拒两任首辅？》
3. （名场面悬念型）《除夕把犯人放回家过年的县令，写出了《牡丹亭》》

> 主选改“三位”的理由：据邹迪光、钱谦益，癸未年来拉拢他的是时相张四维、申时行两家（据《神宗本纪》，万历十一年三月庚子放榜，四月丁巳张四维以忧去，申时行接任首辅；两相之子确为同年，见《明史·魏允贞传》），连同张居正一共三位当过首辅的人；“两任”说法也不算错（张居正、申时行），故列为备选。平台短标题建议：《连拒三位首辅的汤显祖》；封面主标题：`连 拒 首 辅 的 汤 显 祖`。

## 印章拟定
- **印章四字**：`一往而深`（出自汤显祖《牡丹亭记题词》“情不知所起，一往而深”，作于他弃官当年的万历戊戌秋；既是名句，也概括他做人做官一条路走到底的脾气）
