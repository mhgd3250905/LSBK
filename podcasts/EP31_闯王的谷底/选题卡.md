# 选题卡：EP31《李自成真的只剩“十八骑”吗？他最落魄的两年，是谁给了他活路》

> 2026-10-13 立项，明朝篇·闯王李自成系列第 2/5 期（闯王的谷底，1636–1640）。事实依据与原文出处见同目录 `史料核对.md`（下称“核对表”，#编号对应），凡冲突以核对表为准。系列总纲：`/workspace/work/arc_chuangwang/李自成_摸排.md`（摸排报告 EP-B）。

## 基本信息
- **选题缘由**：用户定调这条长线要史诗感、趣味性和跌宕起伏，李自成是绝对主角，顺着他的人生讲。第二期是他人生的谷底：刚接过闯王名号，就撞上杨嗣昌的十面网，一路掉人掉到几百人，前线以为他死了。这一段史料最薄，最流行的“十八骑入商洛山”恰恰是证据最弱的部分——正好把弱点做成卖点，用“史书说／小说说”把这件事从源头拆开。
- **题型**：人物低谷型（主角跌到底再爬起）+ 史源辨析（一件事的五种写法）+ 对照（同一时段的张献忠受抚）
- **系列归属**：《笑谈历史》明朝篇·闯王李自成系列（5期）第 2 期。下接 EP32 河南一呼百万。
- **时间跨度**：崇祯九年（1636）七月高迎祥被擒、李自成被推为闯王 → 崇祯十年（1637）三月杨嗣昌到京、十面张网、十月李自成入川 → 崇祯十一年（1638）出川、马坞三百人、城固一千四五百人；张献忠谷城受抚；九月清兵入塞；“潼关南原”（日期各书不一）；十一月罗汝才受抚 → 崇祯十二年（1639）正月洪承畴、孙传庭北调；五月张献忠谷城再反、孙传庭下狱；六月加练饷；七月罗猴山；杨嗣昌督师 → 崇祯十三年（1640）鱼复山被围（年份各书不一）、出山入河南；河南旱蝗、斛谷万钱；十二月破宜阳、永宁（只到“饥民附之”）。

## 核心认知反差（生死线）
- **你以为的**：
  1. 李自成潼关大败，带着十八骑钻进商洛山，在深山里卧薪尝胆两年，然后杀出来；
  2. 他能翻身，是因为他自己够硬；
  3. 明朝镇压农民军，是一直在打、越打越弱。
- **实际上的**：
  1. “十八骑”最早成形于清初私家史书《绥寇纪略》，名单只开了九个名字，藏身处写的是崤函而不是商洛；同一部《明史》，本纪说十月、“数骑”，列传说春天、“十八骑”；把这个故事写进千家万户的姚雪垠，自己在前言里说这一仗“根本没有发生过”。档案里能看到的谷底更琐碎：四月剩三百人，八月剩一千四五百人，前线一度报他死了（#20–#35）；
  2. 他能喘过气，很大一块是明朝自己松了手：清兵入塞，网的两根大绳洪承畴、孙传庭被调走；孙传庭说这是“替贼撤兵”，急聋了耳朵，还被说成装聋，连查验的人一起下狱。《明史》原话：二人去，自成稍得安（#47–#53）；
  3. 那两年明朝最得意的不是打，是招安：张献忠在谷城盖房种麦，熊文灿下令“杀贼者偿命”、送酒肉去“求贼”；崇祯说盖房种地正是招安的好处——直到张献忠再反（#36–#46、#55）。
- **反差的强度自评**：⭐⭐⭐⭐（课本/小说熟脸“十八骑” + 史书互相打架 + 名场面“真聋下狱” + 主角在自己的故事里几乎消失了两年）

## 核心问题（一句话）
一个刚当上闯王的人，怎么在两年里被撵到只剩几百人、被人当成死了，又活着走进了河南？是谁给了他这条活路？

## 三大基因自检
- [x] **小切口**：一座路边小庙，两个人，三次占卜（#65）；礼县马坞，三百人，追兵四五十里外歇了一天（#20）。
- [x] **大纵深**：杨嗣昌的“安内攘外”与十面网、剿饷练饷、清兵入塞造成的两线作战、主抚与主剿之争、清初史书如何填补史料空白。
- [x] **人性内核**：人在谷底靠什么撑着（史书给的答案是一次占卜）；朝廷宁可相信一个人装聋，也不肯相信撤兵会出事；故事讲得越悲壮，离档案越远。

## 标题候选（熟脸 + 认知反转问句）
1. 《李自成真的只剩“十八骑”吗？他最落魄的两年，是谁给了他活路》（**主选**。“十八骑”是熟脸，问句本身就是本期的辨析；“谁给了他活路”指向孙传庭北调与“二人去，自成稍得安”，不说“明朝故意放走”）
2. 《“十八骑入商洛山”，写进小说的人自己说没打过？》（备选，偏史源辨析；姚雪垠原话是“根本没有发生过这次战争”，标题用问句，避免替他扩大）
3. 《李自成最惨的时候，为什么有人急聋了耳朵？》（备选，偏名场面；主角不在标题里，作平台短标题更合适）

## 印章拟定
- **印章四字**：`三卜三吉`（出自《明史·李自成传》“宗敏諾，三卜三吉”，即冷开场；**史源是《绥寇纪略》一系，属“史书这样写”，非档案**）

## 内容弹药
- **主要素材**：《明史》卷23、24 本纪，卷252 杨嗣昌传，卷260 熊文灿传，卷262 孙传庭传，卷309 李自成传、张献忠传；吴伟业《绥寇纪略》卷六、八、九；戴笠、吴殳《怀陵流寇始终录》卷首、卷十一、卷十三；顾诚《明末农民战争史》第四章第六、七节，第五章，第六章第二、三节，第七章第一节（转引洪承畴题本等档案）；姚雪垠《李自成》第一卷前言（经维基百科转引）。
- **对照组**：小说“十八骑商洛”vs 档案“三百人、一千四五百人”；《明史》列传“春、十八骑、商洛”vs 本纪“十月、数骑”vs《绥寇》“十月、九个名字、崤函”；张献忠受抚盖房种麦 vs 李自成被以为死了；悬赏张献忠万金 vs 张献忠悬赏督师三钱；孙传庭“真聋”vs 杨嗣昌“装聋”。
- **合法跑偏**：①熊文灿酒后吹牛撞上皇帝的探子（#14）；②庐山和尚的预言（#15）；③“求贼”（#42）；④张献忠是十八个死囚里唯一活下来的（#37，点到为止）；⑤“恨用卿晚”（#7）。
