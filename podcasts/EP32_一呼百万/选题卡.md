# 选题卡：EP32《“迎闯王，不纳粮”：不到一千人进河南的李自成，凭什么三年拉起百万大军？》

> 2026-10-13 编写。闯王系列（李自成长线）第 3 期 / 共 5 期。事实依据见同目录 `史料核对.md`（#1–#55），凡冲突以史料核对为准。系列总纲见工作区 `arc_chuangwang/李自成_摸排.md`（EP-C）。

## 基本信息
- **选题缘由**：用户定下的系列是李自成的人生长线，要史诗感和跌宕。前两期是“五次死而复生”和“谷底”，这一期是整条线的第一次大翻盘：崇祯十三年秋带着不到一千人钻出鄂豫陕交界的大山（#4），三年后进西安、开国号（#52、#55）。课本只给了一句“迎闯王，不纳粮”和“百万之众”，大众不熟的是中间这三年怎么滚起来的：洛阳的城门是明朝自己的兵打开的（#13），开封三次没打下、最后被黄河淹了（#21–#31），明朝最后一支能打的陕西兵两次被雨和粮道拖垮（#34、#50），盟友在一场宴会后被吞并（#39）。
- **题型**：战争史诗（洛阳—开封—郏县—潼关四场大戏）＋ 两个悬案拆解（李岩是否存在、黄河谁决的）＋ 一个野史拆解（福禄酒）
- **系列归属**：《笑谈历史》大明篇·闯王系列 3/5（EP30 下岗驿卒的五次死而复生 → EP31 闯王的谷底 → **EP32 河南一呼百万** → EP33 四十二天 → EP34 一片石到九宫山）
- **时间跨度**：崇祯十二年（1639）谷城再反（一句承接）→ 十三年（1640）秋入河南、十二月破宜阳永宁 → 十四年（1641）正月洛阳杀福王、二月首攻开封、九月项城杀傅宗龙、十二月二攻开封 → 十五年（1642）二月襄城杀汪乔年（此前汪掘李氏祖坟）、四五月三攻开封、七月朱仙镇、九月十五黄河决口、十月柿园一败孙传庭、十二月入襄阳 → 十六年（1643）正月承天、三月杀罗汝才贺一龙、襄京建制、八月孙传庭出关、九月郏县二败孙传庭、十月潼关孙传庭死、入西安、回米脂封祖坟 → 十七年（1644）正月初一西安国号大顺（结尾）

## 核心认知反差（生死线）
- **你以为的**：
  1. 李自成靠军师李岩编的一句“迎闯王，不纳粮”，一呼百应，百万农民跟着他打天下；
  2. 农民军攻城略地势如破竹，福王被他煮成了“福禄宴”；
  3. 开封是李自成挖开黄河淹掉的。
- **实际上的**：
  1. 这句歌谣有三个出处：正史说是李岩编的，同时代的张岱说是老百姓自己唱的，计六奇又说是大顺军派人散布的（#9）；而那个李岩，当时在起义军里待过的河南人郑廉说根本没这个人（#8）。真正把人推过去的，是斛谷万钱的大旱（#3）、官军“打粮”和官府催粮（#9 张岱）、王府里堆着的钱（#12），以及起义军后来真的宣布不征粮、发牛种（#43，明朝官员自己的奏疏）。
  2. 洛阳不是打下来的，是守城的明朝官兵饿着肚子、半夜从城头和城外的人说笑，然后开了北门（#13）；“福禄宴”越传越肥，同一部《明史》两处说法打架，出土圹志说福王尸骨下葬了（#16）。李自成在河南三年，开封打了三次都没打下（#21、#27、#28）。
  3. 黄河是谁决的，至今是悬案：清修《明史》本纪说是“贼”，同书两篇列传说双方都挖了，顾诚认为是明朝官员（#30）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸“迎闯王，不纳粮” × 李岩悬案 × 洛阳开城门的冷开场；扣一星是三年里战役密集，叙事要靠剪裁，且两个悬案都不能给定论）

## 核心问题（这期节目回答的一句话问题）
一个带着不到一千人钻出大山的“流贼”头目，凭什么在饥荒的河南三年滚成号称百万的大军，还把明朝最后一支能打的军队送进了坟墓？

## 三大基因自检
- [x] **小切口**：崇祯十四年正月，洛阳。过路的援兵在街上嚷嚷：王府里钱有百万，却叫我们饿着肚子去死。几天后的半夜，总兵王绍禹的亲兵在城头和城外的起义军说说笑笑，挥刀砍了守垛口的人，烧了城楼，打开北门（#12、#13）。歌谣里唱“开了城门迎闯王”，洛阳这扇门是明朝自己的兵开的。
- [x] **大纵深**：万历朝国本之争留下的福王庄田（#11）；明末大旱与河南诸藩；黄河与开封城（宋汴都、金人重筑，#27）；明朝最后的野战军（孙传庭的秦兵，#47–#51）；向后埋下福王世子朱由崧（弘光帝，#14）与南明长线。
- [x] **人性内核**：饿肚子的人会给开门的人开门。同一个李自成，一面不好酒色、和士兵同吃粗粮（#40），一面“守一日杀十之三”（#41）、宴会上吞并盟友（#39）；对面的孙传庭明知这一去回不来，还是被催出了潼关（#47）。

## 内容弹药
- **主要素材**：《明史》卷24、116、120、262、267、309（正史，A）；郑廉《豫变纪略》、张岱《石匮书后集》、李永茂题本等（经顾诚转引，B）；顾诚《明末农民战争史》第七、八、十章，《李岩质疑》（今人研究，B）；陈生玺《再论李岩其人》、戴福士《李岩故事的起源》（今人研究，B）；彭孙贻、计六奇、吴伟业笔记与福王圹志报道（C，只用于拆解）。
- **系列暗线：祖坟**：EP30 李自成在凤阳烧了朱家祖陵 → 本期崇祯十五年汪乔年奉诏挖了李家祖坟、奏报写得神乎其神（#25）→ 李自成到承天想挖嘉靖父母的陵、没挖成（#37）→ 进陕西后回米脂把祖坟重新堆起土（#54）。由小李自己认出“又是挖坟”。
- **两个悬案（“史书说／小说说”环节，本系列固定动作）**：①李岩是谁（#7、#8、史料核对第二节第 5 条）；②黄河谁决的（#30、第二节第 3 条）。外加一个野史拆解：福禄酒越传越肥（#16）。
- **张献忠穿插（不单独成段）**：①同一个多月里，他在襄阳杀了襄王、李自成在洛阳杀了福王（#20）；②罗汝才原是张献忠的搭档，后来跟了李自成、被李自成杀掉（#23、#39）；③李自成派人威胁他“下一个就是你”，张献忠南下长沙（#44）。
- **对照组**：洛阳北门（明军开）vs 西安东门（明将王根子开，#52）；福王“日闭阁饮醇酒”（#12）vs 李自成“脱粟粗粝，与其下共甘苦”（#40）；开封围城时“河鱼腹中”的告示（#28）vs 九月十五的大水（#30）。
- **回收点**：《明史》说射瞎李自成左眼的是陈永福，两年后陈永福据山不敢下，李自成折箭为誓招降了他（#22、#53，限定为“按《明史》的说法”）。
- **合法跑偏**：①宋献策个子只有三尺多（#6，正史说法）；②李自成攻城不用云梯，让每个兵去城下抠一块砖（#27）；③开封淹了以后，崇祯朝还商量过去水里捞银子，批示“宜专官密行”（#32）；④孙传庭的兵饿到摘青柿子吃，河南人管那一仗叫“柿园之役”（#34）。
- **梗与现代映射**：同一句广告语有三个“原创作者”认领（只作比喻，不代替史实）。

## 选题评分（对抗自审后）
- **8/10**。加分：冷开场正史有据、和课本那句歌谣直接咬合；三年里四场大戏（洛阳、开封、郏县、潼关）都有正史支撑；两个悬案史源清楚、正反证据都有名有姓，正好做“史书说／小说说”；祖坟暗线把 EP30 与本期串起来；张献忠三次穿插都有正史原文。扣分：事件密度太高，开封三攻和孙传庭两败必须大幅剪裁，否则成编年流水账；郑廉、张岱、李永茂等关键文字是经顾诚转引的 B 级，未见原书卷次；“新顺王”与射目两处要用限定说法，削弱了“称王”这个节点的爽感；与 EP15 在孙传庭出关一段有重叠，需换李自成视角。
