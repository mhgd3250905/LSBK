# 选题卡：EP32《晚明最敢说话的李贽，为什么死在一群正人君子手里？》

> 2026-10-13 编写。选题来自明朝篇选题红队评审 C15（8 分，推荐十期第 8 位）。事实依据与原文出处见同目录 `史料核对.md`，凡与之冲突处以史料核对为准（下文 #编号即史料核对第一节序号）。

## 基本信息
- **选题缘由**：心学线在 EP01（王阳明）、EP05（徐阶）、EP10（东渡日本）、EP13（四句教与泰州学派）之后，一直欠一个结局人物。EP13 只用一句话提到“李贽下狱自刎”，把他归为狂禅末流。这一期把这个人完整讲出来：心学喊出“满街都是圣人”，最后喊得最响的那个人，怎么被一群自认为在维护圣人之道的人送进了诏狱。
- **题型**：人物传记型 / 证据交锋型（弹劾疏、实录、友人传记、同时代笔记四方对质）
- **系列归属**：《笑谈历史》第一季·大明篇，万历朝思想篇（心学线收尾）
- **时间跨度**：嘉靖六年（1527）生于泉州 → 万历五年至八年（1577–1580）姚安知府、辞官 → 寓居黄安耿家，约万历十二年（1584）耿定理死后移居麻城芝佛院，与耿定向往复论战 → 万历十八年（1590）《焚书》刊行 → 约万历二十一年（1593）与耿定向和好 → 约万历二十四年（1596）巡道扬言“以法治之” → 万历二十八九年之交芝佛院被焚、葬骨塔被毁 → 万历二十九年（1601）随马经纶到通州 → 万历三十年（1602）闰二月张问达劾奏、下诏狱，三月自尽，年七十六 → 天启五年（1625）书再遭禁毁

## 核心认知反差（生死线）
- **你以为的**：
  1. 李贽是课本里“反封建的进步思想家”，被腐朽的统治者迫害致死，迫害他的应该是奸臣、太监、昏君；
  2. 他死于“思想罪”，朝廷怕的是他的学问；
  3. 网上还有一种说法：东林党人害死了李贽。
- **实际上的**：
  1. 弹劾他的张问达，是屡次上疏请罢矿税、替饥民说话的直臣（#28）；和他吵了二十年的耿定向，当年亲自把他请到黄安，两人同属心学一脉，晚年还和好了（#5、#19、#21）；逐他出麻城的，打的是“维护风化”的旗号（#22、#26）；
  2. 弹劾疏一半是学术罪，一半是风化罪——七十六岁的老人被指“挟妓同浴、勾引士人妻女”（#29），而他的朋友说他有洁癖、厌近妇人（#9）；同时代的沈德符还怀疑背后有首辅沈一贯的私怨（#31）；
  3. 顾宪成确实骂过他，可也在笔记里替他的一句话说过好话，而且顾宪成当时削籍在无锡，跟弹劾无关（#33、#34）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + “好人杀人” + 四方证据互相拆台）

## 核心问题（这期节目回答的一句话问题）
一个七十六岁、躺在门板上被抬走的老人，到底说了什么，让一群公认的好人非要把他从京城边上赶走、把他的书烧光？

## 三大基因自检
- [x] **小切口**：万历三十年春，通州马家，锦衣卫上门，一个病重的老人叫人拿块门板来，自己躺上去，催着快走（#35）。
- [x] **大纵深**：从王阳明“满街皆圣人”到泰州学派，再到李贽质问讲学先生言行不一；从地方士绅的“维护风化”，到给事中的弹劾、首辅的私怨、礼部尚书顺势整顿科场（#32），一套机制怎么合力碾过一个人。
- [x] **人性内核**：言行一致这件事，为什么会让“好人”们愤怒；一个人只要被认定在破坏风化，所有人就都可以心安理得地动手。

## 标题候选（九型公式选优）
1. （认知反转问句型）《晚明最敢说话的李贽，为什么死在一群正人君子手里？》（**主选**，红队标题）
2. （数字反差型）《一个七十六岁的老人，凭什么让万历皇帝下旨抓人烧书？》
3. （课本接口型）《心学说满街都是圣人，说得最响的李贽为什么进了诏狱？》

> 平台短标题建议：《最敢说话的李贽》；封面主标题：`最 敢 说 话 的 李 贽`，底部副题“他为什么死在一群正人君子手里”。

## 印章拟定
- **印章四字**：`绝假纯真`（出自《焚书·童心说》：童心者，绝假纯真，最初一念之本心也，#13；概括他一生要的东西，也是他得罪人的根源）

## 内容弹药
- **主要素材**：袁中道《李温陵传》（友人所作传记，逮捕、审讯、死亡细节的唯一详细来源）；《明神宗实录》卷369 张问达疏与圣旨（顾炎武《日知录》卷十八全文转录）；《明史》卷221《耿定向传》附李贽、卷241《张问达传》、卷216《冯琦传》；沈德符《万历野获编》卷二十七《二大教主》；李贽《焚书》（自序、《答耿司寇》《童心说》《何心隐论》《与曾继泉》《答以女人学道为见短书》《豫约》）、《续焚书》（《与耿克念》《答来书》《与焦弱侯》《释子须知序》）；顾宪成《小心斋札记》卷十、《泾皋藏稿》卷五；黄宗羲《明儒学案·泰州学案》序。
- **对照组**：张问达疏里的李贽（挟妓、惑众） vs 袁中道笔下的李贽（洁癖、扫地、厌近妇人） vs 沈德符笔下的李贽（狷性如铁，但骂人过头）；实录“惧罪不食死” vs 袁中道“持刀自割”。
- **合法跑偏**：①他爱扫地，几个人扎扫帚都供不上（#9）；②剃光头的三种解释，他自己说是为了让家里别再催他回去（#4）；③《焚书》书名的意思就是“该烧的书”，后来真被下旨烧了（#14、#30）；④他和利玛窦有往来，写过《赠利西泰》（#43，一句带过）。

## 阵容配置（固定双人）
- **主讲**：大开（交代每条记载出自谁；倾向于“风化是旗号，真正不能容的是他揭穿言行不一”；对沈一贯私怨说保持“有人这么怀疑”的分寸）
- **主持**：小李（自己算出李贽被指挟妓时已七十六岁、且早已离开麻城；坚持认为李贽骂人过头也是他树敌的原因；认为最可怕的是动手的人大多真心）

## 冷开场方向
- `[00:00-01:00]` 万历三十年春，北通州马经纶家。病重的老人刚改完一部讲《易经》的书，说书成了死也痛快。锦衣卫到了门口，他问来者何人；马经纶说卫士到了。他强撑起身走了几步，大声说这是冲我来的，叫人拿块门板，自己躺上去，催着快走。马经纶要跟着去，老人劝他家有老父；马经纶说朝廷把先生当妖人，我就是窝藏妖人的人。马家几十个仆人哭着拦，没拦住（#35，开场即点明出自他朋友袁中道写的传）。
- `[01:00-02:00]` 标志性报幕 + 小李发问：这个躺在门板上的老人是谁，犯了什么事？大开破题：他叫李贽，课本里那个“进步思想家”；弹劾他的人，是当时公认的好官。
