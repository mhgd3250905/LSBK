# EP33 节目大纲：《进京四十二天就撤，李自成真是输给了“骄傲腐化”？》

> 2026-10-13 编写。闯王系列 4/5。全期以“李自成一路收降表、最后一封信没回”的发现路径为主线；四段只为分工，主播在台词里不知道自己在分段。证据编号对应 `史料核对.md` 第一节（#1–#60）。按约 300 字/分钟估算，目标成片约 26–28 分钟（净台词约 7,800–8,500 字），是估算不是配额。本期从大顺一方讲，崇祯的煤山只回扣 30 秒。

## 分段要点

### [00:00–02:00] 冷开场与报幕
- 冷开场全用 #21：正阳门城头、酒席、城下都督爷、草纸四字。**台词必须带一句“据当时一个叫李长祥的人记载”**；“城下都督爷”是谁不点名。
- 小李第一反应是课本：明朝皇帝到最后还在谈？大开：谈什么，到今天都没定论，先看这些人是怎么走到城下的。
- 报幕后承接 EP32：西安、大顺、永昌，一两句。

### [02:00–09:00] 一、出门：五十万、百万和一路降表
1. 西安的架子（#1、#2），李继迁一句笑点，马踏青苗者斩一句。
2. 传牌（#5）与两路钳形（#7），只交代形状。
3. 檄文“君非甚暗”（#9）：小李的误读（李自成同情崇祯？）→ 大开纠正为劝降口吻。此处埋下 EP15 “诸臣误朕”的呼应，只一句，不复述血书。
4. 宁武：先讲正史版本的激烈（#10）与“不如还秦”（#11），再讲顾诚考证（#12）。由小李先说“这段太像评书”，大开再拿证据。
5. 大同、宣府、居庸关（#13–#15），“此谁家城”收尾。
6. 张献忠一句（#4）。

### [09:00–16:00] 二、城下与城里：先看他干了什么
1. 谈判三版本（#18–#20），扣回冷开场（#21）。由小李追问“哪个是真的”，大开交代层级：正史说要禅位，笔记说要分国，学者倾向前者。
2. 城破与煤山 30 秒（#23）。**不重复 EP15 的血书、王承恩、百官投表细节；不重复 EP17 的景阳钟、承天门外互殴、周钟、龚鼎孳。**
3. 入城画面（#24），射匾野史（#25）。
4. 军纪证据（#26、#27）：杨士聪作为“恨大顺的证人”是这一段的转折。
5. 二十二天清单（#28–#33），挑三四件讲，不报流水账。
6. 顾诚的两段账（#34），抛出“二十二天腐化到不能打仗”的问题。

### [16:00–22:00] 三、价目表
1. 从 #30 的“送刘宗敏营中”接入。
2. 价目表（#35）、夹棍（#36）、魏藻德（#37）。小李在这里要真正反对，大开承认残酷（#38 作补充，不作开脱）。
3. 七千万两更正（#41、#42），骡马笑点。
4. 停追（#39）与顾诚评语（#43），西安伏笔（#3）。
5. 义兴私示（#44）收尾，转到“名单上还有谁”。

### [22:00–28:00] 四、半路掉头的人和没回的信
1. 吴三桂时间线（#45–#48），高第纠错（#46）。
2. 掉头三层（#49、#50）：按“看风向的人 → 全城官绅的恐慌 → 陈圆圆是导火索之一”的顺序讲。
3. 没回的信（#52、#53）：本期暗线的收束，由大开翻出。
4. 骄奢腐化之辩（#55、#56），两人各执一词，不给标准答案。
5. 四十一天冷知识（#57），一句。
6. 落点（#51、#54），停在东去的队伍上；报幕一句“下回，山海关”。
