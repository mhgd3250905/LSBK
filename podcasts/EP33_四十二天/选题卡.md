# 选题卡：EP33《进京四十二天就撤，李自成真是输给了“骄傲腐化”？》

> 2026-10-13 编写。明朝篇·闯王李自成系列第 4 期（共 5 期）。事实依据见同目录 `史料核对.md`（#1–#60），凡冲突以史料核对为准。本期**从大顺一方讲**：李自成的人生走到最高点，再从最高点往下看第一道裂缝。

## 基本信息
- **选题缘由**：用户定下的系列定位是李自成作为绝对主角、按人生顺讲、要史诗感和跌宕。1644 年这四个月是他一生的顶点：正月在西安建国，三月进北京，四月中旬已经带着人质去山海关打一个刚投降又反悔的总兵。课本和大众记忆里只剩一句“进京后骄傲腐化，四十多天就败了”。这一期把四十来天摊开，看大顺在北京到底干了什么、哪一步走错了。
- **题型**：证据链拼接（正史、亲历者笔记、后出野史、今人研究分层交代）＋ 史书说／学者说 双版本对照（宁武、城下谈判、七千万两、吴三桂掉头四处）
- **系列归属**：《笑谈历史》明朝篇·闯王系列 4/5（EP30 下岗驿卒的五次死而复生 → EP31 闯王的谷底 → EP32 河南一呼百万 → **EP33 四十二天** → EP34 一片石到九宫山）
- **时间跨度**：崇祯十七年／永昌元年正月初一（1644-02-08）西安建国 → 正月初八东征 → 二月太原、宁武 → 三月大同、宣府、居庸关 → 三月十八日城下谈判 → 三月十九日入城 → 三月二十七日追赃助饷 → 吴三桂受招西行又掉头 → 四月初八停止追赃 → 四月十二／十三日李自成东征山海关（止于出征，不讲一片石）

## 核心认知反差（生死线）
- **你以为的**：
  1. 李自成一进北京就享乐腐化，手下抢钱抢女人，所以四十多天就垮了（“骄傲腐化”是课本和《甲申三百年祭》以来最熟的说法）；
  2. 他是一路恶战打进北京的；
  3. 吴三桂是因为陈圆圆被抢，“冲冠一怒”才引清兵入关的。
- **实际上的**：
  1. 最恨大顺的亲历者杨士聪都承认，军纪坏是四月二十六日从山海关败回以后的事（#27）；头二十来天大顺在改官制、考生员、赶太监、问耆老、筹备登极（#29–#33）。顾诚说一支军队二十二天腐化到不能打仗，难以置信（#34）；他认为“骄”是轻敌，不是享乐（#56）。
  2. 东征一路几乎没打硬仗，大同、宣府、居庸关都是开门迎降（#13–#15）；唯一硬仗宁武，正史说李自成吓得想退兵，学者考证只打了两天（#10–#12）。
  3. 吴三桂已经接受招降、在去“朝见新主”的路上（#48）；掉头的原因正史写了陈圆圆，但同一时间北京正在按官阶给明朝官员“定价”上夹棍（#35–#36），吴家也在其中（#49）。真正要命的是：关外那位正月就来过信，李自成没当回事（#52、#53）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸“骄傲腐化”“冲冠一怒” × 亲历者反证 × 四处“史书说／学者说”。扣一星：顾诚的辩护色彩较重，需要小李持续提出反方证据，避免变成替大顺洗白）

## 核心问题（这期节目回答的一句话问题）
李自成打进北京时几乎没遇到抵抗，为什么不到一个月，他就得带着刚俘虏的太子去山海关打仗？

## 三大基因自检
- [x] **小切口**：三月十八日晚，北京正阳门城头摆着一桌酒，上座的是城外来的人，陪坐的是太监；兵部尚书问这人怎么上来的，太监拿出一张草纸，崇祯亲笔写着四个字，再与他谈（#21，据李长祥记载）。第二天，城就没了。
- [x] **大纵深**：一个驿卒出身的人第一次面对“怎么治理一个首都”；明朝两三千名在京官员如何站队（#29、#30）；财政上不缺钱却要拷饷（#42、#43）；明、顺、清三方在山海关一线的三角关系（#45–#54）；三百年后一篇文章把这四十天变成“骄傲必败”的教材（#55）。
- [x] **人性内核**：赢得太快的人，最容易把还没解决的问题当成已经解决了——吴三桂投降了，辽东就算完事；百官投降了，就该把钱吐出来。李自成一路收到的降表太多，最后一封没收到的，是关外那封他自己没回的信。

## 印章拟定
- **印章四字**：`君非甚暗`（出自大顺在山西发布的檄文／永昌元年诏书：君非甚暗，孤立而炀蔽恒多；臣尽行私，比党而公忠绝少。见《明季北略》卷20、《明史纪事本末》卷79，#9；古法排列：右列“君非”、左列“甚暗”，自上而下）
- 与前一系列惯例（印章取正史原文四字）不同：本期取的是**大顺自己的文书**，经笔记转录（B 级），理由是这四个字最能代表本期视角——造反者看朝廷的眼光。若用户要求严格取正史，可换《明史》卷309“皆不就”（铸金玺及永昌钱，皆不就）或《明史》卷268“不如还秦”。

## 内容弹药
- **主要素材**：《明史》卷268、309；《清史稿》卷474（正史，A）；赵士锦《甲申纪事》、杨士聪《甲申核真略》（亲历者笔记，经顾诚转引，B）；钱𫐄《甲申传信录》、计六奇《明季北略》、李长祥《天问阁集》（笔记，C）；顾诚《明末农民战争史》第十、十二章，《南明史》（今人研究，B）。
- **一条贯穿暗线**：**降表**。大同的降表、宣府的降表让李自成放弃退兵（#11）；北京百官排队递职名（#29）；吴三桂在永平贴出“朝见新主”的告示（#48）；而关外那封“协谋同力，并取中原”的来信，李自成没理（#52）。收到的都是降表，没回的那一封要了命。
- **对照组**：
  1. 大顺檄文说“君非甚暗……臣尽行私”（#9） vs 崇祯遗言“然皆诸臣误朕”（EP15 已讲，只一句呼应）：打进来的人和守城的人，在“大臣不行”这件事上看法一致。
  2. 赵士锦看到大顺兵抢绸缎被钉在前门栅栏上（#26） vs 三月二十七日开始的价目表和夹棍（#35、#36）：对小民是一套，对官员是另一套。
  3. 张献忠同年在成都称大西国王，年号就叫“大顺”（#4）。
- **合法跑偏**：①大顺认西夏的李继迁当太祖（#1）；②考生员的题目是《天与之人归之》（#32）；③《明季北略》说宫里有三千七百万锭镇库金，作者自己算出要一千八百五十万头骡马才拉得动，当场否定（#42）；④常说四十二天，其实四十一天（#57）；⑤射承天门匾“中分天下”的段子（#25，野史）。
- **梗与现代映射**：公司被收购后第一个月，新老板按职级给老员工开“补缴单”，不交就上手段；员工一边办入职一边给竞争对手发简历（只作比喻，不代替史实）。
