# 选题卡：EP33《翻译〈几何原本〉的徐光启，为什么晚年最急着造大炮？》

> 2026-10-13 编写，来自明朝篇候选红队评审 C16（8 分，推荐入选，原题“徐光启与利玛窦”，红队改切口为军事自强）。事实依据与原文出处见同目录 `史料核对.md`（编号 #1–#40），凡与之冲突处以史料核对为准。

## 基本信息
- **选题缘由**：课本里的徐光启只有两张卡片——和利玛窦合译《几何原本》、写《农政全书》。红队指出“中西交流先驱”的叙述太顺，宗教切口听众未必关心；真正的冷门在萨尔浒之后：这位翻译几何学的翰林，把后半生最急的力气用在练兵、买西洋大炮、培养会造炮的学生上。这条线向后一直通到登州城破、学生被斩、大炮落进后金手里，正好补上 EP15《崇祯十七年》之前那几年辽东与山东的空档。
- **题型**：人物反差型（课本熟脸 × 被忽略的后半生）＋ 证据链拼接（正史、当事人序跋、今人档案研究分层交代）
- **系列归属**：《笑谈历史》第一季·大明篇，万历—崇祯过渡篇（晚明科技/军事侧写）
- **时间跨度**：嘉靖四十一年（1562）生 → 万历二十五年（1597）顺天乡试第一 → 万历三十一年（1603）受洗 → 万历三十二年（1604）进士 → 万历三十五年（1607）《几何原本》前六卷刊行 → 万历四十七年（1619）萨尔浒后请练兵 → 泰昌元年（1620）首批四门西洋炮 → 天启元年（1621）力请多铸西洋大炮、去职 → 天启六年（1626）宁远之战 → 崇祯二年（1629）主持修历 → 崇祯三年（1630）门生孙元化任登莱巡抚、澳门炮师抵京 → 崇祯四年闰十一月（1631/32 之交）吴桥兵变 → 崇祯五年（1632）正月登州陷、五月徐光启入阁、七月孙元化弃市 → 崇祯六年（1633）孔有德载炮降金、十月徐光启卒 → 崇祯十二年（1639）《农政全书》刊行

## 核心认知反差（生死线）
- **你以为的**：
  1. 徐光启是科学家、翻译家，和利玛窦在书房里译几何，跟打仗没关系；
  2. 《几何原本》是一本纯粹的数学书；
  3. 晚明科技人物的悲剧，是“生不逢时、没人重视”。
- **实际上的**：
  1. 《明史》写他从利玛窦那里学的，天文、历算之外还有火器（#2）；萨尔浒之后他累疏请练兵、力请多铸西洋大炮（#12、#15），自己张罗、托朋友捐钱从澳门弄来第一批西洋炮（#14）；
  2. 《几何原本》的序言里，利玛窦就写明了：几何的所有用途中，兵法最急（#7）；
  3. 他的路线被重视过，也真的见过效：宁远城头开过西洋炮（#19、#20）；他的学生孙元化在登州练出一支有葡萄牙教官、有二十来门红夷炮的部队（#24、#29）。毁掉它的是一场因为欠饷、军民冲突引发的兵变（#26、#27），叛军用孙元化造的炮轰莱州（#30），最后载着炮投了后金（#34）。徐光启入阁想救学生没救成（#31），一年后自己死在任上，囊无余赀（#36）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 × 被埋掉的军事主线 × 一个有据可查、讽刺极重的结局；扣一星是因为宁远那一环要靠二手材料拼接，必须讲清边界）

## 核心问题（这期节目回答的一句话问题）
一个翻译几何学的翰林，为什么晚年最急着要大炮？他把炮和会用炮的人凑齐了，这些炮最后又落到了谁手里？

## 三大基因自检
- [x] **小切口**：崇祯五年正月，登州城东一战，辽兵临阵退走，夜里城中火起，有人打开东门，城里有二十来门红夷大炮、几十个澳门来的炮手，一夜之间全成了叛军的（#28、#29）。守城的巡抚是徐光启的学生。
- [x] **大纵深**：利玛窦序言里的“几何为兵法所急”；萨尔浒以后明廷的火器转向；澳门葡萄牙人与白银贸易网络（接 EP11）；宁远与关宁防线；吴桥兵变如何把明朝最先进的炮兵送给后金（接 EP15 的崇祯朝）。
- [x] **人性内核**：一个相信“学问要有用”的人，用二十多年把有用的东西一件件凑齐，最后亲眼看着它们被一场兵变反向送了出去；而他自己死时家无余财，留下的是一屋子手稿。

## 内容弹药
- **主要素材**：《明史》卷251 徐光启传与郑以伟传、卷248 徐从治传附孙元化与余大成、卷23 庄烈帝纪、卷259 袁崇焕传、卷271 满桂传、卷31 历志一、卷326 外国七（正史，A 级）；《清史稿》卷234 孔有德传（正史，A 级）；利玛窦《译几何原本引》、徐光启《刻几何原本序》《几何原本杂议》《题几何原本再校本》（当事人原文，A 级）；《四库提要·农政全书》（A 级）；黄一农《吴桥兵变：明清鼎革的一条重要导火线》（2012）与《红夷大炮与明清战争》（2022）（今人研究，B 级，引《崇祯长编》、范景文、毕自严等档案）；瞿式耜奏疏、陈盟《崇祯阁臣行略》、《罪惟录》、柏应理《徐光启行略》（二手转引，C 级）。
- **对照组**：利玛窦序言里“以羸少之卒，守孤危之城”的西方故事 vs 宁远守住、登州失守；明朝一个巡抚被斩于西市 vs 皇太极出城十里、亲手给叛将斟酒（#31、#34）。
- **合法跑偏**：①《几何原本》只译了前六卷，后九卷等了两百五十年左右（#9、#10）；②红夷大炮的“红夷”其实不专指荷兰，很多炮是从广东沿海沉船里捞出来的（#17、传说溯源 1）；③吴桥兵变的导火线据清代记载是一只鸡（#27）；④《农政全书》六十卷里有十八卷讲荒年怎么活命（#38）。
- **梗与现代映射**：自掏腰包给单位采购设备、请外籍技术顾问，结果项目被一场劳资纠纷整体端走（只作比喻，不代替史实）。
