# 选题卡：EP34《李自成丢了天下，真是因为进了北京就腐化了吗？》

> 2026-10-13 编写。明朝篇·闯王李自成系列第 5 期，系列终篇。事实依据见同目录 `史料核对.md`（#1–#56），凡冲突以史料核对为准。

## 基本信息
- **选题缘由**：用户定下的系列口径是“李自成作为绝对主角，按他的人生顺着讲，要史诗感和跌宕起伏”。终篇要回答整条线最大的问题：一个从驿卒做到皇帝的人，为什么打下北京以后十三个月就死在湖北山里。课本和大众印象给的答案是“进京腐化”和“冲冠一怒”；这一期用一年里的具体溃败过程，把“腐化说”放到桌面上拆。
- **题型**：编年溃败叙事（山海关—武英殿—潼关—南逃—九宫山）＋ 证据对表（三份死亡报告、三处《明史》错误）＋ 系列收束（回扣驿卒、十八骑、左眼、四十二天、李岩）＋ 下一条长线钩子（大顺余部归明）
- **系列归属**：《笑谈历史》明朝篇·闯王系列 5/5（EP30 下岗驿卒的五次死而复生 → EP31 闯王的谷底 → EP32 河南一呼百万 → EP33 四十二天 → **EP34 一片石到九宫山**）
- **时间跨度**：崇祯十七年／顺治元年（1644）四月十三日东征山海关 → 二十一日一片石、二十二日山海关决战 → 二十九日武英殿登基、当夜焚宫 → 五月初二多尔衮入居武英殿 → 五月庆都、真定连败 → 西安数月 → 十二月二十九日至次年正月潼关之战 → 顺治二年（1645）正月十三日弃西安 → 正月至三月内乡、邓州 → 三月襄阳、武昌 → 四月九江老营被破、刘宗敏被杀 → 五月初九宫山（顾诚推断初四）→ 同月十五日南京开城 → 七八月东西两路余部归何腾蛟、堵胤锡，号忠贞营 → （尾声）康熙三年（1664）茅麓山

## 核心认知反差（生死线）
- **你以为的**：
  1. 李自成进了北京就骄傲腐化，失去民心，所以失败；
  2. 吴三桂冲冠一怒为红颜，引清兵入关，一仗就把大顺打垮了；
  3. 李自成死在九宫山，这事清清楚楚；或者反过来，他其实没死，去夹山寺当了和尚。
- **实际上的**：
  1. 研究这段最细的顾诚认为，大顺输在没来得及“变”：进京后仍以追赃代替赋税，把已经投过来的官绅推回对面（#53）；同一时间多尔衮给崇祯发丧、降官照用、田产归还、三饷停征（#52）。“腐化”能解释一部分失控，解释不了北京官绅为什么前脚迎大顺、后脚迎清军；
  2. 山海关之后大顺还有十几万人、还有西安、还有襄荆四府，真正的崩溃是一连串的：潼关十三天、弃西安、分两路、放弃最后的根据地、九江老营被破（#24–#36）；
  3. 关于他的死，清方、南明、《明史》三份记载人数、日期、死法都对不上（#38–#40）；清方说“尸朽莫辨”，南明说“无复得其首级”，两边都报了喜又都没底（#44）；可夹山寺说更站不住：那位和尚是他死后七年才到的（第二节第 9 条）。
- **反差的强度自评**：⭐⭐⭐⭐（“进京腐化”是课本与大众的标准答案 × 一年溃败的具体链条 × 三份死亡报告对不上 × 两个“先帝”的结尾；扣一星是“为什么输”只能给学者观点与分歧，不能给定论）

## 核心问题（这期节目回答的一句话问题）
李自成在武英殿只当了一天皇帝，十三个月后死在九宫山几个不认识他的乡兵手里——他输掉天下，真是因为进京腐化了吗？

## 三大基因自检
- [x] **小切口**：1644 年四月二十九日武英殿登基，祭天由丞相代行，当晚烧宫，次日西走；三天后多尔衮住进同一座武英殿（#12、#13、#16）。正史两书互证，画面完整。
- [x] **大纵深**：明清鼎革最关键的一年；大顺、清、南明三方同时在动——南京一边感谢清兵替明朝报仇（#21），一边自己也在一年内倒下（#37）；张献忠在成都称王，年号也叫大顺（#51）；系列首尾：驿卒丢公文起家，死后留下两份对不上的奏报（#42）。
- [x] **人性内核**：一个人能把二十万人带到北京，却说不清自己该怎么对待投降过来的人；他的部下后来替曾经的敌人打了十九年仗，文书里还管他叫先帝（#48、#50）。

- **梗与现代映射**：创业公司拿下总部大楼却还按“打天下”的办法对待投奔来的老员工，结果人全跑去了竞争对手那边（只作比喻，不代替史实）。
