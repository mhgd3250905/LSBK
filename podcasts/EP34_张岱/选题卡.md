# 选题卡：EP34《写出〈湖心亭看雪〉的张岱，为什么前半生是个顶级纨绔？》

> 2026-10-13 编写，属于明朝篇 10 期批量（EP25–EP34）的最后一期，也是明朝篇的收束期。红队评审 C19 给了 8 分，标题方向沿用红队建议。事实依据与原文出处见同目录 `史料核对.md`，与之冲突的地方一律以史料核对为准。

## 基本信息
- **选题缘由**：EP15 讲了崇祯十七年，EP17 讲了钱谦益们在亡国关口的借口。明朝篇收尾还缺一个人：亡国以后没死、也没去做官，活了几十年的人。张岱的脸课本里就有（初中语文《湖心亭看雪》），可他在《自为墓志铭》里把自己写成纨绔子弟，后半生又在山里写了一部明史。这期用他一个人的前后两半生收束明朝篇。
- **题型**：人物反差型 + 自述辨析型（主要材料是张岱自己写自己，每一处都要说明这是他的自述）
- **系列归属**：《笑谈历史》第一季·大明篇，崇祯—南明收束篇
- **时间跨度**：万历二十五年（1597）八月生于绍兴山阴 → 天启、崇祯年间斗鸡、品茶、养戏班，崇祯元年（1628）动笔写《石匮书》 → 崇祯五年（1632）十二月湖心亭看雪 → 1644 甲申国变 → 1645 迎鲁王、上疏请斩马士英、受职方主事、约五十天后辞去；同年闰六月好友祁彪佳投水 → 1646 正月被方国安逼饷，儿子被绑；六月绍兴陷落，入山 → 1649 回城租住快园 → 1663 前后写《舂米》《担粪》 → 约 1665 写《自为墓志铭》，营生圹 → 1671 写《西湖梦寻》序 → 卒年说法不一（最晚一说 1689）

## 核心认知反差（生死线）
- **你以为的**：
  1. 写《湖心亭看雪》的人是个清高的隐士，一个人划船去看雪，跟俗世不沾边；
  2. 晚明的纨绔子弟大概就是吃喝嫖赌的败家子，跟文学、史学扯不上关系；
  3. 亡国的时候，读书人要么像钱谦益那样嫌水太冷投降，要么像祁彪佳那样投水殉国，没有第三条路。
- **实际上的**：
  1. 《湖心亭看雪》收在《陶庵梦忆》里，这本书是他国破家亡以后，在山里吃不上饭的时候，回想前半生写下的。看雪那年他虚岁三十六，还是那个家里养着戏班、讲究吃喝玩乐的公子哥（斗鸡、品茶、蟹会各有年份，见史料核对）；
  2. 他在给自己写的墓志铭里列了一长串爱好，自称少为纨绔子弟。钱是怎么来的，他在《家传》里也交代了：曾祖是状元，祖父开始养戏班，父亲科场考了四十年考不上，母亲让他用园亭和戏曲解闷，家里的豪奢是一代代攒起来的。他自己一辈子只是个秀才，靠的是家底；
  3. 他选了第三条路：上疏请鲁王斩马士英，在鲁王手下做了不到两个月的小官就被挤走，好友投水他没跟着死，后来自己说既不能觅死，又不能聊生，靠写一部明史撑着活下去，晚年自己舂米担粪。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸 + 自己给自己写的黑材料 + 亡国前后的两种人生）

## 核心问题（这期节目回答的一句话问题）
一个写过湖心亭那场雪的人，前半生到底有多会玩？这些钱和这份闲是哪来的？国破以后他没死也没投降，后半辈子是怎么过的？

## 三大基因自检
- [x] **小切口**：崇祯五年十二月一个大雪的夜里，他坐着小船去湖心亭，船夫小声嘀咕说别说相公痴，还有比相公更痴的。
- [x] **大纵深**：晚明江南世家的钱和闲是怎么来的、一个四代读书人家怎么从状元走到戏班；南明鲁王政权内部的样子；遗民怎么在不死和不降之间找活路。
- [x] **人性内核**：一个人怎么写自己的前半生，是忏悔还是怀念，他自己也说不清；不死要不要理由，理由能不能说服别人。

## 印章拟定
- **印章四字**：`总成一梦`（出自《陶庵梦忆》自序：五十年来，总成一梦。他用这句话概括自己国破前的半生繁华，书名里的梦也从这里来）。古法排列：右列“总成”，左列“一梦”。

## 冷开场方向
- `[00:00-01:00]` 崇祯五年十二月，西湖大雪三天，人声鸟声都没了。打过初更，他坐小船、裹着毛皮衣服带着炉火去湖心亭。亭上已经有两个人铺了毡子对坐，一个童子在烧酒。对方见到他很高兴，拉他喝酒，他喝了三大杯告别，问了姓名，是南京来的客人。下船时船夫小声嘀咕，别说相公痴，还有比相公更痴的（《陶庵梦忆》卷三，张岱自述）。
- `[01:00-02:00]` 标志性报幕 + 小李发问：课本里这是一个清高文人的一夜，怎么红队说他是纨绔？大开破题：这篇文章是他国破以后在山里饿着肚子回忆着写的，同一个人还给自己写过一篇墓志铭。
