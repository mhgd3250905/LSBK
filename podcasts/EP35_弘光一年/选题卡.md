# 选题卡：EP35《有史可法这样的忠臣，弘光朝为什么一年就垮了？》

> 2026-10-13 编写。明朝篇·南明十八年系列第 1 期（共 6 期，EP35–EP40）。事实依据见同目录 `史料核对.md`（#1–#53），凡冲突以史料核对为准。标题按用户口径只给一个“课本熟脸＋认知反转问句”，用户日后会自己重取。

## 基本信息
- **选题缘由**：用户定下的南明系列口径是“长线连续叙事，接在闯王系列后面；要史诗感、趣味性、跌宕起伏；每期锁定一个主角；坚持讲人、讲选择、讲数字争议”。第一期的主角是史可法：课本里的忠臣、梅花岭的主人。这一期不讲他怎么死（那是 EP36），讲他活着的这一年里，在三个关键选择上怎么一步步把主动权交了出去，以及南京这个“临时政府”怎么在一年里自己把自己拆散。
- **题型**：编年政治叙事（定策—监国—四镇—党争—北上—三案—清君侧）＋ 史料两派对表（东林系统／《明史》 vs 顾诚）＋ 系列开篇（地图口播、回扣 EP15 与 EP34）
- **系列归属**：《笑谈历史》明朝篇·南明十八年系列 1/6（**EP35 弘光一年** → EP36 扬州与江南 → EP37 郑芝龙与郑成功 → EP38 李定国两蹶名王 → EP39 孙李内讧 → EP40 1662 群星谢幕）；上接闯王系列 EP34《一片石到九宫山》。
- **时间跨度**：崇祯十七年／顺治元年（1644）三月十九日北京失守 → 三月二十九日消息到淮安 → 四月定策之争 → 四月二十九日福王舟抵燕子矶 → 五月初三监国、十五日即位于南京武英殿、史可法自请督师 → 五月中设江北四镇 → 六月高杰争扬州、马士英荐阮大铖 → 八月阮大铖起用、东林诸臣相继出朝 → 十月高杰北征 → 十二月大悲案、北使失败、假太子南来 → 弘光元年／顺治二年（1645）正月中旬睢州之变 → 二月大悲伏诛 → 三月初假太子、童妃下狱 → 三月二十三日左良玉东下 → 四月初四左良玉死于九江 → 四月初史可法入援至燕子矶、十三日清军渡淮。（扬州城守与南京开城留 EP36。）

## 核心认知反差（生死线）
- **你以为的**：
  1. 南明亡得快，是因为马士英、阮大铖这对奸臣把持朝政，排挤史可法这样的忠臣（课本、《明史·奸臣传》、《桃花扇》）；
  2. 史可法是忠臣，所以他做的事都是对的，只是生不逢时；
  3. 清军太强，南明一打就垮。
- **实际上的**：
  1. 根子在开头那一个月的“定策”：东林一方想立潞王，史可法想出桂王的折中，结果手握兵权的镇将和马士英抢先把福王送进南京，史可法还把列着福王“七不可”的信交到了马士英手里（#8、#12、#16）。从此皇帝欠武将的人情，不欠文臣的。顾诚的判断是：导致武将跋扈的“并不是他（马士英），而是史可法”（#18）；
  2. 史可法清廉、勤勉、宁死不屈都是真的，可江北四镇是他提议设的（#20），高杰北上失败后他退回扬州（#34）。“好人当不好督师”这条线从本期开始；
  3. 弘光朝坐拥半壁江山、最富的地方（#49），清军主力那时还在西边追李自成，驻山东的豪格两次以“未奉旨”为由不肯渡河，顾诚据此判断清方东部兵力单薄（#32）；最后清军南下时，南京的主力在防自己人左良玉（#45、#46）。
- **反差的强度自评**：⭐⭐⭐⭐（“马阮奸臣误国”是课本与戏曲的标准答案 × 七不可那封信这个具体物证 × 三个冒牌货的荒诞 × 结尾“防左不防清”；扣一星是“谁该负责”只能给两派分歧，顾诚本人立场也很鲜明）

## 核心问题（这期节目回答的一句话问题）
南京手里有半壁江山、有史可法这样的忠臣，清军主力还在西边没腾出手——这个朝廷为什么一年就散了伙？

## 三大基因自检
- [x] **小切口**：1644 年四月底，燕子矶边一条破船。船上的福王“角巾葛衣，坐寝榻上；旧枕敝衾，孑影空囊”（#13）。半个月后，他在南京的武英殿即位（#17）；同一时间，史可法写过的那封“七不可”的信，已经在马士英手里（#16）。
- [x] **大纵深**：明清鼎革最乱的一年：北京换了两个主人，南京又立了一个；国本之争（EP14）三十年后在南京重演（#9）；崇祯的“诸臣误朕”一年后变成史可法的“诸臣误国……门户二字实为祸首”（#5、#6）。
- [x] **人性内核**：一个清廉勤勉的好人，在需要当机立断的时刻想照顾所有人，结果谁也没照顾到；一群人在亡国之后的第一件事，是吵谁有资格当皇帝、谁有“定策之功”。

## 印章拟定
- **印章四字**：`伦序当立`（出自《明史》卷274：“福王由崧，神宗孫也，倫序當立”，#7、#8；古法排列：右列“伦序”、左列“当立”，自上而下）
- 沿用前几条长线惯例（印章取正史原文四字）。这四个字正好是本期的戏眼：按伦序该立福王，东林却列出七不可，最后是兵把福王送进了南京。

## 内容弹药
- **主要素材**：《明史》卷120、268、273、274、308，《清史稿》卷4（正史，A，已核）；计六奇《明季南略》卷一、二、三、七，徐鼒《小腆纪年附考》卷五、九、十（私修史，B，已核原文）；顾诚《南明史》第二章第一至四节、第三章第四至五节、第五章第一至四节（B），及其转引的姜曰广《过江七事》、李清《南渡录》《三垣笔记》、谈迁《国榷》《枣林杂俎》、应廷吉《青燐屑》、袁继咸《浔阳纪事》、王铎奏疏揭帖、《清世祖实录》卷13（转引）。
- **三条系列暗线**：
  1. **武英殿线**（EP34 → EP35）：李自成四月二十九日在北京武英殿登基（EP34 #12），朱由崧五月十五日在南京武英殿即位（#17）。小李认出，大开限定。
  2. **“诸臣误朕”线**（EP15 → EP35）：开场崇祯血书“然皆诸臣误朕”，结尾史可法奏疏“诸臣误国之事非一，而门户二字实为祸首”（#5、#6）。
  3. **燕子矶线**（本期首尾）：一年前福王的破船停在燕子矶（#13）；一年后史可法在燕子矶被一道“不必入朝”挡了回去（#46）。
- **对照组**：福王“七不可” vs “伦序当立”（#8）；史可法清廉 vs 四镇是他提议的（#20、#21）；左良玉“八十万”（《明史》） vs “五万余”（李清）（#41）；王铎揭帖“兵不满七百” vs 兵部报“数十万”（#48）；《明史》“马士英奸臣” vs 顾诚“不应打入另册”（#30）。
- **合法跑偏**：①两座武英殿（#17）；②高杰南逃时冒充大顺军喊“闯王安民”，金乡人差点开城劳军（#23，方志）；③大悲和尚一会儿说自己是齐王、一会儿说是吴王，最后被查出是苏州的和尚（#35）；④真的崇祯皇子里，后来能确认的只有定王朱慈焕，隐姓埋名当了几十年私塾先生，康熙四十七年才被捕（#36，顾诚）。
- **梗与现代映射**：创始人突然去世，董事会还没开，几个握着部门预算的高管先把一个人抬上了 CEO 位置；原本最有资历的副总裁，写过一封“此人七不宜”的邮件，邮件转手就到了对手那里（只作比喻，不代替史实）。

## 选题评分（对抗自审后）
- **8/10**。加分：冷开场画面完整、出处硬（《明季南略》＋谈迁亲见）；“七不可”那封信是一个能拎起整期的物证；三案荒诞、适合双人对谈；结尾“防左不防清”有《明史》原文支撑，且天然把听众交给 EP36；两派史料对表，正好体现“讲人、讲选择、讲数字争议”。扣分：人物多（福潞桂三王、四镇、马阮、东林诸臣），稍不留神就成名单；本期的主要论点依赖顾诚，而顾诚对东林与史可法的批评很重，须由小李一方守住《明史》与课本的立场来平衡；“差一点就赢了”的高光（高杰北上）是徐鼒的假设语，不如后几期的衡阳、磨盘山那样硬，只能讲成“一扇窗”。
