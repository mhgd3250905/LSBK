# EP35 Shownotes｜《张献忠的义子，成了大明最后的战神：李定国两蹶名王与背刺悲剧》

顺治九年十一月二十四日的衡阳演武坪，漫天风雪呼啸，山谷的泥潭里陷满了清军战马。大明战象与长矛步兵如铜墙铁壁般推进，战鼓声震裂山谷。被重重包围的清军主帅——顺治皇帝的亲叔父、定远大将军敬谨亲王尼堪，疯狂挥刀咆哮，却再也无法冲出绝境。随着数名明军死士扑上马背，一道寒光闪过，这位满清开国以来战功赫赫的铁帽子王，头颅滚落雪地！

而统帅这场惊天伏击战的明军统帅，竟然是崇祯皇帝剿了整整十七年的死敌——大西王张献忠手下最凶悍的养子，李定国。

在明清鼎革的残酷棋局里，李定国的命运堪称整个南明历史上最悲壮的奇迹。他少年从贼，曾是大明朝廷眼里的巨寇；但在崇祯煤山自缢、汉家江山沉沦的至暗时刻，这位流贼出身的将领，却力排众议走出大山，奉永历帝为正朔，将一腔赤诚全部托付给了风雨飘摇的大明：
- **流贼变义军与西南擎天柱**：大西军残部退入云贵，李定国力驳众议，坚决主张联明抗清。他走出大山，屯田练兵，纪律严明，秋毫无犯，在西南绝壁上为汉家文明筑起了最后的铜墙铁壁；
- **两蹶名王与天下震动**：1652 年李定国率领战象步骑出滇东征，桂林城破逼得清廷定南王孔有德自焚阖门，随后衡阳演武坪设伏阵斩八旗主帅尼堪亲王！一代战神两蹶名王，收复湘桂大片河山，顺治皇帝闻讯大哭辍朝三日，清廷高层甚至密议放弃江南与西南七省割地求和；
- **至暗背刺与同室操戈**：英雄能在正面战场杀得八旗劲旅胆寒，却躲不过自己人从背后捅来的冷刀。后方结拜义兄孙可望嫉功生狂，在安龙行宫制造骇人听闻的十八先生之狱残酷绞杀朝臣，甚至撕破脸皮悍然发兵数万攻打李定国，把南明最辉煌的战略反攻窗口活活撕得粉碎；
- **磨盘山血战与战神绝唱**：内讧兵败的孙可望叛国降清，献出西南全套山川险隘与军防地图，吴三桂与洪承畴三路大军合围。李定国在高黎贡山磨盘山设伏死战，因叛徒卢桂生告密功亏一篑，全军拼尽最后一人血战突围；退守勐腊边境闻听永历帝在昆明被吴三桂弓弦绞杀，李定国面北恸哭数日、呕血数升而亡，留下遗言誓死不降清！

本期《笑谈历史》大明终局·南明四重奏第 3 期，大开与小李将带您重回 1652 至 1662 年西南崇山峻岭之间的惨烈烽烟，穿上战神李定国的鞋，看一个从泥潭贼寇蜕变出千古忠义的悲剧英雄，如何在内讧与背叛的无底深渊中，为大明流尽最后一滴血。
