# 选题卡：EP36《史可法死守扬州，为什么江南最难打的城反而是个典史守的？》

> 2026-10-13 编写。明朝篇·南明十八年系列第 2 期（共 6 期）。事实依据见同目录 `史料核对.md`（#1–#73），凡冲突以史料核对为准。

## 基本信息
- **选题缘由**：用户定下的系列口径是“长线连续叙事，接在闯王系列后面；每期锁定一个主角；要史诗感、跌宕起伏；讲人、讲选择、讲数字争议，不滑向排满情绪”。本期按系列分工锁定的主角**不是史可法，而是江阴、嘉定的乡绅、典史和百姓**。史可法是课本里的熟脸（《梅花岭记》、扬州十日），用他开场；真正的故事是：清军拿下扬州、南京几乎没遇到像样的抵抗，江南的血是在剃发令之后，由一群没有兵权的人流的。
- **题型**：人物对照（大官督师 vs 不入流的典史）＋ 政策转折（剃发令前后两个江南）＋ 数字校正（八十万、八十一天、三王十八将、三屠）＋ 系列推进（结尾两个新明朝）
- **系列归属**：《笑谈历史》明朝篇·南明十八年系列 2/6（EP35 弘光朝 → **EP36 扬州与江南** → EP37 郑芝龙与郑成功 → EP38 李定国两蹶名王 → EP39 孙李内讧 → EP40 1662 群星谢幕）
- **地图口播位置**：南京（本期南京陷落，下期起地图移到福州／厦门）
- **时间跨度**：顺治二年／弘光元年（1645）四月初五多铎自归德南下 → 十三日渡淮 → 十八日抵扬州 → 二十五日扬州城破、屠城 → 五月初九渡江 → 初十弘光出逃 → 十五日南京开城 → 五月底弘光被执 → 六月初五、十五日剃发令 → 闰六月初一江阴起事、闰六月十七日嘉定倡义 → 七月初四嘉定城破（一屠）、二十六、二十七日（二屠、三屠）→ 闰六月二十七日隆武在福州称帝、七月十八日鲁王在绍兴监国 → 八月二十一日江阴城破、屠至二十三日

## 核心认知反差（生死线）
- **你以为的**：
  1. 史可法死守扬州十天，血战到底，最后葬在梅花岭（课本与教辅的标准印象，#16、第三节第 2 条）；
  2. 清军一路南下，到处遇到拼死抵抗，扬州、南京都是血战；
  3. 江南百姓是因为“亡国”才起来反抗的；扬州死了八十万人，江阴城下打死了三个清朝王爷。
- **实际上的**：
  1. 扬州围了七天，真正攻城不到两天（#13）；史可法忠烈无疑，但他自己在城破前四天写下“人心已去，收拾不来”（#12），他节制的将领几天后就来攻他的城（#7）；梅花岭里只有衣冠，连他怎么死的当年就说法不一（#14–#16）；
  2. 南京几乎没流血：皇帝连夜跑了，勋臣大学士三十多人开城出迎（#28、#30），投降的明军加起来二十多万，比来打他们的清军还多（#31）；
  3. 江南很多地方本来已经降了（嘉定家家贴“大清顺民”，#57），真正点燃反抗的是一年前清朝自己收回过、此时又限十天执行的剃发令（#34、#35、#39）；八十万是孤证，学界多认为夸大，死者至少以十万计（#23）；江阴城下没有一个王爷战死，来打城的倒有一个当时的王、两个后来的亲王（#54）。
- **反差的强度自评**：⭐⭐⭐⭐（“史可法守扬州”是课本级熟脸 × 主角换成一个不入流小官 × 剃发令前后两个江南 × 三个流行数字被校正；扣一星是：屠城题材本身沉重，反转必须克制，不能做成“爽点”）

## 核心问题（这期节目回答的一句话问题）
清军拿下扬州、南京几乎没遇到像样的抵抗，为什么一道剃头的命令下来，江南最难打的城，反而是一个连品级都没有的典史守住的？

## 三大基因自检
- [x] **小切口**：梅花岭那座墓里没有史可法——《明史》写遗体“不可辨识”、家人举袍笏招魂（#16）；八年后谈迁专程去墓前，叹扬州城坚、西门却塌了（#18）。一座空墓，开出“好人当不好督师”和“史可法不死”两条线。
- [x] **大纵深**：同一个夏天里，北京下令剃发（#35），南京开门迎降（#30），扬州余烬未冷（#21），江阴、嘉定、昆山、太湖、浙东接连起兵（#41、#57、#70、#71），福州和绍兴各立一个明朝（#72、#73）；清廷以为天下已定，开始派人去招抚七省（#40）。
- [x] **人性内核**：同样不肯剃头，有人选择自己死（刘宗周、徐汧，#69），有人选择守城（侯峒曾、阎应元，#58、#43）；同一把刀，很多握在昨天还是明军的人手里（#7、#60）；剃没剃头，几个月里成了两边都拿来杀人的记号（#65）。

## 印章拟定
- **印章四字**：`誓死固守`（出自《明史》卷277 侯峒曾传：嘉定士民推峒曾为倡，偕黄淳耀等“誓死固守”，#58、#63；古法排列：右列“誓死”、左列“固守”，自上而下）
- 沿用前两条长线惯例（印章取正史原文四字）；选嘉定一句而不选江阴“有降将军，无降典史”，因后者不见于正史（#47）。

## 内容弹药
- **主要素材**：《明史》卷274、277，《清史稿》卷4、218（正史，A，已核）；《明季南略》卷八、《嘉定屠城纪略》、《江阴城守纪》、全祖望《梅花岭记》（笔记／亲历文学／文集，已核原文，C，夸大风险已标）；顾诚《南明史》第五章 4–7 节、第六章 1–3 节、第七章 1–2 节、第八章 1–2 节（B，书中所引《清世祖实录》卷15–17、《青燐屑》、《史可法集》、《南都变略》等均为转引）；张德芳 1964、安东篱 2004、黄一农 2011（二手研究，经 zh.wikipedia 转引，只核到篇目）。
- **三条系列暗线**：
  1. **“降将线”**（EP35 → EP36 → EP38）：江北四镇的兵（李本深、张天禄、刘良佐、李成栋）几天之内变成攻扬州、追弘光、围江阴、屠嘉定的人（#7、#32、#47、#60）——其中李成栋三年后又反清归明，留给后面（本期最多一句）。
  2. **“头发线”**（EP34 → EP36）：EP34 结尾大顺余部归明；顾诚指出大顺余部当时也曾以“不剃头”为条件想归附清朝（#39）——一根辫子，把本可能谈成的统一变成了十几年的战争。
  3. **“史书说／小说说”线**（系列方法）：本期由小李翻出三处“流行说法”——教辅里的“血战十日”（#13）、“三王十八将阵亡”（#54）、“八十万”（#23），大开逐一对表。
- **对照组**：史可法（督师阁部、节制江北诸镇）vs 阎应元（不入流的前典史、手里只有百姓）（#20、#43）；南京三十余名高官开门迎降 vs 江阴生员在明伦堂说“头可断，发不可剃”（#30、#41）；一年前“照旧束发，悉从其便” vs 一年后“限旬日尽令剃发”（#34、#35）；嘉定开头家家贴“大清顺民” vs 结尾“远近始薙发，称大清顺民”（#57、#68）；刘宗周绝食 vs 侯峒曾守城（#69、#58）。
- **合法跑偏**：①清朝自己修的正史写扬州只有“攻克”两个字，屠城靠一封令旨和一本幸存者小册子才留下来（#25、#21）；②孔子的后人上疏想保留祖宗衣冠，被革职，“姑念圣裔免死”（#38）；③有人冒充史可法起兵，地方志里管他叫“伪史阁部”（#17）；④南京百姓在皇帝逃走那天早上，从监狱里请出一个“太子”上了武英殿（#29，与 EP35 假太子案接口）。
- **梗与现代映射**：公司被收购，高管们连夜签好了交接文件，反倒是基层一个早就办了离职手续的老员工，守着仓库不肯交钥匙（只作比喻，不代替史实，且只能用在南京与江阴对照处，不能用在屠城段落）。

## 选题评分（对抗自审后）
- **8/10**。加分：课本熟脸（史可法、梅花岭、扬州十日）进入快、反转强；主角切换（督师 → 典史）有顾诚原话撑腰，戏剧性足；剃发令“收回又重下”是正史与实录可证的硬反转，能把“为什么打”讲成人的选择而不是情绪；三个流行数字的校正天然适合双人对谈；结尾“两个明朝”干净地交给 EP37。扣分：江阴、嘉定的细节高度依赖亲历文学与托名笔记（C 级），正史只有梗概；屠城题材沉重，节奏和分寸难拿，稍不留神就滑向渲染或排满；与 EP35（左良玉、马士英、假太子）、EP17（南京迎降、钱谦益）都有接缝，须按写作交接的禁区处理。
