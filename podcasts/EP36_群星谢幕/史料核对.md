# 史料核对｜EP36《1662，大明群星在同一年谢幕》

---

## 一、核心考据主张与原始史料对照表

| 序号 | 剧本考据主张 | 原始史料出处 | 考证辨析与口径锁定 |
| :--- | :--- | :--- | :--- |
| **01** | **缅甸咒水之难与沐天波夺刀连杀九人**：缅王莽白借吃咒水盟誓为名诱杀南明扈从大臣；黔国公沐天波夺刀殊死肉搏杀九人殉节。 | 《清史稿·沐英传》、屈大均《安南游记》、刘健《庭闻录》卷三、顾诚《南明史》第二十一章。 | 顺治十八年七月十九日（1661年8月13日），缅王莽白发兵伏击者梗。从亡文武马吉翔等数十人手无寸铁惨遭屠杀。黔国公沐天波（明初黔宁王沐英十一代孙）自知难免，夺缅兵长刀连斩九人，力竭被杀。三百年世镇云南之沐氏家族至此殉节。史料真实无误。 |
| **02** | **吴三桂提重兵入缅索人与缅王交帝**：吴三桂率八万大军兵临阿瓦城外，缅王吓破胆，用小轿将永历帝及皇室引渡清营。 | 《清圣祖实录》卷五、《吴三桂纪略》、顾诚《南明史》第二十一章。 | 顺治十八年十一月，吴三桂与爱星阿率大军逼近阿瓦城下江北旧社。缅王见大兵压境，于十二月初二日将永历帝朱由榔、太子朱慈煊、太后皇后等用竹筏小轿押出，移交吴三桂清军大营。 |
| **03** | **昆明逼死坡与弓弦勒杀永历帝**：吴三桂在昆明城外见永历帝伏地汗流浃背；四月十四日在篦子坡用弓弦勒杀永历父子。 | 《庭闻录》卷三、《明季南略》卷十一、顾诚《南明史》第二十二章。 | 康熙元年（1662）三月永历帝被押至昆明。吴三桂前往探视，永历帝厉声质问汝非汉人乎，吴三桂伏地战栗不敢仰视。四月十四日，为防南明复辟隐患并向清廷输送终极投名状，吴三桂遣部将高得捷等将永历帝及太子朱慈煊带至昆明篦子坡，以弓弦勒死，焚骨扬灰。后人称此坡为“逼死坡”。 |
| **04** | **辨伪：永历手书“将军之心忍乎”致吴三桂伪信**：民间盛传永历帝在缅甸写下痛斥吴三桂长信，经学者考证为后人文人附会。 | 顾诚《南明史》第二十一章第二节、王夫之《永历实录》。 | 严谨史实考证：文人私史中所谓永历致吴三桂泣血痛陈旧恩书信（“将军之心忍乎，将军之身何置乎”），多为清初反清文士根据事后情绪加工伪托。永历帝晚年流亡身不由己，通信断绝；文稿在台词中据实澄清，不采用伪信对白，突出吴三桂冷酷的权力自保逻辑。 |
| **05** | **延平王郑成功同年五月猝逝台湾**：郑成功收复台湾后仅数月，面对国破父死多重打击，病逝安平，年仅三十九岁。 | 《郑成功档案史料选辑》、《先王实录》、夏琳《海纪辑要》。 | 康熙元年（1662）五月初八，郑成功于台湾病逝。死因复杂：前有永历遇弑、后有郑芝龙在北京被清廷斩决，加之黄澍叛乱、长子郑经私乱，数重剧变同时爆发，郑成功急火攻心暴卒。文稿着重还原其“孤臣蹈海、天意难挽”的悲剧气节。 |
| **06** | **大明战神李定国同年六月勐腊呕血绝唱**：李定国在勐腊闻永历帝被弑，痛哭呕血，留下“任死荒徼毋降”遗训溘然长逝。 | 《明史·李定国传》、《南疆逸史》卷三十一、顾诚《南明史》第二十二章。 | 康熙元年六月二十七日（1662年8月10日），李定国在勐腊病危。得知永历帝被弓弦勒死噩耗，号哭吐血数升，遗命部将“宁死荒徼，毋降也！”终年四十二岁。历史反讽：九月其子李嗣兴终难支撑降清。一代名将以生命守住了汉家最后的节操。 |
| **07** | **鲁监国朱以海同年病逝金门**：朱以海同年在金门哮喘病逝，《明史》沉海诬陷被现代考古彻底推翻。 | 《皇明监国鲁王圹志》（1959年金门出土）、《清史稿·诸王传》。 | 康熙元年十一月十三日，鲁王朱以海在金门病逝。清修《明史》诬蔑郑成功将其沉入大海，1959年金门金门城出土鲁王真墓与石碑圹志，明确记载因哮喘痰绝而逝，郑成功早已先行病逝数月。1662年所有反清宗室大纛彻底在同一年折断。 |

## 二、关键史料文字摘录备查

1. **《清史稿·沐英传》记沐天波之死**：
   > “顺治十八年，从由榔走缅甸。缅人谋作乱，以饮咒水邀群臣。天波知其诈，负刀力战，斩九人，死之。自英至天波，凡十四世，镇滇者二百六十年，至是而绝。”
2. **刘健《庭闻录》卷三记吴三桂见永历帝**：
   > “桂见帝，帝从容问曰：‘汝非汉人乎？何敢无礼至此？’桂伏地战汗，不能起。帝又曰：‘吴将军，汝昔受先朝厚恩，今乃反颜事仇，忍杀故主乎？’桂大惭，踉跄出，遂谋弑之。”
3. **《明史·李定国传》记定国之死**：
   > “定国在景线闻由榔崩，大哭，呕血数升。六月壬子，病卒，年四十二。临终顾其子嗣兴及部将胡顺九等曰：‘任死荒徼，毋降！’及定国死，嗣兴不能守，以部众降。”
4. **顾诚《南明史》第二十二章终局评述**：
   > “1662年，不仅是永历帝殉难的一年，也是郑成功、李定国相继去世的一年。南明这台充满悲壮、混乱、猜忌与背叛的历史大戏，在这一年同时降下了大幕。所有的抗清旗帜，在短短数月内全部折断。”
