# EP37 节目大纲：《民族英雄郑成功，他爹为什么亲手给清军打开了福建大门？》

> 2026-10-13 编写。南明系列 3/6。全期沿“郑家父子从同一条船上分开”的时间线走：福州称帝 → 权在郑氏 → 空窗的一年 → 仙霞岭空 → 汀州 → 福州洪塘 → 安平 → 南安孔庙 → 广东两个皇帝。分歧主线是“郑芝龙到底图什么、隆武这一年是怎么输的”。四段只为分工，主播在台词里不知道自己在分段。证据编号对应 `史料核对.md` 第一节（#1–#56）。按约 300 字/分钟估算，目标成片约 27 分钟（净台词约 7,500–8,500 字），是估算不是配额。

   疑问：皇帝为什么要追着一个臣子喊先生？这个人为什么非走不可？
   ↓

     → 福州这位皇帝：一年前还关在凤阳的皇族监狱里（#2）；不喝酒、穿布袍、逃难都带着几十车书（#3）；即位十天就杀了清朝来招降的使者，下令“有发为顺民，无发为难民”（#4）。小李：这皇帝听着挺像样。
     → 但他是谁扶起来的？郑鸿逵在半路拥立，哥哥郑芝龙在福州迎接（#1）。郑芝龙是谁：海盗出身，受了招安当总兵，在日本平户娶妻，生了个儿子叫郑森（#10、#11）；田产遍布闽广（#12，一句回扣 EP11 的平户）。

     → 小场面三连：朝班——郑芝龙要站首辅黄道周前面（#14）；郊天大典称病不出、郑鸿逵在大殿上扇扇子，户部尚书何楷当场喝止；何楷辞官回家，半路被割了一只耳朵，正史说是郑芝龙的部将干的（#15）。小李：一只耳朵？大开：当时有副对联……（标李光地记）。
     → 同时浙东还有个鲁王，两家互相挖墙脚：隆武派人带十万两银子去犒师，钱没到，人也没回来；鲁王派人给郑家兄弟封公爵（#6）。
   判断变化：这个朝廷的皇帝想干事，可兵和钱在别人手里。
   疑问：郑芝龙手里那么多兵，他拿去干什么了？
   ↓
[二] 账本：纸面上二十万兵，饷不够一半，预借来年两税、卖官，仙霞岭守关的只有几百个老弱（#16）。
     → 皇帝一遍遍催出兵，两路人马各带几千兵号称几万，走了一百来里说等军饷就回来了（#17）。首辅黄道周看不下去，自己去招了几千个市井之人出关，没多久在婺源兵败被俘，次年春死在南京（#18，兵力两数并存）。
     → 【差一点】大开拿出对面的档案：这一年清军主力北返，南京一度很空（#19）；隆武要离开福建、移驻赣州，往西连湖南、往南靠广东（#21）；清朝江西提督金声桓在奏本里把这个布局比作常山之蛇，请求给他两万满兵拦腰斩断（#22）。顾诚认为郑芝龙这时本可凭水师入长江（#20，标学者观点）。
     → 可是皇帝走不了：据一部私家史书，郑芝龙让几万军民拦在路上号哭，只能停在延平（#23）。另一头，何腾蛟派来“迎驾”的兵，从五月走到九月才到郴州，停住不动（#24）。小李：两边都在拖？大开：顾诚就说，隆武的事不能全算在郑芝龙一个人头上。

   疑问：那郑芝龙等的是什么？

     → 清朝那边早在三月就和郑芝龙搭上了线；《清史稿》说招抚的洪承畴跟他是同县人（#27）。

     → 隆武离开延平往赣州走，二十七日到汀州，第二天清军追到，被俘（#32）。死在汀州还是福州，史书对不上；后来还传说他逃到五指山当了和尚（#32，一句）。
     → 九月十九日清军进福州（#34）。
   判断变化：郑芝龙用一座空关换来了清军的“诚意”。
   疑问：他换到了什么？
   ↓
[四] 博洛的信：我看重将军，正是因为将军立了唐王；闽广总督的印已经铸好了（#35）。韩固山的兵逼近安平，郑芝龙发火，博洛装模作样把兵往后撤了三十里（#35）。
     → 劝阻：子弟都劝他别去（#36，《明季南略》）；正史只写郑成功劝过、父亲没听（#36，《清史稿》）。有一部书写了一大段父子争吵，大开只概述、标出处（#36）。
     → 十一月十五日，郑芝龙带五百人到福州，折箭为誓，喝了三天酒；半夜博洛拔营北上，把他带走了，随从关在别营（#38）。闽广总督没有，到北京是个空头爵位，实际上被看起来（#38）。小李：这笔账算砸了。
     → 郑成功没跟去：父亲想带他见博洛，叔叔郑鸿逵暗中放他下了海（#37）。

     → 【名场面】据清代地方志和后来的书，他把读书人的衣巾拿到南安孔庙前烧了，对着先师说从前是读书的孩子，今天是孤臣（#43）。小李：这么重要的事，正史没写？大开：没有，这一幕是地方志里的。

     → 次年第一仗：和叔叔围泉州，在桃花山打败清军提督，围了一个多月，援兵一到退回海上（#45）——第一次“差一点”。
     → 尾声：同一个冬天，广东一省两个皇帝（#47–#51）：桂王在肇庆监国，他母亲说我儿子担不起，请另选人（#47）；隆武的弟弟在广州抢先称帝，登基借戏班的冠服（#49）；两边在三水打了一仗，各胜一场（#50）；十二月十五日，清军包着头巾装成明军进了广州，广州的皇帝自缢（#51）。攻城的清军里，有郑芝龙的旧部（#52）。
   落点：福州一年，广州四十天；肇庆这位被母亲说“担不起”的皇帝，一边逃一边活了下来，一撑就是十五年（#55）。撑着他的不是郑家，是当年的“流寇”（#53）。停在这里。

## 两位主播的认识起点与分歧

- **大开的起点**：知道整条线，每一环先交代证据层级（正史 / 清实录与档案经顾诚转引 / 清初笔记 / 演义体史书 / 方志与晚出史书）。立场（来自顾诚）：隆武是南明诸帝里少见想干事的人；郑芝龙把朝廷当成巩固自家地盘的招牌；但这一年的崩溃是多方一起拖出来的，唐鲁互耗、何腾蛟不迎驾都有份。
- **小李的起点**：课本里的郑成功（收复台湾、民族英雄）；对郑芝龙的第一印象是“叛徒”；系列老听众，记得弘光朝的定策之争、扬州、剃发令，会自己认出“又在争谁立的皇帝”。
- **真实分歧（主线，不强行统一）：郑芝龙是“卖主求荣”，还是一个算错了账的商人？**
  - 小李（前半）：他就是卖了皇帝换官，开关、撤兵、送降书，一样不落（#27、#28）。
  - 小李（后半，替他算账）：长江都没挡住，福建一隅能守多久？他一家的田产、船队都在这儿，换个总督保住家业，在当时也不算稀奇（#12、#35）。
  - 大开：两层都对一半。账是这么算的，可这笔账从头就押错了对象——清朝要的是他手里的兵和船，不是他这个人（#38）；而且隆武这一年本来有机会，金声桓的奏本说明对手真怕那个布局（#22）。他部分承认小李：郑芝龙不出兵，何腾蛟也没来，隆武身边真心的人不多（#24）。
  - 结尾不统一，各自保留。
- **小分歧（可选）：焚儒服和田川氏之死，能不能讲？** 小李觉得这是郑成功故事里最打动人的部分；大开坚持讲，但要把出处讲清楚。一两个来回即止，落在“故事是这样传的，书是这样写的”。

## 第一段：权在郑氏（约 7 分钟，含冷开场）

- **冷开场**（#28）：
  - `[00:00-01:00]` 延平。奏疏、拜表即走、手敕称先生、船过延平、守关将领撤兵、仙霞岭空无一人。白描，不加心理。
  - `[01:00-02:00]` 报幕。小李：皇帝追着喊先生的这个人是谁？大开：郑芝龙，郑成功的爹。地图口播：南京没了，福州、绍兴各立一个。
- **隆武其人**（#2–#4）：高墙出身、布袍书车、杀清使、“有发为顺民”。给足这个人的分量，后面的崩塌才有落差。
- **郑芝龙其人**（#10–#13）：海盗—招安—总兵—平户娶妻—闽广田产。EP11 平户一句。正史四字“权在郑氏”。
- **三个小场面**（#14、#15）：朝班、扇子、耳朵。对联一句标出处。
- **唐鲁之争**（#5、#6、#9）：压缩到三四个来回。鲁王只作配角，钱塘江守军“日日唱戏”不用或只一句（#8，C）。

## 第二段：常山之蛇（约 6 分钟）

- **账本**（#16）：纸面二十万、饷不够一半、卖官、仙霞关几百人。
- **按兵不动**（#17）：两路出关一百里折回。
- **黄道周**（#18）：自请出征、几千市井之人、婺源被俘、南京就义；临刑一句第三人称。兵力两数并存。
- **差一点**（#19–#22）：清军北返、南京空虚（档案）；移驻赣州的计划；金声桓“常山之蛇”。大开把档案放在桌上，小李自己说出“原来对面最怕的是这个”。顾诚“水师入长江”只作学者判断。
- **走不了**（#23、#24）：拦驾（C，标出处）；何腾蛟迎驾军四个月没走到。小李提出“两边都在拖”，大开引顾诚：不能全算在郑芝龙头上。
- 可选一句：七月皇子出生，隆武大行封赏，有人讽刺（#25，C）。

## 第三段：二百封信（约 7 分钟）

- **钱塘江**（#26）：水浅、洗澡、涉水；鲁王入海。
- **搭线**（#27）：三月就有人见过郑芝龙；同县的洪承畴。
- **回到冷开场**（#28、#29）：这次讲完整：奏疏原话、手敕、施福撤关、空关三天、民谣。
- **焚降书**（#30）：名场面放在清军过岭之前讲（七月二十五日早于八月十八日过岭；与郑芝龙撤兵孰先孰后，史料不足，台词不排先后），大开交代钱秉镫的身份；只讲动作和他说的话（第三人称）。
- **汀州**（#32）：书车（#3）、宫人一骑三人（《明季南略》“隆武奔赣”条，C）、二十八日被俘；死地两说；五指山传闻一句。
- **福州陷落**（#34）一句。

## 第四段：烧掉的衣巾（约 7 分钟）

- **博洛的信与安平对峙**（#35）。
- **劝阻**（#36、#37）：《清史稿》为主，《台湾外记》对话只概述、标“一部讲郑家的书”。
- **洪塘那天**（#38）：五百人、三天酒、半夜拔营、别营、写家书；北京的空头爵位；1661 年被杀只一句（细节归 EP40）。
- **田川氏**（#42）：前一年才到中国；死在清军入安平那几天；三说并列；正史不载。小李追问，大开摆出处。**不渲染受辱，不讲剖腹涤肠的细节**（或只一句“据记载他按日本的办法收殓”）。
- **焚儒服**（#43）：交代出处（清代地方志、连横），地点南安孔庙，原话第三人称。
- **起兵**（#44、#46）：烈屿定盟、南澳募兵、人数诸说、仍用隆武年号；隆武年间已带兵。
- **泉州**（#45）：围城一个多月、援兵到即退——第一次差一点，一两句，不抢尾声。
- **尾声：广东两个皇帝**（#47–#52）：王氏那句话；绍武借戏服；三水各胜一场；清军包头巾进广州；攻城清军里有郑家旧部。
- **落点**（#53、#55）：福州一年、广州四十天；被母亲说担不起的那位撑了十五年；撑着他的是当年的“流寇”。报幕前停住，不总结。

## 结尾形态

- 停在“被母亲说担不起的皇帝，靠流寇撑了十五年”这一反差上，不给“隆武失败的三点原因”式总结；郑芝龙的分歧保留。
- 报幕时可一句：郑成功的故事刚开头，他后来打到南京城下，那是系列后面的事。**不预告李定国名字**，只说“下回说那些流寇”。

## 字数与节奏提示

- 冷开场、焚降书、焚儒服三处是画面最强的段落，可以给足；唐鲁之争和绍武永历互战人物多，压缩成三四个来回。
- 全期“书上对不上”只放三处：田川氏三种死法、隆武两个死地、焚儒服出处晚；由小李追问、大开对表，不要每段都来。
- 日期一律照用农历（闰六月、七月二十五、八月二十八、十一月十五、十二月十五），不自行换算阳历；田川氏卒日如需公历，用史料核对 #42 的换算并说“约合”。
- “十五年”按 1646 年冬即位到 1661 年底被缅甸交出计；不要说“十八年”（那是系列题名，1644–1662）。
