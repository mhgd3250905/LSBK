# 选题卡：EP37《民族英雄郑成功，他爹为什么亲手给清军打开了福建大门？》

> 2026-10-13 编写。明朝篇·南明十八年系列第 3 期（共 6 期）。事实依据见同目录 `史料核对.md`（#1–#56），凡冲突以史料核对为准。标题按用户口径只给一个“课本熟脸＋认知反转问句”，用户之后会自己重取。

## 基本信息
- **选题缘由**：用户定下的系列口径是长线连续叙事、每期锁定一个主角、要史诗感和跌宕起伏、每期留一个“差一点就赢了”的高光。本期接 EP36 结尾“南方冒出两个明朝”，主角是郑家父子：父亲郑芝龙一手把隆武扶上皇位，又一手撤空仙霞关；儿子郑成功在父亲北去、母亲死后烧了读书人的衣巾，拉起几十个人下海。课本里的郑成功只有“收复台湾”，这一期讲他的起点：一个“定策元勋”的儿子，怎样在二十出头的年纪（《台湾通史》说时年二十三，虚岁）跟父亲走上相反的路。
- **题型**：父子双线叙事（父亲的算盘 vs 儿子的选择）＋ 名场面串联（扇子与耳朵、焚降书、仙霞岭空、焚儒服）＋ 证据对表（田川氏三种死法、隆武两个死地、焚儒服出处晚）＋ 尾声对照（广东一省两个皇帝）
- **系列归属**：《笑谈历史》明朝篇·南明十八年系列 3/6（EP35 弘光朝 → EP36 扬州与江南 → **EP37 郑芝龙与郑成功** → EP38 李定国两蹶名王 → EP39 孙李内讧 → EP40 1662 群星谢幕）
- **地图口播**：南京 → **福州／厦门** → 肇庆／桂林 → 安龙 → 昆明 → 缅甸。本期开头一句“上回说到”落在“南京没了，福州和绍兴各立了一个”。
- **时间跨度**：顺治二年（1645）六月潞王降清 → 闰六月隆武在福州称帝、七月鲁王在绍兴监国 → 九月唐鲁颁诏之争 → 十二月隆武离福州移驻建宁 → 顺治三年（1646）二月驻延平 → 五月清军涉钱塘江、鲁王入海 → 六七月郑芝龙撤兵回安平、七月二十五日焚降书 → 八月十八日清军过仙霞岭 → 八月二十八日隆武在汀州被俘 → 九月十九日清军入福州 → 十月永历在肇庆监国 → 十一月初五绍武在广州称帝、十一月十五日郑芝龙到福州见博洛、十八日永历即位、二十九日三水之战、三十日田川氏死 → 十二月初一郑成功烈屿定盟（据《赐姓始末》）、十二月十五日清军伪装入广州 → 顺治四年（1647）八九月郑成功、郑鸿逵围泉州不克

## 核心认知反差（生死线）
- **你以为的**：
  1. 郑成功是收复台湾的民族英雄，郑家一门忠烈；
  2. 南明一年就把福建丢了，是因为清军太强；
  3. 郑成功烧儒服起兵、他母亲为国殉节，这些都是史书写得清清楚楚的事。
- **实际上的**：
  1. 隆武朝的兵权、钱粮全在郑芝龙手里，正史评语就四个字“权在郑氏”（#13）；把福建大门拱手让出的，正是这位“定策元勋”：他上疏说海寇来了要回家，守关将士跟着走光，仙霞岭空无一人（#28）；
  2. 1645 年秋到 1646 年夏，清军主力北返，南京一度很空（#19）；隆武要移驻赣州，清朝将领自己在奏本里把这个布局比作“常山之蛇”（#22）——这一年不是打不过，是没人去打：郑芝龙按兵不动，何腾蛟“迎驾”半年没走到（#17、#24）；
  3. 焚儒服出自清代地方志和更晚的书，正史不载（#43）；田川氏的死有三种说法，没有一种出自正史（#42）；隆武死在汀州还是福州也对不上（#32）。
- **反差的强度自评**：⭐⭐⭐⭐（“民族英雄的父亲是开门的人”反差强 × 名场面密 × 正史原文硬；扣一星是田川氏、焚儒服两处最动人的情节恰恰出处最软，必须边讲边限定，会拖慢情绪）

## 核心问题（这期节目回答的一句话问题）
隆武朝的兵和钱都在郑芝龙手里，他为什么在最该出兵的一年按兵不动，最后亲手撤空仙霞关？他的儿子又为什么偏偏选了相反的路？

## 三大基因自检
- [x] **小切口**：1646 年夏，郑芝龙一纸奏疏说要回家防海寇，隆武写手敕追他，叫他先生，求他稍等一起走；使者追到河边，船已过延平（#28）。两部清初笔记互证，正史有结果（“仙霞岭空无一人”）。
- [x] **大纵深**：南明第二个朝廷怎样在一年里耗光——唐鲁互相挖墙脚、清军主力北返的空窗、敌方档案里的“常山之蛇”、焚降书二百封、广东一省两个皇帝互打、清军伪装成明军进广州；顺带交出系列主线：撑下去的不是皇帝，是昔日的“流寇”（#53）。
- [x] **人性内核**：一个海盗出身的人押上全部身家扶起一个皇帝，又在押注翻盘时把皇帝卖了，最后被新主子软禁、家被抢、妻子死；他的儿子把读书人的衣服烧了，用父亲的旧部和父亲的船跟父亲投降的朝廷打了十几年。

## 选题评分（对抗自审后）
- **8/10**。加分：父子反向选择天然有戏；冷开场“先生稍迟，朕与先生同行”两书互证、正史有结果；“权在郑氏”“仙霞岭空无一人”“截其一耳”都是正史原文；“常山之蛇”用敌方档案撑起“差一点”高光，不靠假设煽情；尾声“广东两个皇帝互打、清军伪装进城”荒诞而有据，直接交出下期主线。扣分：田川氏之死与焚儒服是情绪最高的两处，偏偏都是 C 级、说法不一，台词必须边讲边限定；关键情节（焚降书、常山之蛇、黄熙允题本、墓志卒日）多经顾诚转引，未见原档；人物多（隆武、鲁王、黄道周、何楷、何腾蛟、博洛、永历、绍武），须按大纲压缩，鲁王与绍武只作配角。

## 冷开场方向
- `[00:00-01:00]` 1646 年夏天，福建延平。郑芝龙递上一道奏疏：海寇逼近我家安平，关上的军饷是我出的，我的钱从海上来，海上出事我就没有家了。拜完表就走。皇帝写手敕派人追，称他先生，请他稍等，说要和他一起走。使者追到河边，他的船已经过了延平（#28）。不久，守仙霞关的将领也说缺饷，带兵回了海边；正史只写了一句：仙霞岭空无一人。
- `[01:00-02:00]` 标志性报幕；小李：皇帝追着喊先生的这个人，是谁？大开：他叫郑芝龙，他有个儿子，大家都认识——郑成功。上回说到，南京没了，南方冒出两个明朝，一个在福州，一个在绍兴；福州这个皇帝，就是郑芝龙扶起来的。
