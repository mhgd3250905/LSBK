# 选题卡：EP38《张献忠的养子，怎么成了让清廷连折两王的人？》

> 2026-10-13 编写。明朝篇·南明十八年系列第 4 期（共 6 期）。事实依据见同目录 `史料核对.md`（#1–#38），凡冲突以史料核对为准。

## 基本信息
- **选题缘由**：用户定的系列口径是长线连续叙事、每期锁定一个主角、要史诗感和跌宕，每期留一个“差一点就赢了”的高光。南明六期里，最像“赢了”的一年是 1652 年：桂林、衡阳两仗，清朝一年里死了一位定南王、一位亲王。打出这两仗的人，是张献忠的养子李定国。课本里张献忠是“屠蜀”的那个人，他的养子五年后成了替大明打得最狠的将军——这个反差本身就是一期节目。
- **题型**：人物转身叙事（流寇养子→明朝藩王）＋ 一场名分闹剧（秦王封号）＋ 两场大胜 ＋ 一处必须两面讲的黑历史（晋宁）＋ 一个内讧引线
- **系列归属**：《笑谈历史》明朝篇·南明系列 4/6（EP35 弘光朝 → EP36 扬州与江南 → EP37 郑芝龙与郑成功 → **EP38 两蹶名王** → EP39 孙李内讧 → EP40 1662 群星谢幕）
- **主角**：李定国（王夫之《永历实录》作陕西榆林人、十岁被张献忠掳去收为养子；《清史稿》作陕西延安人；生年各书不明，维基所列 1621 年未见出处，台词不报年龄）
- **时间跨度**：顺治三年腊月（1647 年初）张献忠死于西充 → 四年正月綦江整军 → 三月入滇、四月入昆明 → 五六月临安、晋宁 → 1648 年杖责、擒沙定洲 → 1649 年请封、伪封秦王 → 1651 年南宁逼封、三月追认秦王 → 1652 年正月永历入安隆 → 五月靖州 → 七月初四桂林 → 十一月二十三衡阳 → 1653 年正月武冈密报、二月下旬入广西

## 核心认知反差（生死线）
- **你以为的**：
  1. 张献忠的部下都是杀人魔王，南明靠的是忠臣义士；
  2. 李定国是“民族英雄”，所到之处秋毫无犯；
  3. 清军入关后势如破竹，南明一路挨打，没赢过像样的仗；“清廷吓得要弃七省求和”。
- **实际上的**：
  1. 张献忠一死，孙可望、李定国就杀了张献忠的“皇后”和宰相、改了军令，跟俘虏的明朝官员杨畏知约法三章——第一条就是不再用大西年号（#2、#3、#9）。永历朝廷倒是为了一个“秦王”的名号吵了两年，最后被一枚假印逼着认了账（#11–#16）。
  2. 同一部《晋宁州志》，前半句写他“秋毫无犯，百姓具牛酒犒军”，后半句写他回兵屠城、截手（#7）。称颂他“秋毫无犯”的笔记也真实存在（#35）。两条都在，节目都讲。
  3. 1652 年清朝确实一年折了两王，顺治说“我朝用兵，从无此失”（#29）；但“弃七省议和”出自一篇清末民初人伪托的传记（#33）。真正让胜利停在半路的，是自己人：据永历一方记载，衡阳的包围圈缺了一角，是大哥孙可望下令撤的（#30）；明清两方都记下孙可望要借开会抓他（#31）。
- **反差的强度自评**：⭐⭐⭐⭐（“张献忠养子成明朝名将”× 假印变真的秦王 × 两蹶名王 × 晋宁两面 × 胜利毁于内讧；扣一星是衡阳细节诸说不一、晋宁只靠方志，很多地方只能说“据某书”）

## 核心问题（这期节目回答的一句话问题）
一个从小在张献忠营里长大的人，五年后替大明逼死了定南王、打死了清朝亲王——他是怎么从“贼”变成“王”的，又为什么赢到一半就停住了？

## 三大基因自检
- [x] **小切口**：顺治九年七月初四，桂林靖江王府起火。城里自尽的是孔有德——二十一年前在山东吴桥兵变、后来把红衣大炮带去后金的那个人（EP29）；城外攻城的，是张献忠的养子（#24、#29 顾炎武“廿载吴桥贼”）。
- [x] **大纵深**：大顺余部（EP34 忠贞营）、大西余部、永历朝廷、清朝四方同时在场（#18）；“秦王”封号牵动祖制、军权、朝堂党争（#12–#16）；1652 年是顾诚称为“湘、桂、川全面反攻”的一年，也是南明后期规模最大的一次反攻（#23–#29）。
- [x] **人性内核**：两兄弟的关系——孙可望把他按在演武场打了一百杖，两人抱头痛哭（#11）；四年后，一个在前线连斩两王，一个在后方写信催他回来开会（#31）。“现在由一个王来封另一个王，像话吗”（#32）。

## 印章拟定
- **印章四字**：`天下震动`（黄宗羲《永历纪年》“两蹶名王，天下震动”，经顾诚《南明史》23.3 转引，#29；古法排列：右列“天下”、左列“震动”）
- 未用“秋毫无犯”：反讽最强，但印在封面上易被读成褒扬，与晋宁两面讲的口径冲突。

- **合法跑偏**：①孙可望的“秦王之宝”据研究是颗镀金银印，降清时上缴，洪承畴奏疏里还特意写了（#14）；②王一品不敢去广西做巡抚，行贿规避被处绞；有人抽签抽到广西手都伸不出去（#29）；③王夫之笔下李定国问刘远生：曹操、司马懿是奸是愚？（#36）。
