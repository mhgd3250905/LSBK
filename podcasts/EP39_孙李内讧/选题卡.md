# 选题卡：EP39《清军打进云南的地图，为什么是明朝的“秦王”献上的？》

> 2026-10-13 编写。明朝篇·南明十八年系列第 5 期（共 6 期）。事实依据见同目录 `史料核对.md`（#1–#55），凡冲突以史料核对为准。

## 基本信息
- **选题缘由**：用户定下的系列口径是“长线连续叙事，每期锁定一个主角，讲人、讲选择、讲数字争议”。上一期李定国两蹶名王，南明打出了十几年来最好的局面；这一期回答整条线里最让人憋屈的问题：一个刚刚连杀清朝两个王的政权，为什么七年后皇帝要空着手走进缅甸。答案不在清军有多强（顾诚说 1658 年清军投入的兵力和 1652 年差不多，#40），在两个义兄弟之间。
- **题型**：权力内斗叙事（安龙—昆明—交水—长沙—北京）＋ 叛降与后果（献图、三路入滇）＋ 一个“差一点就赢了”的伏击（磨盘山）＋ 史料立场对表（永历一方 vs 清方档案 vs 顾诚）
- **系列归属**：《笑谈历史》明朝篇·南明十八年 5/6（EP35 弘光朝 → EP36 扬州与江南 → EP37 郑家父子 → EP38 李定国两蹶名王 → **EP39 孙李内讧** → EP40 1662 群星谢幕）
- **本期主角**：**孙可望**（张献忠养子之首、永历朝的实际执政者“国主”，降清后封义王）。李定国是对手戏，永历是被争夺的那个名号，白文选是两次决定胜负的配角。
- **时间跨度**：永历六年／顺治九年（1652）二月永历入安龙 → 同年冬密敕出发 → 1653–1654 李定国两入广东 → 1654 年三月二十日十八先生被杀；同年五六月孙可望谋登基未成 → 1656 年初李定国至安龙救驾、三月入昆明、四月封晋王 → 1657 年八月孙可望誓师、九月交水之战、九月底乞降、十一月到宝庆、十二月封义王 → 同月清廷下令三路进军 → 1658 年四月刘文秀病卒、五月三路会师贵州、十二月十五日永历离昆明 → 1659 年正月初三清军入昆明、闰正月二十日前后磨盘山伏击、二十六日永历入缅 → （尾声）1660 年十一月孙可望死于北京

## 核心认知反差（生死线）
- **你以为的**：
  1. 南明亡于清军太强、明朝气数已尽；
  2. 孙可望就是个篡位不成、卖国求荣的大反派，李定国是从头到尾的完人；
  3. 吴三桂一路追进云南，是硬碰硬打下来的。
- **实际上的**：
  1. 顾诚的判断：清军 1658 年三路进兵时，统帅多尼二十三岁、几乎没打过仗，兵力和 1652 年差不多；三路一直打到贵阳，没遇到像样的抵抗（#40）。南明是先自己打了一仗（交水，#23–#27），才输给清朝的；
  2. 孙可望治滇、整编、1652 年反攻都有大功，顾诚说那是“重大贡献”（#51）；连“行兵五要”这样的好名声，都因为他后来降清被记到了李定国一个人头上（#52）。李定国赢了交水以后，也把孙可望旧部叫“秦兵”另眼看待、把刘文秀挤到病死、把前线大将调回昆明、晚出兵半年（#38–#40）；
  3. 清军手里有孙可望献的云贵山川、将领、兵粮情形图，还有他给的十九个熟悉地形的向导（#30）；洪承畴原本已经以“寸土未拓”请辞回京，是孙可望的来降让他留了下来（#29）。
- **反差的强度自评**：⭐⭐⭐⭐（“清朝太强”的默认印象 × 交水阵前倒戈 × 洪承畴请辞又留任的档案 × 献图；扣一星是“谁的错更大”只能给顾诚的判断，各书立场太重，无法定论）

## 核心问题（这期节目回答的一句话问题）
1652 年南明刚刚打出十几年来最好的仗，七年后皇帝却空着手走进了缅甸——把西南交到清朝手里的，究竟是清军，还是两个义兄弟自己？

## 三大基因自检
- [x] **小切口**：1657 年冬，长沙。洪承畴刚在奏疏里承认经略几年“寸土未拓”、已获准回京养病；半个月后，明朝的“国主”孙可望带着几百人来投降，洪承畴马上上疏说不走了（#29）。档案原文，画面完整，课本熟脸（EP15 讲过他松锦降清、EP31 讲过他在潼关追李自成）。
- [x] **大纵深**：南明最后一个有实力的根据地怎么丢的；系列里两条“流寇转忠臣”的线（大西军、大顺余部）在本期交汇于刘文秀遗表“入蜀以就十三家”（#39）；吴三桂从山海关一路走到磨盘山（#37、#45）。
- [x] **人性内核**：一个人会治国、能整军，却受不了皇帝不在自己手里；另一个人会打仗、肯尽忠，赢了以后也开始提防自己人。当地人的一句话：可望善治国，定国能用兵（#53）。

## 内容弹药
- **主要素材**：《明史》卷120、279，《清史稿》卷5、224、474（正史，A，已核）；《明季南略》卷16、17，《小腆纪年》卷19，《永历实录》卷14（笔记／编年，C，已核）；顾诚《南明史》第二十四章第五节、第二十七章、第二十八章第一、三节、第三十章第一节（B），及其转引的洪承畴揭帖、孙可望揭帖、《清世祖实录》、《安龙逸史》、《残明纪事》、《狩缅纪事》等（A/C，转引）。
- **三条系列暗线**：
  1. **地图线**：开头口播的那张地图（南京→福州／厦门→肇庆／桂林→安龙→昆明→缅甸），本期走完安龙→昆明→缅甸三站；结尾孙可望献给清朝的也是一张图（#30）。
  2. **“流寇”线**（EP34 → EP37 → 本期）：EP34 结尾大顺余部归明、EP37 结尾“永历靠昔日流寇撑了十五年”；本期大西军内部先打了起来，刘文秀临死建议去投大顺余部的夔东十三家（#39）。
  3. **吴三桂与洪承畴线**（EP15、EP31、EP33、EP34 → 本期）：洪承畴请辞又留任（#29）；吴三桂是北路统帅，也是磨盘山伏击的对象（#37、#45）。
- **对照组**：1649 年孙可望带整个云南求一个王号被百般刁难 vs 1657 年带几百人降清当即封王（#31）；孙可望十四万 vs 李刘三万上下（#23）；孙可望降清只带走几百人 vs 刘文秀收编其旧部三万余（#54）；永历“恐清师至此无粮”不烧仓 vs 清军靠这些粮吃到九月（#42）；磨盘山差一点赢 vs 五天后皇帝在关前解甲（#45、#48）。
- **合法跑偏**：①一句“我以为你也知道”泄了天下最大的密（#9）；②冯双礼的三声假号炮（#27）；③清朝和南明此时历法差一个月，同一天一边叫二月一边叫闰正月（#43）；④孙可望在北京为弟弟要一张驿站勘合，被御史骂“何功何德”（#34）。
- **梗与现代映射**：一家公司的两个联合创始人，一个管运营、一个管业务，董事长名义上还在；运营那位想把董事长换掉，业务那位把董事长接走——最后运营那位带着全部内部资料去了竞争对手（只作比喻，不代替史实，台词里最多一句）。

## 选题评分（对抗自审后）
- **8/10**。加分：冷开场是档案原文且有课本熟脸（洪承畴）；“未经奏明”“我以为你也知道”“迎晋王”“三声号炮”“坐山顶土扑满脸”几个名场面都有出处、适合双人对谈；孙可望的平衡讲法有顾诚做底，正好落实系列“讲人、讲选择”的口径；磨盘山给了全期一个“差一点就赢了”的高光，结尾入缅画面有《明史》原文。扣分：史料一边倒（多出永历一方），很多细节只能“据记载”，写手容易写成流水账式的“据……据……”；交水、三路入滇两段战役信息密，需要大幅删减；李定国形象在本期回落，需与 EP38 写手对齐口径；“谁的错更大”无定论。
