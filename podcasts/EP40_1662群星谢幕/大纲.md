# EP40 节目大纲：《郑成功收复台湾的那一年，大明最后一个皇帝在哪里？》

> 2026-10-13 编写。南明系列 6/6（终篇）。全期沿“1659 年出境 → 1662 年四颗星陨落”的时间线走，主轴是永历帝的最后三年，副线是郑成功（南京城下、台湾、病卒），第三条线是李定国（迎驾、焚表、病卒）。分歧主线是“南明到底在哪一刻结束”。四段只为分工，主播在台词里不知道自己在分段。证据编号对应 `史料核对.md` 第一节（#1–#62）。按约 300 字/分钟估算，目标成片约 28 分钟（净台词约 7,800–8,800 字），是估算不是配额。

## 全期发现路径

```

   ↓
[冷开场] 1661 年十二月初二，缅甸阿瓦城外：缅兵连人带椅子把永历抬上船，说中国兵马来了；对岸人声嘈杂。据一本书说，背他上岸的人自报是平西王的前锋；永历说了一句“平西王，吴三桂也”，再不开口（#32）。

[一] 地图口播＋接上回：磨盘山没打成（#1，一句），皇帝往西出了国境。

     → 小李：李定国呢？就这么让皇帝走了？大开：李定国没进缅甸，派人追，使者一进去就被杀（#4）。
     → 缅甸的待遇：玉玺对不上，得靠沐天波的官印证明皇帝是真的——原来的玉玺 1644 年就被大顺军缴了（#6，回扣闯王系列）；国王隔河住了两年，一次没见过（#7）；沐天波光着脚去给缅王行礼，回来大哭；皇帝把金国玺扔地上，让人凿碎分了（#8）。
   判断变化：入缅的那一刻，这个朝廷就只剩一个名字了。
   ↓
     → 镜头切到东边，同一个夏天：郑成功的十几万人进了长江，破瓜洲、下镇江（#10）；七月十二日在孝陵前祭太祖，八十三座营盘扎在南京城外（#11）；张煌言带着不到一千人往上游走，三四十座城望风来附（#13）。
     → 小李：这回能成吧？大开：围了十三天，一箭没往城里射（#12）。据一部清代写郑家的书，城里的人请他宽限三十天再投降，他答应了（#14，限定出处）。
     → 七月二十三、二十四两天，梁化凤出城突袭，郑军陆师崩溃，甘辉被俘，潘庚钟站在主帅的黄伞下替他死了（#15）；据传北京那边慌到皇帝要亲征（#16）。郑成功撤得太快，连张煌言都没通知（#17）。
   判断变化：这是南明十八年里最后一次真正接近翻盘——差的不是兵，是那十三天。
   疑问：东边败了，西边缅甸里的皇帝，还有人去救吗？
   ↓
[二] 救兵与圣旨：
     → 白文选打进缅甸，打赢了，皇帝一道敕书让他退兵，他磕头就退了（#18）；另一路高文贵也被敕令退回，忧愤而死，传旨的官员回来以“退兵有功”升官（#19）。
     → 最刺的一笔：据随行者记载，皇帝给缅甸守关的人下旨，说自己已经去福建了，后面再来明军，你们只管狠狠地打（#20）。小李：这是自己人打自己人？大开：是马吉翔这帮人怂恿的，但旨是他发的。
     → 李定国的信：三十多道奏疏不知道送到没有，你们只顾在里面过安稳日子（#21）。小李：这是两蹶名王的那个李定国？大开：同一个人，现在连皇帝的面都见不着。
     → 最后一次：白文选搭浮桥，被缅军砍断（#22）；沐天波想带太子突围，被反诬，皇帝杀了他的家丁（#23）。
     → 东边，郑成功收拾残兵转向台湾（#42，一句）；十月，北京杀了郑芝龙（#44，一句回扣 EP37）。
   判断变化：缅甸那道门，有一半是从里面关上的。
   ↓
[三] 咒水与篦子坡（主线最重的一段）：
     → 1661 年五月缅甸政变，新王杀兄（#24）；永历君臣不肯去贺。
     → 七月：缅方请廷臣过江“吃咒水盟誓”（#25；交代咒水是盟誓的名义，不是巫术）。十九日（诸书不一，第二节第 1 条）塔下三千缅兵围住，沐天波夺刀杀了九个人后战死，四十多位文武官员一个不剩（#26）。皇帝要上吊，被身边仅存的人劝住；二十五个人被关在一间小屋（#27）。
     → 十一月，永历对身边人说：当初是被奸臣误了（#28）。小李：这话怎么那么耳熟？大开：十八年前，煤山上那一位写的是“诸臣误朕”。（只对照，不总结）
     → 吴三桂：是他自己要来的。部下劝他“先除由榔绝人望”，他上了三患二难疏（#29）；九月发兵，十二月到了离缅都六十里的地方（#30）。
     → 据传永历给他写过一封信：将军之功大矣，将军之心忍乎（#31）。小分歧：小李信；大开说出处有，可文字太工整，有人怀疑后人修过（第二节第 3 条）。
     → 回到冷开场：十二月初二，椅子、船、晋王来接——两本书谁在岸边说法不一（#32）。按今天的日历，这已经是 1662 年开年（#33）。吴三桂伏地流汗那一幕，是部下商人传出来的故事（#34，传说）。
     → 1662 年三月押回昆明，百姓看着他哭（#35、#36）；四月，吴三桂主张砍头，满洲将领说他当过皇帝，留个全尸（#37）；弓弦，篦子坡，一说在门前小庙（#38）；哪一天，书上有三四种说法（#39）。后来那里叫逼死坡，两百多年后（1911 年）才有人在那里立了碑（#40）。
     → 五月，吴三桂进封亲王（#41）。
   判断变化：最后一个明朝皇帝，不是死在战场上，是被从一个国家的河边、一路抬回自己的旧都处决的。
   疑问：剩下的人呢？
   ↓
[四] 四颗星，同一年：
     → 郑成功：台湾拿下了，荷兰人举着旗走出城堡——按今天的日历，离永历被交出只隔十来天（#43）。四月听到永历的消息（#45）；家里出了事，他要杀儿子，部下拒命（#46）；五月初一还坐在胡床上见诸将，据说每天登台拿望远镜望澎湖有没有船来，初八就死了，不到四十岁（#47）。
     → 李定国：白文选被部下挟走时，他拦住儿子不许打——当年一起起事的几十个人，就剩我们两个了（#48）；五月焚表告天，求老天如果气数已尽，让我一个人早死（#50）；六月，生日那天病倒，留下“任死荒徼，毋降”，十几天后死在边地（#51、#52）。小李：然后他儿子守住了？大开：不到半年，降了（#53）。
     → 鲁王：张煌言请他称帝，没人理（#55）；十一月十三日哮喘发作死在金门（#56）。
     → **史书说**：小李翻《明史》——郑成功把鲁王沉海了（#57）。大开：1959 年金门挖出了他的墓志，写的是哮喘；而且他比郑成功晚死半年，郑成功怎么沉他？（不说“篡改”）
     → 分歧主线（见下）：南明到底在哪一刻结束？
   落点：1664 年，张煌言在杭州就义，李来亨在茅麓山自尽（#58、#59，回扣 EP34）。地图口播的最后一站：缅甸 → 昆明。大开报幕：“十八年前南京那位说诸臣误朕，十八年后昆明这位说朕为奸臣所误；中间那些人，没有一个被谁误过——他们是自己选的。”（这句为方向示意，写手可改，但不要拔高成“历史的教训”）停在这里。
```

## 两位主播的认识起点与分歧

- **大开的起点**：知道整条线，每一环先交代证据层级（正史 / 实录与档案转引 / 当事人文集 / 幸存者笔记 / 小说化史书 / 地方传说）。立场（来自顾诚）：入缅是永历朝廷的决策失误，缅甸不是主要被指责对象；郑成功南京之败是轻敌与部署失当；永历之死、李定国之死的细节都有多个版本。
- **小李的起点**：课本印象（1662 收复台湾、明亡于 1644）加系列前五期记忆：EP35 诸臣误朕、EP36 江阴嘉定、EP37 郑家父子、EP38 两蹶名王、EP39 磨盘山。她会自己认出“诸臣误朕”的回声、“平西王”是山海关那个吴三桂、“三十多道奏疏”的李定国是两蹶名王的李定国。
- **真实分歧（主线，不强行统一）：南明到底在哪一刻结束？**
  - 小李：1662 年。皇帝死了，李定国死了，郑成功也死了；《清史稿》在李定国儿子投降那里直接写了“明亡”（#54）。
  - 大开：要看你认什么。顾诚说 1661 年底永历被交出就“明统告绝”；张煌言、李来亨撑到 1664；郑家用永历年号一直用到 1683（#60）。但他部分同意小李：郑经的年号已经没有号召力了，旗是 1662 年倒的。
  - 结尾不统一，各自保留。
- **小分歧（可选）：“将军之心忍乎”那封信是真是假**（第二节第 3 条）。小李被打动，信；大开给两边理由，倾向“事可能有，字被修过”。一两个来回即止。
- **小分歧（可选）：永历值不值得同情。** 小李：窝囊，缴械、砸印、下旨打救兵；大开：顾诚也是这么骂的，但最后那封信和“朕为奸臣所误”，说明他自己也知道。不替他洗白。

## 第一段：缅甸的门和南京的城（约 8 分钟，含冷开场）

- **冷开场**（#32）：
  - `[00:00-01:00]` 椅子、船、河对岸的人声；背他上岸的人自报平西王前锋；“平西王，吴三桂也”，默然。大开白描，交代“据一本清初的书”。
  - `[01:00-02:00]` 报幕＋地图口播；小李认出吴三桂。
- **出境**（#1—#5）：磨盘山一句；被自家护卫抢；关前缴械；李定国没有入缅（大开用 #4 反驳小李“李定国把皇帝送进去的”）。
- **缅甸两年**（#6—#8）：玉玺对不上靠官印（回扣大顺缴玺，一句）；隔河两年不见面；沐天波赤足朝见；凿碎金国玺——典玺太监那句第三人称。
- **南京城下**（#9—#17）：
  - 去年海上飓风一句（#9）；瓜洲、镇江（#10）。
  - **孝陵祭太祖、八十三座营盘**——全期唯一的昂扬画面，给足（#11）。张煌言上游三四十座城（#13）。
  - **一箭未射**（#12）：张煌言原话第三人称；“三十天”只讲“据一部清代写郑家的书”（#14）。
  - 崩溃：前几天有士兵离营去江边捕鱼；余新被袭；二十四日大败；潘庚钟黄伞下战死（#15）。“据传顺治要亲征”一句（#16）。
  - 没通知张煌言（#17）——为尾声埋线（台词里不说“伏笔”）。

## 第二段：救兵被圣旨挡回去（约 5 分钟）

- 白文选退兵（#18）；高文贵忧愤、传旨官升官（#19，黑色幽默）。
- **“可奋力剿歼”**（#20）：小李反应要真；大开交代马吉翔怂恿、单一来源。
- **李定国三十多道奏疏**（#21）：两书互证，可直说；小李认出两蹶名王。
- 浮桥被砍、沐天波密谋被反诬（#22、#23）——为咒水段的沐天波埋线。
- 东线两句：郑成功转向台湾（#42）、郑芝龙被杀（#44，回扣 EP37，不讲细节）。

## 第三段：咒水和弓弦（约 9 分钟）

- **政变与咒水**（#24—#27）：新王杀兄；永历不贺；“吃咒水”的意思交代清楚；塔下三千人；沐天波夺刀杀九人战死；《明史》四十二人；二十五人关进小屋。日期说“七月，多数书说十九日”。
- **“朕为奸臣所误”**（#28）：小李自己认出“诸臣误朕”；大开只说“随行者记下的话”，不总结。
- **吴三桂**（#29—#31）：主动请战、杨珅那句、三患二难；信——小分歧。信中“缟素誓师”一句可由大开点出它指的是 1644 年山海关（回扣闯王系列）。
- **回到冷开场**（#32—#34）：两本书的岸边版本；公历已是 1662；伏地流汗只作传说。
- **昆明**（#35—#41）：押回、百姓哭、“须长过脐”标出处；满洲将领主张全尸；弓弦、篦子坡／门前小庙；日期诸说；焚尸；民国立碑一句；吴三桂进亲王。
- **注意**：这一段最容易“演”，咒水塔下与篦子坡都只白描史书写到的动作，不编心理活动和最后的话。

## 第四段：四颗星（约 6 分钟）

- **郑成功**（#43—#47）：荷兰人举旗出城（一句，课本熟，不讲战役）；“前后差十来天”由小李算出来；家变只讲骨架；望远镜望澎湖标《台湾外纪》；“狂怒咬指”标《清史稿》；不到四十岁。
- **李定国**（#48—#53）：“就剩我们两个了”；焚表；生日病倒；“任死荒徼，毋降”；勐腊／景线；儿子不到半年降清——反讽由小李说出，大开不责备李嗣兴。
- **鲁王**（#55—#57）：称帝无人理；哮喘；**史书说：沉海 vs 墓志**。
- **分歧主线**（第二节第 9 条）：小李 1662，大开列 1661／1664／1683，各留一半。
- **落点**：1664 张煌言、李来亨一句；地图口播最后一站；两句“误朕”对照；停住。可选：吴三桂 1673 起兵、清廷公布三患二难疏一句（#61），放在落点之前，不展开三藩。

## 结尾形态

- 停在“诸臣误朕 / 朕为奸臣所误 / 中间的人是自己选的”这一对照上，或者停在“任死荒徼”四个字上（写手二选一），不给“南明灭亡的三点原因”式总结；分歧保留。
- 报幕可一句交代：南明系列从 1644 年南京定策讲起，到这里结束。**不预告下一条线**（用户未定），只说“明朝篇的这一段讲完了”。

## 字数与节奏提示

- 冷开场、孝陵、咒水塔下、“任死荒徼”是四处画面最强的段落，可以给足；入缅初期和救兵段落信息密，每件事只留一个能记住的细节（缴械／凿印／“奋力剿歼”／三十多道奏疏）。
- 全期“史书说”只有一处正式的（鲁王沉海），其余是“诸书不一”：咒水日期、永历死期与地点、李定国卒地——**统一用一句“书上有几种说法”带过，不要每处都展开对表**，否则节奏会碎。
- “据随行者记载”这类限定语全期会反复出现，写手可以让大开在第一段一次性交代“入缅以后的事，几乎都是几个活下来的随从记下来的”，之后简写为“随从的书里说”。
- 人物主次：永历＞李定国＞郑成功＞吴三桂＞沐天波＞白文选＞鲁王＞张煌言。马吉翔只作“怂恿者”出现，不单独成段。
- “十八年”按 1644→1662 计（系列题名）；尾声的 1664、1683 只作分歧材料。
