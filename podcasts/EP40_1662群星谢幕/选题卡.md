# 选题卡：EP40《郑成功收复台湾的那一年，大明最后一个皇帝在哪里？》

> 2026-10-13 编写。明朝篇·南明十八年系列第 6 期，系列终篇。事实依据见同目录 `史料核对.md`（#1–#62），凡冲突以史料核对为准。

## 基本信息
- **选题缘由**：用户定下的系列口径是“长线连续叙事，每期锁定一个主角，要史诗感、趣味性、跌宕起伏，讲人、讲选择、讲数字争议”。终篇要把整条线收住：从南京一路退到缅甸的“大明”，最后在哪一刻、以什么方式结束。课本里 1662 年只有一句“郑成功收复台湾”；同一年，永历帝在昆明被弓弦勒死，李定国病死在边地，郑成功自己也死了，年底鲁王死在金门。这一期把“收复台湾”这张课本熟脸翻过来，看它背后的整个 1662。
- **题型**：编年谢幕叙事（入缅—南京城下—咒水—被执—昆明—四人之死）＋ 证据对表（咒水日期、永历死期与执行者、“将军之心忍乎”真伪、李定国卒地、鲁王沉海说）＋ 系列收束（地图口播走完最后一站、回扣 EP15“诸臣误朕”、EP34 吴三桂与大顺余部）
- **系列归属**：《笑谈历史》明朝篇·南明十八年系列 6/6（EP35 弘光朝 → EP36 扬州与江南 → EP37 郑芝龙与郑成功 → EP38 李定国两蹶名王 → EP39 孙李内讧 → **EP40 1662 群星谢幕**）
- **本期主角**：**永历帝朱由榔**（按摸排报告的主角分配）。他是南明在位最久、存在感最弱的皇帝；本期用他的最后三年做主轴，李定国、郑成功作为另两颗“星”，鲁王与张煌言作尾声。
- **时间跨度**：顺治十六年／永历十三年（1659）闰正月二十六日入缅 → 同年五月至七月郑成功长江之役、七月二十四日南京城下大败 → 1659—1661 年李定国、白文选数次入缅迎驾 → 1661 年四月郑成功登陆台湾 → 五月缅甸政变 → 七月十九日咒水之难 → 十月郑芝龙被杀 → 九月至十二月吴三桂入缅、十二月初永历被交出（公历已是 1662 年 1 月）→ 公历 1662 年 2 月 1 日荷兰人投降 → 康熙元年（1662）三月永历押回昆明 → 四月永历父子遇害 → 五月初八郑成功卒 → 六月李定国病卒 → 十一月十三日鲁王卒 → （尾声）1664 年张煌言就义、李来亨茅麓山覆灭

## 核心认知反差（生死线）
- **你以为的**：
  1. 1662 年是“郑成功收复台湾”的年份，一件扬眉吐气的事；
  2. 明朝亡于 1644 年煤山，后面的南明只是苟延残喘，没什么可讲；
  3. 吴三桂冲进缅甸，亲手用弓弦勒死了最后一个明朝皇帝；
  4. 最后的皇帝被抓，是因为缅甸人背信弃义。
- **实际上的**：
  1. 按今天的日历，1662 年 1 月永历被缅甸交给吴三桂，2 月荷兰人向郑成功投降，前后只差十来天；之后永历被杀、郑成功病死、李定国病死、鲁王病死，全挤在这一年（#33、#43、#47、#51、#56；公历为换算）；
  2. 1659 年郑成功的大军曾把南京围了半个月，祭了孝陵，张煌言拿下了三四十座城——这是整个南明最接近翻盘的时刻之一，却一箭没往城里射（#11—#13、#15）；
  3. 吴三桂是主动要去缅甸的那个人，但动手的是他的部下，用的是弓弦；满洲将领反倒主张给永历留全尸（#29、#37、#38）；
  4. 把皇帝困死在缅甸的，有缅甸的政变，也有皇帝自己：入境时自缴兵器、给救兵下旨让缅甸“奋力剿歼”、把国玺砸碎分给群臣（#3、#8、#20）。顾诚的判断是，该受指责的是永历朝廷流亡缅甸这个决定（第四节禁区 11）。
- **反差的强度自评**：⭐⭐⭐⭐（“收复台湾”是全国课本最熟的一句 × 同一年四颗星全部陨落 × 救兵被皇帝自己的圣旨挡回去 × 系列首尾“诸臣误朕”与“朕为奸臣所误”对照；扣一星是入缅后的细节几乎全部来自幸存者笔记，日期各书打架，只能边讲边限定）

## 核心问题（这期节目回答的一句话问题）
郑成功收复台湾的同一年，大明最后一个皇帝被人从缅甸抬回昆明、用弓弦勒死——南明这十八年，到底是在哪一刻真正结束的？

## 三大基因自检
- [x] **小切口**：1661 年十二月初二，缅甸兵把永历连椅子一起抬上船，告诉他“晋王来接您了”；船靠岸，背他上岸的人说自己是平西王的前锋（#32）。两本笔记情节有异，骨架一致；而“平西王”三个字，正是系列从 EP33/34 山海关就一路跟过来的那个人。
- [x] **大纵深**：一年之内，东边郑成功拿下台湾、西边永历死于昆明、南边李定国死于边地、海上鲁王死于金门；地理上走完了系列的地图：南京→福州/厦门→肇庆/桂林→安龙→昆明→缅甸→回到昆明（#33、#43、#51、#56）。
- [x] **人性内核**：一个十几年里被各路人马抬着跑的皇帝，最后一次后悔，说的是“朕为奸臣所误”（#28）——十八年前，煤山上那位说的是“诸臣误朕”。另一边，一个出身“流寇”的将军给他上了三十多道奏疏，临死只留下四个字：任死荒徼（#21、#51）。

## 内容弹药
- **主要素材**：《明史》卷120、116，《清史稿》卷6、224、474（正史，A，已核）；顾诚《南明史》第二十六章第二节、第二十八至三十一章（B，引《狩缅纪事》《也是录》《庭闻录》《行在阳秋》《从征实录》《北征录》《台湾外纪》、满文档案、清实录、康熙方志）；zh.wikipedia《咒水之难》《永历帝》《皇明監國魯王壙誌》（C，用于核对日期出处与圹志）。
- **三条系列暗线**：
  1. **“误朕”线**：EP15 崇祯“然皆诸臣误朕” → EP35 开头回扣 → EP40 永历“当日朕为奸臣所误”（#28）。由小李自然认出，大开限定“这是随行者笔记里的话”。
  2. **吴三桂线**（闯王系列 EP33/34 → 本期）：1644 山海关借兵 → 1659 率军入滇 → 1660 “三患二难”疏 → 1661 入缅 → 1662 进封亲王（#29、#41）；永历信里那句“将军缟素誓师，提兵问罪”指的正是 1644 年（#31）。尾声一句：1673 年他自己反了，清廷把这份奏疏公之于众（#61）。
  3. **“史书说／墓志说”线**：本期的“史书说”给《明史》卷116 的“郑成功沉鲁王”——1959 年金门挖出的墓志说他是哮喘病死的，而且死在郑成功之后半年（#56、#57）。
- **对照组**：郑成功在南京城下“一箭不射”等对方投降 vs 永历在缅甸下旨让缅军打自己的救兵（#12、#20）；李定国“三十多道奏疏” vs 廷臣“只顾在内安乐”（#21）；吴三桂主张斩首 vs 满洲将领主张留全尸（#37）；《清史稿》在李嗣兴投降处写“明亡” vs 郑经继续用永历年号二十年（#54、#60）；1644 年吴三桂“缟素誓师” vs 1662 年吴三桂进封亲王（#31、#41）。
- **合法跑偏**：①永历要靠沐天波的官印证明自己是皇帝，因为原来的玉玺 1644 年就被大顺军缴了（#6，回扣闯王系列）；②去传旨让救兵退走的官员，回来以“退兵有功”升了官（#19）；③缅甸国王和永历隔一条河住了两年多，据记载一次面都没见过（#7）；④那位“嫌水太冷”的钱谦益，后来暗中为长江之役奔走过（#62，EP17 一句彩蛋，可不用）。
- **梗与现代映射**：一个公司已经被收购了，最后一个“总经理”还带着公章流落海外，靠前台小哥的工牌证明身份（只作比喻，慎用，不代替史实）。

## 选题评分（对抗自审后）
- **8/10**。加分：标题以课本最熟的一句“收复台湾”做反转，入口极低；1662 年四颗星陨落的结构天然有史诗感和收束感；冷开场“晋王来接您了”画面强、又直接连上闯王系列的吴三桂；“诸臣误朕—朕为奸臣所误”给整个南明系列一个干净的首尾；“郑成功沉鲁王”被墓志推翻是一条硬的“史书说”。扣分：入缅后的现场细节几乎全出自《狩缅纪事》《也是录》等幸存者笔记，单一视角、日期互相矛盾（咒水、永历死期、李定国卒地卒日都有三四种说法），写手须频繁说“据随行者记载”“诸书不一”，节奏容易被打断；南京城下段落最动人的“三十日缓兵计”出自小说化史书，只能降格使用；本期人物多（永历、李定国、郑成功、吴三桂、沐天波、白文选、鲁王、张煌言），须严格按主次分配篇幅，否则会散；整体基调偏悲，靠南京城下一段撑“差一点就赢了”。
