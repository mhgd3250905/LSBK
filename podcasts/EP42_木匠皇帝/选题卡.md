# 选题卡：EP42《“木匠皇帝”真的只会做木工吗？》

> 2026-10-14 编写。明朝篇·天启与九千岁系列第 2 期（摸排 EP-B）。事实依据见同目录 `史料核对.md`（#1–#44），凡冲突以史料核对为准。

## 基本信息
- **选题缘由**：用户 2026-10-14 批准的系列口径：全线一个问题——九千岁的权力是从哪借来的？主线“体制视角”，“翻案视角”集中在本期；不替魏忠贤洗白；按时间顺讲，每期有承接和钩子。EP41 讲魏忠贤怎么把权力借到手，结尾停在“奏疏是念给皇帝听的，那皇帝当时在干什么”。本期回答这个问题：出借人在干什么。课本里天启只有一个标签“木匠皇帝”，网上又流行“九千岁收商税救大明”；本期把这两张熟脸都翻过来看。
- **题型**：人物翻面（木匠皇帝的两份原始档案）＋ 人事叙事（孙承宗四年、通州折返、高第撤防、襁褓封伯）＋ 账本对表（辽饷 → 撤税监 → 复榷 → 停榷，补充 EP12）
- **系列归属**：《笑谈历史》明朝篇·天启与九千岁系列 2/4（EP41 九千岁的权力链 → **EP42 木匠皇帝** → EP43 生祠与五人墓 → EP44 崇祯除阉与逆案）
- **本期主角**：**明熹宗朱由校**（天启皇帝）。副主角：孙承宗（他亲手送走、又被一场哭声拦回去的边臣）；魏忠贤作为“站在耳边的人”出现，不做主角。
- **时间跨度**：万历四十六年（1618）辽饷开征 → 万历四十八年（1620）七月遗诏罢榷税、泰昌撤税监 → 天启二年（1622）八月孙承宗督师出关 → 天启四年（1624）秋冬孙承宗通州折返 → 天启五年（1625）李起元复榷、九月柳河、十月孙承宗去职、高第撤防 → 天启六年（1626）正月宁远、四月殿工兵饷搜括、五月初六京城大灾、五月十七停榷 → 天启七年（1627）正月免潼关咸阳商税、宁锦后叙功封伯；钩子落在天启六年夏（六月或闰六月，《明史》两处不一）西湖生祠。

## 核心认知反差（生死线）
- **你以为的**：
  1. 天启皇帝只会做木工，国家大事一概不管，全扔给了魏忠贤；
  2. 他是个糊涂人，魏忠贤说什么就是什么；
  3. （网上）魏忠贤是被冤枉的能臣，靠向江南富商收商税撑住了辽东，东林一上台就废了商税；
  4. （老听众）EP12 讲过：东林上台就罢了矿税、减了江南商税，军饷只能全压在北方农民身上。
- **实际上的**：
  1. 同一个皇帝亲自到宫门口送孙承宗出关，给尚方剑，许他“便宜行事，不从中制”；还爱打听边关的事，专门让人去关上“较事”（#11、#13）；
  2. 他听得懂、会发火：对客魏破口大骂，有人奉承过头他亲手拿朱笔圈掉；可孙承宗要进京当面谈的时候，魏忠贤绕着御床一哭，他就动了心，孙承宗被拦在通州（#8、#15）；
  3. 天启五年请求重开商税的是户部尚书李起元；天启六年五月提出停掉“新复商税”的是督修宫殿的崔呈秀，圣旨说加商税“原非朕意”，同一道旨让全国官员捐一年俸禄修宫殿（#28、#29）；
  4. 撤税监发生在万历遗诏和泰昌即位那几天；辽饷在万历末年税监还在的时候就已经按田亩加上了（#24、#25）。
- **反差的强度自评**：⭐⭐⭐⭐（“木匠皇帝”是全民熟脸 × 同一个人送孙承宗出关又被哭声劝住 × “九千岁收商税”被实录原文拆掉 × 停商税那天全国官员捐俸修宫殿；扣一星是两份“木匠”档案立场相反，只能讲分歧不能下结论，财政一段信息密，容易讲成课）

## 核心问题（这期节目回答的一句话问题）
奏疏念到一半的时候，那位在木料堆边上干活的皇帝，到底在想什么——他管过什么，又把什么交了出去？

## 三大基因自检
- [x] **小切口**：一个皇帝脱了外衣坐在木料边上干活，太监在旁边念奏章，他手不停、侧着耳朵听，念完说一句“你们用心去办吧，我知道了”（#3）。同一件事，《明史》写的是“谬曰：朕已悉矣”（#1）。
- [x] **大纵深**：从木工房到山海关（孙承宗四年，推出四百里），再到户部的账本（辽饷九厘、五年复榷、六年停榷）和三大殿的工地；两条线最后汇回木工房（#12、#24—#33）。
- [x] **人性内核**：一个听得懂话、也会发脾气的人，把“谁替我听、谁替我念”交给了身边的人；他亲自送走的边臣，带着一卷铺盖在通州掉头回去（#15）。

## 印章拟定
- **印章四字**：`朕已悉矣`（出自《明史》卷305 魏忠贤传：“帝厭之，謬曰：朕已悉矣，汝輩好為之”，#1；古法排列：右列“朕已”、左列“悉矣”，自上而下）
- 沿用前几条长线惯例（印章取正史原文四字）。这四个字本身就是本期的分歧：他是真“悉”了，还是“谬”。

## 内容弹药
- **主要素材**：《明史》卷21、22、78、81、250、259、305、306（正史，已核）；《明熹宗实录》卷71、76（实录，已核）；刘若愚《酌中志》卷三、卷十四（宫中太监笔记，已核）；《剑桥中国明代史》第九章（黄仁宇）、第十章（艾维四）；吴晗《明成祖仁宗景帝之死及其他》（二手研究，已核）；EP12 已上线文稿（origin/main，已核）。
- **三条系列暗线**：
  1. **“念奏疏”线**：EP41 王体乾念杨涟疏时漏读要语 → 本期冷开场王体乾在木工房边念本子、皇帝“倾耳注听” → 本期孙承宗认为“抗疏帝未必亲览”所以要当面谈，结果被拦（#3、#15）→ EP44 钱嘉征的疏被一字不漏念给魏忠贤听。本期由小李自然认出 EP41 那一幕，大开不点题。

  3. **“宫殿”线**：《酌中志》作者自己把木工和三大殿放在一起犯嘀咕（#3）→ 殿工与兵饷抢同一笔银子（#32）→ 停商税的同一道旨让官员捐俸修宫殿（#29）→ 福建已收的税送去修宫殿（#30）→ 叙三大工功封侯（#33）。

- **合法跑偏**：①熹宗的水戏：木桶铜缸里装机关，水柱托着核桃大的木球转个不停（#2）；②魏忠贤派来“犒军”的太监，在孙承宗那里只喝到一杯茶（#13）；③孙承宗被拦回去时，魏忠贤还派人去看他车里装了什么——一卷铺盖（#15）。
- **梗与现代映射**：一个老板在车间里亲自上手做模型，秘书在旁边念报告，他头也不抬说“你们看着办，我知道了”——后来公司的章，就都盖在了秘书手里（只作比喻，慎用，不代替史实）。
