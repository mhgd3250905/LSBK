# EP43 节目大纲：《〈五人墓碑记〉里的五个人，为什么葬在魏忠贤的生祠旧址上？》

> 2026-10-14 编写。天启系列 3/4。全期按时间走：天启六年二月空印疏 → 三月苏州开读 → 五月王恭厂 → 六月第一座生祠 → 天启七年正月虎丘普惠祠 → 五月国子监请祀 → 七月皇帝病倒；尾声闪回崇祯元年五人入葬。主线是“全国官员怎么替九千岁放大权力，又是谁在说不”；分歧主线是“建祠的官员是被逼的还是自愿的”。四段只为分工，主播在台词里不知道自己在分段。证据编号对应 `史料核对.md`（#1–#60）。按约 300 字/分钟估算，目标成片约 28 分钟（净台词约 7,800–8,800 字），是估算不是配额。

## 两位主播的认识起点与分歧

- **大开的起点**：知道整条线，每一环先交代证据层级（正史 / 清初私史 / 东林子弟所编奏疏 / 当事太监回忆 / 碑记 / 民间报房）。立场：七君子是魏忠贤借李实空印疏一手抓的，账记在他名下；生祠是官员发起、互相传染的，魏忠贤收下了，但第一块砖不是他搬的。这两件事分开讲，系列定调“明朝的病养出了他，但下刀的是他自己”在第一段落实。
- **小李的起点**：高中背过《五人墓碑记》，记得“匹夫之有重于社稷”；系列前两期记忆：EP41 不识字、九千岁、王体乾漏读；EP42 停商税在爆炸后第十一天。她会自己认出“一丁不识”“九千岁”的回声，会背出碑记第一句。
- **真实分歧（主线，不强行统一）：建生祠的官员，是被逼的还是自愿的？**
  - 小李：被逼的。刘之待晚交一天就丢官，耿如杞不拜就判死罪，换谁不怕（#33、#35）。
  - 大开：两样都有。赵翼的原话就是“黠者献媚，次亦迫于避祸”（#54）；可王点闭门、叶宪祖叹气，丢的是官，不是命；梁廷栋干脆请假回家（#40、#49）；阎鸣泰一个人修七座、陆万龄要和孔子并祀，那已经不是怕了（#37、#44）。
  - 结尾不统一：小李保留“大多数人是怕”，大开保留“怕和想分不开”。
- **小分歧（可选）：王恭厂是不是天谴。** 小李半开玩笑说老天都看不下去；大开不认天谴，只说当时的人各自拿这场灾干了什么（#5—#7）。一两个来回即止。
- **小分歧（可选）：苏州民变算不算造反。** 小李：打死了朝廷的差人，那不就是造反？大开：五个人临刑自己说了“好义非乱”，周顺昌和黄尊素事后都自己去投案（#24、#26）；他们拦的是东厂，不是朝廷。不替任何一方拔高。

## 结尾形态

- 停在五人墓与普惠祠的空间重叠上（同一块地，先是给活人修的庙，后是给死人修的墓），再接钩子；不做“生祠现象的三点启示”式总结；主线分歧保留。
- 大开可以说一句方向示意：“一座祠，一年多以前是巡抚替三吴感恩修的；一年多以后，三吴的人把五个市民埋在了它的地基上。”（写手可改，不要拔高成“历史自有公论”）

## 字数与节奏提示

- 冷开场、高攀龙投水、黄尊素自投、五人临刑、西湖关岳之间、开封拆房、陆万龄、五人墓是八处画面最强的段落；其余每件事只留一个能记住的细节。
- **人名压缩**：七君子里只给周顺昌、高攀龙、黄尊素三人画面，周宗建只用“一丁不识”一句，周起元、缪昌期、李应升各一句或不点名；建祠者只点潘汝桢、刘之待、阎鸣泰、毛一鹭、陆万龄（袁崇焕一句）；对照组只点叶宪祖、耿如杞（王点、孙承宗可选其一）。其余一律“有人”“一个巡按”。
- “据《明史纪事本末》”“据文秉的书”这类限定语全期会出现多次，建议大开在第三段开头一次性交代：“生祠最离谱的细节，很多是东林那边的人和清初的人记下来的，《明史》的名单是骨架。”之后简写。
- 王恭厂段严格控制在 5 分钟以内：EP41 用过现场，EP42 用过停商税，本期只做“两种账”和底牌。
- 日期只报到月；“天启六年三月”“天启七年正月”“五月”“七月”。
