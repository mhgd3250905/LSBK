# 选题卡：EP43《〈五人墓碑记〉里的五个人，为什么葬在魏忠贤的生祠旧址上？》

> 2026-10-14 编写。明朝篇·天启与九千岁系列第 3 期（共 4 期），对应摸排报告 EP-C。事实依据见同目录 `史料核对.md`（#1–#60），凡冲突以史料核对为准。标题按用户口味给一个主选，用户以后会自己重取。

## 基本信息
- **选题缘由**：系列全线问一个问题：九千岁的权力是从哪借来的？（用户 2026-10-14 批准）EP41 讲他怎么借到手，EP42 讲出借人（皇帝）在干什么，本期讲**全国官员怎么替他放大**，以及**谁在这时候站出来说不**。课本里的《五人墓碑记》第一句就写着“即除魏阉废祠之址以葬之”，几乎所有人都背过，很少有人问过：那座“废祠”是什么？它是苏州巡抚毛一鹭给活着的魏忠贤修的生祠；修祠的，正是十个月前上报苏州人造反、抓了这五个人的同一个巡抚（#47、#56）。
- **题型**：群像叙事（生祠传染链）＋ 现场还原（苏州开读）＋ 证据对表（王恭厂数字阶梯、各书分歧）＋ 系列承接（王恭厂悬念回收）
- **系列归属**：《笑谈历史》明朝篇·天启与九千岁系列 3/4（EP41 不识字的九千岁 → EP42 木匠皇帝与辽东、财政 → **EP43 生祠与五人墓** → EP44 崇祯除阉与逆案）
- **本期主角**：没有单一主角，用“一座祠”做主角——从西湖普德祠到虎丘普惠祠，再到普惠祠地基上的五人墓。人物分两组：**放大器**（潘汝桢、刘之待、阎鸣泰、陆万龄、毛一鹭，袁崇焕一两句）和**说不的人**（周顺昌、高攀龙、黄尊素、颜佩韦等五人；叶宪祖、耿如杞作对照）。摸排建议的五人群像加两组对照照用，另加毛一鹭作首尾。
- **时间跨度**：天启六年（1626）二月李实疏逮七人 → 三月苏州开读、高攀龙投水 → 五月初六王恭厂 → 六月潘汝桢请祠、周顺昌死狱 → 闰六月黄尊素、李应升死 → 九月周起元死 → 天启七年（1627）正月毛一鹭建虎丘普惠祠 → 二至五月生祠遍天下 → 五月陆万龄请祠国学“许之” → 七月熹宗不豫、体肿；尾声闪回崇祯元年（1628）五人葬于祠址

## 核心认知反差（生死线）
- **你以为的**：
  1. 《五人墓碑记》是篇讲“匹夫有重于社稷”的课文，五个人死了，修个墓，张溥写个碑；
  2. 魏忠贤权势熏天，所以天下给他修生祠，是他逼的、他要的；
  3. 王恭厂大爆炸是一桩明末“天谴”悬案，跟魏忠贤没关系；
  4. 东厂抓人，从来没人敢拦。
- **实际上的**：
  1. 墓下面压着的，是苏州巡抚毛一鹭给魏忠贤修的普惠祠；抓这五个人的、修这座祠的，是同一个人（#47、#56）；
  2. 第一座生祠是浙江巡抚潘汝桢以“机户请求”的名义上奏请建的，奏疏晚到一天的同僚丢了官；此后一年多名单上有几十处，督抚、侯爷、王爷、国子监生都在里面，书上记得最清楚的不是魏忠贤下令，是官员抢着写（#30、#33、#36、#46、#50）；
  3. 王恭厂是一座有太监掌厂的火药厂；爆炸后借天变进言的官被削籍，朝廷反倒下敕夸魏忠贤扑灭雷火有功；十二年后同一座厂又炸了一次（#6—#9）；
  4. 苏州人问缇骑：圣旨是朝廷的还是东厂的？缇骑说：不从东厂出还能从哪出？打死了缇骑之后，东厂的人从此不出京城抓人（#21、#25）。
- **反差的强度自评**：⭐⭐⭐⭐（课本熟脸极高 × 墓压在祠上的空间反转 × “旨不出东厂将谁出”一句话点穿体制 × 系列悬念回收；扣一星是生祠反面细节多出自东林立场的《先拨志始》和清初私史，人物又多，写手要压住密度）

## 核心问题（这期节目回答的一句话问题）
天启六年到七年，一个太监的生祠为什么能在一年多里修遍全国——而苏州五个普通人，为什么最后被葬在了其中一座的地基上？

## 三大基因自检
- [x] **小切口**：苏州开读那天，缇骑把铁链往地上一摔：东厂抓人，你们也敢插嘴？有人问：圣旨到底是朝廷的还是东厂的？（#21）一句话把 EP41 讲的“批红权、东厂、中旨”全部翻到台面上。
- [x] **大纵深**：一张先盖印后填名的空白奏本（#14）→ 七个人的死 → 北京一声巨响（#1）→ 西湖边关羽、岳飞中间多出一座祠（#32）→ 开封拆了两千多间民房（#38）→ 国子监旁边要和孔子并祀（#44）；往前接到四十多年前百官给张居正打醮（#54），往后接到崇祯元年的五人墓（#56）。
- [x] **人性内核**：同一座城里的两种人。一种是十个月前报“吴人尽反”、十个月后替“三吴”感恩修祠的巡抚；一种是临刑前对知府说“我们是为义，不是作乱”的五个市民（#26、#47）。中间还有晚了一天就丢官的巡按（#33）、上梁那天闭门不出的巡抚（#49）——大多数人在这两头之间。

## 选题评分（对抗自审后）
- **8/10**。加分：课本熟脸（《五人墓碑记》）和“墓压在祠上”的空间反转天然成立，且是卷245 原文写明的硬事实；苏州开读现场有正史级别的戏剧性和一句点穿体制的台词；生祠有卷306 逐月名单和《先拨志始》奏疏原文，传染机制、惩罚机制、对照组都在原文里；王恭厂悬念能落在一个冷静的事实上（有太监掌厂的火药厂、十二年后又炸）；系列主线“权力是借来的”在本期有最直观的画面——全国官员替他写借条。扣分：人名密度高（七君子＋五人＋五个建祠者＋对照组），写手必须严格按主次压缩；生祠最“好笑”的细节（沉香像削头、西湖关岳之间、王点闭门）多出自清初私史和东林子弟的书，需要边讲边交代来源；王恭厂已在 EP41 冷开场用过、财政已在 EP42 讲过，本期只能回收不能重讲，节奏上要防止“炒冷饭”；尾声的五人墓入葬发生在魏忠贤倒台后，只能闪回，不能讲倒台经过。
