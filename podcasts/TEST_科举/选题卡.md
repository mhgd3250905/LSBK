## 基本信息
- **选题缘由**：待选——a) 高考/考研季临近（考试季借势）；b) 系列衔接（可挂"古代制度系列"）。测试取 a)。

## 核心认知反差（生死线）
- **你以为的**：科举 = 公平的上升通道，读书人挤独木桥是为了"改变命运、实现阶层跃迁"
- **实际上的**：科举首先是帝国花了上千年打磨的**社会稳定器**——它最了不起的功能不是选拔人才，而是把最聪明、最有组织能力的一批人牢牢锁在书桌前，让他们把精力花在系统内竞争而不是掀桌子。唐太宗看着新科进士鱼贯而出说"天下英雄入吾彀中矣"——这句话的正确译法是"都进我的口袋了"。
- **反差的强度自评**：⭐⭐⭐⭐（"防躺平装置/维稳工具"的视角对大众认知有实在冲击；且有李世民原话这种硬锚点）

## 核心问题
**科举到底是给谁设计的——是给读书人设计的，还是给皇帝设计的？**

## 三大基因自检
- [x] 小切口：每个中国人都经历过的"考试人生"（高考、考研、考公、上岸）
- [x] 大纵深：从隋唐到清末的制度史 → 组织学/政治学的"合法性再生产"理论
- [x] 人性内核：努力与系统设计的关系——"你以为你在打游戏，其实游戏在打你"；个体奋斗 vs 系统目的的永恒错位

## 标题候选（九型公式）
1. （反差颠覆型）**科举根本不是给你改变命运用的？它其实是帝国最强的"维稳神器"**
2. （悬念问句型）**李世民说"天下英雄入吾彀中矣"，这句话细想有多可怕？**
3. （网感嫁接型）**古人早就开始"卷上岸"了：一部科举版的内卷进化史**
4. （大小相形型）**从一个考场到一个帝国：科举凭什么稳住中国一千年？**

（选定 1 为正标题方向，2 为副钩）

## 内容弹药
- **主要素材/案例**：
  1. 唐太宗"入吾彀中"（《唐摭言》，五代王定保——标注：笔记体，准史料）
  2. 宋真宗《劝学诗》"书中自有黄金屋"（皇帝亲自下场写励志文学——皇帝为什么要劝你读书？）
  3. 范进中举（54 岁上岸后的疯癫——系统对人的一生做了什么）
  4. 洪秀全落榜四次后掀桌子（科举最怕的事发生了：聪明人不考了）
  5. 清代进士平均年龄 30+ 岁、录取率对比今天高考（数据流）
  6. 宋代"榜下捉婿"（富豪抢进士当女婿——进士的"期权价值"）
- **可用的对照组**：科举 vs 军功爵（战功上升，秦制的暴力版）；科举 vs 九品中正制（不考试=豪门垄断=不稳）；洪秀全（考不上的人）vs 曾国藩（考上了的人）——同一场太平天国，两端都是科举产物
- **可交付的概念工具**："上升通道的开关理论"——任何系统的稳定，取决于最有能力的人是否被绑定在系统内；考试内容考什么不重要，重要的是让所有人认同同一套规则
- **降维三步法候选点**：①"合法性再生产"（学术词）→ 吐槽 → 比喻"游戏公司定期发新版本，不是为了让你变强，是为了让你别退游"；②"精英吸纳"→ 比喻"把最能闹事的人请进学生会"
- **理论对垒**：科举公平论（钱穆：科举是中国的"民主"雏形）vs 科举工具论（制度设计视角）→ 收束"各有各的道理"
- **合法跑偏候选**：①主持/主讲聊自己高考查分那天的记忆（听众共鸣区）；②"如果今天公务员考试考八股文会怎样"的荒诞推演
- **梗与现代映射弹药**："上岸"这个词的古今对照（古代是真的岸，翻了船就没命）；"范进 = 考了 20 次的上岸者"；"榜下捉婿 = 上市敲钟现场被投资人堵门"；游戏语言（保底机制/日常任务/赛季更新）
