## 一、 复盘背景：为什么归档《公羊学派》并重做《姚广孝》？

原 EP18《春秋公羊学派》在完成音频合成后被主动归档，核心原因并非制作技术问题，而是触碰了播客内容生产的两大硬伤：
1. **选题过于抽象空泛**：纯经学与政治哲学流派概念繁密（微言大义、通三统、张三世），时间线跨越两千年，缺乏有血有肉的核心主角与具体的人性博弈，文稿容易滑向“大学讲座式硬灌输”；
2. **丢失了核心节目法度**：开头无具象抓耳名场面，退化为概念问答；全篇无标志性双人报幕，导致整集缺乏仪式感与正片结构层次。

新版 EP18《黑衣宰相姚广孝》通过全方位推倒重构，全面恢复并升级了《笑谈历史》的高口碑基准线。

## 三、 《笑谈历史》后续必须遵循的四大长效规范

### 规范一：选题三要素（无戏剧主角不立项）
1. **一个有极致矛盾的血肉主角**：拒绝纯概念串讲或散点式通史，必须有一个能承载欲望、挣扎、抉择与失败的具象人物（如徐阶、张居正、高拱、海瑞、钱谦益、姚广孝）；
2. **一个正史有据的黑色幽默名场面**：每期必须至少拥有一个可供影视化还原的绝妙细节（如海瑞备棺材、嘉靖城门掀桌、钱谦益试水温、姚广孝养鸭掩盖打铁）；
3. **一个能打穿古今的人性命题**：剥离历史知识点后，留给听众的生活镜子（如面对最恶劣环境如何忍受侮辱、极致智力脱离人性后的孤独）。

### 规范二：两段式黄金开场公式（雷打不动）
每期第一幕必须在前两分钟内完成标准化两级火箭助推：
```
[00:00 - 01:00] 冷开场（纯具象名场面）
  - 不打招呼、不报幕、不寒暄、不讲宏大背景；
  - 直接从最荒谬、最激烈或最具悬念的具体历史镜头切入（30-60秒）。

[01:00 - 02:00] 标志性正式双人报幕 + 选题缘由与破题
  - 大开：“大家好，这里是笑谈历史，我是大开。”
  - 小李：“大家好，我是小李。”
  - 小李承接开场名场面，带出常人的人情困惑或上一期关联；
  - 大开顺势破题，指出大众常识与历史内核的深层矛盾，正式切入正片。
```

### 规范三：去 AI 味与文稿表达负面清单（零容忍）
1. **严禁句首呼唤重读**：小李台词首句**绝对禁止写“大开，”**（如“大开，如果……”），一律改写为口语化自然带入（“你说如果……”、“其实很多人都在琢磨……”、“按常理说……”）；
2. **严禁惊悚夸张 AI 词**：绝不出现“头皮发麻”、“让人窒息”、“脊背发凉”、“细思极恐”、“绝了”等廉价煽情套话。让具体事实、动作和数字说话，不替听众预设生理反应；
3. **严禁说教式 AI 标签词**：绝不使用“这就太反常识了”、“颠覆认知”等自卖自夸标签；
4. **严禁机械对仗句式**：杜绝“不是……而是……”、“既不是……也不是……而是……”等机器八股句型，用连贯的单句推进事实；
5. **严禁暴露剧本结构**：绝不出现“这一幕/下一幕/彩蛋/伏笔/板块/环节/大纲/脚本”等元词汇。

### 规范四：工程级合成与质检底线
1. **正文双引号零容忍**：全篇为纯双人第三人称转述，正文中严禁出现直接双引号（`“”`）与角标引号（`「」`），引语必须转为转述句（“姚广孝说，飞龙在天必有风雨”）；
2. **内嵌 ID3 标签剥离**：各幕合并前必须调用 `strip_embedded_id3` 清理豆包 API 返回的逐轮内嵌标签，并用 `ffmpeg -v error -i 完整版.mp3 -f null -` 验证解码；
3. **字幕话轮 1:1 对齐**：`完整版.srt` 条数必须严格等于四幕总话轮数，毫秒级实测无重叠；
4. **Shownotes 必须实测回写**：时间轴必须基于最终 `完整版.srt` 实际跑出的时间节点逐条标定，严禁使用写稿阶段的预估时间戳。

## 五、 EP19 实战提炼：深层去 AI 化与纯故事驱动铁律（2026-10-06 用户共创沉淀）

在 EP19《土木堡之变与朱祁镇》打磨过程中，针对文稿中残留的“隐形 AI 味”与“大道理说教感”，提炼出以下两项最高准则，后续所有剧集（特别是大明三部曲 EP20、EP21）必须无条件执行：

### 1. 四类深层“AI口癖”全面清剿清单
除了字面上的“头皮发麻、反常识、让人窒息、不是……而是……”，以下四类 AI 习惯表达必须在写稿和自检中连根拔起：

| AI 口癖类别 | 典型中毒句式（严禁出现 ❌） | 真实人类口语 / 具象白描替代（必须使用 ✅） |
|---|---|---|
| **① 机械排比与宏大口号** | “在承平时期，他是……；但在绝境中，他是……”<br>“在宏大棋局里他是输家，在个人相处里他是……”<br>“这不仅是皇权的较量，更是一场……” | 讲具体人情：“换了任何一个娇生惯养的帝王，谁还顾得上一个手下的小卒子。他倒好，真拿身边人的命当命看。” |
| **② 短视频标签与自卖自夸** | “你会看到更令人唏嘘的一幕”<br>“这还不算最绝的”<br>“这波操作简直绝了 / 这真是神来之笔”<br>“剧情简直比小说还离谱” | 严禁预告和自夸。把镜头直接推到现场，把动作、原话讲出来，惊叹留给听众。 |
| **③ 翻译腔与惊悚舞台腔** | “等待着命运的裁决”<br>“青史难书”<br>“死神已经追到了脚后跟”<br>“命运的齿轮开始转动” | 用白描写动作：“他就安安静静坐在乱石堆里，不跑也不喊”；“瓦剌铁骑的马蹄声已经近在咫尺”。 |
| **④ 机械接茬与预设垫话** | “一点没错”<br>“做梦都想不到”<br>“这组合凑在一块儿就差导火索了”<br>“这画面想想就……” | 换成真实自然的日常接话：“可不是嘛”、“两个人凑在一块儿，火星子立马就得点着”、“按常理说”、“换谁谁不发懵啊”。 |

### 2. 纯故事叙述原则：坚决不讲大道理，用场景和事实说话
- **用户原话戒律**：“这个故事算是跌宕起伏、波澜壮阔了，我们可以稍微更偏向于这个故事的讲述，而不要太多的去讲大道理。”
- **落地规范**：
  - 严禁在幕末或对话中塞入“人生感悟”、“职场启示录”、“现代管理学隐喻”或大段形而上的抽象总结；
  - 戏剧张力必须来自**正史细节的戏剧性冲撞**（如王竑咬马顺的肉、徐珵看星象劝逃被当面拍桌子痛骂、关死九门城外兵马不许进、杨善靠铁齿铜牙把太上皇白嫖接回）；
  - 两位主播的角色是“坐在茶馆里的说书人与好奇听友”，小李负责追问具体场景的细节与常人反应，大开负责还原历史现场的波诡云谲与人性格局。
