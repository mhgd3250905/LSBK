|---|---|---|
| **《百官图》事件与"朋党"指控（景祐三年五月）** | **正史确载**：《宋史·范仲淹传》卷314："時呂夷簡執政，進用者多出其門。仲淹上《百官圖》，指其次第曰：如此為序遷，如此為不次，如此則公，如此則私。況進退近臣，凡超格者，不宜全委之宰相。夷簡不悅。"其后范以汉成帝信张禹比喻，"夷簡怒訴曰：仲淹離間陛下君臣，所引用，皆朋黨也……由是罷知饒州。"**编年确载**：《长编》卷118，景祐三年五月丙戌（初九）："天章閣待制權知開封府范仲淹落職知饒州……夷簡大怒，以仲淹語辨於帝前，且訴仲淹越職言事、薦引朋黨、離間君臣。" | 可作全期主线。注意两点：①《百官图》原图不存，只能讲"图上分出序迁/不次/公/私"，不可描绘图的具体样式或点名图上人物；②"四论"篇名据《长编》为《帝王好尚》《选贤任能》《近名》《推委》。 |
| **"朋党"榜朝堂、戒百官越职言事** | **编年确载**：《长编》卷118："侍御史韓瀆希夷簡意，請以仲淹朋黨牓朝堂，戒百官越職言事，從之。"**正史确载**：《宋史·范仲淹传》："殿中侍御史韓瀆希宰相旨，請書仲淹朋黨，揭之朝堂。"欧阳修《与高司谏书》亦提及"御史臺榜朝堂，戒百官不得越職言事"。 | 正史+文集互证，可直接讲。韩渎官衔二书有"侍御史/殿中侍御史"之异，讲"御史韩渎"即可。 |
| **余靖、尹洙、欧阳修连锁被贬，按日期推进** | **编年确载**：《长编》卷118（五月戊寅朔）：丙戌（初九）范落职；辛卯（十四）余靖上言"陛下自專政已來三逐言事者"，壬辰（十五）落职监筠州酒税；乙未（十八）尹洙上言"仲淹既以朋黨得罪，臣固當從坐"，贬监郢州酒税；戊戌（廿一）欧阳修贬夷陵县令。**正史确载**：《宋史·尹洙传》卷295："臣與之義兼師友，則是仲淹之黨也。今仲淹以朋黨被罪，臣不可苟免。"《宋史·余靖传》卷320。 | 两周内四人出京，节奏感强，可作中段推进。日期为据朔日推算，写稿用"十几天之内"足矣。 |
| **欧阳修《与高司谏书》** | **文集自述**：原文（《欧阳文粹》卷6、《欧阳文忠公文集》外集卷17）："前日范希文貶官後，與足下相見於安道家，足下詆誚希文為人"；"今足下家有老母，身惜官位，懼饑寒而顧利祿，不敢一忤宰相以近刑禍，此乃庸人之常情"；"足下猶能以面目見士大夫，出入朝中稱諫官，是足下不復知人間有羞恥事爾"；结尾"願足下直攜此書於朝，使正予罪而誅之"。**编年确载**：《长编》卷118 录高若讷奏，称范"今茲狂言，自取譴辱，豈得謂之非辜"，并"繳進修書"。 | 名场面级素材。注意：信里明说"直攜此書於朝"，高若讷交信等于照办，写稿可点出这一层讽刺，但不要把高若讷写成纯粹小人；《宋史·高若讷传》记其后来弹劾宦官阎文应、精通医书，人物有另一面。另：《宋史·高若讷传》写作"范仲淹坐言事奪職知睦州"，与范传、《长编》"知饶州"不合，属《宋史》内部误记，以饶州为准。 |
| **蔡襄《四贤一不肖诗》流传至契丹** | **正史确载**：《宋史·蔡襄传》卷320："襄作《四賢一不肖詩》，都人士爭相傳寫，鬻書者市之，得厚利。契丹使適至，買以歸，張於幽州館。"**编年确载**：《长编》卷118："四賢指仲淹、靖、洙、修，不肖斥若訥也。泗州通判陳恢尋上章乞根究作詩者罪，左司諫韓琦劾恢越職希恩。" | 可讲。诗全文维基文库有收（《四賢一不肖詩》），引用时只取片段转述。 |
| **李纮、王质送行；"希文贤者，得为朋党幸矣"** | **编年确载**：《长编》卷118："時治朋黨方急，士大夫畏宰相，少肯送仲淹者。天章閣待制李紘、集賢校理王質皆載酒往餞，質又獨留語數夕。或以誚質，質曰：希文賢者，得為朋黨幸矣。" | 可作名场面。 |
| **"三黜三光"** | **宋人笔记**：文莹《续湘山野录》："范文正公以言事凡三黜。初為校理，忤章獻太后旨，貶倅河中。僚友餞於都門曰：此行極光。後為司諫，因郭后廢……貶睦州。僚友又餞於亭曰：此行愈光。後……撰《百官圖》進呈……貶饒州。時親賓故人又餞於郊曰：此行尤光。范笑謂送者曰：仲淹前後三光矣，此後諸君更送，只乞一上牢可也。"**正史旁证**：《宋史》本传载天圣七年谏太后受朝后"尋通判河中府"、明道二年伏閤争废后"出知睦州"、景祐三年"知饶州"，三次外放均有正史支撑。 | 三次外放是正史事实；"极光/愈光/尤光"的对白与"一上牢"玩笑属笔记，可用"宋人笔记里记了这样一个段子"的口吻讲。注意笔记中丞相奏语"宰相者所以器百官"与正史版本不同，不要混用。第一次（河中）正史写作"尋通判河中府"，严格说带有补外性质，称"贬"沿用笔记口径。 |
| **仁宗私下称贬范是因"密请建立皇太弟"** | **正史确载（孤证）**：《宋史·范仲淹传》："仁宗謂宰相張士遜曰：向貶仲淹，為其密請建立皇太弟故也。今朋黨稱薦如此，奈何？再下詔戒敕。" | 可作"怪而深"的一笔，但只能讲"仁宗自己后来这样对宰相说"，不能断言范仲淹确曾密请立皇太弟，《长编》卷118 未见此说（其他卷原文待核）。 |
| **范仲淹徙润州后险被流放岭南，程琳解救** | **编年确载**：《长编》卷120（景祐四年末）："范仲淹既徙潤州，讒者恐其復用，遽誣以事，語入，上怒，亟命置之嶺南。參知政事程琳辨其不然，仲淹訖得免。自仲淹貶而朋黨之論起，朝士牽連出語及仲淹者，皆指為黨人。" | 可作"朋党之论"持续发酵的证据，"诬以何事"原文未载，不可补写。 |
| **康定元年：吕夷简主动请超迁范仲淹，范答"于夷简何憾"** | **编年确载**：《长编》卷127，康定元年五月己卯："初仲淹與呂夷簡有隙，及議加職，夷簡請超遷之，上悅，以夷簡為長者。既而仲淹入謝，帝諭仲淹使釋前憾，仲淹頓首曰：臣向所論蓋國事，於夷簡何憾也。"**正史确载**：《宋史·范仲淹传》同（文字略异）。 | 正史+编年互证，可讲。注意：这是"君臣对话中的表态"，不能扩写为二人当面握手言和的场景。 |
| **"二公欢然相约"与范纯仁删碑之争** | **文集**：欧阳修《资政殿学士户部侍郎文正范公神道碑铭》："及呂公復相，公亦再起被用，於是二公歡然相約戮力平賊。天下之士皆以此多二公，然朋黨之論遂起而不能止。"**宋人笔记**：邵博《邵氏闻见后录》卷21："文正之子堯夫以為不然，從歐陽公辯，不可，則自削去'歡然''共力'等語。歐陽公殊不樂，為蘇明允云：《范公碑》，為其子弟擅於石本改動文字，令人恨之。"苏辙《龙川别志》（李焘引于《长编》卷150注）称范晚年与吕夷简途中相遇"有悔過之語……申公欣然相與語終日"，李焘按："轍所志未必盡可據。" | 只能讲"欧阳修这样写，范家儿子不认，删了碑上的字"这个争议本身，不能替任何一方下结论。碑铭"戮力平贼"与笔记转述"共力國事"文字有异，以碑铭原文为准。 |
| **庆历四年四月：仁宗问"亦有君子之党乎"；欧阳修《朋党论》** | **编年确载**：《长编》卷148，庆历四年四月戊戌："上謂輔臣曰：自昔小人多為朋黨，亦有君子之黨乎？范仲淹對曰：臣在邊時，見好戰者自為黨，而怯戰者亦自為黨，其在朝廷邪正之黨亦然，唯聖心所察爾。苟朋而為善，於國家何害也。"随后"修乃作《朋黨論》上之"。**文集**：《朋党论》"大凡君子與君子以同道為朋，小人與小人以同利為朋……然臣謂小人無朋，惟君子有之"。**正史确载**：《宋史·欧阳修传》卷319 录其略。 | 可讲。范仲淹原话留有"唯圣心所察"的余地，比欧阳修的表态谨慎，这个分寸是本期人物塑造的关键，不要把两人说成同一口径。 |
| **蓝元震把"四贤"反用为结党证据** | **编年确载**：《长编》卷148："內侍藍元震上疏言：范仲淹、歐陽修、尹洙、余靖，前日蔡襄謂之四賢，斥去未幾，復還京師。四賢得時，遂引蔡襄以為同列，以國家爵祿為私惠，膠固朋黨……今一人私黨止作十數，合五六人門下黨與已無慮五六十人。" | "帽子回旋镖"的核心证据，可讲。疏文后半在本页截断，"五六十人"之后的推算原文待核，只引到此处。 |
| **夏竦伪造石介书信诬"废立"** | **编年确载**：《长编》卷150，庆历四年六月："石介奏記於弼，責以行伊周之事。夏竦怨介斥己，又欲因是傾弼等，乃使女奴陰習介書，久之習成，遂改'伊周'曰'伊霍'，而偽作介為弼撰廢立詔草，飛語上聞。帝雖不信，而仲淹、弼始恐懼，不敢自安於朝。"李焘注："今據弼自敘劄子增以夏竦偽作書詔事……國史及仲淹墓誌、神道碑皆不明言也。" | 可讲，但须交代这一情节来自富弼本人的自述劄子、经李焘采入，国史未明载。不可添加夏竦与女奴的对话、伪造过程细节。 |
| **新政"规摹阔大"、任子磨勘触动利益，"朋党之论浸闻上"** | **正史确载**：《宋史·范仲淹传》："然更張無漸，規摹闊大，論者以為不可行。及按察使出，多所舉劾，人心不悅。自任子之恩薄，磨勘之法密，僥倖者不便，於是謗毀稍行，而朋黨之論浸聞上矣。"**编年**：《长编》卷150 同叙，李焘注认为"更張無漸，規摹闊大"系当时小人谤语，"李清臣、蒲宗孟因而著之，未可信也"。 | 讲新政失败原因时要说明史家本身有分歧：《宋史》沿用"更张无渐"的评价，李焘认为那是诋毁之词。 |
| **"一网打尽"** | **正史确载**：《宋史·范纯仁传》（卷314）范纯仁追述："昔先臣與韓琦、富弼同慶曆柄任，各舉所知，常時飛語指為朋黨，三人相繼補外，造謗者公相慶曰一網打盡。" | 这是范纯仁数十年后的追述，引用时说明"范仲淹儿子后来回忆"。坊间常把此语安在王拱辰名下（据《东轩笔录》等，原文待核），本期不点名。 |
| **滕子京泾州公使钱案；范仲淹力争从宽** | **正史确载**：《宋史·滕宗谅传》卷303："御史梁堅劾奏宗諒前在涇州費公錢十六萬貫……宗諒恐連逮者眾，因焚其籍以滅姓名。仲淹時參知政事，力救之，止降一官，知虢州。御史中丞王拱辰論奏不已，復徙岳州。"**编年确载**：《长编》卷155 欧阳修疏："至如杜衍欲深罪滕宗諒，仲淹力爭而寬之。" | 可讲，且是连接《岳阳楼记》的关键。注意"费公钱十六万贯"是弹劾所称数额，正史紧接着说中使检视后发现多为犒赏属羌、馈遗游士故人，焚账是为保护受馈者，不宜直接说成"贪污十六万贯"。 |
| **滕子京修岳阳楼的钱从哪来** | **宋人笔记**：司马光《涑水记闻》卷10（注"君貺云"，即王拱辰转述）："滕宗諒知岳州，修岳陽樓，不用省庫錢，不斂於民，但牓民間有宿債不肯償者，獻以助官，官為督之。民負債者爭獻之，所得近萬緡，置庫於廳側，自掌之，不設主典案籍。樓成，極雄麗，所費甚廣，自入者亦不鮮焉。州人不以為非，皆稱其能。" | 极有料，但须交代两层：①这是笔记；②司马光注明消息来自"君贶"，即王拱辰——正是当年对滕子京"论奏不已"的人。"自入者亦不鲜"只能作为"有人这样说"处理。 |
| **《岳阳楼记》成文缘由与日期** | **文集**：《岳阳楼记》（《范文正公集》卷7）："慶曆四年春，滕子京謫守巴陵郡。越明年，政通人和，百廢具興，乃重修岳陽樓……屬予作文以記之。"落款"時六年九月十五日"。**正史确载**：范仲淹庆历五年罢参知政事知邠州，后"以疾請鄧州"（《宋史》本传）。 | 写作时范在邓州任上，属正史可推；"范仲淹未亲临岳阳楼、凭滕子京所寄图画作记"的说法流传很广，原文待核，不得当事实讲（见证据禁区）。 |
| **"一家哭何如一路哭"** | **宋人笔记**：《宋名臣言行录》前集卷7 引《遗事》：范为参政，取监司班簿，不才者一笔勾之，富弼谓"六丈則是一筆，焉知一家哭矣"，范曰"一家哭何如一路哭耶"。 | 人物性格旁证，可用，需标"宋人笔记记载"。 |

## 证据禁区（常见但不可靠，写稿不得当事实讲）
1. **"范仲淹从未去过岳阳楼""他是看着滕子京寄来的《洞庭晚秋图》写的"**：流传极广，本次未查到宋代原始出处，原文待核。可以说"写记时范仲淹人在邓州"，不能断言他一生没去过岳阳，也不能讲"寄图"情节。
2. **"范仲淹一生只被贬两次"或"被贬四次"的确数**：外放计数取决于是否把补外、自请出朝算作"贬"。稳妥口径：笔记有"三黜"之说，正史可见河中、睦州、饶州三次外放，庆历五年罢政又一次离京。
3. **"吕夷简是大奸臣"**：《宋史·吕夷简传》对他评价复杂（"為世名相"，"所斥士旋復收用，亦不終廢"），并记他主动请超迁范仲淹。本期不把吕夷简脸谱化。
4. **"范吕晚年握手言和、相谈终日"**：出自苏辙《龙川别志》，李焘明言"未必盡可據"，只能作为一说。
5. **"一网打尽"是王拱辰说的**：正史只记"造谤者公相庆曰一网打尽"，未点名。
6. **"滕子京是大贪官"**：弹劾所称数额与中使复查结果不一致，《涑水记闻》的"自入者亦不鲜"来源于对手王拱辰，均不足以定性。
7. **"仁宗贬范是因为范要立皇太弟"**：仅仁宗一面之词，正史孤证，不得当作事实动机。
8. **《灵乌赋》"宁鸣而死，不默而生"的写作年份**：通行说法为景祐年间答梅尧臣，原文出处可查（范仲淹《灵乌赋》），但系年未核，引用时不说具体年份。

## 给写稿者的说明
- **最该抓的名场面**：①《百官图》"如此为序迁，如此为不次，如此则公，如此则私"；②王质"得为朋党幸矣"的送行；③尹洙主动上奏"自认同党"求贬；④吕夷简在西北战事中主动请超迁范仲淹、范答"于夷简何憾"。这四个都有正史或《长编》原文，能撑起完整弧线。
- **名人的哪一面**：课本里的范仲淹是"忧乐"标语，本期要让听众看到一个政治上会犯难、会被误读、又有分寸的人：他在仁宗面前论朋党时说"唯圣心所察"，比欧阳修的《朋党论》克制；他对吕夷简的表态是"论的是国事"。不要把他塑造成没有缺点的圣人，也不要反向猎奇。
- **易踩的坑**：
  1. 把《宋史》与《长编》的措辞混用成一句"原话"；引语一律第三人称转述，正文零直接引号。
  2. 时间线错位：《百官图》在景祐三年（1036），范吕和解在康定元年（1040），《朋党论》在庆历四年（1044），滕子京谪守巴陵在庆历四年春，《岳阳楼记》在庆历六年九月（1046）。
  3. 把滕子京案讲成范仲淹包庇贪腐，或反过来讲成纯粹冤案，两种都超出证据。
  4. 冷开场不可写范仲淹登楼、望湖、落泪等无据画面。
  5. 规避节目禁用词：头皮发麻、细思极恐、颠覆认知，及"不是……而是……"类对仗句。
