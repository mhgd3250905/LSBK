# S02 史料核对与写作边界：《课本里的北宋朋友圈②·醉翁亭记》

| **案前背景：欧阳修上疏救四大臣，触怒当政** | **编年确载**：《长编》卷155，庆历五年三月"是月"条录欧阳修疏："杜衍、韓琦、范仲淹、富弼等，皆是陛下素所委任之臣，一旦相繼而罷，天下士皆素知其可用之賢，而不聞其可罷之罪……欲廣陷良善，則不過指為朋黨；欲搖動大臣，則必須誣以專權。"**正史确载**：《宋史·欧阳修传》卷319："於是邪黨益忌脩，因其孤甥張氏獄傅致以罪，左遷知制誥、知滁州。" | 正史明确把张甥案定性为"傅致以罪"（罗织），这是本期叙事立场的正史依据。 |
| **张氏身世与婚配** | **编年确载**：《长编》卷157，庆历五年八月甲戌："初修有妹適張龜正，卒而無子，有女實前妻所生，甫四歲，以無所歸，其母攜養於外氏。及笄，修以嫁族兄之子晟。"**文集自述**：《滁州谢上表》："同母之親，惟存一妹，喪厥夫而無託，攜孤女以來歸。張氏此時，生才七歲……況晟於臣宗，已隔再從，而張非己出，因謂無嫌。" | 张氏与欧阳修无血缘（张龟正前妻所生）。年龄有"四岁/七岁"两说，写稿须并列交代或只说"幼年"，不可只取一说当定论。 |
| **案发：张氏在欧阳晟家与奴私通，开封府审理** | **编年确载**：《长编》卷157："會張氏在晟所與奴姦，事下開封府。"**宋人笔记**：《默记》卷下："晟自虔州司戶罷，以替名僕陳諫同行，而張與諫通。事發，鞫於開封府右軍巡院。" | 私通者姓名"陈谏"、审理机构"右军巡院"仅见笔记，使用时标注。 |
| **杨日严与狱吏"附致"欧阳修** | **编年确载**：《长编》卷157："權知府事楊日嚴前守益州，修嘗論其貪恣，因使獄吏附致其言以及修。"李焘注："修論奏日嚴，據何郯章疏。" | 可讲"主审方与欧阳修有旧怨"。不可编造杨日严授意狱吏的具体对话。 |
| **钱明逸弹劾"私于张氏，且欺其财"** | **编年确载**：《长编》卷157："諫官錢明逸遂劾修私于張氏，且欺其財。"李焘注："錢明逸劾修，據修與蔣之奇辨第六劄。"**正史确载**：《宋史》卷317 钱明逸附传："為呂夷簡所知，擢右正言。首劾范仲淹、富弼：更張綱紀，紛擾國經。凡所推薦，多挾朋黨……蓋希章得象、陳執中意也。" | 可讲弹劾内容与钱明逸的政治站位。"钱明逸因欧阳修修《五代史》贬损吴越钱氏而报复"属后世推测，不得当事实（见证据禁区）。 |
| **复审"卒无状"，只落"买田立欧阳氏券"；审官同贬** | **编年确载**：《长编》卷157："詔安世及昭明雜治，卒無狀，乃坐用張氏奩中物買田立歐陽氏劵。安世等坐直牒三司取錄問吏人而不先以聞，故皆及於責……獄事起，諸怨惡修者必欲傾修，而安世獨明其誣，雖忤執政意，與昭明俱得罪，然君子多之。"贬：欧阳修降知制诰知滁州，苏安世为殿中丞监泰州盐税，王昭明监寿春县酒税。 | 本期核心事实，可放心讲。注意定性用词：乱伦指控"查无实据"，财产问题被坐实了一条"用嫁妆钱买田、地契立欧阳氏名下"，不能说成"彻底清白、毫无问题"。 |
| **《默记》版审讯内幕：孙揆、苏安世、王昭明** | **宋人笔记**：王銍《默记》卷下："張懼罪，且圖自解免，其語皆引公未嫁時事，詞多醜異。軍巡判官、著作佐郎孫揆止劾張與諫通事，不復支蔓。宰相聞之怒，再命太常博士、三司戶部判官蘇安世勘之，遂盡用張前後語成案。俄又差王昭明者監勘，蓋以公前事，欲令釋恨也。昭明至獄，見安世所劾案牘，視之駭曰：昭明在官家左右，無三日不說歐陽修；今省判所勘，乃迎合宰相意，加以大惡，異日昭明吃劍不得。安世聞之大懼，竟不敢易揆所勘。"又记此前欧阳修拒绝王昭明同行："故事無內侍同行之理，而臣實恥之。"王銍并称"王荊公為蘇安世埋銘，盛稱能回此獄，而世殊不知揆守之於前，昭明主之於其後"。 | 名场面级素材，但属笔记。与《长编》"安世独明其诬"直接冲突，写稿须交代"正史编年一种说法、宋人笔记另一种说法"，可让两位主播就此展开分歧，不可把《默记》版当唯一真相。"吃剑不得"一语只能转述。 |
| **欧阳修《滁州谢上表》自辩** | **文集自述**：《滁州谢上表》（《庐陵文钞》卷9）："謗讒始作，大喧群口而可驚；誣罔終明，幸賴聖君之在上"；"不幸其人自為醜穢，臣之耳目不能接，思慮不能知"；"若臣身不黜，則攻者不休"；"必欲為臣明辯，莫若付於獄官；必欲措臣少安，莫若置之閑處"。 | 当事人自述，可大量转述。上表写作时间为到任滁州后（"已於今月二十二日赴任訖"），月份原文未载。 |
| **《醉翁亭记》本文与写作年代** | **文集**：《醉翁亭记》（《古文观止》《庐陵文钞》卷21、《皇朝文鉴》卷78）："太守與客來飲於此，飲少輒醉，而年又最高，故自號曰醉翁也"；"蒼顏白髮，頹然乎其間者，太守醉也"；"太守謂誰？廬陵歐陽脩也"。**文集旁证**：《题滁州醉翁亭》"四十未為老，醉翁偶題篇"；《赠沈遵》"我時四十猶強力，自號醉翁聊戲客"（二诗句经多个诗文网站互证，文集卷次原文待核）。 | 记文本身无落款年月。"作于庆历六年（1046）"是通行说法（香港教育局教材注释、统编教材配套资料多取此说），也有作"庆历五年"者，写稿说"到滁州后第二年前后"最稳，或明言"一般认为"。 |
| **《宋史》对欧阳修性格与遭遇的总评** | **正史确载**：《宋史·欧阳修传》："天資剛勁，見義勇為，雖機阱在前，觸發之不顧。放逐流離，至於再三，志氣自若也。"又："脩以風節自持，既數被污蔑，年六十，即連乞謝事。" | 可作人物定调。 |
| **治平四年第二案：薛良孺造谤、蒋之奇弹劾** | **编年确载**：《长编》卷209，治平四年三月："朝論以濮王追崇事疾修者衆，欲擊去之，其道無由。有薛良孺者，修妻之從弟也，坐舉官被劾，會赦免，而修乃言不可以臣故徼幸，乞特不原。良孺竟坐免官，怨修切齒。修長子發娶鹽鐵副使吳充女，良孺因謗修帷薄事連吳氏。集賢校理劉瑾與修亦仇家，亟騰其謗。思永聞之，間以語其僚屬之奇。之奇始緣濮議合修意，修特薦為御史，方患衆論指目為姦邪，求所以自解，及得此，遂獨上殿劾修，乞肆諸市朝。上疑其不然，之奇引思永為證，伏地叩首，堅請必行。"思永助之奇，"言修罪當貶竄，且曰：以陰訟治大臣誠難，然修首違濮園事犯衆怒"。**正史确载**：《宋史·欧阳修传》作"脩婦弟薛宗孺有憾於脩，造帷薄不根之謗"；《宋史·蒋之奇传》作"因修妻弟薛良孺得罪怨修，誣修及婦吳氏事"。 | 可讲。造谤者名字有"薛良孺/薛宗孺"之异（《长编》与《蒋之奇传》作良孺，《欧阳修传》作宗孺），写稿统一用"欧阳修夫人的堂弟（一说内弟）薛良孺"。"吴氏"是欧阳修长子欧阳发之妻、吴充之女，即长媳。谤言具体内容史书未载，不可补写。"修首违濮园事犯众怒"一句是本案与濮议的因果钩子，S04 会引用，本期点到即可。注意此句在《长编》原文中紧接"思永助之奇"，主语可读作彭思永；S04 选题卡归于蒋之奇弹章，两期写稿宜统一为"弹劾一方声称"。 |
| **"法许御史风闻言事"与神宗的批示** | **编年确载**：《长编》卷209：神宗"令思永、之奇分析所聞，具傳達人姓名以聞。之奇言得自思永，而思永辭以出於風聞，年老昏繆，不能記主名，且言：法許御史風聞言事者，所以廣聰明也，若必問其所從來，因而罷之，則後不得聞矣，寧從重謫，不忍塞天子之言路"。神宗再批："凡朝廷小有闕失，故許博議聞奏，豈有致人大惡便以風聞為託？宜令思永等不得妄引浮說，具傳達人姓名并所聞因依明據以聞。" | 本期制度命题的核心原文，务必讲透：彭思永的辩护本身有制度依据，神宗划出的边界是"议政可风闻，诬人大恶不可"。 |
| **欧阳修的抗辩** | **编年确载**：《长编》卷209 录欧阳修章："之奇誣罔臣者，乃是禽獸不為之醜行，天地不容之大惡。臣苟有之，是犯天下大惡；無之，是負天下至冤。犯大惡而不誅，負至冤而不雪，則上累聖政，其體不細。乞選公正之臣為臣辨理，先次詰問之奇所言是臣閨門內事，自何所得，因何彰敗。"章凡三上；吴充亦上章请辨正，"使門戶不致枉受汙辱"。 | 可讲，引语转述。 |
| **结局：彭、蒋被贬，手诏榜朝堂；欧阳修仍求退** | **编年确载**：《长编》卷209：彭思永降给事中知黄州，蒋之奇降太常博士监道州酒税；神宗手诏赐修："今日已令降黜，仍榜朝堂，使中外知其虛妄，事理既明，人疑亦釋，卿宜起視事如初。"三月壬申，欧阳修罢参知政事，以观文殿学士知亳州（"修亦三表乞罷"）。神宗后谓吴奎："蔣之奇敢言而所言曖昧，既罪其妄，欲賞其敢。"吴奎以"賞罰難並行"止之。**正史确载**：《宋史·蒋之奇传》："神宗批付中書，問狀無實，貶監道州酒稅，仍榜朝堂。" | 可讲。欧阳修新职《长编》作"刑部郎中"、《宋史》作"刑部尚书"，李焘注已标异文，写稿只说"外放知亳州"。 |
| **"神宗起初想杀欧阳修"之说** | **编年存疑**：《长编》卷209 正文有"上初欲誅修"一语，但四库馆臣按语、李焘引朱史均质疑："神宗初立，何至以曖昧之言即欲誅舊輔臣耶"；《宋史》作"神宗初即位，欲深護脩"。 | 两说相反，正史倾向"深护"。写稿不可说"神宗差点杀了欧阳修"，最多交代史书有分歧。 |
| **孙思恭为欧阳修辨释** | **编年/正史**：《长编》卷209 "以詔密問天章閣待制孫思恭，思恭極力捄解，上寤"；《宋史·欧阳修传》"訪故宮臣孫思恭，思恭為辨釋"。 | 可讲。 |
| **蒋之奇同月弹劾钱明逸** | **编年确载**：《长编》卷209，治平四年三月丙寅："先是御史蔣之奇言：臣累奏彈明逸姦邪……以傾險憸薄，在仁宗朝附賈昌朝、夏竦、王拱辰、張方平之黨，陷杜衍、范仲淹、尹洙、石介之徒，朝廷一空，天下同疾。"钱明逸罢翰林学士。**正史确载**：《宋史》钱明逸附传："御史論其傾險憸薄，頃附賈昌朝、夏竦以陷正人……乃罷學士。" | 历史回旋的好素材，可讲。弹劾奏状在蒋之奇被贬前所上（"先是"），罢免执行在丙寅，二者先后关系按"同一时期"表述即可。 |
| **蒋之奇此后仕途与"清议所薄"** | **正史确载**：《宋史·蒋之奇传》："之奇為部使者十二任，六典會府，以治辦稱……特以畔歐陽修之故，為清議所薄。" | 可作结尾余波，体现正史对其"能吏但失节"的双面评价，不脸谱化。 |

## 证据禁区（常见但不可靠，写稿不得当事实讲）
1. **《望江南·江南柳》是欧阳修写给外甥女张氏的情词**：出自钱愐《钱氏私志》（"張氏此時年方七歲。內翰伯見而笑云：年七歲，正是學簸錢時也"，随后引词）。作者为吴越钱氏后人，书中自述钱家与欧阳修因《五代史·十国世家》贬毁吴越、《归田录》记钱惟演事而结怨，立场明显；该词今本欧集不收，胡适《欧阳修的两次狱事》亦只认为"此词大概不是伪造的，但不一定是为张氏作的"。**只能作为"诋毁者的材料"介绍，绝不能拿来暗示欧阳修有私。**
2. **钱明逸弹劾是为报复欧阳修贬损吴越钱氏**：网络常见说法，宋代原始史料未见钱明逸本人动机的记载，属推测。可以讲"钱明逸是吕夷简提拔的、曾首劾范仲淹富弼"这类有据的站位。
3. **张氏供词的具体内容**：史书仅称"引公未嫁時事，詞多醜異"（《默记》），无具体供词。坊间小说化的审讯对白（如网文中苏良、苏安世诈供张氏的情节）均为虚构。
4. **"苏安世一人力排众议救下欧阳修"**：《长编》此说与《默记》"孙揆守之于前、王昭明主之于后、安世不敢改"冲突，单讲任何一方都不完整。
5. **"神宗差点杀了欧阳修"**：见上表，史家已辨其不可信。
6. **"欧阳修第二案中确有不检点"**：神宗手诏明言"使中外知其虛妄"，正史定性为诬，无任何反证。
7. **《醉翁亭记》作于庆历五年还是六年的确定说法**：记文无落款，通行庆历六年说，标"一般认为"。
8. **欧阳修弹劾杜曾家事致其自缢**：仅见《默记》（"論杜曾家事，通嫂婢有子，曾出知曹州，即自縊死"），正史原文待核；如用作"他自己也用过私德弹劾"的对照，必须标明出自宋人笔记。

## 给写稿者的说明
- **最该抓的名场面**：①张氏奁中物"买田立欧阳氏券"——人伦大罪查无实据，剩下一张地契；②宦官王昭明看案卷说"吃剑不得"（笔记，须标注）；③欧阳修谢表"若臣身不黜，则攻者不休"；④治平四年神宗追问消息来源，彭思永答"出于风闻，年老昏缪，不能记主名"，神宗批"岂有致人大恶便以风闻为托"；⑤手诏"仍榜朝堂，使中外知其虚妄"。
