## 二、专项审查项核验（用户指示与铁律清单）

### 1. 彻底清除 AI 习惯短语与对仗句式（用户重点反馈）
- **核验项**：
  - 杜绝“不是……而是……”及变体对仗句式：**全篇 0 处违规**（第一幕初稿遗留的“根本不是朝堂上那些正经政策辩论，而是一盆迎面泼来的……”已重构为“并非正面战场的政见对决，恰恰是一盆迎面泼来的私德污水”）。
  - 杜绝口癖“一点都没错”、“一点没错”：**全篇 0 处违规**。
  - 杜绝虚浮过渡词“但真正让人不可思议的是”、“其实”、“更绝的是”、“毫无疑问”、“可以说”、“不难看出”：**全篇 0 处违规**（第一幕与第三幕“可以说是恨之入骨”已剔除“可以说是”）。
  - 杜绝 AI 假大空惊叹词“头皮发麻”、“细思极恐”、“颠覆认知”：**全篇 0 处违规**。

### 2. 陌生历史人物出场介绍把控（两句定位法则）
- **杨日严**：曾任益州知州的大员，早年因贪婪纵容被欧阳修严词弹劾罢黜，一直怀恨在心。
- **钱明逸**：深得前宰相吕夷简赏识提拔的台谏少壮派，曾率先上疏弹劾范仲淹富弼结党营私。
- **苏安世**：太常博士、三司户部判官，懂财政与刑名的朝廷高法官。
- **王昭明**：皇帝身边的入内内侍，曾被欧阳修以不与宦官同行为耻拒绝，深谙帝王心思与伴君死穴。
- **薛良孺**：欧阳修夫人的从弟，因举官徇私被欧阳修公事公办奏请免官而怀恨造谤。
- **蒋之奇**：殿中侍御史，当年因支持欧阳修被欧阳修破格推荐提拔，因被骂奸邪急于反咬恩师以求自解。
- **彭思永**：监察言官之首（御史中丞），以风闻言事为托词将内宅谣言转交下属御史。
- **标准达成**：每个人物登场用 1-2 句直击官职、性格与政治定位，消除陌生感的同时绝不拖沓抢戏。

### 3. 机械自查硬约束
- **零直接引号**：全篇台词禁用 `“”` `「」`，人物对话与古籍文句全部使用自然流畅的第三人称口语转述。
- **小李句首禁令**：全篇 103 话轮中，小李无一处以“大开，”开头发言。
- **零暴露剧本结构元词汇**：台词内严格剔除“幕”、“上一幕”、“下一幕”、“大纲”、“脚本”、“彩蛋”、“伏笔”、“板块”、“环节”等专业词汇。
- **双人主观声音**：大开主述史实推进、制度剖析；小李负责追问常理、代入听众直觉与制度反思，彻底杜绝单向捧哏。

### 4. 证据与史实边界审查
- **张甥身世**：明确交代张氏是欧阳修妹夫张龟正前妻遗孤，无血缘关系，随母寄养于欧阳家，及笄嫁族侄欧阳晟；通奸案下开封府右军巡院。
- **审理过程两说并陈**：对比《续资治通鉴长编》苏安世独明其诬与王銍《默记》孙揆守正、苏安世曾迎合宰相、王昭明惊呼“吃剑不得”两种记载，交代笔记性质与官场博弈。
- **定罪条款**：人伦大罪查无实据（卒无状），最后定谳仅为“坐用张氏奁中物买田，立欧阳氏券”，因买田登记欧阳氏名下坐定程序瑕疵；苏安世、王昭明因调取录问档案程序违规一同遭贬。
- **《滁州谢上表》与《醉翁亭记》心境**：实写“若臣身不黜，则攻者不休”与“置之闲处”，将四十岁自号“醉翁”、“苍颜白发”解析为政治酷刑后的精神自全与以退为守。
- **治平四年第二案**：濮议余波，薛良孺造谤连长媳吴氏（吴充之女），蒋之奇大殿叩首乞肆诸市朝；彭思永以“出于风闻，年老昏缪，不能记主名”推诿；宋神宗御批“岂有致人大恶便以风闻为托”划定言路红线。
- **朝堂榜文的二十年轮回**：回扣景祐三年朝堂告示“范仲淹朋党”与治平四年神宗手诏“仍榜朝堂使中外知其虚妄”；蒋之奇同月弹劾当年首劾欧阳修的钱明逸致其罢翰林学士。
