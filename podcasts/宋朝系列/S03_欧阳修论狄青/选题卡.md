# 选题卡：S03 欧阳修论狄青——写《醉翁亭记》的人，为什么要把北宋最能打的将军请出朝廷

> 2026-10-07 启动底稿。只含选题与史料方向，不含脚本台词。史料逐条出处见同目录 `史料核对.md`。

## 基本信息
- **选题缘由**：《课本里的北宋朋友圈》系列第 3 期。S01–S02 讲"君子结党"和台谏风闻言事如何成为武器；本期把镜头转向文官集团整体对武将的态度。欧阳修在庆历年间曾上札子替狄青说情，十三年后又亲笔上札子要求罢免狄青，同一个人前后两份奏议，正好拿来剖开宋朝"重文抑武"这套制度。
- **题型**：系列连载 / 人物反差 + 制度剖析型
- **系列归属**：《笑谈历史》宋朝系列·课本里的北宋朋友圈（S03，时间段 1043–1057，核心在嘉祐元年 1056）
- **关键人物速查**：狄青（行伍出身，面有刺字，皇祐五年拜枢密使）；欧阳修（翰林学士，两度上札子请罢狄青）；宋仁宗（嘉祐元年正月起病重，未立储）；文彦博（宰相，起初保狄青，后以熟状出之）；吕景初（殿中侍御史，屡请出青）；刘敞（知制诰，"宁负青，无使负国家"）；庞籍（皇祐五年力阻狄青入枢府）；韩琦（接替狄青任枢密使）。
- **时间锚点**：庆历三年（1043）欧阳修《论乞不勘狄青侵公用钱札子》→ 皇祐五年（1053）狄青平侬智高后拜枢密使 → 嘉祐元年（1056）七月欧阳修因水灾上疏再论、八月癸亥狄青罢判陈州 → 嘉祐二年（1057）狄青卒于陈州。

## 核心认知反差（生死线）
- **你以为的**：
  1. 写"与民同乐"的欧阳修，是北宋文坛的温厚长者，政治上一贯站在"正人君子"一边；
  2. 狄青被挤出朝廷，是因为有奸臣嫉贤妒能，或者狄青自己真有什么过错；
  3. 宋朝"重文抑武"是皇帝定下的偏好，文官只是执行。
- **实际上的**：
  1. 庆历三年，欧阳修上札子替狄青求情，说朝廷用兵五六年只得到狄青、种世衡两个将才，请求对狄青"特与免勘"；到嘉祐元年，同一个欧阳修写《论狄青札子》，自己承认狄青"未有显过"，仍请"罢青机务，与一外藩"，理由是"武臣掌机密而得军情"本身就不便，"不计青之用心如何也"；
  2. 正史里罢免狄青的推手是一整排名臣：欧阳修、刘敞、吕景初；宰相文彦博起初还替狄青说话，等京城大水、狄青避水搬进相国寺，才以"熟状"把他外放陈州。罪名从头到尾是"得军情之名"，外加家狗生角、宅有光怪之类的流言；
  3. "猜忌武将"是文官集团的共识与职业本能：太祖杯酒释兵权、赵普一句"陛下何以能负周世宗"、晚唐五代骄兵拥立的记忆，层层沉淀成士大夫的政治常识。欧阳修甚至在疏中把"大水"推导为"水者阴也，兵亦阴也，武臣亦阴也"。
- **反差的强度自评**：⭐⭐⭐⭐⭐

## 核心问题（这期节目回答的一句话问题）
一个打了二十五仗、中了八箭、从士兵爬到枢密使的人，没有任何过错，为什么连当初夸他的欧阳修都认为他必须离开？

## 三大基因自检
- [x] **小切口**：一张脸。狄青面上的刺字，皇帝让他敷药除掉，他不肯，说留着劝勉军中（《宋史·狄青传》）。同一张脸，在士兵眼里是"我辈之内出得此人"，在欧阳修札子里是"面有黥文，乐其同类"。
- [x] **大纵深**：从陈桥兵变、杯酒释兵权，到"以文制武"的枢密院人事惯例，再到嘉祐元年仁宗病重、未立储君、京城大水的政治高压，一个武将的去留，牵动的是宋朝立国以来的安全焦虑。
- [x] **人性内核**：一个真诚的好人，出于"保全"的善意，做了一件对另一个好人极不公平的事；体制里的人怎样用"为你好"完成排斥。

## 内容弹药
- **主要素材/案例**（严格区分出处性质）：
  1. 狄青出身与战功：延州前线四年二十五战、中流矢者八，临敌披发戴铜面具；尹洙荐之韩琦、范仲淹，范仲淹授《左氏春秋》（正史：《宋史·狄青传》）；
  2. 傅药除字与"留涅以劝军中"（正史：《宋史·狄青传》）；
  3. 庆历三年欧阳修为狄青说情：五六年所得边将"惟狄青、种世衡二人"，请"特与免勘"（文集：《论乞不勘狄青侵公用钱札子》；《续资治通鉴长编》卷一四四亦载）；
  4. 昆仑关夜袭、斩陈曙等三十人、"宁失智高，不敢诬朝廷以贪功"（正史：《宋史·狄青传》）；
  5. 拜枢密使前庞籍力争、授官被压（正史：《长编》卷一七四皇祐五年二月）；
  6. 京城百姓围观狄青"至壅路不得行"、家狗生角、"数有光怪"（正史：《长编》卷一八三、《宋史·狄青传》）；
  7. 《论狄青札子》全文：承认"未有显过"，仍请罢机务；引唐朝朱泚"本非反者，仓卒之际为军士所迫"（文集：欧阳修奏议）；
  8. 嘉祐元年七月水灾疏再论狄青，以"水者阴也，兵亦阴也，武臣亦阴也"立论；同疏讥枢密使王德用为"老衙官"（正史编年：《长编》卷一八三）；
  9. 吕景初对文彦博说"青虽忠，如众心何"；刘敞两度请出狄青，"宁负青，无使负国家"（正史编年：《长编》卷一八三）；
  10. 避水徙家相国寺、"行坐殿上"，执政以熟状出青判陈州（正史：《长编》卷一八三、《宋史·狄青传》）；
  11. 嘉祐二年疽发髭卒于陈州，谥武襄；熙宁元年神宗取其画像入禁中（正史：《宋史·狄青传》）；
  12. 文彦博"太祖岂非周世宗忠臣""无他，朝廷疑尔"（笔记：王大成《野老纪闻》，后被冯梦龙《智囊》转载；与《长编》所记文彦博起初保狄青相抵，只能作辨析素材）；
  13. 韩琦斩焦用、"东华门外以状元唱出者乃好儿"；狄青自言"我少一进士及第耳"；歌妓"劝斑儿一盏"（笔记：王铚《默记》，可作时代氛围辨析，不作主线）。
- **可用的对照组**：
  - **庆历三年的欧阳修 vs 嘉祐元年的欧阳修**：同一支笔，前一份说狄青难得、"不可与常人一例推鞫"，后一份说狄青"一常才"、必须外放；
  - **赵普劝太祖 vs 文官劝仁宗**：赵普一句"陛下何以能负周世宗"（正史：《宋史·石守信传》）与笔记里文彦博的"太祖岂非周世宗忠臣"句式几乎一样，正好用来讨论这句名言为何"像真的"；
  - **狄青 vs 韩琦**：两人同为枢密使，狄青罢免当日由韩琦接任（《长编》卷一八三）。一个起于行伍，一个进士出身。
- **可交付的概念工具**：
  - **"得军情之罪"**：在一个靠兵变起家的王朝里，武将最危险的品质是"受士兵爱戴"。猜忌的对象从具体的人转向一种结构位置，当事人越优秀，越说明他该离开。听众可以拿它理解组织里"能力太强、人缘太好反而被调岗"的处境。
- **降维三步法候选点**：
  - "一犬吠形，百犬吠声"：札子原句 → 欧阳修把军中对狄青的拥戴形容成群犬跟叫 → 落回士大夫对普通士兵的真实看法；
  - "水者阴也……武臣亦阴也"：京城下暴雨 → 推导出武臣不宜掌枢密 → 九年后同样的"大水天谴"论被台谏拿来攻击欧阳修本人（S04 伏线，写作时仅点到）。
- **合法跑偏候选**：
  - 狄青的铜面具与"面涅"：宋代士兵刺字制度（需另做史料核对）；
  - 狄青谢绝狄仁杰后人献画像、不肯攀附为远祖（宋人言行录类文献，见识典古籍所收《宋名臣言行略》，存疑，只能作传说处理）。

## 冷开场方向（只写方向，不写台词）
- **类型**：一张脸的名场面。
- **名场面要素**：仁宗下令让狄青敷药除去脸上刺字；狄青指着自己的脸拒绝，说要留着劝勉军中（正史）。镜头随后切到几年后：一份翰林学士的奏札，把同一张脸上的黥文写成士兵"乐其同类"的根源，请皇帝把他调离。最后揭出奏札作者，就是写《醉翁亭记》的欧阳修。
- **节奏**：冷开场约 1 分钟内落在"作者是欧阳修"这个反差上，01:00 左右进入标志性报幕，随后由小李发问"他到底犯了什么错"。

## 结尾设计
- **收束回扣点**：熙宁元年，神宗把狄青画像取入宫中，亲写祭文（正史）。生前被请出去的人，死后画像被请了回来。
- **互动设计**：讨论题：如果你是嘉祐元年的仁宗，手里有一位无过错但"得军心"的大将，你留不留？
- **系列衔接**：
  - **上接 S02（欧阳修张甥案·醉翁亭记）**：S02 里欧阳修是被台谏风闻言事、"帷薄"丑闻打下去的受害者；S03 里他自己成了以"浮议""讹言"为据请罢大臣的一方。开场可点一句：被流言赶到滁州的人，十年后也用流言作理由。
  - **下启 S04（濮议）**：嘉祐元年欧阳修用"大水是阴气、应在武臣"论狄青；治平二年京城再发大水，台谏吕诲、贾黯把水灾归为"濮王一事失中"的天谴，矛头指向欧阳修，欧阳修在中书札子里反驳这是"厚诬天人"。结尾可以只留这个钩子：九年后，同一场雨落到了他自己头上。
