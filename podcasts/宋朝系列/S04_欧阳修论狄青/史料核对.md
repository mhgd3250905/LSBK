# S03 史料核对与写作边界：《欧阳修论狄青》

> 2026-10-07 启动底稿。原文均于当日在维基文库（zh.wikisource.org）原始页面逐字比对（四库本异体字照录，如"宻""竒"）。出处性质分四档：**正史确载**（《宋史》、李焘《续资治通鉴长编》）/ **文集自述**（欧阳修奏议）/ **宋人笔记**（《默记》《野老纪闻》等）/ **后世演绎或存疑**。

## 核对总表

| 核心主张 | 史料出处与卷次 | 写作边界 |
|---|---|---|
| **狄青行伍出身、延州四年二十五战** | **正史确载**：《宋史》卷二九〇狄青传："凡四年，前后大小二十五战，中流矢者八……臨敵被髮、帶銅面具，出入賊中，皆披靡莫敢當。" | 战功数字可直接用。铜面具是正史细节，可作画面，但不要发挥成"面具下的伤疤"之类的想象。 |
| **尹洙荐狄青，范仲淹授《左氏春秋》** | **正史确载**：同传："仲淹以《左氏春秋》授之曰：『將不知古今，匹夫勇爾。』青折節讀書，悉通秦、漢以來將帥兵法。" | 可用来说明狄青与"庆历君子"圈本有渊源，这也是欧阳修庆历年间替他说话的背景之一（背景关联属节目推断，需说明）。 |
| **傅药除字，留涅以劝军中** | **正史确载**：同传："帝嘗敕青傅藥除字，青指其面曰：『陛下以功擢臣，不問門地，臣所以有今日，由此涅爾，臣願留以勸軍中，不敢奉詔。』" 时间在其任马军副都指揮使之后、知延州擢枢密副使之前（皇祐四年前后，年份待核）。 | 冷开场主素材。台词须第三人称转述。不可写成仁宗当面亲手递药等细节。 |
| **庆历三年欧阳修为狄青求情** | **文集自述**：《论乞不勘狄青侵公用钱劄子》（题注"慶曆三年"）："國家兵興以來，五六年所得邊將，惟狄青、種世衡二人而已……臣料青本武人，不知法律……其狄青縱有幹連，仍乞特與免勘。" **正史编年**亦收：《长编》卷一四四同文。 | 本期最关键的反差证据，可放在第一幕后段。注意这份札子同样带有"青本武人，不知法律"的居高临下口吻，两份札子的态度差异要讲准：前一份是惜才，后一份是防患，底色里的文官视角是同一个。 |
| **皇祐五年平侬智高，斩陈曙等** | **正史确载**：同传："晨會諸將堂上，揖曙起，並召用等三十人，按以敗亡狀，驅出軍門斬之。沔、靖相顧愕眙，諸將股慄。""寧失智高，不敢誣朝廷以貪功也。" | 可作狄青"守规矩、不贪功"的人物底色。昆仑关夜袭的天气、灯会等细节多出笔记演义，不用。 |
| **拜枢密使前庞籍力争** | **正史确载**：《长编》卷一七四皇祐五年二月癸未："上大喜謂宰相龎籍曰青破賊卿執議之力也遂欲擢青樞密使同平章事籍以為不可力争之乃罷。" | 说明阻力从狄青入枢府之前就已存在。狄青正式拜枢密使的月份（皇祐五年，约五月）原文待核。 |
| **在枢府四年，京城人围观、家狗生角** | **正史确载**：《长编》卷一八三："青在西府四年京城小民聞青驟貴相與推說誦詠其材武青每出入輙聚觀之至壅路不得行……又青家犬生角數有光怪。"《宋史》狄青传同义。 | 可用。注意"家狗生角""光怪"是当时的流言，史书照录"言者"之说，节目要讲成"有人这样上报"，不能讲成真有其事。 |
| **《论狄青札子》：承认无过而请罢** | **文集自述**：欧阳修《论狄青劄子》（题注"至和三年"，即嘉祐元年改元前）："今三四年間，雖未見其顯過，然而不幸有得軍情之名……蓋由軍士本是小人，麵有黥文，樂其同類……所謂一犬吠形，百犬吠聲……如臣愚見，則青一常才，未有顯過，但為浮議所喧，勢不能容爾……但武臣掌機密，而為軍士所喜，自於事體不便，不計青之用心如何也……罷青機務，與一外藩。" | 全期核心文本，可分句拆读。欧阳修在文中说罢官是为了"永保终始"、保全狄青，这一层善意必须如实交代，不能把他写成单纯妒贤的小人。上书月份未注，原文待核（只能说至和三年、嘉祐元年七月前）。 |
| **嘉祐元年七月水灾疏再论狄青** | **正史编年**：《长编》卷一八三嘉祐元年秋七月（丙戌后）载欧阳修疏："臣又見樞宻使狄青出自行伍遂掌樞宻……欲乞且罷青樞務任以一州既以保全青亦為國家消未萌之患……至於水者隂也兵亦陰也武臣亦陰也此推類而易見者。"疏凡再上，皆留中不出。 | 可用"水者阴也"作为降维点。同条记王德用闻建储议，欧阳修说"老衙官何所知"，可作他对武臣态度的旁证，点到即可。 |
| **吕景初、文彦博、刘敞的态度** | **正史编年**：《长编》卷一八三七月："景初數詣中書白執政請出青文彦博以青忠謹有素外言皆小人為之不足置意景初曰青雖忠如衆心何。"八月癸亥条记刘敞："今外說紛紛雖不足信要當使無後憂寧負青無使負國家。"《宋史》卷三一九刘敞传亦载其请出青"以全其終"。 | 要点：**正史里文彦博起初是替狄青说话的**。主推手是台谏（吕景初）与词臣（欧阳修、刘敞）。不可把文彦博写成从头到尾的主谋。 |
| **避水相国寺，以熟状出判陈州** | **正史确载**：《长编》卷一八三嘉祐元年八月癸亥："及京師大水青避水徙家於相國寺行坐殿上都下喧然執政聞之始懼以熟状出青判陳州。"《宋史》狄青传："青避水徙家相國寺，行止殿上，人情頗疑，乃罷青為同中書門下平章事，出判陳州。"同日韩琦为枢密使。 | 日期可写嘉祐元年八月。"行坐殿上"是史书原话，至于狄青穿什么衣服坐在殿上，见下方笔记条，不作正史讲。 |
| **欧阳修本传的定性** | **正史确载**：《宋史》卷三一九欧阳修传："狄青為樞密使，有威名，帝不豫，訛言籍籍，脩請出之於外，以保其終，遂罷知陳州。" | 正史采用"保其终"的说法。节目可以提出质疑，但要说明这是节目的判断。 |
| **狄青之死** | **正史确载**：《宋史》狄青传："明年二月，疽發髭，卒。帝發哀，贈中書令，諡武襄。"《长编》卷一八五系于嘉祐二年三月庚子"陳州言……狄青卒"（为奏报到京日期）。 | 死因按正史只写"疽发髭"（胡须处生疽）。"忧惧而死""被吓死"属笔记说法，只能作"有一种传说"处理。卒月写"嘉祐二年春"最稳妥。享年通行说法为 50 岁左右，原文待核，不报具体岁数。 |
| **神宗取画像入禁中** | **正史确载**：同传："熙寧元年，神宗考次近世將帥……命取青畫像入禁中，御製祭文，遣使齎中牢祠其家。" | 结尾回扣点，可直接用。 |
| **杯酒释兵权与赵普"何以能负周世宗"** | **正史确载**：《宋史》卷二五〇石守信传，系于"乾德初"："人孰不欲富貴，一旦有以黃袍加汝之身，雖欲不為，其可得乎？"同传赵普谏太祖："陛下何以能負周世宗？"太祖默然。 | 作制度背景用。注意：《宋史》系于乾德初，《长编》系于建隆二年，学界对"杯酒"情节是否经过后人加工有争论，节目只说"史书记载"，不当作逐字实录。 |
| **文彦博"太祖岂非周世宗忠臣""朝廷疑尔"** | **宋人笔记 / 存疑**：南宋王大成《野老纪闻》（二手转引："青自陳無功而受兩鎮節麾……公曰：太祖豈非周世宗忠臣……公直視語之曰：無他，朝廷疑爾。青驚怖……"），明冯梦龙《智囊》转载。原书原文待核。 | **不得作为主线或冷开场**。它与《长编》"文彦博以青忠谨有素"相抵触，且句式与正史赵普谏太祖语高度相似，可做一段"这句名言为什么流传最广却最不可靠"的辨析。 |
| **狄青"我少一进士及第耳"、韩琦斩焦用、白牡丹"劝斑儿"** | **宋人笔记**：王铚《默记》卷中："妓有名白牡丹者……勸班兒一盞，譏其面有涅文也……魏公曰：東華門外以狀元唱出者乃好兒……青每語人曰：韓樞密功業官職與我一般，我少一進士及第耳。" | 可用来呈现"进士出身"与"行伍出身"的身份落差，但每次引用都要标明"宋人笔记记载"。《默记》四库提要已指出其书有不可尽信处。 |
| **狄青"衩衣浅黄袄子坐殿上"** | **宋人笔记**：《默记》同条："衩衣衣淺黃襖子，坐殿上指揮士卒。盛傳都下。" | 存疑。《默记》另一条写曹汭"衩衣衣淡黃襖子"被告谋反，情节高度相似，疑为流行的构陷套路。只能作"当时京城盛传"处理，不能当事实讲。 |
| **"狄家爷爷所赐"、中使抚问即惊疑终日** | **宋人笔记 / 存疑**：同出《野老纪闻》转引。 | 不用作事实，可与上条一并辨析。 |
| **欧阳修自身对武臣的看法** | **文集自述**：《论狄青劄子》"軍士本是小人"；《长编》卷一八三水灾疏"武臣亦陰也"。 | 可以据此讲士大夫阶层对军人的普遍看法，不扩大成"欧阳修蔑视所有武人"。 |

## 证据禁区（不得写成事实）
1. 文彦博当面对仁宗说"太祖岂非周世宗忠臣"、对狄青说"朝廷疑尔"——笔记，且与正史相抵；
2. 狄青被中使问候吓出病、忧惧而死——笔记；正史只写疽发髭；
3. 狄青穿黄袄坐相国寺大殿"指挥士卒"——笔记，疑为构陷套路；
4. 欧阳修出于嫉妒、私怨排挤狄青——无任何史料支持，属动机臆测；
5. 宋仁宗私下流泪不舍、与狄青话别——无载；
6. 欧阳修与狄青见面交谈、当面冲突——无载；
7. "狄青面具下的伤疤""昆仑关上元灯会诱敌"——演义与评书来源；
8. 任何狄青"谋反"的说法——正史与笔记均无实据，连欧阳修本人也说"未有显过"。

## 给写稿者的说明
- **最该抓的名场面**：①傅药除字、留涅劝军（正史）；②庆历三年与嘉祐元年两份札子同台对读（文集，两份都有原文）；③京城大水、狄青避水住进相国寺，执政"始惧"，以熟状把他外放（正史）。三件事都有原文，戏剧性足够，不需要笔记补戏。
- **欧阳修的哪一面**：一个真诚、敢言、自认在"保全"别人的士大夫。他的札子逻辑严密，承认对方无罪，又坦然要求罢免。要让听众看懂这种"出于制度安全感的善意"，比把他写成坏人更有力量。
- **狄青的哪一面**：守规矩、慎密寡言、不贪功（正史"慎密寡言""喜推功與將佐"）。他越无可挑剔，越能显出制度猜忌的荒谬。
- **易踩的坑**：
  1. 把文彦博写成头号推手——正史顺序是台谏、词臣先发，宰执最后才动；
  2. 把"重文抑武"讲成某个皇帝的个人喜好——要讲成从五代教训到宋初家法、再到士大夫常识的累积；
  3. 引用"太祖岂非周世宗忠臣"不标笔记；
  4. 把"家狗生角""光怪"讲成真事；
  5. 狄青卒年月混用《宋史》"二月"与《长编》"三月庚子"，统一写"嘉祐二年春"并说明《长编》为奏报日；
  6. 欧阳修上《论狄青札子》的具体月份原文未注，不要编造日期。
- **与 S04 的伏线**：本期只点"水者阴也"这一推理方式；九年后的大水与濮议留给下一期展开，避免本期结尾抢戏。
