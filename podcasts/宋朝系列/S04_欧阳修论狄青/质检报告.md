## 二、专项审查项核验（用户指示与铁律清单）

### 1. 彻底清除 AI 习惯短语与对仗句式
- **核验项**：
  - 杜绝“不是……而是……”及变体对仗句式：**全篇 0 处违规**（第二幕初稿遗留的“文官们害怕的根本不是狄青这个人，而是他身后那个……”已重构为“文官们真正忌惮的并非狄青个人，恰恰是他身后那个……”；第四幕“绝不是长治久安，而是……”重构为“换不来长治久安，反而彻底阉割了……”）。
  - 杜绝口癖“一点都没错”、“一点没错”：**全篇 0 处违规**。
  - 杜绝虚浮过渡词“但真正让人不可思议的是”、“其实”、“更绝的是”、“毫无疑问”、“可以说”、“不难看出”：**全篇 0 处违规**（第二幕“庞籍可以说是他的伯乐”已修正为“庞籍正是他的伯乐”）。
  - 杜绝网络流行套话“绝了”：**全篇 0 处违规**（第一幕初稿“回绝了”已替换为“婉拒了”）。
  - 杜绝 AI 假大空惊叹词“头皮发麻”、“细思极恐”、“颠覆认知”：**全篇 0 处违规**。

### 2. 陌生历史人物出场介绍把控（两句定位法则）
- **狄青**：从小兵一路凭借战功升到枢密使的北宋第一战神，二十五战中八箭、面有刺字临敌戴铜面具。
- **庞籍**：老派宰相，曾赏识狄青但坚决反对武臣破例掌管枢密院。
- **文彦博**：当朝首辅宰相，深谙祖宗家法，起初为狄青辩护、大水后见相国寺局面始惧拟熟状定案出判陈州。
- **吕景初**：殿中侍御史，监察台核心少壮铁面，质问宰相“狄青虽忠如众心何”。
- **刘敞**：知制诰，名满天下的学者型词臣，直言上奏“宁负青，无使负国家”。
- **王德用**：同样行伍出身的枢密使老将，被欧阳修在奏疏里讥讽为“老衙官何所知”。
- **标准达成**：每个人物登场用 1-2 句直击官职、性格与政治定位，消除陌生感的同时绝不拖沓抢戏。

### 3. 机械自查硬约束
- **零直接引号**：全篇台词禁用 `“”` `「」`，人物对话与古籍文句全部使用自然流畅的第三人称口语转述。
- **小李句首禁令**：全篇 77 话轮中，小李无一处以“大开，”开头发言。
- **零暴露剧本结构元词汇**：台词内严格剔除“幕”、“上一幕”、“下一幕”、“大纲”、“脚本”、“彩蛋”、“伏笔”、“板块”、“环节”等专业词汇。
- **双人主观声音**：大开主述史实推进、制度剖析；小李负责追问常理、代入听众直觉与制度反思，彻底杜绝单向捧哏。

### 4. 证据与史实边界审查
- **狄青面涅与战功**：按《宋史·狄青传》实写四年二十五战、中流矢者八、临敌戴铜面具；仁宗赐药除字狄青指面拒绝留涅劝军，不写当面递药等虚构细节。
- **两折对比**：庆历三年欧阳修上奏《论乞不勘狄青侵公用钱札子》称赞“国家兵兴以来，五六年所得边将，惟狄青、种世衡二人而已”；嘉祐元年《论狄青札子》直言其在任“未有显过，然而不幸有得军情之名”，引朱泚兵变警示“武臣掌机密而为军士所喜，自于事体不便，不计青之用心如何也”。
- **陈桥兵变与立国胎记**：按《宋史·石守信传》实写赵普质问太祖“陛下何以能负周世宗”，剖析文官集团对武夫擅权的集体心理创伤。
- **京城大水与避水相国寺**：嘉祐元年仁宗重病未立储背景核实；大水后欧阳修以天人感应推导“水者阴也，兵亦阴也，武臣亦阴也”；狄青避水移居大相国寺正殿“行坐殿上”，文官“始惧”，刘敞奏“宁负青，无使负国家”，文彦博以熟状出判陈州。
- **狄青之死与民间流言辨析**：正史确载死于“疽发髭”（嘴角生毒疮），享年五十；严肃辨析宋人笔记王大成《野老纪闻》中“无他，朝廷疑尔”及“中使抚问吓死”等流言的虚构性质与制度投射。
- **熙宁画像入禁中**：熙宁元年神宗取狄青画像入禁中亲制祭文，体现生前防范驱逐与死后哀荣的巨大历史讽刺。
