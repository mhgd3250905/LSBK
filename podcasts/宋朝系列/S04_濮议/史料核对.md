## 核对总表

| 核心主张 | 史料出处与卷次 | 写作边界 |
|---|---|---|
| **英宗身世与立嗣** | **正史确载**：《宋史·英宗本纪》："濮安懿王允讓第十三子……四歲，仁宗養於內。寶元二年，豫王生，乃歸濮邸。"嘉祐七年八月"戊寅，立為皇子……帝聞詔稱疾，益堅辭"。《宋史·濮王允让传》："仁宗在位久無子，乃以王第十三子宗實為皇子。" | 英宗是**生前正式立为皇子**的养子，这是与明世宗最大的结构差异，务必讲准。 |
| **治平元年至二年议礼启动** | **正史确载**：《宋史·濮王允让传》："治平元年，宰相韓琦等奏：請下有司議……詔須大祥後議之。"《宋史·英宗本纪》治平二年"夏四月戊戌，詔議崇奉濮安懿王典禮"。 | 时间线可直接用。 |
| **司马光独奋笔写"皇伯"议** | **正史确载**：《宋史·司马光传》："學士王珪等相視莫敢先，光獨奮筆書曰：『為人後者為之子，不得顧私親。王宜凖封贈期親尊屬故事，稱為皇伯，高官大國，極其尊榮。』議成，珪即命吏以其手稿為按。"《长编》卷二〇五同。 | 课本钩子与本期的连接点。可说"司马光是皇伯说的执笔人"。 |
| **中书主"皇考"及依据** | **正史确载**：《长编》卷二〇五治平二年六月："中書又奏按儀禮為人後者為其父母報……又漢宣帝光武皆稱其父為皇考今王珪等議稱皇伯於典禮未見明據。"《宋史·欧阳修传》："若本生之親，改稱皇伯，歷考前世，皆無典據。" | 欧阳修的核心论点是"服可降、名不可没"，可作降维点。 |
| **吕公著驳"皇伯考"** | **正史确载**：《长编》卷二〇五："天章閣待制吕公著曰真宗以太祖為皇伯考非可加于濮王也。" | 可作背景补充，非必需。 |
| **治平二年六月太后手书切责，罢集议** | **正史确载**：《长编》卷二〇五："辛亥内出手書切責韓琦等以不當議稱皇考……甲寅降詔曰如聞集議議論不一冝權罷議。"《宋史·英宗本纪》六月"甲寅，罷尚書省集議，令有司博求典故"。 | 讲清太后第一次出手是**站在皇伯一边**叫停的，后来第二次手书方向相反。 |
| **八月京师大水与"天谴"论** | **正史确载**：《宋史·英宗本纪》治平二年"八月庚寅，京師大雨，水……軍民水死者千五百八十人"。《宋史·吕诲传》："會秋大水，誨言：『陛下有過舉而災沴遽作，惟濮王一事失中，此簡宗廟之罰也。』"《长编》卷二〇六记贾黯"七廟神靈震怒天降雨水"。《长编》卷二〇七中书札子："簡宗廟致水災者是厚誣天人之言也。" | 与 S03 欧阳修"水者阴也……武臣亦阴也"呼应，属节目的串联解读，可讲。中书札子执笔人是否为欧阳修，原文待核，只说"中书"。 |
| **吕诲劾韩琦、劾欧阳修"首开邪议"** | **正史确载**：《宋史·吕诲传》："遂劾宰相韓琦不忠五罪……又與御史范純仁、呂大防共劾歐陽修『首開邪議，以枉道說人主，以近利負先帝，陷陛下於過舉』。" | 可转述。弹章中"乞行诛戮"一说出自欧阳修《濮议》自述（见下），不要算到正史头上。 |
| **治平三年正月：手书出于执政谋划，"相视而笑"** | **正史编年**：《长编》卷二〇七："執政乃相與審議欲令皇太后下手書尊濮安懿王為皇夫人為后皇帝稱親又令上下詔謙讓不受尊號但稱親……歐陽修手為詔草二通一納上前日中太后果遣中使齎實封文書至中書執政相視而笑。" | 冷开场核心素材。"相视而笑"只能如实写四个字，不添加神情和台词。"手为诏草二通"一句前接"外间言濮王已议定称皇"，断句有歧义，写作时以"《长编》记载"引出。 |
| **太后手书内容与英宗只受"称亲"** | **正史确载**：《宋史·英宗本纪》治平三年正月："丁丑，皇太后下書中書門下：『封濮安懿王宜如前代故事，王夫人王氏、韓氏、任氏，皇帝可稱親。尊濮安懿王為皇，夫人為后。』詔遵慈訓。以塋為園……即園立廟。"《宋史·欧阳修传》："太后出手書，許帝稱親，尊王為皇，王夫人為后。帝不敢當。" | 结局是折中：称"亲"，不称"皇考"也不称"皇伯"。不要说成"欧阳修一派大获全胜"。 |
| **欧阳修对手书来历的辩解** | **文集自述**：《濮议》卷二："議者謂韓琦交結髙居簡惑亂皇太后請降手書……答曰手書非皇太后本意事出禁中非外人所得知也若云因韓琦使髙居簡請降手書則又厚誣也。" | 与《长编》"执政相与审议欲令皇太后下手书"有张力。节目须两说并陈：正史编年记执政事先谋划，欧阳修本人否认勾结宦官。 |
| **吕诲等缴告敕、"势难两立"；欧阳修"当留御史"** | **正史确载**：《长编》卷二〇七壬午："歐陽修曰御史以為理難並立若以臣等為有罪即當留御史若以臣等為無罪則取聖㫖上猶豫乆之乃令出御史既而曰不冝責之太重也。"《宋史·吕诲传》同。 | 名场面，可转述。欧阳修这句话是以退为进，有分寸地讲出锋利感即可。 |
| **台谏被贬名单** | **正史确载**：《宋史·英宗本纪》治平三年正月"壬午，黜御史呂誨、範純仁、呂大防"；三月"辛酉，黜諫官傅堯俞、御史趙鼎、趙瞻"。《长编》卷二〇七：吕诲知蕲州、范纯仁通判安州、吕大防知休宁县。 | 处分是外放地方，**无人下狱、无人受杖**，与明朝左顺门对照时要准确。 |
| **范纯仁"命出房闱"之忧** | **正史确载**：《宋史·范纯仁传》："陛下受命仁宗而為之子，與前代定策入繼之主異……奈何使命出房闈，異日或為權臣矯托之地，非人主自安計。" | 范纯仁是范仲淹之子（《宋史》卷三一四），可点出这层人物关系。 |
| **司马光请求与御史同贬** | **正史确载**：《宋史·司马光传》："御史六人爭之力，皆斥去。光乞留之，不可，遂請與俱貶。" | 可用。司马光当时并未被贬，只是"请"，不可说他被贬。 |
| **吕大防、王珪、吕公著的立场** | **正史确载**：《宋史·吕大防传》："豈可生以為子，沒而背之哉？"章十数上，出知休宁县。《宋史·王珪传》："珪與侍從、禮官合議宜稱皇伯。"《宋史·吕公著传》：稱親則有二父之嫌，乞补外，出知蔡州。 | 可按需取用，避免人名过多。 |
| **欧阳修《濮议》对台谏的评价** | **文集自述**：《濮议》卷一："其本欲以言得罪而買名，故其言惟務激怒朝廷……借指臣某為首議之人，恣其醜詆。"又记市井传言："待將濮王入太廟，換了仁宗木主。"卷二："是時䑓諫方吹毛求疵。" | 一方之词，可以用来表现欧阳修的怨气，但必须说明"这是欧阳修自己的说法"。 |
| **欧阳修的处境与性格** | **正史确载**：《宋史·欧阳修传》："脩平生與人盡言無所隱。及執政……雖臺諫官論事，亦必以是非詰之，以是怨誹益眾。" | 可解释他为何成为众矢之的。 |
| **治平四年蒋之奇以"帷薄"弹劾欧阳修** | **正史编年**：《长编》卷二〇九治平四年三月："之竒始緣濮議合修意修特薦為御史方患衆論指目為姦邪求所以自解……之竒言修罪當貶竄且曰以隂訟治大臣誠難然修首違濮園事犯衆怒。"欧阳修自辩"乃是禽獸不為之醜行"。结果彭思永、蒋之奇被贬。**正史确载**：《宋史·蒋之奇传》："乃詣修盛言濮議之善，以得御史……遂劾修。"《宋史·欧阳修传》："脩亦力求退，罷為觀文殿學士、刑部尚書、知亳州。" | **此案已由 S02 作为欧阳修"第二案"完整展开，本期只取"修首违濮园事犯众怒"一句说明与濮议的因果，不重复案情。**只讲弹劾与"查无实据"的结果，不复述丑闻细节。造谣者姓名两处记载不同：《宋史·欧阳修传》作"薛宗孺"，《长编》与《宋史·蒋之奇传》作"薛良孺"，节目只说"欧阳修妻子的堂弟"。《长编》注疑"上初欲诛修"之说，不采用。 |
| **英宗之死** | **正史确载**：《宋史·英宗本纪》治平四年"正月……丁巳，帝崩于福寧殿"。 | 距治平三年正月称亲约一年，可作结尾时间点。 |
| **明朝毛澄援引濮议** | **正史确载**：《明史·毛澄传》："又考宋濮安懿王之子入繼仁宗後，是為英宗。司馬光謂濮王宜尊以高官大爵，稱王伯而不名……程頤之言曰……曰皇伯、叔父某國大王。" | 宋明对照的硬证据，可直接用。 |
| **程颐参与濮议** | **正史转引**：《明史·毛澄传》引程颐语。程颐原文（《代彭思永上英宗皇帝论濮王典礼疏》）原文待核。 | 只说"明朝人引用过程颐的意见"，暂不展开程颐原疏。 |

## 证据禁区（不得写成事实）
1. 欧阳修与司马光当面争吵、互骂——史料未见两人当面交锋的记载，两人分属两方是事实，"撕破脸"指阵营对立，写作时不得虚构对话；
2. 曹太后被韩琦"胁迫""灌醉"后写手书——民间流传说法，史料只有"执政相与审议欲令皇太后下手书"；
3. 吕诲等弹章要求"诛杀欧阳修"——出自欧阳修《濮议》自述，正史弹章原文未见此语，只能作"欧阳修说台谏要求诛他"；
4. 英宗对濮议的心理活动、哭诉——史料未载英宗本人表态细节，不得模仿 EP08 嘉靖"哭诉父母不可易"的写法；
5. 台谏有人受杖、下狱或死亡——无，宋代处分仅为外放；
6. 蒋之奇弹劾所涉丑闻的具体内容——史料定为不实，不复述细节；
7. 司马光因濮议被贬——不实，他只是请求同贬；
8. "濮议导致英宗早逝"之类因果——无据。

## 给写稿者的说明
- **最该抓的名场面**：①司马光"独奋笔"、王珪拿他的手稿当正式议状（正史）；②太后文书送到中书、执政"相视而笑"（《长编》）；③欧阳修对皇帝说"若以臣等为有罪，即当留御史"，皇帝犹豫良久才让御史出外（《长编》）；④一年多以后蒋之奇弹章里那句"首违濮园事犯众怒"（《长编》）。
- **名人的哪一面**：司马光是规则的守护者，耿直、执拗、愿意陪同伴一起受罚；欧阳修是"尽言无所隐"、凡事以是非诘问台谏的执政者，赢了论证，也把怨气攒满了。两人都真诚，节目不判谁是坏人。
- **与 EP08 的对照要点**：英宗是生前过继的皇子、病弱且有太后垂帘，嘉靖是未过继的藩王、少年亲自上阵；宋朝以太后手书折中收场、失败者外放，明朝以廷杖收场、死者十六人。毛澄援引司马光、程颐，是两期之间最硬的连接点。
- **易踩的坑**：
  1. 把太后两次手书混为一谈（第一次叫停"皇考"，第二次许称"亲"）；
  2. 把称"亲"讲成称"皇考"，结局是折中；
  3. 把欧阳修《濮议》中对台谏动机的指控当成事实；
  4. 照搬 EP08 的"少年皇帝逆袭"叙事；英宗本人在史料里几乎没有台词；
  5. 人名过多，建议正片只保留：英宗、曹太后、韩琦、欧阳修、司马光、吕诲、范纯仁、蒋之奇，其余点到即止；
  6. 薛宗孺/薛良孺异名，统一回避为"妻子的堂弟"。
