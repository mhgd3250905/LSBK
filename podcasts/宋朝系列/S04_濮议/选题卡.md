# 选题卡：S04 濮议——砸缸的司马光和写《醉翁亭记》的欧阳修，为一个称呼撕破了脸

> 2026-10-07 启动底稿。只含选题与史料方向，不含脚本台词。史料逐条出处见同目录 `史料核对.md`。本期与 EP08《嘉靖大礼议》构成"宋明两场认爹之争"的对照。

## 基本信息
- **选题缘由**：《课本里的北宋朋友圈》系列第 4 期。S01–S03 里，范仲淹、欧阳修这批"庆历君子"一路结盟、一路被攻击，也一路攻击别人。到了治平年间，他们第一次从内部分裂：同为名臣的欧阳修、韩琦一边，司马光、王珪、范仲淹之子范纯仁、吕端之孙吕诲另一边，为宋英宗该怎样称呼亲生父亲濮王吵了近两年（从治平元年中书奏请议礼算起），最后台谏集体被贬，君子之间的怨结从此埋下。
- **题型**：系列连载 / 礼法争端 + 宋明对照型
- **系列归属**：《笑谈历史》宋朝系列·课本里的北宋朋友圈（S04，时间段 1063–1067，核心在治平二年至三年）
- **关键人物速查**：宋英宗赵曙（濮王第十三子，仁宗养子）；曹太后（仁宗皇后，垂帘听政）；韩琦（宰相，主皇考）；欧阳修（参知政事，主皇考，被指"首开邪议"）；司马光（天章阁待制，执笔皇伯议）；王珪（翰林学士，领衔皇伯议）；吕诲（侍御史知杂事，吕端之孙）；范纯仁（侍御史，范仲淹之子）；吕大防（监察御史里行）；蒋之奇（濮议附和欧阳修而得御史，后反劾之）。
- **时间锚点**：嘉祐七年（1062）英宗立为皇子 → 嘉祐八年（1063）即位，曹太后垂帘 → 治平二年（1065）四月诏议濮王典礼，六月太后手书切责中书、罢集议，八月京师大水 → 治平三年（1066）正月太后手书许称"亲"，吕诲、范纯仁、吕大防被黜，三月傅尧俞等再黜 → 治平四年（1067）正月英宗崩，三月蒋之奇以"帷薄"事弹劾欧阳修失败，欧阳修出知亳州。

- 钩子用法：听众心里，司马光是七岁砸缸救人的机灵孩子，欧阳修是醉翁亭里的太守。课文没有告诉他们，这两位在治平年间分属两派，一个执笔写下"称皇伯"的议状，一个被台谏弹劾"首开邪议"，弹章要求追究他的罪责。

## 核心认知反差（生死线）
- **你以为的**：
  1. 管皇帝的亲爹叫"爹"还是叫"伯"，是一帮书生的咬文嚼字，跟真实权力无关；
  2. 欧阳修、司马光、范仲淹的儿子都是"君子"，君子之间吵架无非学术分歧；
  3. 明朝嘉靖大礼议才是"认爹之争"的祖师，宋朝的濮议只是小插曲。
- **实际上的**：
  1. 称呼背后是谁说了算：台谏要守住"为人后者为之子"的大宗正统，中书宰执要维护新皇帝的孝道与自己的拥立之功，曹太后的手书则先被用来叫停、后被用来定案。《长编》写到太后手书送达中书时，执政"相視而笑"；
  2. 吵到最后，吕诲上弹章称欧阳修"首开邪议"，说中书与御史"势难两立"；欧阳修当着皇帝说"若以臣等为有罪，即当留御史"。台谏六人先后被贬，司马光请求与他们一同贬黜。欧阳修在自己写的《濮议》里说台谏"本欲以言得罪而买名"；
  3. 四百多年后，明朝礼部尚书毛澄在大礼议中正式援引濮议，引的正是司马光"称王伯而不名"、程颐"皇伯叔父某国大王"之说（《明史·毛澄传》）。宋朝濮议中没能占上风的"皇伯"一派，成了明朝文官手里的标准答案，而嘉靖又一次让这套答案落败。
- **反差的强度自评**：⭐⭐⭐⭐⭐

## 核心问题（这期节目回答的一句话问题）
当最讲道理的一群人为一个称呼吵到势不两立，他们争的究竟是礼，还是谁有资格替皇帝定义"孝"？

## 三大基因自检
- [x] **小切口**：一个字。议状上写"皇伯"还是"皇考"；最后太后手书里落下的是一个"亲"字，皇帝只接受这个字，把"皇""后"推辞掉了。
- [x] **大纵深**：从仁宗无子、英宗被两次抱进宫，到台谏"风闻言事"制度的权力膨胀，再到明朝嘉靖大礼议援引濮议为先例，一条礼法线贯通宋明两代。
- [x] **人性内核**：好人与好人的冲突。每一方都自认在守护正道，于是每一方都把对方当作"奸邪"。君子结党的反噬，从这一期开始在君子内部发作。

## 内容弹药
- **主要素材/案例**（严格区分出处性质）：
  1. 英宗身世：濮王第十三子，四岁被仁宗养于宫中，宝元二年豫王出生后送回；嘉祐七年才正式立为皇子，屡次称疾推辞（正史：《宋史·英宗本纪》）；
  2. 司马光"独奋笔"写皇伯议、王珪据其手稿定案（正史：《宋史·司马光传》《长编》卷二〇五）；
  3. 欧阳修据《仪礼·丧服》立论：服可降，父母之名不可没，"皇伯"之称"历考前世，皆无典据"（正史：《宋史·欧阳修传》；文集：《濮议》）；
  4. 治平二年六月太后手书切责韩琦，诏罢集议（正史：《长编》卷二〇五、《宋史·英宗本纪》）；
  5. 八月京师大水，贾黯、吕诲把水灾归为"濮王一事失中"的天谴，中书札子反驳为"厚诬天人"（正史：《宋史·吕诲传》《长编》卷二〇六、二〇七）；
  6. 吕诲劾韩琦"不忠五罪"，与范纯仁、吕大防劾欧阳修"首开邪议，以枉道说人主"（正史：《宋史·吕诲传》）；
  7. 治平三年正月：执政商议请太后下手书，《长编》记欧阳修亲手拟诏草两通，太后文书送到中书时执政"相视而笑"；英宗辞"皇""后"，只称"亲"，即园立庙（正史：《长编》卷二〇七、《宋史·英宗本纪》）；
  8. 吕诲等缴还告敕、居家待罪；欧阳修"御史以为理难并立，若以臣等为有罪即当留御史"；吕诲知蕲州、范纯仁通判安州、吕大防知休宁县（正史：《长编》卷二〇七、《宋史·吕诲传》）；
  9. 范纯仁说"奈何使命出房闱，异日或为权臣矫托之地"（正史：《宋史·范纯仁传》）；司马光乞留御史不得，"遂请与俱贬"（正史：《宋史·司马光传》）；
  10. 欧阳修《濮议》自述：台谏"本欲以言得罪而买名"，市井传言"待将濮王入太庙，换了仁宗木主"（文集自述，属一方之词）；
  11. 治平四年三月，蒋之奇以"帷薄"丑闻弹劾欧阳修，自称"修首违濮园事犯众怒"；查无实据，蒋之奇、彭思永被贬（正史：《长编》卷二〇九、《宋史·蒋之奇传》《宋史·欧阳修传》）；
  12. 明朝毛澄议大礼时援引濮议、司马光与程颐之说（正史：《明史·毛澄传》）。
- **可用的对照组**：
  - **濮议 vs 嘉靖大礼议（EP08）**：见下方对照表；
  - **S03 的欧阳修 vs S04 的欧阳修**：九年前他用"大水应在武臣"论狄青，九年后台谏用"大水是濮议天谴"攻他；
  - **范仲淹 vs 范纯仁**：景祐、庆历年间欧阳修一再为范仲淹出头（S01、S02），治平年间范仲淹之子弹劾欧阳修。

|---|---|---|
| 皇帝身份 | 英宗生前已被仁宗正式立为皇子，幼年还曾养于宫中 | 世宗从未过继给孝宗或武宗，以"嗣皇帝位非皇子位"入京 |
| 皇帝本人 | 病弱、有曹太后垂帘，主要由韩琦、欧阳修代为发声 | 十五岁亲自下场，绝食、罢朝、以退为进 |
| 两派 | 中书（韩琦、欧阳修）主"皇考" vs 两制台谏（司马光、王珪、吕诲、范纯仁、吕大防）主"皇伯" | 张璁、桂萼等新进主"考兴献王" vs 杨廷和、毛澄、杨慎为首的阁部主"考孝宗" |
| 定案方式 | 太后手书许称"亲"，皇帝辞"皇""后"，折中收场 | 皇帝强推，最终改称兴献王为"皇考"，后又追尊入太庙 |
| 失败者下场 | 台谏贬为地方官，无人下狱、无人受杖 | 左顺门廷杖，死者十六人（据 EP08 史料核对引《明史》） |
| 理论关系 | 司马光、程颐的"皇伯"说 | 被毛澄直接援引为先例 |

- **可交付的概念工具**：
  - **"名分代理战"**：当真正的权力问题（谁拥立了皇帝、台谏能不能压住宰相）无法直说时，人们就会在一个看似无害的名分上决战。称呼越小，越说明大家在借它争别的东西。
- **降维三步法候选点**：
  - "服可降而名不可没"：欧阳修的核心论证 → 意思是丧服可以降等，"父母"这个称呼不能改 → 回扣到他在自己的《濮议》里反复为这一点辩护；
  - "相视而笑"：《长编》一句四个字 → 太后的手书是执政事先商量好的 → 讨论这场"太后定案"有多少是太后本意（欧阳修《濮议》对此另有辩解，须两说并存）。
- **合法跑偏候选**：
  - 宋代台谏"风闻言事"制度（可与 S02 呼应，需另核）；
  - 英宗与曹太后的两宫嫌隙、欧阳修"太后一妇人，臣等五六书生耳"一语（正史：《宋史·欧阳修传》，可作背景）。

## 冷开场方向（只写方向，不写台词）
- **类型**：课本人物错位 + 中书"相视而笑"的名场面。
- **名场面要素**：先立起两个课本形象（砸缸的司马光、醉翁亭里的欧阳修）；随即切到治平三年正月的中书：太后的密封文书由中使送到，几位宰执彼此对望一笑（正史《长编》）；同一时刻，御史吕诲等人已经缴还告敕、闭门待罪，弹章里点名欧阳修"首开邪议"。最后点出：两位课本里的名人，此刻站在对立的两边。
- **节奏**：冷开场约 1 分钟内完成"课本形象 → 对立阵营"的翻转，01:00 左右进入标志性报幕，由小李发问"到底在吵什么"。

## 结尾设计
- **收束回扣点**：治平四年正月英宗去世，距称"亲"定案只有一年；两个月后，蒋之奇以私德丑闻弹劾欧阳修，弹章里明说他"首违濮园事犯众怒"（正史）。争赢了的一方，也没能全身而退。
- **互动设计**：讨论题：如果你是英宗，你会坚持叫亲生父亲"爹"，还是为了朝堂安宁接受"皇伯"？
- **系列衔接**：
  - **上接 S03（欧阳修论狄青）**：开场或第一段可回扣：九年前欧阳修说京城大水是阴气应在武臣，治平二年京城再发大水，贾黯、吕诲说这是濮议招来的天谴，欧阳修这回站到了"被天谴"的一边，并反驳这种推论"厚诬天人"。
  - **呼应 S02（张甥案·醉翁亭记）**：S02 已把治平四年蒋之奇"帷薄"案作为欧阳修的"第二案"完整讲过（含彭思永风闻、神宗追问、榜朝堂辟谣）。本期结尾只用一句话点出蒋之奇弹章里"首违濮园事犯众怒"这层与濮议的因果，不复述案情，并提示听众"这件事前面那一期讲过"，避免两期内容重复。
  - **下启 S05（阿云之狱）**：濮议之后，司马光的下一位论敌是王安石。熙宁元年，一个乡下姑娘阿云的伤人案，让王安石与司马光在神宗面前第一次正面交锋。结尾钩子只点人物与案名，不展开。
