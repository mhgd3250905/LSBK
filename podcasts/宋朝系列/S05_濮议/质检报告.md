- **核验项**：
  - 杜绝“那么接下来发生了什么呢？”“我们继续”“接下来看……”“接着往下聊/看”等主持人报幕串场式口癖：**全篇 0 处违规**。
  - 各幕衔接逻辑审查：
    - **第一幕末尾 → 第二幕开头**：第一幕以“一道看似例行公事的礼仪请示，把整个大宋朝廷直接推到了分裂的悬崖边缘”自然收住；第二幕开头直接由大开陈述“韩琦和欧阳修的奏折递上去之后，朝廷照章办事批转给翰林学士院”，事件无缝咬合，无人工剧本切割感。
    - **第二幕末尾 → 第三幕开头**：第二幕以“朝野上下所有人的目光，全都聚焦到了深宫里那个拥有最高仲裁权力的女人身上”收住；第三幕直接以“两派官员在朝堂上吵得不可开交的时候，后宫垂帘听政的曹太后终于坐不住了”切入，承前启后顺畅。
    - **第三幕末尾 → 第四幕开头**：第三幕以“这场历时一年多的濮议大争论，最终以台谏集团的全军覆没告终”落定；第四幕开头大开直接点出“从表面上看，这场历时一年半的濮议争端，以宰相中书门下的大获全胜画上了句号”，剖析表面胜利背后的残酷代价，水到渠成。

### 4. 证据与史实边界审查
- **英宗身世与立嗣**：按《宋史·英宗本纪》实写濮安懿王第十三子、四岁入宫由曹后抚养、豫王生后送回濮邸、嘉祐七年正式立嗣坚辞称疾，严守真实身世，不脑补心理哭诉。
- **司马光独奋笔**：按《宋史·司马光传》与《长编》卷二〇五实写“学士王珪等相视莫敢先，光独奋笔”，确立“为人后者为之子，不得顾私亲”与“称皇伯”主张。
- **欧阳修中书驳议**：按《长编》卷二〇五引《仪礼·丧服》立论“服可降而名不可没”，举汉宣帝、汉光武帝称皇考先例，严斥皇伯“于典礼未见明据”。
- **曹太后两道手书与大水天谴**：治平二年六月太后首封手书切责韩琦、罢集议；八月京师大水淹死一千五百八十人，吕诲等归咎濮议天谴，中书反驳为厚诬天人；精准回扣 S2E04 欧阳修九年前论狄青“大水为武臣之阴”的历史回旋镖；治平三年正月执政密谋、欧阳修亲草诏书、太后次道手书许称亲、执政“相视而笑”，英宗辞皇与后、独受称亲。
- **台谏被贬与以退为进**：吕诲等缴告敕居家待罪，欧阳修当殿言“若以臣等为有罪即当留御史，若以臣等为无罪则取圣旨”；英宗出御史（吕诲知蕲州、范纯仁通判安州、吕大防知休宁县）；司马光乞留御史不得，请与俱贬未果；宋代文官无受杖、无下狱。
- **蒋之奇反噬与宋明对照**：治平四年正月英宗病逝，三月蒋之奇以私德弹劾欧阳修，直言“修首违濮园事犯众怒”，呼应 S2E02 张甥案丑闻背后的濮议政治动因；欧阳修出知亳州；明代毛澄大礼议抗旨正是引司马光皇伯议（《明史·毛澄传》），宋代外放贬官与明代左顺门廷杖死十六人形成制度对比。
