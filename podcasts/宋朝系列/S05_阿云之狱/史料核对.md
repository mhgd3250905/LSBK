# S05 史料核对与写作边界：《阿云之狱》

> 2026-10-07 底稿。所有文言引文均于当日在线核对，来源 URL 附于文末“检索来源”。性质标注四档：**正史确载**（《宋史》）/ **文集自述**（当事人奏议、文集）/ **宋人笔记**（《涑水记闻》《龙川略志》《邵氏闻见后录》等，作者多有党派立场）/ **后世演绎或存疑**。
>
> **一条总前提**：李焘《续资治通鉴长编》今本缺治平四年四月至熙宁三年三月（神宗朝缺 85 卷），阿云案发与王马廷议恰在缺卷内。本期所谓“《长编》记载”只能落到熙宁三年四月以后的追述条目，或清人黄以周《续资治通鉴长编拾补》（据杨仲良《长编纪事本末》补辑）。本稿未直接检出《拾补》卷三相关原文，标“原文待核”。主干史料以《宋史·刑法志三》《宋史·许遵传》与司马光奏状为准。

| 核心主张 | 史料出处与卷次 | 写作边界 |
|---|---|---|
| **案情：母服中许聘、嫌夫丑陋、持刀砍伤未死、断一指** | **正史确载**：《宋史》卷330《许遵传》：“初，云许嫁未行，嫌婿陋，伺其寢田舍，懷刀斫之，十餘創，不能殺，斷其一指。”《宋史》卷201《刑法志三》：“登州奏有婦阿云，母服中聘於韋，惡韋醜陋，謀殺不死。”<br>**文集自述**：司马光《议谋杀已伤案问欲举而自首状》（《传家集》卷40）：“阿云嫌夫醜陋，親執腰刀，就田野中，因其睡寐，斫近十刀，斷其一指。” | 可讲：母丧未除、许聘、嫌丑、夜里在田舍趁睡砍伤、约十刀、断一指。<br>伤数两说：《宋史》“十餘創”，司马光“斫近十刀”，口播说“十来刀”即可。<br>**婚姻状态有出入**：《宋史·许遵传》作“许嫁未行”；司马光状题注所引许遵奏作“定婚，成亲后嫌韦阿大”。讲成“已经订了婚”最稳，不要说“新婚之夜”。 |
| **受害人名“韦阿大”** | **文集自述**（题注转引）：《传家集》卷40本状题注：“知登州許遵奏：婦人阿云於母服內與韋阿大定婚……”；《历代名臣奏议》卷211同。《宋史》只作“韋”。 | 可用“韦阿大”，说明出自许遵原奏。网文“韦大”“韦大宝”无据，**不用**。 |
| **审讯细节：县尉一句“实道来不打你”，阿云即招** | **文集自述**（题注转引许遵奏）：“縣尉令弓手勾到阿云，問：是你斫傷本夫？實道來不打你。阿云遂具實招通。”<br>**正史确载**：《宋史·许遵传》：“吏求盜弗得，疑云所為，執而詰之，欲加訊掠，乃吐實。”<br>**文集自述**：司马光状：“初不陳首，直至官司執錄，將行栲棰，勢不獲已，方肯招承。” | **本期最该抓的名场面**。同一刻有两种描述：许遵一方强调“问即承”，司马光一方强调“将行栲棰才招”。两种说法都要交代，争点就在这里，节目不替任何一方定论。 |
| **审刑院、大理寺论死；以“违律为婚”奏裁，敕贷其死** | **正史确载**：刑法志：“審刑院、大理寺論死，用違律為婚奏裁，敕貸其死。”<br>**文集自述**：司马光状：“朝廷貸命編管，已是寬恩。” | **关键事实**：阿云在王马争论之前已被免死，处置为“贷命编管”。后面的争论是在定规则。节目里不能说“王安石救了阿云一命”。 |
| **许遵援律注主张减二等；刑部维持大理** | **正史确载**：刑法志：“知登州許遵奏，引律‘因犯殺傷而自首，得免所因之罪，仍從故殺傷法’，以謀為所因，當用按問欲舉條減二等。刑部定如審刑、大理。”<br>《许遵传》：“遵駁言：‘云被問即承，應為按問。審刑、大理當絞刑，非是。’事下刑部，以遵為妄，詔以贖論。” | 可讲。“诏以赎论”指谁，学界有两读：一读为许遵“议法”失当、以赎铜论处，一读为对阿云的处置。**存疑**，口播回避，只说“刑部认为许遵错了”。 |
| **许遵动机：“欲立奇以自鬻”** | **正史确载（史臣贬语）**：《许遵传》：“執政許以判大理，遵欲立奇以自鬻。會婦人阿云獄起。” | 只能作为《宋史》编者的评价转述，并说明《宋史》对新党一方普遍不友好。不得说成许遵本人承认。 |
| **神宗命司马光、王安石同议，二人各奏，诏从安石** | **正史确载**：刑法志：“乃令翰林學士司馬光、王安石同議，二人議不同，遂各為奏。光議是刑部，安石議是遵，詔從安石所議。”<br>《宋史》卷327《王安石传》：“登州婦人惡其夫寢陋，夜以刃斮之，傷而不死。獄上，朝議皆當之死，安石獨援律辨證之，為合從謀殺傷，減二等論。帝從安石說，且著為令。” | 熙宁元年这一轮是**各自上奏**，史料不支持两人当面对吵。“廷辩”画面属于熙宁二年二月以后王安石与唐介等“数争议帝前”。口播可说“书面交锋”“打笔仗”。 |
| **司马光奏状的核心论证** | **文集自述**：《传家集》卷40：“其處心積慮，巧詐百端，掩人不備者，則謂之謀；直情徑行，略無顧慮，公然殺害者，則謂之故。謀者尤重，故者差輕。”“其直犯殺傷更無他罪者，惟未傷則可首，但係已傷，皆不可首也。”“以此知‘謀’字止因‘殺’字生文，不得別為所因之罪也。”甲乙之比：“甲因鬥毆人，鼻中血出，既而自首，猶科杖六十罪；乙有怨讎，欲致其人於死地，暮夜伺便推落河井（梦远书城本作“推落河，並”，断句待核），偶得不死，又不見血，若來自首，止科杖七十罪。二人所犯絕殊，而得罪相埒。”结论：“開巧偽之路，長賊殺之原。” | 均可转述，给司马光完整的法理分量。甲乙之比适合做降维例子。 |
| **王安石一方论证** | **正史确载（转述）**：刑法志熙宁二年王安石奏：“律意，因犯殺傷而自首，得免所因之罪，仍從故殺傷法；若已殺，從故殺法，則為首者必死，不須奏裁。”<br>《宋史纪事本末》卷37概括司马光反驳语：“豈可以謀與殺分為兩事，而謂謀為所因，得以首原乎？” | 王安石熙宁元年的原奏全文**原文待核**（《临川先生文集》中是否存原奏，本次未检出）。节目只能用刑法志的转述。 |
| **熙宁元年诏书“谋杀已伤，按问欲举，自首，从谋杀减二等论”** | **正史确载**：刑法志。月份异文：维基文库本《宋史》卷201作“熙寧元年七月”；识典古籍、语文迷等转录本作“八月”，识典古籍本且作“減三等”。《宋朝法律史论》第13章《论熙宁初年刑名之争》（zi5.net 转载，作者待核）作“七月癸酉”，吴钩文作“七月三日”。 | 口播说“熙宁元年夏秋之间”或“七月”，减等说“减二等”（与许遵奏、王安石传一致）。“减三等”系转录异文，不用。 |
| **反复议驳：滕甫、钱顗反对，吕公著等重议从安石，齐恢、王师元、蔡冠卿再驳** | **正史确载**：刑法志：“御史中丞滕甫猶請再選官定議，御史錢顗請罷遵大理，詔送翰林學士呂公著、韓維、知制誥錢公輔重定。公著等議如安石……於是法官齊恢、王師元、蔡冠卿等皆論奏公著等所議為不當。又詔安石與法官集議，反覆論難。” | 可讲，用来表现“一年吵不完”。 |
| **熙宁二年二月：定制、王安石参知政事、与唐介等争于帝前** | **正史确载**：刑法志：“明年二月庚子，詔：‘今後謀殺人自首，並奏聽敕裁。’是月，除安石參知政事……與唐介等數爭議帝前，卒從安石議。復詔：‘自今並以去年七月詔書從事。’”<br>《宋史》卷316《唐介传》：“介自是數與安石爭論。安石強辯，而帝主其說。介不勝憤，疽發於背，薨，年六十。” | 唐介传里与王安石的争论直接指向中书札子问题，未点名阿云案。可说“唐介屡与王安石争于帝前，不久背疽发作去世”，**不可说唐介因阿云案被气死**。 |
| **再交两府合议：文彦博、吕公弼反对，陈升之、韩绛附安石，富弼称病不议** | **正史确载**：刑法志：“文彥博以為：‘殺傷者，欲殺而傷也，即已殺者不可首。’……陳升之、韓絳議與安石略同。會富弼入相，帝令弼議，而以疾病，久之弗議。” | 可讲。富弼“久之弗议”是很好的细节，不要加心理解读。 |
| **站队清算：刘述、刘琦、钱顗被贬；司马光疏救不报** | **正史确载**：《宋史》卷321《刘述传》：“述兼判刑部，安石爭謀殺刑名，述不以為是。及敕下，述封還中書，奏執不已。”刘述等疏：“去年因許遵文過飾非，妄議自首按問之法，安石任一偏之見，改立新議，以害天下大公。”司马光疏：“彼謀殺已傷自首刑名，天下皆知其非。朝廷既違眾議而行之，又以守官之臣而罪之，臣恐失天下之心也。”“不報。”<br>同卷《钱顗传》：离台时斥孙昌龄“我視君犬彘之不如也”。 | **本期“站队压倒事实”的核心证据**。刘述等疏把阿云案与条例司、八使、章辟光事一并打包攻击王安石，法律争点和人事、新法彻底混在一起，正好说明“绑架”的过程。 |
| **郑獬不用“按问新法”被外放** | **正史确载**：《宋史》卷321《郑獬传》：“民喻興與妻謀殺一婦人，獬不肯用按問新法，為王安石所惡，出為侍讀學士、知杭州。” | 可讲，作为“地方执法者被迫站队”的例子。 |
| **新法扩张：“虽累问不承者，亦得为按问”** | **正史确载**：《许遵传》：“安石既執政，悉罪異己者，遂從遵議。雖累問不承者，亦得為按問。或兩人同為盜劫，吏先問左，則按問在左；先問右，則按問在右。獄之生死，在問之先後，而非盜之情，天下益厭其說。”<br>**宋人笔记**：苏辙《龙川略志》“许遵议法虽妄而能活人以得福”条（卷次待核），文字几同，系《宋史》此段来源。 | 可讲，但标明《宋史》此段袭自苏辙（旧党）笔记，带有立场。“悉罪异己者”是评价语。 |
| **元丰年间“按问”被反向利用：相州狱** | **宋人笔记**：司马光《涑水记闻》（通行本编号406条，卷次待核）：堂后官周清援“新法：凡殺人，雖已死，其為從者被執，雖經拷掠，苟能先引服，皆從按問欲舉律減四等”驳相州旧案为“失入死罪”；蔡确兴狱，“收大理寺詳斷官竇平、周孝恭等，枷縛暴於日中，凡五十七日”。<br>**正史确载**：刑法志元丰三年周清又以“按问自首”议妻谋杀夫案。 | 可作为“新法被新党自己人拿来整人”的故事，但必须说明是司马光的私人记录，立场鲜明；“减四等”一语以原文为准，不扩写。蔡确、周清细节如需进一步展开，**原文待核**（《长编》元丰元年相关条可补核）。 |
| **元丰八年司马光为相改法；元祐元年范纯仁的死刑数据** | **正史确载**：刑法志：“初，王安石與司馬光爭議按問自首法，卒從安石議。至是，光為相，復申前議改焉。乃詔：‘強盜按問欲舉自首者，不用減等。’”范纯仁：“前歲四方奏讞，大辟凡二百六十四，死者止二十五人，所活垂及九分。自去年改法，至今未及百日，所奏按凡一百五十四，死者乃五十七人，所活纔及六分已上。” | 数据可直接讲，是全期最硬的结尾材料。注意：元丰八年诏限于“强盗”按问；范纯仁随后又请取嘉祐编敕折中，朝廷“从之”。不要说成司马光一刀切全面废除。 |
| **苏辙评语与许遵子孙** | **宋人笔记**：《龙川略志》：“予曰：‘雖然遵議則非，而要能活人；吾議則是，而要能殺人。予意亦難改之。’”“後十餘年，謫居筠州。筠守許長卿，遵之子也。言其兄弟及諸子仕宦者十餘人……予復嘆曰：‘遵之議妄甚矣，而子孫仕者若是其多也。一能活人，天理固不遺之也哉！’” | 可作结尾。苏辙是旧党、苏轼之弟，由他说出这番话分量更重；同时说明这是他的个人感慨。 |
| **绍圣以后复行荆公之法** | **宋人笔记**：邵博《邵氏闻见后录》：“至紹聖以來，復行荊公之法，而殺人者始不死矣。”同条称“王荊公不知法，好議法，又好與人為異”。 | 只作旧党视角的转述。“杀人者始不死”是夸张的党派语言，不可当统计事实。 |
| **乾隆御批：阿云“必死无疑”式评语** | **后世评论**：《御批历代通鉴辑览》乾隆三十三年御批（吴钩文转引）：“婦謀殺夫，悖惡極矣……安石偏執妄行，不復知有明罰。” | 可作为“后世如何站队评价”的跑偏素材，标明是清帝的立场，原文**待核**（仅见二手转引）。 |
| **阿云最终结局** | 史料无载。司马光状只说“贷命编管”。 | **证据禁区**，见下。 |

## 证据禁区（以下内容不得进入正文，或只能作为“网传说法”被辟谣）
1. **“司马光拜相后翻案，将阿云斩首/以大逆处死”**：宋人史料无此记载。吴钩《再说一遍：司马光没有杀那女孩》（儒家网，2017）已辨。阿云已经敕贷死罪，元丰八年改的是今后的法条，宋代亦有“凡用旧条已断过，不得引新条追改”之制（吴钩文转引，原文待核）。节目如提及只能作辟谣。
2. **阿云年龄（“十三岁”）、“叔父贪财逼婚”“韦大宝”“老光棍”“菜刀”“遇大赦释放”**：均为网文演绎，无任何宋代出处。
3. **“王安石与司马光当庭对骂”**：熙宁元年是各自上奏；帝前争议的是熙宁二年王安石与唐介等。
4. **“唐介因阿云案气死”**：唐介传没有把背疽与阿云案连在一起。
5. **把刑法志“减三等”异文当真**：以“减二等”为准。
6. **对阿云内心、韦阿大相貌的任何细节描写**：史料只有“丑陋/寝陋/陋”。
7. **把《宋史·许遵传》“欲立奇以自鬻”“悉罪异己者”当客观事实**：这是史臣评语，需带上出处立场。

## 给写稿者的说明
- **最该抓的名场面**：①县尉“实道来不打你”与“欲加讯掠，乃吐实”的两种记法，一句话决定了是不是“按问”；②司马光的甲乙之比（鼻血杖六十 vs 推人落河杖七十）；③范纯仁的两组死刑数字；④钱顗离台骂人、刘述封还诏书；⑤苏辙在筠州见到许遵之子。
- **名人的哪一面**：
  - 王安石：在这件事上他主宽，手段上却极强硬，“独援律辨证”、借执政之势定案、贬斥异议者。两面都要给。
  - 司马光：讲法理很扎实，人道上也不残忍（他承认贷死是宽恩），他怕的是规则被滥用。后来亲手改法，又被同党范纯仁用数据顶回来。
  - 许遵：真正的发起人，《宋史》把他写成投机者，苏辙却承认他“能活人”，两说并存。
- **易踩的坑**：
  1. 说“王安石救了阿云的命”——错，阿云在争论前已敕贷死。
  2. 说“司马光要杀阿云”——不准确，他支持的是“谋杀已伤”的定罪原则，并认可贷死。
  3. 引用“《长编》熙宁元年条”——今本缺卷，不存在。
  4. 把相州狱、《龙川略志》等旧党笔记当中立记录。
  5. 法律概念讲太细会劝退听众：建议只抓“问一句就招算不算自首”“谋能不能和杀拆开”两个点。
  6. 法条对比最容易写出机械对仗的否定句式，台词按《AI书写规范》第三节“表层五禁”处理，改用连续陈述。
