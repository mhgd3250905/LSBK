# 选题卡：阿云之狱：一个村姑砍了未婚夫一刀，王安石和司马光为她吵了十八年

> 状态：选题材料（2026-10-07 起草），待用户审批后方可进入大纲。本卡只给方向与证据，不含任何台词。史料细节与原文见同目录 `史料核对.md`。

## 基本信息
- **选题缘由**：“课本里的北宋朋友圈”系列按时间推进到熙宁元年（1068）。神宗刚即位、王安石刚入京，新法一条还没推，两位翰林学士已经先在一桩登州乡下的伤人案上正面交锋。这是王、马二人第一次在制度层面公开对撞，也是北宋党争从“君子论政”滑向“站队定是非”的第一块骨牌。
- **题型**：系列连载 / 案件复盘型（法律争议 × 党争）
- **系列归属**：《笑谈历史》宋朝系列“课本里的北宋朋友圈”第 05 期（熙宁篇·开局）
- **时间跨度**：熙宁元年（1068）案发上奏 → 熙宁二年二月定制 → 元丰年间“按问”新法被反向利用 → 元丰八年至元祐元年（1085—1086）司马光执政改法 → 绍圣以后复行

## 核心认知反差（生死线）
- **你以为的**：
  1. 王安石和司马光的对立从熙宁变法、青苗法开始，吵的是经济政策；
  2. 砸缸救人的司马光宽厚仁慈，搞激进改革的王安石手段强硬；
  3. 一桩乡下伤人案，按法条判就完了，用不着皇帝和翰林学士出面。
- **实际上的**：
  1. 两人第一次公开对撞在一桩刑案上，争的是一个法律技术问题：谋杀已经伤人，被盘问时立刻招认，算不算“按问欲举”的自首，能不能减二等。
  2. 在这件事上主张从轻的是王安石，主张维持绞刑的是司马光。司马光的理由也很硬：怕“谋杀伤人还能自首减刑”变成通行规则，“开巧伪之路，长贼杀之原”。
  3. 案子本身早就有了结果：审刑院、大理寺判死后，朝廷已经因婚约违律“敕贷其死”。阿云的命在王马开吵之前就保住了，此后十八年反复争的，是要不要把这次处理变成全国通行的法条。
  4. 站队很快压过了法理：反对新解释的郑獬被外放，判刑部刘述等人因封还诏书被贬，御史钱顗临走当众骂同僚“犬彘之不如”。法律问题成了政治表态。
- **反差的强度自评**：⭐⭐⭐⭐（“司马光主杀、王安石主活”本身就很反直觉；扣一星是因为法理细节需要讲清，门槛偏高）

## 核心问题（这期节目回答的一句话问题）
一桩证据确凿、当事人早被免死的乡下伤人案，为什么能让北宋最聪明的两个人吵上一年、让朝廷反复改法十八年？一个法律问题在什么时候、以什么方式，变成了“你站哪边”？

## 三大基因自检
- [x] **小切口**：登州田舍里一把腰刀、十来道伤、一根断掉的手指；县尉一句“实道来不打你”，阿云当场招了。这一句问话的性质，后来成了全案的法理焦点（司马光奏状题注所引许遵奏）。
- [x] **大纵深**：从《宋刑统》“于人损伤不在自首之例”的律注，到神宗“敕”能否改“律”的权力问题；从熙宁二年二月王安石参知政事后与唐介等“数争议帝前”，到元丰年间新法被周清、蔡确拿来翻旧案，再到元祐元年范纯仁拿出的死刑数据。
- [x] **人性内核**：两个都自认为在守护公义的人，各自都有道理；真正让事情变味的，是围在他们身边的人开始按阵营投票。苏辙后来一句“遵议则非，而要能活人；吾议则是，而要能杀人”，把这种两难说透了。

2. （悬念疑问型）《一个村姑砍了未婚夫一刀，为什么让王安石和司马光吵了十八年？》

> 主选理由：两个课本人设直接对撞，信息全在标题里；“砸缸”是全民记忆点。注意主选标题里“要判她绞刑”的说法要配合正文交代：司马光支持的是刑部、大理寺“谋杀已伤”的定罪，同时承认朝廷贷死“已是宽恩”，他反对的是把减等变成通例。若担心误导，备选 2 最稳。

## 内容弹药
- **主要素材/案例**（严格区分出处性质）：
  1. 案情：阿云母服未除时许聘韦姓男子（司马光状题注引许遵奏作“韦阿大”），嫌其丑陋，趁其在田舍睡觉持刀砍十余刀，未死，断一指；官府捕盗不得，疑到阿云，“欲加讯掠，乃吐实”（**正史**：《宋史·许遵传》卷330、《宋史·刑法志三》卷201；**文集**：司马光《议谋杀已伤案问欲举而自首状》，《传家集》卷40）。
  2. 审判链：审刑院、大理寺论死（绞），因“违律为婚”奏裁，敕贷其死；知登州许遵援律注“因犯杀伤而自首，得免所因之罪，仍从故杀伤法”，主张以“谋”为所因，按“按问欲举”减二等；刑部支持大理寺（**正史**：刑法志）。
  3. 许遵的动机：《宋史·许遵传》称执政已许他判大理寺，“遵欲立奇以自鬻”（**正史，但属史臣贬语**，《宋史》对新党人物多有成见，讲时要带上这一层）。
  4. 王、马分别上奏：司马光议从刑部，王安石议从许遵，诏从安石；随后滕甫、钱顗反对，吕公著、韩维、钱公辅重议仍从安石，法官齐恢、王师元、蔡冠卿等又驳（**正史**：刑法志）。
  5. 司马光奏状的两个具体论证：甲斗殴致人鼻血、自首仍杖六十，乙蓄意推人落河未死、若许自首只杖七十，“二人所犯绝殊，而得罪相埒”；以及“阿云……斫近十刀，断其一指……朝廷贷命编管，已是宽恩”（**文集**：《传家集》卷40）。
  6. 熙宁元年七月诏“谋杀已伤，按问欲举，自首，从谋杀减二等论”；熙宁二年二月庚子诏“今后谋杀人自首，并奏听敕裁”；同月王安石参知政事，与唐介等“数争议帝前，卒从安石议”（**正史**：刑法志。注意诏书月份各本有“七月/八月”之异，见史料核对）。
  7. 站队与清洗：判刑部刘述封还诏书，与刘琦、钱顗上疏攻王安石，被贬；钱顗离台时当众骂孙昌龄；郑獬知开封府时“不肯用按问新法”，被外放（**正史**：《宋史》卷321刘述、钱顗、郑獬传）。司马光上疏为刘琦、钱顗说情，称“谋杀已伤自首刑名，天下皆知其非”，不报（**正史**：卷321）。
  8. 新法的反噬：元丰初相州劫盗案，堂后官周清援引“按问”新法翻旧案，蔡确借机兴狱，大理寺官员窦平等被枷暴五十七日（**笔记**：司马光《涑水记闻》（梦远书城/太玄书阁通行本编号第406条，卷次待核），作者为旧党当事人，立场明确）；苏辙在齐州看到“二人同劫，先问其左，则按问在左；先问其右，则按问在右”（**笔记**：苏辙《龙川略志》；《宋史·许遵传》几乎照录）。
  9. 元祐改法与数据：元丰八年司马光为相，诏“强盗按问欲举自首者，不用减等”；范纯仁随即上言改法前一年奏谳大辟 264 人、死 25 人，改法后不到百日奏 154 人、死 57 人（**正史**：刑法志）。
  10. 绍圣以后“复行荆公之法”（**笔记**：邵博《邵氏闻见后录》，立场偏旧党）。
- **可用的对照组**：
  - 熙宁元年的司马光（守律，主张维持“谋杀已伤”的绞罪定性）vs 元祐元年的范纯仁（同为旧党，拿死刑数据反对司马光收紧过头）；
  - 主张从轻的王安石 vs 后来借他的新法翻案兴狱的蔡确——同一条法，不同的人拿去做不同的事；
  - 苏辙：旧党，判定许遵“妄”，却承认他“能活人”，晚年在筠州见许遵子孙满堂，感叹天理不遗。
- **可交付的概念工具**：
  - **“法条站队化”**：当一个技术性法律问题被贴上阵营标签，人们表态的依据就从“条文怎么读”变成“谁提的”。阿云案里，赞成或反对按问减等，很快和赞成或反对王安石绑在一起。
- **降维三步法候选点**（留在创作笔记，不进台词）：
  - “按问欲举”：被抓后一问就招，算不算自首。类比现代“如实供述”与“自首”的区别，帮听众抓住争点，但须提醒宋律与现代刑法体系不同，只作理解桥梁。
  - “因犯杀伤而自首，得免所因之罪”：盗窃中失手伤人，自首可免盗罪、伤人罪照算。许遵把“谋”当成“所因之罪”，司马光说“谋”字是跟着“杀”字生出来的，拆不开。
- **合法跑偏候选**：
  - 跑偏 1：宋代“奏谳”制度——疑案逐级上报，大理寺、审刑院、刑部三道关；为什么一桩地方案能直达御前。
  - 跑偏 2：苏辙《龙川略志》里许遵子孙“仕者十余人”的后记——旧党文人自己写下的“善报”故事。

## 结尾设计 与 系列衔接
- **收束回扣点**：苏辙在筠州遇到许遵之子许长卿，听说许家子孙做官的有十几人，感叹“一能活人，天理固不遗之”（《龙川略志》）。阿云本人此后下落史无记载，节目据实说“不知道”，不替她编结局。
- **互动设计**：如果你是熙宁元年的翰林学士，按法条你会站司马光；按良心你会站王安石。那你投哪一票？
- **上一期怎么接（S04 濮议）**：S04 结尾已用一句话点出“濮议之后，司马光的下一位论敌是王安石”，并预告阿云案。S05 开头可顺势回扣：治平年间司马光和欧阳修为一个称呼吵到台谏集体被贬；两年后神宗即位，他在一桩乡下伤人案上撞上了王安石。濮议里的“台谏集体表态—被贬”模式，在阿云案里又演了一遍（刘述、刘琦、钱顗），这是两期之间最硬的结构呼应。
- **下一期怎么接（S06 乌台诗案）**：本期末尾点出两个伏笔，都有正史支撑：一是钱顗、刘述等因言获罪的先例，御史台已经成为站队工具；二是司马光在熙宁年间与新法决裂、退居洛阳，元丰二年他的名字出现在乌台诗案的罚铜名单上（《长编》卷301）。挖坑句方向：下一次轮到苏轼，罪名是写诗。
