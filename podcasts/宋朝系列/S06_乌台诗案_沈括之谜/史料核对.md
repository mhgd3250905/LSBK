## 一、乌台诗案主线

| 核心主张 | 史料出处与卷次 | 写作边界 |
|---|---|---|
| **弹劾者与罪名** | **正史确载**：《宋史》卷338《苏轼传》：“徙知湖州，上表以謝。又以事不便民者不敢言，以詩託諷，庶有補於國。御史李定、舒亶、何正臣摭其表語，並媒蘖所為詩以為訕謗，逮赴臺獄，欲置之死，鍛煉久之不決。神宗獨憐之，以黃州團練副使安置。”<br>《宋史》卷329《何正臣传》：“遂與李定、舒亶論蘇軾，得五品服。”同卷“论曰”：“何正臣之論蘇軾，皆小人之盜名。” | 可讲。《宋史》立场明显偏苏轼，“小人”是史臣评语。另一弹劾者国子博士李宜之见于《东坡乌台诗案》辑本（二手转引），《宋史》本传未列。 |
| **导火索：《湖州谢上表》** | **文集自述**：苏轼《湖州谢上表》：“知其愚不適時，難以追陪新進；察其老不生事，或能牧養小民。”（一本“牧養”作“收養”） | 可原句转述。“新进”“生事”在熙宁语境里是攻击新党的常用语，这是御史抓住它的原因，可讲清背景。 |
| **罪证是刊印诗集** | **二手转引**：《东坡乌台诗案》辑本舒亶札子“小則鏤板，大則刻石，傳播中外，自以為能”“印行四冊，謹具進呈”；御史台检会册子题名《元丰续添苏子瞻学士钱塘集》（据刘汉鼎《沈括到底有没有给苏轼“告黑状”？》转引，原文待核）。<br>《长编》卷299 舒亶弹章“并上轼印行诗三卷”（据同文转引，原文待核）。 | 可讲“刻印诗集成了证据”，标明据辑本。“盗版”说法无据，不用。 |
| **舒亶要求株连二十余人** | **正史确载**：《宋史》卷329《舒亶传》：“若司馬光、張方平、范鎮、陳襄、劉摯，皆略能誦説先王之言，而所懷如此，可置而不誅乎？帝覺其言為過，但貶軾、詵，而光等罰金。”<br>《长编》卷301正文：“收受軾譏諷朝政文字人，除王詵、王鞏、李清臣外，張方平而下凡二十二人……顧可置而不誅乎？” | 可讲。“可置而不诛乎”可第三人称转述为舒亶问皇帝这些人难道能放着不杀。 |
| **李定：亲审苏轼，私下称“奇才”** | **正史确载**：《宋史》卷329《李定传》：“方定自鞫軾獄，勢不可回。一日，於崇政殿門外語同列曰：‘蘇軾乃奇才也。’俱不敢對。” | 可讲，人物复杂性的好材料。不得揣测李定心理。 |
| **逮捕现场（湖州）** | **宋人笔记**：孔平仲《孔氏谈苑》卷一（维基文库本核对）：皇甫僎“攜一子二臺卒倍道疾馳”；王诜“密遣人報蘇轍”，苏辙遣人先到；“僎徑入州廨，具靴袍秉笏立庭下，二臺卒夾侍，白衣青巾，顧盼佇惡（ctext 本作‘儜惡’）”；苏轼“自以為得罪，不可以朝服”，祖无颇说“未知罪名，當以朝服見也”；“二卒懷臺牒拄其衣，若匕首然”；苏轼说“今日必是賜死，死固不辭，乞歸與家人訣別”，皇甫僎“始肯言曰：不至如此”；开视台牒“只是尋常追攝行遣耳”；“僎促軾行，二獄卒就執之，即時出城登舟，郡人送之雨泣，頃刻之間，拉一太守如驅犬雞。”<br>**文集自述**：《杭州召还乞郡状》：“定等選差悍吏皇遵，將帶吏卒，就湖州追攝，如捕寇賊。” | 冷开场可用，须说明出自孔平仲（与苏轼同时代、属旧党圈子）的记载，并非案卷。“如驱犬鸡”已核实在《孔氏谈苑》卷一。逮捕官员名“皇甫遵/僎”两写并存，苏轼本人写作“皇遵”。 |
| **押解途中欲投江、入狱欲绝食；先帝遣使约敕** | **文集自述**：《杭州召还乞郡状》（元祐六年五月）：“過揚子江，便欲自投江中，而吏卒監守不果。到獄，即欲不食求死。而先帝遣使就獄，有所約敕，故獄吏不敢別加非橫。臣亦覺知先帝無意殺臣。” | 可讲，苏轼本人事后追述（写于十二年后，有为自己和神宗定调的意图，可提一句）。注意与诀别诗题“狱吏稍见侵”存在张力，两条都讲更真实。 |
| **苏轼对加害者的定性** | **文集自述**：同状：“黨人疑臣復用，而李定、何正臣、舒亶三人，構造飛語，醞釀百端，必欲致臣於死。先帝初亦不聽，而此三人執奏不已，故臣得罪下獄。” | **重要**：苏轼本人只点名三御史，没有提沈括。这是沈括辨析中的反方证据之一。 |
| **狱中受辱：“诟辱通宵不忍闻”** | **文集**：苏颂诗“卻憐比戶吳興守，詬辱通宵不忍聞”（刘汉鼎文转引，原诗题与卷次待核）。 | 可讲，标明苏颂当时因另案关在隔壁。原文待核。 |
| **下狱即问“五代有无誓书铁券”** | 网文多引，出处未检出。 | **原文待核**，暂不用。 |
| **诀别诗及诗题** | **文集自述**：苏轼诗题：“予以事繫御史臺獄，獄吏稍見侵，自度不能堪，死獄中，不得一別子由，故作二詩授獄卒梁成，以遺子由。”诗句：“是處青山可埋骨，他年夜雨獨傷神。與君世世為兄弟，更結來生未了因。”“夢繞雲山心似鹿，魂驚湯火命如雞。”（各本字句小异：“世世/今世”“魂驚/魂飛”“他年/他時”） | 诗与诗题是苏轼本人文字，**可讲、可整句转述**。写诗缘由以诗题为准：狱吏欺压、自料必死。 |
| **“送鱼”暗号** | **宋人笔记**：叶梦得《避暑录话》：“蘇子瞻元豐間赴詔獄，與其長子邁俱行。與之期，送食惟菜與肉，有不測，則徹二物而送以魚……逾月，忽糧盡，出謀於陳留，委其一親戚代送，而忘語其約。親戚偶得魚送之……子瞻大駭，知不免……乃作二詩寄子由，祝獄吏致之，蓋意獄吏不敢隱，則必以聞。已而果然，神宗初固無殺意，見詩益動心。” | **能讲，必须标“据叶梦得记载”**。叶梦得（1077—1148）案发时两岁，属事后传闻。与诗题自述的缘由（“狱吏稍见侵”）不同，可与《孔氏谈苑》版并列（见下条），让小李追问。“红烧鲤鱼”“熏鱼”“铁杆粉丝亲戚”等均为网文添油，不用。“神宗见诗动心”也只是叶梦得的推断。 |
| **另一种狱中叙事：藏青金丹、狱卒濯足、诗藏枕中** | **宋人笔记**：孔平仲《孔氏谈苑》卷一（维基文库本核对）：“李定、舒亶、何正臣雜治之，侵之甚急，欲加以指斥之罪，子瞻憂在必死，嘗服青金丹，即收其餘，窖之土中，以備一旦當死，則並服以自殺。有一獄卒，仁而有禮，事子瞻甚謹，每夕必然湯為子瞻濯足。”苏轼托诗，“獄卒受其詩，藏之枕中”；“其後子瞻謫黃州，獄卒曰：還學士此詩。子由以面伏案，不忍讀也。” | **与《避暑录话》冲突**：孔平仲版里诗交给狱卒、藏在枕中，苏轼出狱后才转到苏辙手里，没有“送鱼”，也没有“神宗见诗”。孔平仲与苏轼同时代，年代早于叶梦得。苏轼诗题“授狱卒梁成，以遗子由”与孔平仲版更贴合。**节目可把两种版本并列，这本身就是一段好的史料辨析。** |
| **营救一：太皇太后曹氏** | **正史确载**：《宋史》卷242《慈圣光献曹皇后传》：“蘇軾以詩得罪，下御史獄，人以為必死。后違豫中聞之，謂帝曰：‘嘗憶仁宗以制科得軾兄弟，喜曰：吾為子孫得兩宰相。今聞軾以作詩繫獄，得非仇人中傷之乎？捃至於詩，其過微矣。吾疾勢已篤，不可以冤濫致傷中和，宜熟察之。’帝涕泣，軾由此得免。” | 可讲。曹氏于元丰二年十月去世（《长编》卷300 有其山陵使任命），她的谏言发生在苏轼入狱后、她病重期间。“由此得免”是《宋史》的归因，可如实转述。 |
| **营救二：王安礼；李定的警告** | **正史确载**：《宋史》卷327《王安礼传》：“蘇軾下御史獄，勢危甚，無敢救者。安禮從容言：‘自古大度之主，不以言語罪人。’……帝曰：‘朕固不深譴也，行為卿貰之。卿第去，勿漏言，軾方賈怨於眾，恐言者緣以害卿也。’李定、張璪皆擿使勿救。”<br>《长编》卷301正文：李定对王安礼说“軾與金陵丞相論事不合，公幸毋營解，人將以為黨”；张璪“忿然作色曰：公果救蘇軾耶？何為詔趣其獄？” | **本期站队主题的最佳证据**：李定用“人将以为党”来劝阻营救，等于明说案件的性质。可讲。 |
| **营救三：张方平、范镇上书** | **正史级编年**：《长编》卷301正文：“軾初下獄，方平及鎮皆上書救之，不報。”张方平书引祁奚救叔向、韩愈谏佛骨。李焘注引刘安世《元城语录》称张方平疏“亦不果投”（文脉国学转录注文，待核）。 | 可讲“上书不报”；张疏是否真正递上，有异说，口播带一句即可。 |
| **王安石“岂有圣世而杀才士者乎”** | **宋人笔记**：周紫芝《读诗谳》（《太仓稊米集》卷49），据维基百科“乌台诗案”条转引：“大丞相王文公曰：‘豈有聖世而殺才士者乎？’當時議，以公一言而決。” | **存疑**：周紫芝为南宋人，王安石时已退居金陵，“一言而决”说法夸大。只能作为“另有一种说法”。 |
| **王珪“蛰龙”构陷** | **后出编年/笔记**：《宋史全文》元丰七年条：“宰臣王珪言蘇軾有不臣意，因舉軾《檜》詩‘根到九泉無曲處，世間唯有蟄龍知’之句……上曰：‘彼自詠檜，何預朕事？’” 源出叶梦得《石林诗话》等笔记（原文待核）。 | 可讲但须标“据宋人笔记，后被元人编年采入”。章惇当场反驳王珪的版本出自王巩笔记，**原文待核**，暂不用。 |
| **判决：“会赦当原”与“特责”** | **正史级编年**：《长编》卷301 元丰二年十二月庚申：“祠部員外郎、直史館蘇軾責授檢校水部員外郎、黃州團練副使，本州安置，不得簽書公事，令御史臺差人轉押前去。”“初，御史臺既以軾具獄上法寺，當徒二年，會赦當原。於是中丞李定言……伏乞特行廢絕……疏奏，軾等皆特責。”罚铜名单：张方平、李清臣三十斤；司马光、范镇、钱藻、陈襄、刘攽、李常、孙觉、曾巩、王汾、刘挚、黄庭坚、王安上等各二十斤。王诜追两官勒停，苏辙监筠州盐酒税，王巩监宾州盐酒税。 | **核心事实**，必须讲：按法本可免罪，“特责”是法外加罚。罚铜名单里有司马光、曾巩、黄庭坚，还有王安石的弟弟王安上。入狱时长：八月十八日入台狱至十二月庚申（二十八日），约一百三十天；也有“百余日”“一百零三天”等说法，口播说“四个多月”。 |
| **出狱诗** | **文集自述**：苏轼《十二月二十八日蒙恩責授檢校水部員外郎黃州團練副使復用前韻二首》：“百日歸期恰及春”“平生文字為吾累，此去聲名不厭低。” | 可讲，“平生文字为吾累”适合收束。 |
| **黄州作品与“不得签书公事”** | **文集**：《记承天寺夜游》首句“元豐六年十月十二日夜”；《念奴娇·赤壁怀古》《赤壁赋》（元丰五年）。<br>**正史确载**：元丰七年手札：“蘇軾黜居思咎，閱歲滋深，人材實難，不忍終棄。”（《宋史·苏轼传》） | 课本钩子落点。“闲人”与“不得签书公事”的关联属于通行解读，可讲。 |

## 二、案中案：沈括“签帖进呈”说的证据辨析

**唯一原始记载**（转引互校）：《长编》卷301 元丰二年十二月庚申条注文：
> 王銍《元祐補錄》：沈括集云，括素與蘇軾同在館閣，軾論事與時異，補外。括察訪兩浙，陛辭，神宗語括曰：“蘇軾通判杭州，卿其善遇之。”括至杭，與軾論舊，求手錄近詩一通，歸則簽帖以進，云詞皆訕懟。軾聞之，復寄詩。劉恕戲曰：“不憂進了也？”其後李定、舒亶論軾詩置獄，實本於括云。元祐中，軾知杭州，括閑廢在潤，往來迎謁恭甚。軾益薄其為人。

李焘按语：“此事附注，當考詳，恐年月先後差池不合。”

> 句读提示：“沈括集云”四字如何读，有歧义（是王铚引“沈括集”，还是《元祐补录》“沈括”条“集”录？）。本稿不作判断，口播统一说“王铚《元祐补录》记载”。**句读待核**。

| 论点 | 支持“确有其事”（正方） | 质疑（反方） | 可讲的结论 |
|---|---|---|---|
| 来源数量 | 王铚为南宋初史家，所记可能有家传旧闻；李焘仍选择收录。 | 遍检群籍，此事只此一条，属孤证（王瑞来《孤证难立：质疑沈括告密苏轼公案》，2025）。李焘把它放在注文、并当场质疑，《元祐补录》在《长编》注中被引用时多遭李焘驳正（同文）。 | 孤证，且原始引用者已表示怀疑。 |
| 时间 | 莫砺锋《“乌台诗案”史话》解释为神宗当时“隐忍未发”；也有人推测沈括压着材料，到元丰二年才配合发难。 | 沈括察访两浙在熙宁六年八月至七年三月（《长编》卷245—256，刘汉鼎文转引；《宋史·沈括传》确有“察訪兩浙農田水利”）。距元丰二年五年之久；其间苏轼熙宁七年升知密州，元丰元年因徐州抗洪受诏奖。 | 时间间隔与神宗对苏轼的态度都难以对上。 |
| 沈括1079年的处境 | — | 熙宁十年起沈括被蔡确劾“首鼠乖剌”，出知宣州（《宋史》卷331《沈括传》），元丰二年在宣州任上，与新党御史台处于对立（祖慧《沈括评传》年表，刘汉鼎文转引）。 | 案发时沈括不在朝，且被新党排挤。 |
| 案卷 | — | 《东坡乌台诗案》所收弹章作者为何正臣、舒亶、李宜之、李定，证物为刻本《钱塘集》，案卷无沈括（二手转引）。 | 正式案卷里找不到沈括。 |
| 当事人自述 | — | 苏轼多次只控诉李定、何正臣、舒亶（《杭州召还乞郡状》）；苏辙《亡兄子瞻端明墓志铭》归咎“言者”。苏氏兄弟对沈括另有批评，却从未提此事（刘汉鼎文）。 | 受害人本人没有指认沈括。 |
| “刘恕戏曰”细节 | — | 刘恕熙宁年间在南康军修《通鉴》，与苏轼可考的会面在熙宁七年正月润州，早于沈括还朝两个月；此后两人未再相见（任同斌考证，刘汉鼎文转引）。 | 带画面的细节时序矛盾，削弱全条可信度。 |
| “迎谒恭甚，轼益薄其为人” | — | 苏轼元祐四年七月到杭，沈括九月才迁润州，赴任途中无从相见；二人可考的唯一交往是元祐六年沈括赠石墨，苏轼作《书沈存中石墨》（喻世华说，刘汉鼎文转引）。 | 后半段与年谱不合。 |
| 旁证人物 | — | 李之仪与苏、沈都交好，熙宁六年曾陪沈括游两浙；元丰二年七月仍请沈括为其母撰墓志（刘汉鼎文）。王铚之子王明清《挥麈录》把乌台诗案的源头归于蔡确摘汪辅之谢表的先例，未提沈括。 | 圈内人的行为与“告密”说不协调。 |
| 采信情况 | 孔凡礼《苏轼年谱》熙宁六年条、王水照与崔铭《苏轼传》采信；余秋雨《苏东坡突围》写成定论，影响最广。 | 张荫麟斥为“凭空谤造”；包伟民认为或有人举报苏诗，但未必是沈括（均据刘汉鼎文转引，原著待核）。 | 学界未定论。 |

**节目处理建议**：完整呈现正反双方，结论表述为“现有证据不足以认定沈括告密；这条记载在李焘时代就被打了问号；但也无法彻底排除”。避免把沈括写成“被冤九百年的完人”，同样避免沿用余秋雨的定论式叙述。

## 证据禁区
1. **“沈括告密导致乌台诗案”作为定论**：只能作为“王铚的说法”进入辨析段。
2. **“沈括与苏轼是好朋友，临别手录诗相赠”**：余秋雨语，无据。
3. **网文版送鱼细节**：红烧鲤鱼、熏鱼、“铁杆粉丝亲戚”、苏迈“去借钱”以外的情节扩写。只能用《避暑录话》原有要素：菜与肉、鱼、陈留筹粮、亲戚忘约。
4. **“神宗读诀别诗感动落泪”**：无据；叶梦得只说“见诗益动心”，且是推断。
5. **“王安石一句话救了苏轼”作为定论**：只见于南宋周紫芝，存疑。
6. **“下狱先问有无誓书铁券”**：出处未检出，暂不用。
7. **把《元丰续添苏子瞻学士钱塘集》称为“盗版”**：史料只称“镂板”“印行”。
8. **苏轼受刑的具体手段、伤情**：史料只有“诟辱通宵”“狱吏稍见侵”，不得具体化。
9. **曹太后“临终遗言救苏轼”**：《宋史》是“违豫中”进言，口播不渲染成临终托付。

## 给写稿者的说明
- **最该抓的名场面**：①湖州州衙的台牒与“朝服”问题（孔平仲）；②诀别诗的两个版本：叶梦得的“送鱼—神宗见诗”与孔平仲的“狱卒藏诗枕中—黄州归还”；③李定对王安礼说“人将以为党”；④法司“会赦当原”，御史台坚持“特责”；⑤罚铜名单念出来：司马光、曾巩、黄庭坚、王安上；⑥李焘注文后那行“恐年月先后差池不合”。
- **名人的哪一面**：
  - 苏轼：不只是受害者形象。他确实写诗讥刺新法，供状里大多承认“有讥讽之意”（辑本，原文待核），后来又自称“以诗託諷，庶有補於國”。狱中恐惧到想自尽，出狱当晚又写“试拈诗笔已如神”。这些都是他本人留下的文字。
  - 沈括：科学家之外，他是新法干将、后被新党抛弃的人。节目给他一个公平的证据审查，这是本期的“深度”所在。
  - 李定、舒亶：本期“反派”，但李定说“苏轼乃奇才”的细节要保留，避免脸谱化。
  - 神宗：《宋史》写他“独怜之”，苏轼说他“无意杀臣”，可他同时批准了“特责”。
- **易踩的坑**：
  1. 把《避暑录话》“送鱼”当正史，或把它和诗题自述混为一谈。
  2. 把“沈括告密”讲成定论，或反过来讲成“已被证伪”。正确说法是“孤证存疑、证据倾向于不成立、尚无定论”。
  3. 统编教材册次：《记承天寺夜游》在不同版本中课序不同（2017 版第 10/11 课，2024 版第 12 课），口播只说“八年级上册”。
  4. 苏轼入狱天数有多种算法，避免说死。
  5. 本期引号多，写稿时历史人物话语一律第三人称转述（README 硬红线）。
  6. 台词遵守《AI书写规范》第三节“表层五禁”（惊悚煽情词、说教式标签、机械对仗否定句式等）。
