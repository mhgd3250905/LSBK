# 选题卡：乌台诗案与沈括之谜：苏轼被一本诗集送进御史台，科学家沈括是不是告密者？

> 状态：选题材料（2026-10-07 起草），待用户审批后方可进入大纲。本卡只给方向与证据，不含任何台词。史料原文与边界见同目录 `史料核对.md`。

## 基本信息
- **选题缘由**：“课本里的北宋朋友圈”按时间推进到元丰二年（1079）。上一期阿云案里，法律问题被党争绑走；这一期，文学被拿来定罪。苏轼因谢表和印行诗集被御史台逮捕，坐狱一百三十天左右，二十多位名臣被罚铜。案中还套着一桩八百年来被反复转述的“案中案”：《梦溪笔谈》的作者沈括，是否在熙宁年间抄录苏轼诗、加签注进呈，成了乌台诗案的源头。这条记载只有一个来源，而且李焘当年引用时就写了疑问。
- **题型**：系列连载 / 案件复盘 + 证据辨析型
- **系列归属**：《笑谈历史》宋朝系列“课本里的北宋朋友圈”第 06 期（元丰篇）
- **时间跨度**：熙宁六年至七年（1073—1074）沈括察访两浙 → 元丰元年（1078）《元丰续添苏子瞻学士钱塘集》刊行 → 元丰二年七月弹劾、七月二十八日湖州被逮、八月十八日入台狱 → 十二月庚申（二十八日）责授黄州团练副使 → 元丰三年至七年黄州

## 核心认知反差（生死线）
- **你以为的**：
  1. 乌台诗案是几个小人嫉妒苏轼才华，抓了几句诗就要置他于死地；
  2. “沈括告密”是史书写明的事实，科学家人品有问题；
  3. 苏轼在狱中靠一条鱼、两首诀别诗打动神宗，才捡回一条命。
- **实际上的**：
  1. 立案的直接证据是苏轼的《湖州谢上表》和书坊刻印的《元丰续添苏子瞻学士钱塘集》。舒亶随弹章“印行四册，谨具进呈”（《东坡乌台诗案》辑本，二手转引），御史台审的是一部公开发行的出版物。苏轼本人后来说得很明白：“党人疑臣复用”，三位御史“构造飞语……必欲致臣于死”（《杭州召还乞郡状》）。这是一场政治清算。
  2. “沈括告密”只出自王铚《元祐补录》一条，经李焘《长编》卷301注文转引，李焘随即写下“此事附注，当考详，恐年月先后差池不合”。案发时沈括正被新党蔡确排挤在宣州任上，案卷中的弹章作者是何正臣、舒亶、李定、李宜之四人。学界对此至今两说并存。
  3. 法司拟的本是“当徒二年，会赦当原”，按法可以直接释放。最后的贬谪是李定、舒亶坚持之后的“特责”（《长编》卷301）。营救者里有太皇太后曹氏、王安礼、张方平、范镇，“送鱼”与诀别诗出自叶梦得《避暑录话》，属于笔记，而苏轼自己的诗题给出的写诗缘由是“狱吏稍见侵”。
- **反差的强度自评**：⭐⭐⭐⭐⭐（课本里最熟的苏轼 + 课本里最熟的科学家 + 一条只有孤证的指控）

## 核心问题（这期节目回答的一句话问题）
把一个人送进御史台，需要多少证据？乌台诗案用一本诗集办成了案，而“沈括告密”这条流传最广的指控，证据却只有一条带着问号的注文。我们愿意相信什么，往往取决于我们先站了谁。

## 三大基因自检
- [x] **小切口**：湖州州衙的院子里，皇甫遵穿靴袍执笏立在庭下，两名台卒白衣青巾，怀里的台牒顶着衣服像藏着匕首；苏轼不敢出来，问该不该穿朝服；打开台牒，只是一纸“寻常追摄”（孔平仲《孔氏谈苑》，笔记）。
- [x] **大纵深**：从雕版印刷让在世作家第一次拥有“畅销书”，到御史台“风闻言事”变成政争工具；从熙宁年间谢景温查苏轼贩私盐“锻炼不成”，到元丰二年二十余人罚铜；从李焘的“考异”注文，到余秋雨《苏东坡突围》把孤证写成定论。
- [x] **人性内核**：落难时谁伸手、谁落井下石，史书记了一笔；后人急着给沈括定罪，也是一种站队。这期让听众亲手掂一掂证据的分量。

## 内容弹药
- **主要素材/案例**（严格区分出处性质）：
  1. 导火索：《湖州谢上表》“知其愚不適時，難以追陪新進；察其老不生事，或能牧養小民”（**文集**；何正臣据此弹劾，见《宋史·何正臣传》卷329）。
  2. 弹劾者：李定、舒亶、何正臣“摭其表語，並媒蘖所為詩以為訕謗，逮赴臺獄，欲置之死，鍛煉久之不決。神宗獨憐之”（**正史**：《宋史·苏轼传》卷338）；李定“自鞫軾獄”，却在崇政殿门外对同列说“蘇軾乃奇才也”（**正史**：《宋史·李定传》卷329）。
  3. 舒亶扩大打击面：要求连带诛责张方平、司马光、范镇、陈襄、刘挚等，“可置而不誅乎”；神宗“覺其言為過”（**正史**：《宋史·舒亶传》卷329；《长编》卷301）。
  4. 逮捕现场：皇甫遵（一作僎）赶赴湖州，王诜报信给苏辙、苏辙遣人先到；庭下台卒、台牒像匕首、苏轼问穿不穿朝服、“頃刻之間，拉一太守如驅犬雞”（**笔记**：孔平仲《孔氏谈苑》卷一）。苏轼自述：“定等選差悍吏皇遵，將帶吏卒，就湖州追攝，如捕寇賊。”（**文集**：《杭州召还乞郡状》）
  5. 狱中：苏轼自述过扬子江欲投江、入狱欲绝食，“先帝遣使就獄，有所約敕，故獄吏不敢別加非橫”（**文集**：《杭州召还乞郡状》）；苏颂同时系狱邻室，有“詬辱通宵不忍聞”之句（**文集**：苏颂诗，二手转引，原文待核）。
  6. 诀别诗：诗题“予以事繫御史臺獄，獄吏稍見侵，自度不能堪，死獄中，不得一別子由，故作二詩授獄卒梁成，以遺子由”（**文集**：苏轼诗集）；“送鱼”暗号及“神宗见诗益动心”（**笔记**：叶梦得《避暑录话》）；另一版本见孔平仲《孔氏谈苑》卷一：苏轼藏青金丹备自尽，托诗给每夜为他烧水濯足的狱卒，狱卒把诗藏在枕中，苏轼贬黄州后才归还，苏辙“以面伏案，不忍读”（**笔记**，年代早于叶梦得，且没有送鱼情节）。两版并列讲。
  7. 营救：太皇太后曹氏病中谏神宗，提仁宗“为子孙得两宰相”（**正史**：《宋史·后妃传》卷242）；王安礼进言“自古大度之主，不以言語罪人”，李定事先警告他“公幸毋營解，人將以為黨”（**正史**：《宋史·王安礼传》卷327；《长编》卷301）；张方平、范镇上书（《长编》卷301，注引刘安世语称张疏“亦不果投”）。
  8. 王珪“蛰龙”构陷与神宗“彼自咏桧，何预朕事”（**后出编年/笔记**：《宋史全文》元丰七年条，源出叶梦得《石林诗话》等，属存疑级）。
  9. 判决：“法寺當徒二年，會赦當原”，李定、舒亶力争，“軾等皆特責”；十二月庚申，责授检校水部员外郎、黄州团练副使，本州安置，不得签书公事；王诜追两官勒停，苏辙监筠州盐酒税，张方平、李清臣罚铜三十斤，司马光、范镇、曾巩、黄庭坚等各罚铜二十斤（**正史级编年**：《长编》卷301正文）。
  10. 黄州：《记承天寺夜游》（元丰六年十月十二日）、《念奴娇·赤壁怀古》、前后《赤壁赋》；元丰七年神宗手札移汝州，“人材實難，不忍終棄”（**正史**：《宋史·苏轼传》）。
  11. **案中案：沈括**。正方：王铚《元祐补录》（《长编》卷301注引）；孔凡礼《苏轼年谱》、莫砺锋、王水照与崔铭《苏轼传》等采信。反方：李焘自注“恐年月先后差池不合”；祖慧《沈括评传》、喻世华、王瑞来《孤证难立》、刘汉鼎（《中华读书报》）等提出时间差、刘恕不可能在场、案卷无沈括、苏轼兄弟只控诉三御史、李之仪与沈括交往如常等疑点（**存疑，必须做正反辨析**，详见史料核对）。
- **可用的对照组**：
  - 李定：亲手审苏轼，又私下说“苏轼乃奇才也”；
  - 王安礼（王安石之弟）冒着被视为“党”的风险救苏轼 vs 御史张璪责问他“公果救苏轼耶”；
  - 熙宁元年阿云案，王安石一方用诏敕压过法司；元丰二年乌台诗案，法司拟“会赦当原”，御史台又用“特责”压过法司。两期对照，看出法律被权力改写的同一机制。
- **可交付的概念工具**：
  - **“孤证的引力”**：一条生动、带画面、符合我们对“好人坏人”预期的记载，即使史家当场标了问号，也会被一代代复述成定论。判断它，要看来源数量、时间能否对上、当事人有无旁证、立场是否可疑。
- **降维三步法候选点**（留在创作笔记，不进台词）：
  - 《长编》的“正文 + 注文”结构：正文是李焘认可的事实，注文是“另有一说，待考”。类比论文的正文与脚注。
  - “会赦当原”与“特责”：法律判决本可免罪，皇帝在法外另行处分。
- **合法跑偏候选**：
  - 跑偏 1：内山精也“第一例以出版物为罪证的文字狱”之说，雕版印刷与“活着的畅销书作家”（刘汉鼎文转述，原著待核）。
  - 跑偏 2：苏轼与沈括唯一可证的交往，是元祐六年沈括赠鄜延石墨，苏轼写《书沈存中石墨》（喻世华说，刘汉鼎文转述，原文待核）。

## 结尾设计 与 系列衔接
- **收束回扣点**：回到《记承天寺夜游》的“闲人”；再回到李焘那行小字“当考详”。节目把判断留给听众，也说清楚节目自己的倾向（证据不足以定沈括的罪）。
- **互动设计**：如果只有一条史料，作者还是事后几十年的人，你会相信“沈括告密”吗？你相信的理由，是证据，还是你本来就更喜欢苏轼？
- **上一期怎么接（S05 阿云之狱）**：S05 里因“按问”之争被贬的刘述、钱顗都是御史台、刑部的言官；到了元丰二年，御史台自己成了发动者。可用的衔接事实：S05 主角之一司马光，在本案罚铜名单里（《长编》卷301），而他十年前为刘琦、钱顗上的疏是“不报”。
- **下一期怎么接（S07 王安石苏轼金陵相会）**：S07 已定为元丰七年苏轼过金陵见王安石。本期结尾留一个悬念交给 S07：南宋周紫芝说王安石一句“岂有圣世而杀才士者乎”救了苏轼，这话靠不靠得住？本期只交代正史里出手的是他弟弟王安礼，王安石之语属存疑“旧传”，答案留到下一期。另一条可递的线：黄州四年后，神宗手札“人材实难，不忍终弃”把苏轼北移，他顺江而下，在金陵停了船。
