| 核心主张 / 历史事件 | 史料出处与卷次 | 写作边界 |
|---|---|---|
| **熙宁二年王安石执政，压制苏轼** | **正史确载**。《宋史》卷三三八《苏轼传》："熙寧二年，還朝。王安石執政，素惡其議論異己，以判官告院。"又："安石不悅，命權開封府推官，將困之以事。軾決斷精敏，聲聞益遠。" | 可直接讲"王安石不喜欢苏轼的议论，先冷置、再派难差"。"困之以事"是史臣对动机的判断，转述时说"史书认为王安石是想用繁杂事务难住他"。 |
| **苏轼当面评神宗"求治太急"** | **正史确载**。同传：神宗问"方今政令得失安在"，苏轼对曰："不患不明，不患不勤，不患不斷，但患求治太急，聽言太廣，進人太銳。"神宗"悚然"。 | 名场面可用，保留"三个太"的结构；不渲染神宗情绪，史书只写"悚然"和"朕当熟思之"。 |
| **《上神宗皇帝书》反新法** | **正史节录＋文集**。同传节录："臣之所欲言者，三言而已。願陛下結人心，厚風俗，存紀綱。""夫制置三司條例司，求利之名也；六七少年與使者四十餘輩，求利之器也。"并论免役："萬一後世不幸有聚斂之臣，庸錢不除，差役仍舊……"论青苗："異日天下恨之，國史記之，曰『青苗錢自陛下始』。" | 宋史未系月份，一般系于熙宁四年（**系年待核**，可说"熙宁年间"）。注意苏轼这时反对免役，元祐时又反对骤废免役——这正是 S08 的伏笔，不要讲成他立场反复，他反对的是"骤变"。 |
| **策问激怒王安石→谢景温论奏→苏轼外放** | **正史确载**。同传："因試進士發策，以『晉武平吳以獨斷而克，苻堅伐晉以獨斷而亡……事同而功異』為問，安石滋怒，使御史謝景溫論奏其過，窮治無所得，軾遂請外，通判杭州。" | 可讲"查了一圈没查出问题"。谢景温所论具体罪名（常见说法为扶丧贩私盐）**正史本传未写，待核**，不可当事实讲；谢景温与王安礼的姻亲关系亦**待核**。 |
| **邵伯温的另一种说法：二人"初无隙"，吕惠卿挑拨** | **宋人笔记**。邵伯温《邵氏闻见录》卷十二："王介甫與蘇子瞻初無隙，呂惠卿忌子瞻才高，輒間之。" | 邵氏父子属旧党立场，倾向把恶名推给吕惠卿。可作"另一种说法"并列，不可覆盖《宋史》"素恶其议论异己"的记载。 |
| **乌台诗案的起诉者** | **正史确载**。《苏轼传》："御史李定、舒亶、何正臣摭其表語，並媒蘖所為詩以為訕謗，逮赴臺獄，欲置之死，鍛煉久之不決。神宗獨憐之，以黃州團練副使安置。" | 细节交给 S06；本期只用一两句回顾。 |
| **王安礼御前救苏轼** | **正史确载**。《宋史》卷三二七《王安礼传》："蘇軾下御史獄，勢危甚，無敢救者。安禮從容言：『自古大度之主，不以言語罪人……』帝曰：『朕固不深譴也……卿第去，勿漏言，軾方賈怨於眾，恐言者緣以害卿也。』"同卷论曰："安石惡蘇軾而安禮救之。" | 本期回答"谁救了苏轼"的主证据。神宗叮嘱王安礼"勿漏言"一句很有戏，可用。 |
| **"岂有圣世而杀才士者乎"** | **存疑（南宋追记的传闻）**。周紫芝《太仓稊米集》卷四十九《读诗谳》："舊傳元豐間，朝廷以群言論公，獨神廟惜其才不忍殺，丞相王文公曰：『豈有聖世而殺才士者乎？』當時讞議以公一言而決。"周紫芝生于 1082 年，案发时尚未出生。 | 只能说"南宋有人记下一个旧传"。三处硬伤需提示听众：①原文自称"旧传"；②元丰二年王安石已罢相退居金陵，并非在任"丞相"；③《宋史》本传与王安礼传都未载，且论赞写"安石恶苏轼"。**禁止**讲成"王安石一封信救了苏轼"，网传的"连夜写信、飞马进京"属后世演绎。 |
| **神宗手札移汝州** | **正史确载**。《苏轼传》：神宗欲用苏轼修国史被王珪阻，"遂手札移軾汝州，有曰：『蘇軾黜居思咎，閱歲滋深，人材實難，不忍終棄。』" | 可用"人才实难，不忍终弃"八个字作转场。 |
| **金陵对谈：大兵大狱** | **正史确载（史源为笔记）**。《苏轼传》："道過金陵，見王安石，曰：『大兵大獄，漢、唐滅亡之兆。……今西方用兵，連年不解，東南數起大獄，公獨無一言以救之乎？』安石曰：『二事皆惠卿啟之，安石在外，安敢言？』……安石厲聲曰：『安石須說。』又曰：『出在安石口，入在子瞻耳。』又曰：『人須是知行一不義，殺一不辜，得天下弗為，乃可。』軾戲曰：『今之君子，爭減半年磨勘，雖殺人亦為之。』安石笑而不言。"同事较早见《邵氏闻见录》卷十二，且多出"介甫色動，意子瞻辨前日事也"及"蓋介甫嘗為惠卿發其『無使上知』私書，尚畏惠卿，恐子瞻泄其言也"。 | 本期最硬的名场面，可放第三幕高潮。正史版本与邵氏版本要分开："王安石一度紧张以为苏轼要翻旧账""怕吕惠卿"这两层心理只见于邵伯温，转述时注明"邵伯温的解释是……"。 |
| **《次荆公韵四绝》其三** | **文集自述**。《东坡全集》卷十四："騎驢渺渺入荒陂，想見先生未病時。勸我試求三畝宅，從公已覺十年遲。"其四末有苏轼自注："公病後，舍宅作寺。" | "十年"是约数（王安石熙宁九年第二次罢相，至此约八年）。**不要**把"从公已觉十年迟"解释为苏轼承认新法正确，原意是"早该追随您退隐林下"。南宋施元之等注本另有"东坡得请归宜兴道过钟山"之说（查慎行《苏诗补注》辨之），系年以元丰七年过金陵为通行说法。 |
| **《上荆公书》：买田金陵、推荐秦观** | **文集自述**。苏轼《上荆公书》（又题《与王荆公》）："近者經由，屢獲請見，存撫教誨，恩意甚厚。……軾始欲買田金陵，庶幾得陪杖履，老於鍾山之下。既已不遂，今來儀真，又已二十餘日，日以求田為事……若幸而成，扁舟往來，見公不難也。"后半推荐秦观"行義修飭，才敏過人"。 | "屡获请见"说明不止一次见面，可用"见了好几次"；具体停留天数史无明文，不要说"一个月""四十天"。 |
| **王安石的回信** | **文集（据转引）**。王安石《回苏子瞻简》首句常引作"承誨喻累幅，知尚盤桓江北，俯仰逾月，豈勝感悵"，并称许秦观诗。 | 原文仅见二手转引，**原文待核**（应核《临川先生文集》）。核实前只转述大意"王安石回信说分别一个多月，很是惆怅"。 |
| **"不知更几百年，方有如此人物"＋"平生作诗无此二句"** | **宋人笔记**。蔡絛《西清诗话》卷上："元豐中，王文公在金陵，東坡自黃北遷，日與公遊，盡論古昔文字，閑即俱味禪悅。公歎息謂人曰：『不知更幾百年，方有如此人物。』東坡渡江至儀真，《和遊蔣山詩》寄金陵守王勝之益柔，公亟取讀，至『峰多巧障日，江遠欲浮天』，乃撫几曰：『老夫平生作詩，無此二句。』"又记苏轼称王安石"積李兮縞夜，崇桃兮炫晝"是屈宋以后的《离骚》句法，王安石答"非子瞻見諛，自負亦如此"。 | 可用，但必须交代作者蔡絛是蔡京之子；吴曾《能改斋漫录》卷十称蔡京"使其門下客著西清詩話，以載蘇黃語，亦欲為他日張本"（据维基文库《西清诗话》题解转引，**能改斋原卷待核**）。王安石《和子瞻同王胜之游蒋山》诗序"余愛其『峰多巧障目，江遠欲浮天』之句，故次其韻"可作旁证（**原文据转引，待核《临川集》**；注意"障日/障目"异文）。"积李崇桃"所出王安石诗题，网传为《寄蔡氏女子》，**待核**。 |
| **野服乘驴、"礼岂为我辈设哉"** | **宋人笔记**。一般引作朱弁《曲洧旧闻》："東坡自黃徙汝，過金陵，荊公野服乘驢謁於舟次，東坡不冠而迎……"后接苏轼"軾今日敢以野服見大丞相"、王安石笑曰"禮豈為我輩設哉"。 | 本条仅见于后人辑本与二手转引（如《东坡先生遗事》卷九），**《曲洧旧闻》卷次与原文待核**。可作"宋人笔记里有个画面"，不能说"史书记载"。 |
| **"子瞻，人中龙也"与一字师** | **宋人笔记，存疑**。王安石在钟山读苏轼《胜相院经藏记》，叹"子瞻人中龍也，然有一字未穩"，主张"日勝日負"改"日勝日貧"（见惠洪《冷斋夜话》，后入《宋稗类钞》）。《经进东坡文集事略》卷五十四注引苏轼之孙苏符跋："此先祖文成日所書，如人善博日勝日貧，貧初不作負字，可見世所傳荊公事為妄也。" | 时间在元丰三年，早于金陵相会，只可作跑偏辨伪素材，示范"笔记会被当事人家属反驳"。 |
| **王安石赠太傅制（苏轼起草）** | **文集（制诰）**。苏轼《王安石赠太傅》："將有非常之大事，必生希世之異人。使其名高一時，學貫千載。智足以達其道，辯足以行其言。瑰瑋之文，足以藻飾萬物；卓絕之行，足以風動四方。""屢爭席於漁樵，不亂群於麋鹿。進退之美，雍容可觀。" | 制词是代皇帝立言的公文，不等于苏轼私人评价；但措辞之高可作结尾回扣。王安石卒于元祐元年（《宋史》本传只写"元祐元年，卒，年六十八"，月日据通行说法为四月，**月日待核**）。 |
| **司马光要求"优加厚礼"** | **文集自述**。司马光《与吕晦叔第二简》："介甫文章節義過人處甚多，但性不曉事而喜遂非，致忠直疏遠，讒佞輻輳，敗壞百度，以至於此。……光意以謂朝廷特宜優加厚禮，以振起浮薄之風。" | 可作 S07 尾声与 S08 的桥：司马光一边尽废新法，一边要求厚待王安石身后名。原话褒贬并存，转述时两半都要讲。 |
| **《泊船瓜洲》《赤壁怀古》写作时间** | **后世考订，存疑**。《泊船瓜洲》通行教材系于熙宁八年王安石二次拜相赴京途中，但学界另有早年之作等说法；《念奴娇·赤壁怀古》一般系于元丰五年黄州。"春风又绿"改字故事见洪迈《容斋续笔》（**卷次待核**）。 | 冷开场只说"两首课文的作者"，不要把《泊船瓜洲》的写作时间说成定论。 |

## 证据禁区（写稿不得出现的说法）
1. **"王安石上书/写信救了苏轼"**：正史无载，唯一早期出处是周紫芝自称"旧传"的追记，且时间、官职对不上。
2. **"王安石是乌台诗案的幕后黑手"**：无任何史料支持。起诉者李定虽出王安石门下，但案发时王安石已退居金陵，不可连坐推论。
3. **"苏轼在金陵向王安石认错，承认新法好"**：曲解"从公已觉十年迟"。同一次见面苏轼还当面批评用兵与大狱。
4. **具体停留天数**（"一个月""四十天""七天"）：史无明文，只说"屡获请见""见了好几次"。
5. **半山园里的私下对白**：除上表所列《宋史》、邵伯温、蔡絛、朱弁等已有记载外，不得编造任何对话、表情、饮食起居。
6. **"王安石临终前还惦记苏轼"之类**：无出处。
7. **"安石恶苏轼"与"不知更几百年方有如此人物"同时引用时，不得只取后者。**

## 给写稿者的说明
- **这期最该抓的名场面**：金陵对谈的那一来一回——苏轼开口问的是西北用兵和东南大狱，王安石先推给吕惠卿，被苏轼一句"在朝则言，在外则不言，事君之常礼耳"顶回去，王安石厉声说"安石须说"，又压低一句"出在安石口，入在子瞻耳"。这一段正史有据，冲突、分寸、人情都在里面，比"同游唱和"更能撑起高潮。
- **名人的哪一面**：
  - 王安石：执政时排斥异议、对苏轼不客气；退休后病中舍宅为寺、骑驴吟诗，仍对时局有话不敢公开说。他的"倔"和他的坦荡是同一个人。
  - 苏轼：对谁都敢当面说。熙宁时当面说神宗"求治太急"，元丰末当面问王安石为何沉默，元祐时又当面跟司马光争免役法（S08）。他和王安石的和解，是文字和人品上的互相服气，政见上谁也没让步。
- **易踩的坑**：
  1. 把《西清诗话》当正史。每次引用王安石夸苏轼的话，都带一句"这是蔡京儿子蔡絛的诗话里记的"，并点出这本书本身被宋人怀疑是党争产物——这个反转可以做成节目里的一个小高潮。
  2. 把"十年迟"讲成"十年后才认识到新法正确"。
  3. 课本年级说错：《泊船瓜洲》现行统编版在六年级下册，旧人教版在五年级上册。
  4. 正文直接引号为零：上表原文仅供核对，写稿时一律第三人称转述，例如"王安石说，这话从我嘴里出来，只进你的耳朵"。
- **标"待核"的条目（开工前补核）**：谢景温论奏的具体罪名与其姻亲关系；《上神宗皇帝书》系年；王安石《回苏子瞻简》原文；王安石《和子瞻同王胜之游蒋山》诗序原文；"积李崇桃"所出诗题；《曲洧旧闻》野服乘驴条卷次原文；《能改斋漫录》卷十原文；王安石卒日；"春风又绿"改字出处卷次；两人金陵之后是否再有会面。
