# S2E08A 史料核对与写作边界：《王安石（上）：天变不足畏》

> **出处层级**：**正史确载**（《宋史》本纪列传、《长编》）／**文集自述**（王安石《答司马谏议书》、司马光《与王介甫书》）／**宋人笔记**（《邵氏闻见录》《能改斋漫录》）。  
> 文稿遵循规范：正文直接引号为 0，事实有出处，字数严丝合缝。

## 一、 核心史实与引文核对表

| 核心主张 / 历史事件 | 史料出处与原文 | 写作边界与台词转述口径 |
|---|---|---|
| **王安石二十年屡辞京官** | **正史确载**。《宋史·王安石传》：“累拜度支判官，不就；寻知常州，移提点江东刑狱。欧阳修荐为主客员外郎、判吏部南曹，辞之……及至和、嘉祐之际，名震京师，公卿大夫目为奇才，屡召不肯起。” | 突出其非贪恋权位之徒。冷开场交代其二十年间数次辞谢入京，甘于下沉基层，积累了对大宋真实烂疮的深刻洞察。 |
| **鄞县治水与贷谷雏形** | **正史确载**。《宋史·王安石传》：“知鄞县，起堤堰，决陂塘，为水陆之利；贷谷于民，立息以偿，部内始富。” | 真实交代青苗法绝非王安石在书斋里脑补拍脑袋的产物，而是早在鄞县知县任上就亲自实验过的“政策性低息信贷”。 |
| **崇政殿初对：“何不法尧舜”** | **正史确载**。《续资治通鉴长编》卷二百零九（熙宁元年四月）：神宗问“唐太宗何如？”安石对曰：“陛下当法尧舜，何以太宗为哉？尧舜之道，至简而不烦，至要而不迂，至易而行。” | 正史明载对话。神宗问唐太宗，王安石直接拔高到三代尧舜，一举征服二十岁热血天子。台词第三人称口语化转述。 |
| **司马光“天地货财”之辩** | **正史确载**。《宋史·司马光传》卷三三六（熙宁元年八月）：安石曰：“善理财者，民不加赋而国用饶。”光曰：“此乃桑弘羊欺汉武帝之言。天地所生货财百物，止有此数，不在民则在官。善理财者，不过头会箕敛以尽民财。” | 殿上顶级君子之争。清晰展现司马光的清醒与现实主义批判，不歪曲、不脸谱化司马光。 |
| **“三不足”宣言** | **正史确载**。《宋史·王安石传》：“安石必曰：天变不足畏，祖宗不足法，人言不足恤。中外指为三不足之说。” | 必须精准引用九个字“天变不足畏，祖宗不足法，人言不足恤”，作为王安石一人单挑天下的精神图腾。 |
| **制置三司条例司与新法出台** | **正史确载**。《宋史·食货志》：熙宁二年二月设制置三司条例司，王安石与陈升之领其事；九月颁青苗法，次年颁免役法。 | 交代改革指挥部的超常规设置，这是后来纠错机制失效的根源。 |
| **基层异化与强制摊派** | **正史确载**。《宋史·食货志》：“提举官与转运使各以所贷多寡为殿最，由是州县竞务抑配，甚至勒令富室为保，困竭下户。” | 讲透基层异化的机制：提举官以放贷多寡考核升迁，导致自愿变成强制摊派（抑配），还不起则拷打下狱。 |
| **熙宁七年北方大旱与《流民图》** | **正史确载**。《宋史·郑侠传》：“熙宁七年春，自秋不雨，民失农耕……侠监安上门，见灾民负耒、身戴锁链者，遂绘《流民图》，开封飞奏御前。” | 上篇收尾名场面，悬念定格于安上门外大旱与郑侠提笔。 |

## 二、 禁忌与雷区核对清单
1. **严禁将司马光、欧阳修、韩琦塑造成猥琐反派**：他们不是阻碍富强的奸党，而是站在法统、财政伦理与底层真实体感上的良知守护者；
2. **严禁把王安石塑造成冷血权奸**：他动机极度纯洁，是悲剧的圣人，而非阴谋家；
3. **数字严谨性**：涉及引言字数严格点清纯汉字数（如“天变不足畏”五字、“三不足”三项）。
