# S2E08A 节目大纲：《天变不足畏：私德第一的圣人王安石，如何以一人单挑整座朝廷？》

> **分期定位**：第二季·大宋篇 · 王安石双部曲（上篇）  
> **叙事基调**：前半程传奇爽剧式狂飙，后半程深渊浮现与致命盲区反思；大主角命运叙事；纯双人对话。  
> **核心命题**：如果一个人的动机纯洁到近乎圣人、才华横溢到冠绝当世，但他坚信只有自己手里的真理能拯救世界时——这种崇高的纯粹，为什么最终往往会演变成一场吞噬所有人的滔天大祸？  
> **预估体量**：4 幕 / 约 80-90 话轮 / 8,000-9,000 字 / 预估时长 28-30 分钟。

## 分幕详细设计

### 第一幕：鄞县怪杰与二十年抗旨不就
- **幕名**：鄞县怪杰与二十年抗旨不就
- **时间线**：庆历七年（1047）知鄞县至嘉祐年间屡辞京官
- **核心任务**：
  1. 两段式黄金开场：王安石不修边幅的生活白描（几个月不洗脸、衣服脏兮兮、吃鹿肉只吃眼前一盘）vs 二十年屡辞京官的极端清高；
  2. 标志性双人报幕；
  3. 破除世俗偏见：他不是贪权之徒，他是真正的苦行僧；
  4. 鄞县实践：亲手拿锄头下田治水，青苗贷谷的原始雏形；
  5. 深刻洞察大宋烂疮：三冗危机国库见底，豪强高利贷百倍盘剥小农，他上万言书沉睡深宫，他在等一个敢打破乾坤的天子。

### 第二幕：崇政殿夜话与君臣豪赌
- **幕名**：崇政殿夜话与君臣豪赌
- **时间线**：熙宁元年（1068）神宗召见至熙宁二年（1069）制置三司条例司建立
- **核心任务**：
  1. 幕间无缝流动：从小李对“二十年苦等”的追问自然切入神宗登基；
  2. 崇政殿君臣初见：二十岁热血天子赵顼 vs 四十七岁布衣大儒王安石；
  3. “唐太宗何如？”“陛下何不法尧舜？！”一语点燃少年天子雄心；
  4. 破格授权：建立制置三司条例司，架空传统官僚系统；
  5. 青苗法、免役法惊艳出台：国家直接充当低息信贷与物流统筹，民不加赋而国用足的现代性理论震撼朝野。

### 第三幕：一人单挑天下与群星逆行
- **幕名**：一人单挑天下与群星逆行
- **时间线**：熙宁二年（1069）至熙宁四年（1071）朝堂大论战与旧党出局
- **核心任务**：
  1. 幕间无缝流动：从小李感叹新法理论之完美，切入满朝公卿的剧烈反弹；
  2. 殿上世纪大论战：司马光与王安石正面交锋，司马光痛斥“天地货财止有此数，不在民则在官”；
  3. 王安石的极致自负与悲壮孤愤：“天变不足畏，祖宗不足法，人言不足恤！”九字宣言震碎大殿；
  4. 满朝群星逆行：恩师欧阳修挂冠归隐，二十年知己司马光退居洛阳写通鉴，韩琦富弼全员出局；
  5. 爽剧高潮：王安石以一人之力打扫朝堂，新法狂飙突进，国库银绢堆积如山，皇帝大喜过望。

### 第四幕：失控的齿轮与城外流民
- **幕名**：失控的齿轮与城外流民
- **时间线**：熙宁四年（1071）至熙宁七年（1074）初大旱前夕
- **核心任务**：
  1. 幕间无缝流动：从小李沉浸在国库暴富的爽剧快感，大开冷峻切入基层真实视界；
  2. 基层异化的血腥逻辑：当善意变成自上而下的硬性考核 KPI，地方官竞相摊派，青苗法演变成催命的官家高利贷；
  3. 深度哲学反思（全剧灵魂）：
     - 盲区一：圣人以为人人皆是圣人，忽略官僚机器的自私嗜血；
     - 盲区二：为了追求效率与无阻力，亲手拆掉了所有言官诤友的刹车皮；
  4. 终局绝命悬念：熙宁七年北方大旱十月，饥民披枷吞草根涌向开封；安上门守门官郑侠展开了画纸……
  5. 双人闭环收口：抛出最大悬念，大开一句历史注脚，小李电台标志性告别引出下篇。
