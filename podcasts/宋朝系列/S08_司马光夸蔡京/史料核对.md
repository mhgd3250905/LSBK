# S08 史料核对与写作边界：《司马光夸蔡京》

| 核心主张 / 历史事件 | 史料出处与卷次 | 写作边界 |
|---|---|---|
| **司马光击瓮救人（课文出处）** | **正史确载**。《宋史》卷三三六《司马光传》："群兒戲于庭，一兒登甕，足跌沒水中，眾皆棄去，光持石擊甕破之，水迸，兒得活。其後京、洛間畫以爲圖。" | 史书写的是"瓮"，民间说"缸"。"京洛间画以为图"说明当时就传成了故事，可用于冷开场。 |
| **熙宁初司马光与王安石的理财之辩** | **正史确载**。同传：安石曰"善理財者，不加賦而國用足"，光曰"天下安有此理？天地所生財貨百物，不在民，則在官"。王安石论司马光："今用光，是與異論者立赤幟也。" | 作为"两人为何势不两立"的背景，一两句即可。 |
| **元祐元年司马光力主尽废免役** | **正史确载**。同传："時青苗、免役、將官之法猶在，而西戎之議未決。光歎曰：『四患未除，吾死不瞑目矣。』……乃論免役五害，乞直降敕罷之。"又："先帝之法，其善者雖百世不可變也。若安石、惠卿所建，為天下害者，改之當如救焚拯溺。" | 司马光当时已病重（同年九月卒），急迫有其个人因素。可讲"他觉得自己时间不多了"，但这是推断，要说"从'吾死不瞑目'这句话看"。 |
| **蔡京五日复差役，司马光称赞** | **正史确载**。《宋史》卷四七二《蔡京传》："司馬光秉政，復差役法，為期五日，同列病太迫，京獨如約，悉改畿縣雇役，無一違者。詣政事堂白光，光喜曰：『使人人奉法如君，何不可行之有！』" | 本期核心名场面，正史原文，放心用。蔡京时任知开封府（同传"改龍圖閣待制、知開封府"）。 |
| **清人编年的另一版本：一千余人、"媚光"** | **后世编年（清）**。毕沅《续资治通鉴》卷七十九："司馬光奏復差役法，既得旨，知開封府蔡京即用五日限，令兩縣差一千餘人充役，亟詣東府白光。光喜曰：『使人人如待制，何患法之不行乎！』議者謂京但希望風旨，苟欲媚光，非其實也。" | 史源当为李焘《续资治通鉴长编》元祐元年条，**《长编》原卷原文待核**。"一千余人"只能说"据后世编年记载"；"议者谓京苟欲媚光"是当时舆论，可用作"当时就有人看出来了"。 |
| **台谏看穿蔡京** | **正史确载**。《蔡京传》："已而臺諫言京挾邪壞法，出知成德軍，改瀛州，徙成都。諫官范祖禹論京不可用，乃改江淮荊浙發運使。" | 与司马光的"喜"形成对照。不要说司马光亲自贬了蔡京，史书主语是台谏。 |
| **苏轼与司马光争免役** | **正史确载**。《宋史》卷三三八《苏轼传》："軾曰：『差役、免役，各有利害。免役之害，掊斂民財，十室九空，斂聚於上而下有錢荒之患。差役之害，民常在官，不得專力于農，而貪吏猾胥得緣為奸。此二害輕重，蓋略等矣。』……『法相因則事易成，事有漸則民不驚。……公欲驟罷免役而行差役，正如罷長徵而復民兵，蓋未易也。』光不以為然。軾又陳於政事堂，光忿然。軾曰：『昔韓魏公刺陝西義勇，公為諫官，爭之甚力，韓公不樂，公亦不顧。軾昔聞公道其詳，豈今日作相，不許軾盡言耶？』光笑之。" | 可完整讲一来一回。史书前面还有史臣总评："司馬光為相，知免役之害，不知其利。"注意苏轼熙宁时反对推行免役（见 S07），元祐时反对骤废免役，讲成"他反对的始终是急转弯"。 |
| **"司马牛"** | **宋人笔记**。蔡絛《铁围山丛谈》："東坡公元祐時既登禁林，以高才狎侮諸公卿，率有標目殆遍也，獨於司馬溫公不敢有所重輕。一日相與共論免役差使利害，偶不合。及歸舍，方卸巾弛帶，乃連呼曰：『司馬牛！司馬牛！』" | 作者蔡絛是蔡京第四子，书中对其父多有回护（梦远书城题解）。可用，必须注明出处与作者身份；**卷次待核**（通行六卷本，本条约在卷三）。注意笔记原文强调苏轼"独于司马温公不敢有所重轻"，是背后发牢骚，不是当面骂。 |
| **范纯仁劝缓行** | **后世编年转录**。毕沅《续资治通鉴》卷七十九："范純仁與光素厚，謂光曰：『治道去其太甚者可也。差役一事，尤當熟講而緩行，不然，滋為民病。……』光不從，持之益堅。純仁歎曰：『以是使人不得言爾。若欲媚公以為容悅，何如少年合安石以速富貴哉！』" | 《宋史·范纯仁传》原文**待核**。核实前可讲大意并注"据《续资治通鉴》"。"何如少年合安石以速富贵"一句很有力量，适合与蔡京的"媚光"对照。 |
| **章惇帘前力争** | **正史确载**。《宋史》卷四七一《章惇传》："乃駁司馬光所更役法，累數千言。其略曰：『……若役法則熙寧之初遽改免役，後遂有弊。今復為差役，當議論盡善，然後行之，不宜遽改，以貽後悔。』呂公著曰：『惇所論固有可取，然專意求勝，不顧朝廷大體。』光議既行，暴憤恚爭辨簾前，其語甚悖。宣仁后怒……黜知汝州。" | 章惇此时观点与苏轼接近（都反对"遽改"），但动机复杂（同传说他因蔡确罢相"不自安"）。不要把章惇讲成元祐时的"理性派"英雄，他绍圣时的报复更狠（见下）。 |
| **王安石闻罢免役** | **宋人笔记（转引）**。朱熹《三朝名臣言行录》卷六之二引《卮史》："王荊公在金陵，聞朝廷變其法，夷然不以為意。及聞罷役法，愕然失聲曰：『亦罷至此乎？』良久曰：『此法終不可罷。安石與先帝議之，二年乃行，無不曲盡。』後果如其言。"毕沅《续资治通鉴》卷七十九亦载。 | 可用，标"宋人笔记"。"后果如其言"是编者事后评语。 |
| **绍圣：蔡京一句话恢复雇役** | **正史确载**。《蔡京传》："紹聖初，入權戶部尚書。章惇復變役法，置司講議，久不決。京謂惇曰：『取熙寧成法施行之爾，何以講為？』惇然之，雇役遂定。差雇兩法，光、惇不同。十年間京再蒞其事，成於反掌，兩人相倚以濟，識者有以見其姦。" | 本期结构性命题的正史依据，"十年间京再莅其事，成于反掌"可作全期题眼（转述）。 |
| **绍圣报复：请发司马光冢** | **正史确载**。《司马光传》："紹聖初，御史周秩首論光誣謗先帝，盡廢其法。章惇、蔡卞請發塚斫棺，帝不許，乃令奪贈諡，仆所立碑。"《章惇传》同载"請發司馬光、呂公著塚，斫其棺。哲宗不聽"。 | 主语是章惇、蔡卞，不是蔡京。蔡卞是王安石女婿（《王安石传》"薦臣婿蔡卞"）、蔡京之弟（《蔡京传》"時弟卞已為舍人"）。 |
| **崇宁元年：120 人刻石端礼门** | **正史确载**。《宋史》卷十九《徽宗本纪一》崇宁元年九月己亥："籍元祐及元符末宰相文彥博等、侍從蘇軾等、餘官秦觀等、內臣張士良等、武臣王獻可等凡百有二十人，御書刻石端禮門。" | 首批即有苏轼。司马光此时已卒，但同年五月已被"降復太子太保司馬光為正議大夫"。 |
| **崇宁二年：天下立碑** | **正史确载**。同卷崇宁二年九月辛丑："令天下監司長吏廳各立《元祐姦黨碑》。"同年四月"詔毀刊行《唐鑑》並三蘇、秦、黃等文集"。 | 可讲"全国各路官署都要立"；三苏文集被下令毁版也是正史。 |
| **崇宁三年：309 人合籍** | **正史确载**。同卷崇宁三年六月戊午："詔重定元祐、元符黨人及上書邪等者合為一籍，通三百九人，刻石朝堂。"《蔡京传》："首以司馬光，目曰姦黨，刻石文德殿門，又自書為大碑，遍班郡國。……凡名在兩籍者三百九人，皆錮其子孙。" | 两处记载的刻石地点（朝堂／文德殿门）略异，写稿说"刻在宫中，又由蔡京亲笔书写颁行各地"即可。今人常说"崇宁四年立碑"属误记或别说，以本纪崇宁三年为准。 |
| **新党宰相也入另册** | **正史确载**。同卷崇宁三年二月己酉："詔王珪、章惇別為一籍，如元祐黨。" | 讲"翻烧饼"时的关键细节：连绍圣时恢复新法的章惇都被打入另册。 |
| **石工安民** | **正史确载**。《司马光传》："長安石工安民當鐫字，辭曰：『民愚人，固不知立碑之意。但如司馬相公者，海內稱其正直，今謂之姦邪，民不忍刻也。』府官怒，欲加罪，泣曰：『被役不敢辭，乞免鐫安民二字于石末，恐得罪於後世。』聞者愧之。" | 结尾回扣素材。注意他最后还是刻了，只求不留自己的名字。 |
| **崇宁五年彗星毁碑** | **正史确载**。《宋史》卷二十《徽宗本纪二》崇宁五年正月："戊戌，彗出西方，其長竟天。……乙巳，以星變，避殿損膳，詔求直言闕失。毀《元祐黨人碑》。"《蔡京传》："帝以言者毀黨碑，凡其所建置，一切罷之。京免為開府儀同三司。"次年（大观元年）蔡京复相。 | 毁碑因天象而非醒悟，可轻点一句。 |
| **蔡京拿王安石做招牌** | **正史确载**。《蔡京传》："京陰託『紹述』之柄，箝制天子"；"追封王安石、蔡確皆為王"。《徽宗本纪一》崇宁三年六月："以王安石配饗孔子廟。" | 可讲"蔡京把王安石抬进孔庙"，与 S07 王安石骑驴半山园形成反照。不要推断王安石本人会如何看。 |
| **蔡京结局** | **正史确载**。《蔡京传》："天下罪京為六賊之首……行至潭州死，年八十。" | 收官点到即止。 |
| **司马光与蔡京的人物定评** | **正史确载**。《司马光传》："自少至老，語未嘗妄"；《蔡京传》："京天資凶譎，舞智御人。" | 对照组素材；元人修史的定评，可直接转述为"《宋史》的评价"。 |
| **现存两方南宋重刻党籍碑** | **文物及今人研究**。桂林龙隐岩摩崖，庆元四年（1198）梁焘曾孙梁律据家藏拓本重刻；融水真仙岩碑，嘉定四年（1211）沈千曾孙沈暐重刻（维基百科"元祐黨籍碑"、广西新闻网 2014-07-23、辽宁日报 2021-02-18 等）。 | 属今人资料，讲时说"今天在广西还能看到两块南宋人重刻的"。人数均为 309。 |
| **《水浒传》蔡太师与生辰纲** | **小说演绎**。《水浒传》第十六回"杨志押送金银担 吴用智取生辰纲"，梁中书为岳父蔡京祝寿。 | 只作课本钩子，必须明说是小说：梁中书、生辰纲均非史实。 |

## 证据禁区（写稿不得出现的说法）
1. **把《水浒传》情节当史实**：生辰纲、梁中书、蔡京与高俅同谋陷害林冲等，一律不当正史讲。
2. **"司马光被蔡京骗了，后来后悔了"**：史书只记"光喜"，无司马光事后评价蔡京的记载。司马光元祐元年九月即去世。
3. **"司马光亲自贬了蔡京"**：贬蔡京的是台谏弹劾，史书主语不是司马光。
4. **"苏轼当面骂司马光是司马牛"**：笔记原文是回家卸冠后连呼，且出自蔡京之子蔡絛。
5. **差役复行造成多少人破产、死亡的具体数字**：无可靠史料，不得编造。"一千余人"仅为开封两县充役人数，且出清人编年。
6. **"蔡京是新党"或"蔡京是旧党"**：两头都不对，史臣的定性是"两人相倚以济"。
7. **"元祐党人碑上的人都是君子"**：309 人中也有因元符末上书被列"邪等"者，还有新党宰相王珪、章惇被另册；不要把碑讲成"好人名单"。
8. **"苏黄米蔡的蔡本来是蔡京"**：后世传闻，不作事实陈述。

## 给写稿者的说明
- **这期最该抓的名场面**：两次"一句话定役法"——元祐元年蔡京五天办完、司马光说"使人人奉法如君"；绍圣初章惇议而不决、蔡京说"取熙宁成法施行之耳"。两个场景隔了八年，主角都是蔡京，宰相从司马光换成章惇。把这两幕前后对照摆出来，再接《宋史》那句"十年间京再莅其事，成于反掌，两人相倚以济"，全期的命题就立住了。
- **名人的哪一面**：
  - 司马光：道德无可挑剔，"语未尝妄"，但在役法上急、固执，连老朋友范纯仁、苏轼的劝都听不进，史臣说他"知免役之害，不知其利"。要让听众同时看到这两面。
  - 苏轼：在 S07 敢问王安石，在 S08 敢顶司马光，并且他在元祐、绍圣、崇宁三朝都吃了亏，最后上了奸党碑。他是这个系列里"对事不对人"的标尺。
  - 蔡京：不要演成脸谱化坏人。他的可怕之处在于"能干"——每一次都是最快、最准地执行上意，并因此受到不同阵营的赏识。
- **役法是非要讲公道**：差役之苦（编户轮役、常致破产，《苏轼传》"編戶充役者不習其役，又虐使之，多致破產"）与免役之弊（"行法者過取，以為民病"）都是史书原话。节目立场：问题在于用"立场"决定政策、用"速度"证明忠诚。
- **易踩的坑**：
  1. 课本年级：《司马光》在三年级上册（第 24 课），《孙权劝学》在七年级下册（第 4 课），《智取生辰纲》在九年级上册（第 22 课）。
  2. 年份：复差役在元祐元年（1086），绍圣恢复雇役在绍圣元年前后（1094），党籍碑 120 人在崇宁元年（1102）、309 人在崇宁三年（1104），毁碑在崇宁五年（1106）。
  3. 正文直接引号为零：上表原文只供核对，写稿一律第三人称转述。
- **标"待核"的条目（开工前补核）**：《续资治通鉴长编》元祐元年蔡京复差役条原文及卷次；《宋史·范纯仁传》"熟讲缓行"原文；《铁围山丛谈》"司马牛"条卷次；王安石卒月（与 S07 共用）；洛蜀党争跑偏素材的史料。
