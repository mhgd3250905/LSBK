## 基本信息

- **选题缘由**：嘉祐二年（1057）的进士考试，欧阳修主考。这一榜里有苏轼、苏辙兄弟，有曾巩，有章惇和他侄子、状元章衡。后来几十年，这些人有的一路做到宰相，有的一路被贬到海南。当年同一张榜上的同年，后来分成了两边。
- **题型**：话题中心型。中心是一张榜：嘉祐二年那一榜。
- **系列归属**：单期。主体是嘉祐二年（1057）这一场考试，尾声一笔到绍圣年间（1094 以后）。
- **话题中心**：嘉祐二年那一榜。围绕它推演四步：欧阳修为什么要借这一场考试改文风 → 苏轼怎么考中、怎么只拿了第二 → 章惇为什么考中了又不要 → 这些同年后来怎么分开。
- **榜的命运线**：主考欧阳修要刷掉"险怪奇涩"的"太学体"，"凡如是者辄黜" → 放榜后，落榜的人等他出门，围在马前起哄，巡街的拦不住 → 苏轼一篇《刑赏忠厚论》让欧阳修想取第一，又怕是门客曾巩写的，放了第二；苏辙十九岁同榜；状元章衡，他叔叔章惇不肯排在侄子后面，"委敕而出"，下一回再考 → "场屋之习，从是遂变" → 几年后苏轼、章惇同游仙游潭，苏轼说"君他日必能杀人" → 将近四十年后章惇当宰相，苏轼兄弟被贬到岭南（只一笔）。
- **照出的时代变局**：北宋后期的党争，两边很多人是在同一个时候、经同一批考官出来的。一场考试能把一代人的文风改掉，却管不了这一代人以后怎么相处。
- **配角**：欧阳修（主考，两句定位从简，他在 S2E02、S2E04 当过主角）、苏轼、苏辙、曾巩、章惇、章衡、梅尧臣（一句）。

## 核心认知反差

- **你以为的**：苏轼一考就是状元；唐宋八大家是一帮志同道合的朋友。
- **实际上的**：苏轼只拿了第二，因为主考怕那篇文章是自己门客写的，避嫌；状元是章衡，听众几乎没听过。同一榜的章惇，后来当宰相，把苏轼兄弟贬到岭南。

## 核心问题

一张榜上考出来的一代人，后来为什么走成了两边？

## 三大基因自检

- [x] **小切口**：一场考试，一张榜。放榜后欧阳修出门，被落榜的人围住。
- [x] **大纵深**：欧阳修知贡举、排抑太学体 → 放榜 → 苏轼第二、苏辙同榜、曾巩中第、章衡状元、章惇委敕 → 场屋之习从是遂变 → 仙游潭 → 绍圣贬谪（一笔）。
- [x] **人性内核**：年轻时一起考中的人，谁都不知道自己以后会站在哪一边。

## 内容弹药（原文已打开，性质按规范第 5 节第 3 条）

1. 欧阳修"知嘉祐二年贡举。时士子尚为险怪奇涩之文，号'太学体'，修痛排抑之，凡如是者辄黜"（**A**：《宋史》卷319 欧阳修传）。
2. 放榜后："向之嚣薄者伺修出，聚噪于马首，街逻不能制；然场屋之习，从是遂变"（**A**：卷319）。
3. 苏轼："得轼《刑赏忠厚论》，惊喜，欲擢冠多士，犹疑其客曾巩所为，但置第二；复以《春秋》对义居第一，殿试中乙科"；"脩语梅圣俞曰：'吾当避此人出一头地。'闻者始哗不厌，久乃信服"（**A**：《宋史》卷338 苏轼传）。
4. 苏辙："年十九，与兄轼同登进士科"（**A**：《宋史》卷339 苏辙传）。
5. 曾巩："中嘉祐二年进士第"（**A**：卷319 曾巩传）；欧阳修早年就赏识他（同卷欧阳修传：曾巩、王安石、苏洵父子"布衣屏处，未为人知，修即游其声誉"）。
6. 章衡："嘉祐二年，进士第一"（**A**：《宋史》卷347 章衡传）。
7. 章惇："进士登名，耻出侄衡下，委敕而出。再举甲科"（**A**：《宋史》卷471 奸臣传 章惇；章惇在《宋史》里列在奸臣传，讲时说清是元人修史的归类，不当节目结论）。
8. 仙游潭："惇平步过之，垂索挽树，摄衣而下，以漆墨濡笔大书石壁曰：'苏轼、章惇来。'"苏轼拊其背曰"君他日必能杀人"，"能自判命者，能杀人也"，"惇大笑"（**A**：卷471；像笔记里的段子，讲时说"《宋史》记了这么一段"；年份待核）。
9. 绍圣年间章惇当宰相、苏轼兄弟南贬（待核具体卷次和年份，只作一笔）。

## 写稿风险提示

1. **名单只报核过的**：苏轼、苏辙、曾巩、章衡、章惇已核（卷338、339、319、347、471）。张载、程颢、吕惠卿通常也算在这一榜，《宋史》本传没写年份，开工时查登科记一类的书再定。
2. **"千古第一榜"之类的说法不用**：没有出处，也是夸张。
3. **苏轼的名次说清**：礼部试《刑赏忠厚论》置第二、《春秋》对义第一、殿试乙科，三件事别混；"差点当状元"不说。
4. **曾巩代考的疑心是欧阳修自己的顾虑**，不是曾巩有什么事，讲时别让人误会。
5. **章惇不脸谱化**：《宋史》把他列进奸臣传是元人修史的定性，本期只摆他做了什么。
6. **年份**：嘉祐二年放榜的月份、仙游潭是哪一年、绍圣南贬的年份，都待核。《长编》这段（卷185 一带）维基文库没有，开工时找别的本子。
