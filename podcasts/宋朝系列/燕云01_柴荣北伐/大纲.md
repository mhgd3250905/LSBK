## 选题评估

**结论**：值得做，适合当燕云十六州系列的第一期。主角立得住，起落大，冷开场和高潮落在同一天；课本钩子（黄袍加身）和大众常识（儿皇帝）现成。主要风险是前史和柴荣身后的事把主角挤出去，对策是前史压到 1 分钟、身后事压成两三句和一个钩子，全期每一段都落在柴荣身上。

### 按主人 10-14 的标准过一遍

| 关 | 本期怎么过 |
| --- | --- |

| 影视化 | 冷开场：瓦桥关行宫宴诸将议取幽州，诸将劝止，他当天就派先锋去固安、自己去安阳水边命人架桥（#22）。高潮：同一天晚上病倒。结尾画面：病倒后第三天，他给瓦桥关、益津关定名雄州、霸州（#31） |

### 好在哪里

1. **一个人的起落就是一部戏**：从被冯道问"能为山否"到高平亲冒矢石，从"若朕身可以济民"到瓦桥关病倒，每一步都有原文，不用编。
2. **反差有原文**：从沧州出兵半个月，关南州县一座接一座开城投降（#21）；赵匡胤是柴荣一手提拔的，连挑殿前诸班的差事都是柴荣给的（#15），点检的位子是他死前四天换上的（#32）。
3. **熟人进门**：儿皇帝、黄袍加身是大众常识，课本七年级下册第 8 课直接接得上。
4. **一根数字线**：936 年帛三十万匹（#3）→ 太祖想攒三五十万赎回来（#29）。下一个三十万在燕云03。
5. **给后面铺路**：柴荣拿回来的关南，后面几期还要被辽国来要（燕云03、05）。这一期把它的来历讲清楚；开封外城是他筑的（#33），燕云07 可以回扣。

### 风险和对策

1. **主角失踪**：前史（936）和身后事（960–978）容易各占几分钟。对策：前史压进破题，两三句；陈桥一笔、杜太后两三句都挂在"七岁的孩子"上；封桩库、太宗看库只做下期钩子，一两句。
2. **笔记多**：王朴"三十年"、病龙台出自宋初笔记，杜太后"幼儿主天下"是金匮之盟那段，点检木头只见《宋史》。对策：讲时都交代出处；病倒按《通鉴》讲，病龙台只当笔记补一笔；考据细节留在史料核对，台前最多一句"史书有两种说法"。
3. **结局压抑**：主角死在高潮之后。对策：第四幕不渲染悲情，靠日子（初五定名、三十回京、初九封王、十五换点检、十九崩）和三尺木头、七岁这几件具体的事撑；结尾画面落在他病中起的名字上。
4. **第三幕流水账**：955–959 四年的事容易排成一串。对策：整幕围绕"王朴排的时间表"和"柴荣不等了"这一对矛盾走，南唐只留半句。

## 幕次细化大纲

### 第一幕：能为山否（含冷开场与报幕；959 冷开场 → 936 两三句 → 954；预估 6 分钟）
- **核心场景与时间线**：959 年五月瓦桥关、安阳水（冷开场）→ 报幕 → 936 年晋阳求援表（两三句）→ 954 年开封朝堂。
- **内容要点**：
  1. **两段式冷开场**（#22、#21）：
     - `[00:00-01:00]` 大开纯具象冷开场（《通鉴》卷294），要点按顺序：
       - 时间地点：显德六年（959）五月初，瓦桥关行宫；后周皇帝柴荣从沧州出兵才半个月，关南的州县一座接一座开城投降。
       - 宴诸将：他把将领们叫来，议取幽州。（原文是"宴诸将"，别说成庆功宴。）
       - 将领们劝（"四十二天"是将领们的话，见 #22 边界）：陛下离京四十二天，兵不血刃拿下燕南之地，这是不世之功；契丹骑兵都聚在幽州北面，不宜深入。
       - 他不高兴。当天就派先锋都指挥使刘重进先走，去占固安；自己骑马到安阳水边，命人架桥。
       - 落点：天快黑了，他往瓦桥关回走。（停在这里，不说病倒；"离燕云最近"这层意思留给小李或大开在报幕后说，冷开场不下评语。）
       - 写法提醒：纯场景，直接讲故事，不报幕；引语一律第三人称转述。
     - `[01:00-02:00]` 标志性双人报幕 + 破题：
       - 报幕原句（台词里不加引号）：大家好，这里是笑谈历史，我是大开。／我是小李。
       - 破题方向：小李问燕云十六州是什么，顺口说出常识：儿皇帝石敬瑭割给契丹的，后来就再没回来过。大开接：回来过一块，就是刚才开头那个人拿回来的。
  2. **这块地是怎么没的（约 1 分钟，两三句，#1、#3、#4、#5；可选 #16）**：
     - 接法建议：从柴荣这边起，他一直憋着一口气，恨唐末以来中原的地盘一天比一天小（#16），接到"这块地当初是怎么没的"。
     - 只交代三件事：936 年石敬瑭被围在晋阳，自己在求援表里写上称臣、认父、割地，手下当场劝过；他认的"父亲"耶律德光比他小十岁；十六州就是今天北京、天津北部、河北北部到山西大同一带，每年再送帛三十万匹。点出瀛州、莫州两个名字，二十三年后要回来。
     - "儿比梦石郎"（#2）可选，一句轻松处，时间紧删。947 年契丹入汴（#6）不用。
     - 不设主播分歧，不展开石敬瑭这个人。
  3. **柴荣登场**（954，《通鉴》卷290、291，《新五代史》卷12；#7、#9）：
     - 一句交代：947 年刘知远建后汉，951 年郭威建后周。
     - 柴荣两句定位：郭威妻子的侄子，从小在姑母家长大，被郭威收为养子；954 年三十出头即位，刚办完丧事就要亲自上阵。
     - 北汉主刘崇趁丧来攻，契丹派了一万多骑兵来助（援将名字字形待辨，可只说"契丹派来的援将"）。刘崇和郭威有杀子之仇（#9）。柴荣自己说：刘崇是看他年少新立（#8）。群臣都劝别去。
  4. **能为山否**（《通鉴》卷291；#8）：
     - 冯道两句定位：五代换了好几个朝廷都在当宰相的老臣；对新皇帝说话不留情面。
     - 柴荣说唐太宗打天下都是自己去，冯道问：不知陛下能当唐太宗吗？柴荣说以我兵力，破刘崇像大山压鸡蛋，冯道又问：不知陛下能当山吗？柴荣很不高兴，还是出发了。
- **主播分歧**（可选，一两个话轮）：新皇帝该不该亲征。小李站冯道这边：刚即位、刚办完丧事，把自己押上战场太冒险；大开说柴荣看得清自己的处境，刘崇就是冲着他年少新立来的，不去更压不住。两人不必谈拢。
- **主角锚点**：一个被老臣当面看轻的新皇帝，不高兴地出发了。

### 第二幕：高平（954 年三月 → 954 年十月 → 955 年九月，预估 7 分钟）
- **核心场景与时间线**：954 年三月高平巴公原 → 战后行营 → 954 年十月开封 → 955 年九月（两三句）。
- **内容要点**：
  1. **北汉主不要契丹帮忙**（《通鉴》卷291；#10）：北汉主看周军人少，说用汉军就能赢，何必契丹；契丹援将看了周军回来说是强敌，北汉主捋着胡子说机不可失，请您别说话。援将不吭声，很不高兴。
  2. **右军解甲呼万岁**（《通鉴》卷291、《宋史》卷1；#11、#12）：
     - 刚交战，右军主将樊爱能、何徽带骑兵先跑，右军溃散，一千多步兵当场解甲、高呼万岁，投降北汉。这是全期主角最危险的时刻。
     - 柴荣亲自带亲兵冒着箭雨督战。赵匡胤两句定位：当时二十多岁的宿卫将，柴荣身边的禁军军官；这一天他对同伴说，主上危险到这个地步，我们怎能不拼死。他请张永德带兵从高处向西出为左翼，自己带兵为右翼，两人各领两千人冲上去。
     - 北汉骁将张元徽马倒被杀，北汉兵泄了气，大败（#12）。契丹援军一兵没救，全军退走（不说契丹被打败）。
  3. **摔枕叫好，斩七十余将**（《通鉴》卷291；#13、#14）：
     - 柴荣犹豫要不要杀。白天躺在帐里问张永德，张永德说军法不立，就算有百万大军也用不上。柴荣把枕头摔在地上，大声叫好。
     - 收捕樊爱能、何徽及军使以上七十多人，骂他们：你们都是几朝的老将，望风就跑，就是想把我当奇货，卖给刘崇。全部斩首。
     - 赵匡胤升殿前都虞候；他乘胜攻太原城时左臂中了箭。
  4. **兵务精不务多**（954 年十月，《通鉴》卷292；#15）：
     - 司马光说五代的禁军"不走即降"，几个朝廷丢天下多半因为这个；柴荣从高平那天才看清。
     - 他对侍臣说：兵在精不在多，一百个农夫养不起一个甲士，怎么能拿百姓的血汗养这些没用的人；好的坏的不分，谁还肯出力。于是大简诸军，精锐升上军，老弱裁掉；又下诏招天下壮士到京城，让赵匡胤从里面挑最好的编成殿前诸班。
     - 写法提醒：这里只摆事实，不点破结局；适合由小李多问一句"挑兵的是谁"，大开只答"赵匡胤"，不接话。
  5. **若朕身可以济民**（955 年九月，《通鉴》卷292；#17，两三句）：
     - 钱不够用，他下令收民间铜器、佛像，照价给钱，交官铸钱。对侍臣说：佛为了利人，连头和眼睛都舍得布施，要是我这个身子能救百姓，我也不吝惜。司马光评了一句：周世宗算得上仁了，不爱惜自己，爱惜百姓。
     - 用处：给主角一个性格切片，后面"他赌命"有了来由。不讲成为了北伐毁佛（#17 边界）。时间紧可并进柴荣的两句定位。
- **主播分歧**：七十多个将校该不该全杀。小李觉得太狠，打了胜仗还要杀这么多人；大开说"不走即降"是五代的老毛病，柴荣不立这个规矩，下一仗还会有人解甲呼万岁。两人不必谈拢。
- **主角锚点**：差点死在自己人手里的皇帝，回来把兵从头练了一遍，挑兵的差事交给了赵匡胤。
- 【给写稿人】本幕结尾停在事件上（挑兵的人、铸钱那句话），不做阶段总结，不提示"后面还要用"。

### 第三幕：不及一旅（955 → 959 年三月 → 五月初二，预估 8 分钟）
- **核心场景与时间线**：955 年王朴献《平边策》→ 958 年南唐（半句）→ 959 年三月王朴灵前 → 四天后下诏 → 四月沧州出兵、关南开城、野地宿营 → 五月初二瓦桥关当夜。
- **主线**：王朴给他排了时间表，他没按时间表等。
- **内容要点**：
  1. **王朴排的时间表**（《通鉴》卷292、《五代史补》卷5；#16、#18）：
     - 高平之后，柴荣有了削平天下之志。王朴两句定位：柴荣最倚重的谋臣，后来做到枢密使；话说得硬，敢给皇帝排时间表。《平边策》：先取江北、江南，再岭南、巴蜀，南方定了，燕地必望风内附；河东北汉是必死之寇，留到最后。
     - 宋初笔记《五代史补》：柴荣问王朴我能在位几年，王朴说三十年以后的事臣算不出来；柴荣大喜，说那我十年开拓天下，十年养百姓，十年致太平，够了。（交代是笔记；谜底等他死时再揭。）
     - 可选一句（#33）：开封的外城，是他显德三年筑起来的。
  2. **南方半句**（《通鉴》卷294；#19）：三次出征淮南，958 年南唐献出江北最后四州，画江为界。
  3. **王朴灵前，四天后**（959 年三月，《通鉴》卷294；#20）：王朴病逝，柴荣临丧，拿玉钺戳着地，痛哭好几回停不下来。四天后，他下诏北上，十天后离开大梁。排时间表的人不在了，南方还没定，他没再等。
  4. **关南开城**（《通鉴》卷294；#21）：
     - 从沧州带步骑几万直入契丹境内，河北州县凡是车驾没经过的，老百姓都不知道。宁州刺史举城降，益津关守将降，赵匡胤先到瓦桥关，守将姚内斌降，莫州、瀛州刺史也相继举城投降，关南全平。王朴说的燕地望风内附，应验了（适合由小李点出）。
     - 柴荣上岸往西赶路，夜里宿在野地，身边侍卫不满一旅，随从都怕；契丹骑兵成群在左右出没，不敢靠近。
  5. **瓦桥关那天晚上**（《通鉴》卷294；#22）：
     - 只用两三句把开头接上：议取幽州，将领们劝止，他不高兴，派先锋去固安，自己去安阳水边命人架桥。
     - 天黑回瓦桥关。就在这一天，病倒了。契丹那边正派人一天跑七百里去太原催北汉出兵，听说他南归，就罢兵了。
  6. **病龙台**（《五代史补》卷5，笔记；#24，一口气带过）：宋初笔记讲得更像一出戏：他登上一处高坡看六军，一百多个父老捧着牛酒来献，他问这地方叫什么，父老说世代相传叫病龙台；他不说话，上马就走，当夜病倒。（交代：正史只写病了，病龙台是笔记。）
- **主播分歧**：柴荣是不是太急。小李认为，他没等南方平定就北上，跳过了王朴排的次序，又在野地里宿营，是在赌命；而且辽国那边也不是没动静，这一年派了大将迎击，辽穆宗自己也赶到了幽州（#23）。大开认为，前一年辽穆宗还在山里射鹿、不上朝（#23），窗口就这么一段，一停可能就再没机会；但也承认"侍卫不满一旅"确实是在赌。两人不必谈拢。
- **主角锚点**：一个等不及的人，离幽州最近的那天晚上，病倒了。

### 第四幕：最后二十天（含尾声与末幕闭环；959 年五月初五 → 六月十九 → 960 一笔 → 钩子；预估 7 分钟）
- **核心场景与时间线**：959 年五月初五雄州 → 南还路上 → 五月三十大梁 → 六月初九 → 六月十五 → 六月十九滋德殿 → 960 年正月陈桥（一笔）→ 961 年杜太后（两三句）→ 钩子 → 闭环。
- **内容要点**：
  1. **病中定名**（《通鉴》卷294；#31）：病倒后第三天，他下令把瓦桥关改为雄州、益津关改为霸州，还派人去筑霸州城。又过三天，他从雄州南还。只摆事实，不补他怎么想。
  2. **一块三尺长的木头**（《宋史》卷1；#25）：《宋史》记载，回京路上，他翻看各地文书，翻出一个皮口袋，里面一根三尺多长的木头，写着点检作天子。史书只写他觉得奇怪。当时的点检是张永德，高平那天的左翼。【给写稿人】只说"《宋史》记载"，不说木头是谁放的；木头和后面换点检分开说，不用"于是""就"连起来（#25 边界）。
  3. **最后二十天**（《通鉴》卷294、《新五代史》卷12；#32、#26）：
     - 五月三十回到大梁。
     - 六月初九立符皇后，紧接着封儿子宗训为梁王，宗训七岁。
     - 六月十五，殿前都点检加给了赵匡胤，高平那天的右翼；张永德加同平章事。
     - 六月十九，他去世了，三十九岁。从病倒那天算，一个半月。
     - 用日子当节拍，不加心理描写，不用"宿命""命运"一类词。
     - 王朴三十年的谜底（笔记，整句挂在"笔记说"下面，#18）：笔记算他在位五年零六个月，五六三十。十年开拓天下，他只用了五年半。
  4. **陈桥一笔**（《宋史》卷1；#27）：
     - 小李带出课本第 8 课：960 年陈桥兵变、黄袍加身。大开只补三点：出兵的理由是边报北汉勾结契丹入寇；即位二十多天后，镇州报契丹和北汉的兵都退了；小皇帝和符太后被迁到西宫。
     - 回到柴荣：拥立赵匡胤的，就是柴荣从高平以后亲手练出来的禁军；点检的位子，是柴荣死前四天给他的（#15、#32）。只摆事实，不评赵匡胤。
  5. **杜太后的话**（《宋史》卷242；#28，两三句）：第二年（961），赵匡胤的母亲杜太后病重，问他知不知道天下是怎么得的，说正因为周世宗让幼儿主天下。挂在"那个七岁继位的孩子"上。台前只说一句：这段话后人多有怀疑。【给写稿人】燕云02 要回扣这句，台词里不提下一期。
  6. **钩子：没等到的钱，和看着觉得够了的人**（《长编》卷19；#29、#30，一两句）：赵匡胤另开一座库攒钱，说攒满三五十万就去跟契丹谈价赎回燕云，谈不成就拿钱招勇士去打，没等到。他弟弟赵光义刚即位，去看国库，金帛堆得像山，说哥哥总为钱操心，何必呢。三年后，赵光义去打了。【给写稿人】说"国库"，不说"封桩库"，不演兄弟同在库里；"三五十万"不说单位；不引《宋史》的二百万；三十万这根线（936 年帛三十万匹 → 三五十万）可由小李点一句。
  7. **互动问题**（二选一，放在闭环之前）：柴荣要是多活十年，燕云十六州能回来吗？／高平以后柴荣把挑禁军的差事交给赵匡胤，换了你是他，会不会这么用人？
  8. **末幕三轮双人闭环**（AI书写规范 §一.5、§六维度二.3）：
     - ① 小李回扣全期、沉淀情感：建议回到柴荣，从冯道当面问他能不能当山，到瓦桥关那天晚上，到那个七岁继位的孩子；不回到赵光义。
     - ② 大开一句历史注脚：回到画面上，他病倒第三天给瓦桥关起的名字，叫雄州；宋朝接着用了这个名字（#31）。只一句，不定性、不拔高。
     - ③ 小李固定告别语，原句（台词里不加引号）：感谢大家收听本期的《笑谈历史》，我们下期接着聊。
     - 【给写稿人】这一幕最后 3 个话轮写完人工核一遍：顺序是回扣 → 注脚 → 告别语，告别语一字不改；结尾停在雄州这个画面上，不停在悬念上。
- **主播分歧**：金匮之盟可信不可信（压在一两个话轮）。小李怀疑是后来编的；大开认为真伪可以存疑，但宋朝官方流传下来的这个说法里，赵家自己把得天下归因于对方是个孩子。
- **主角锚点**：病床上还在给拿回来的关起名字的人，留下一个七岁的孩子和一个他亲手提拔的点检。
