## 选题评估

**结论**：值得做，适合当燕云十六州系列的第一期。主角立得住，起落大，冷开场和高潮落在同一天；课本钩子（黄袍加身）和大众常识（儿皇帝）现成。主要风险是前史（936 年石敬瑭）容易拖长，把主角挤到后面出场，对策已经落在第一幕。

### 按主人 10-14 的标准过一遍

| 关 | 本期怎么过 |
| --- | --- |
| 一个主角 | 柴荣。石敬瑭只在前史里出场（约 3 分钟），赵匡胤、王朴、冯道都是围着柴荣转的配角 |
| 命运线 | 一个在姑父家长大的养子，三十四岁接过一个将领"不走即降"的后周 → 高平差点送命，回头把禁军从头练起 → 四十二天拿回关南，在离幽州最近的那天病倒 → 三十九岁死，半年后他亲手练的兵、亲手换上的点检拿走了他七岁儿子的江山 |
| 起落 | 第一幕低（新君、被老臣当面看轻）→ 第二幕先险后升（高平）→ 第三幕升到顶又一下摔下来（四十二天、病倒）→ 第四幕落到底（死、七岁、陈桥），尾声留一口气（赵匡胤接着想办法） |
| 见微知著 | 五代的兵换主子像换衣服（#15）；柴荣想用自己练出来的兵终结这个局面，做到了，结果落在赵家手里。燕云差一点回来是因为一个人，没回来也是因为这个人倒下了 |
| 影视化 | 冷开场：瓦桥关庆功宴上议取幽州，诸将劝止，他当天就派先锋去固安、自己去安阳水看造桥（#22）。高潮：同一天晚上病倒。结尾画面：赵匡胤的封桩库，和弟弟站在库里说"何其过也"（#29、#30） |

### 好在哪里

1. **一个人的起落就是一部戏**：从被冯道问"能为山否"到高平亲冒矢石，从"若朕身可以济民"到瓦桥关病倒，每一步都有原文，不用编。
2. **反差有原文**：认父的"儿子"比"父亲"大十岁、割地是石敬瑭自己写进求援表的（前史）；柴荣四十二天兵不血刃；赵匡胤是柴荣一手提拔的，连挑殿前诸班的差事都是柴荣给的（#15）。
3. **熟人进门**：儿皇帝、黄袍加身是大众常识，课本七年级下册第 8 课直接接得上。
4. **一根数字线**：936 年帛三十万匹（#3）→ 太祖想攒三五十万赎回来（#29）。下一个三十万在燕云03。
5. **给后面铺路**：柴荣拿回来的关南，1004 年萧太后来要（燕云03），1042 年辽国又来要（第三部分）。这一期把它的来历讲清楚。

### 风险和对策

1. **前史拖长**：936–947 年的事有六条史料，讲细了主角要十分钟以后才出场。对策：前史压在第一幕前半，约 3 分钟，只讲求援表、"儿比梦石郎"、割地和三十万匹、年龄差；947 年契丹入汴是可选。
2. **笔记多**：王朴"三十年"、病龙台出自宋初笔记，杜太后"幼儿主天下"是金匮之盟那段。对策：讲时都交代出处；病倒按《通鉴》讲，病龙台只当笔记补一笔。
3. **结局压抑**：主角死在高潮之后。对策：第四幕不渲染悲情，靠三尺木头、七岁、点检换人这几件具体的事撑；尾声交给赵匡胤的封桩库，留一口气给下一期。

## 幕次细化大纲

### 冷开场与报幕（预估 2 分钟）
- **内容要点**：
  1. **两段式冷开场**（#22、#21）：
     - `[00:00-01:00]` 大开纯具象冷开场（《通鉴》卷294），要点按顺序：
       - 时间地点：显德六年（959）五月初，瓦桥关行宫；后周皇帝柴荣从沧州出兵才半个月，关南的州县一座接一座开城投降。
       - 庆功宴：他把诸将叫来，议取幽州。
       - 诸将劝（"四十二天"是将领们的原话，见 #22 边界）：陛下离京四十二天，兵不血刃拿下燕南之地，这是不世之功；契丹骑兵都聚在幽州北面，不宜深入。
       - 他不高兴。当天就派先锋都指挥使刘重进先走，去占固安；自己骑马到安阳水边，命人造浮桥。
       - 落点：天快黑了，他往瓦桥关回走。这是中原离燕云最近的一天。（停在这里，不说病倒。）
       - 写法提醒：纯场景，直接讲故事，不报幕；引语一律第三人称转述；不下评语。
     - `[01:00-02:00]` 标志性双人报幕 + 破题：
       - 报幕：用节目固定的双人报幕，大开、小李各一句。
       - 破题方向：小李问燕云十六州是什么，顺口说出常识：儿皇帝石敬瑭割给契丹的，后来就再没回来过。大开接：没回来过不对，回来过一块，就是刚才那个人拿回来的；可这块地当初不是被抢走的，是一个中原人自己开价送出去的。
       - 交代范围：燕云十六州系列从这里开始，第一期的主角是柴荣，从 936 年那张求援表讲起，讲到 960 年他的江山换了姓。

### 第一幕：能为山否（936 前史；954，预估 6 分钟）
- **核心场景与时间线**：936 年晋阳城下、柳林 →（可选）947 年开封、杀胡林 → 954 年开封朝堂。
- **内容要点**：
  1. **晋阳城下的求援表**（《通鉴》卷280；#1）：
     - 石敬瑭两句定位：后唐明宗的女婿、坐镇太原的河东节度使；和新皇帝李从珂互相猜忌，起兵后被后唐大军围在晋阳。
     - 求援表三条：称臣、以父礼事之、事成割卢龙一道及雁门关以北诸州。部将刘知远当场劝：称臣可以，认父太过；多给金帛就足够请动契丹兵，不必许土地，恐怕将来成为中原大患。石敬瑭不听。
     - 契丹主耶律德光收到表大喜，对母亲说前几天刚梦见石郎派使者来，果然来了（#2）。
  2. **柳林册立与三十万匹帛**（《通鉴》卷280；#3–#5）：
     - 德光亲手脱下自己的衣冠给石敬瑭，在柳林筑坛即位，国号大晋；当天割幽、蓟、瀛、莫、涿、檀、顺、新、妫、儒、武、云、应、寰、朔、蔚十六州，每年再送帛三十万匹。
     - 年龄差：石敬瑭生于 892 年，德光生于 902 年，儿子比父亲大十岁（#4）。
     - 十六州在哪：今北京、天津北部、河北北部，一直到山西大同一带（#5）。点出瀛州、莫州两个名字，二十三年后要回来。
  3. **（可选，两三个话轮）契丹吞不下中原**（947，《通鉴》卷286、《新五代史·四夷附录》；#6）：德光打进开封，纵骑打草谷，自己叹中国之人难制；北撤途中病死在杀胡林。时间紧可删。
  4. **柴荣登场**（954，《通鉴》卷290、291，《新五代史》卷12；#7、#9）：
     - 一句交代：947 年刘知远建后汉，951 年郭威建后周。
     - 柴荣两句定位：郭威妻子的侄子，从小在姑母家长大，被郭威收为养子；954 年即位，虚岁三十四，刚办完丧事就要亲自上阵。
     - 北汉主刘崇趁丧来攻，契丹派杨兖带一万多骑兵来助。刘崇和郭威有杀子之仇（#9）。群臣都劝别去。
  5. **能为山否**（《通鉴》卷291；#8）：
     - 冯道两句定位：五代换了好几个朝廷都在当宰相的老臣；对新皇帝说话不留情面。
     - 柴荣说唐太宗打天下都是自己去，冯道问：不知陛下能当唐太宗吗？柴荣说以我兵力，破刘崇像大山压鸡蛋，冯道又问：不知陛下能当山吗？柴荣很不高兴，还是出发了。
- **主播分歧**：石敬瑭到底有没有选择。小李认为，被围城的人开高价是为了让契丹一定来，换谁都一样；大开认为，刘知远当场给了更便宜的方案，割地这一条是石敬瑭自己加的，代价落在十六州百姓头上。两人不必谈拢，一两个话轮就收，别抢主角的时间。
- **本幕落点**：一个被老臣当面看轻的新皇帝，不高兴地出发了。

### 第二幕：高平（954，预估 7 分钟）
- **核心场景与时间线**：954 年三月高平巴公原 → 战后行营 → 954 年十月开封。
- **内容要点**：
  1. **北汉主不要契丹帮忙**（《通鉴》卷291；#10）：北汉主看周军人少，说用汉军就能赢，何必契丹；契丹将杨兖看了周军回来说是强敌，北汉主捋着胡子说机不可失，请您别说话。杨兖不吭声，很不高兴。
  2. **右军解甲呼万岁**（《通鉴》卷291、《宋史·太祖本纪》；#11、#12）：
     - 刚交战，右军主将樊爱能、何徽带骑兵先跑，右军溃散，一千多步兵当场解甲、高呼万岁，投降北汉。这是全期主角最危险的时刻。
     - 柴荣亲自带亲兵冒着箭雨督战。赵匡胤两句定位：当时二十多岁的宿卫将，柴荣身边的禁军军官；这一天他对同伴说，主上危险到这个地步，我们怎能不拼死。他请张永德带兵从高处向西出为左翼，自己带兵为右翼，两人各领两千人冲上去。
     - 北汉骁将张元徽马倒被杀，北汉兵大败。契丹的杨兖一兵没救，全军退走（不说契丹被打败，#12）。
  3. **摔枕叫好，斩七十余将**（《通鉴》卷291；#13、#14）：
     - 柴荣犹豫要不要杀。白天躺在帐里问张永德，张永德说军法不立，就算有百万大军也用不上。柴荣把枕头摔在地上，大声叫好。
     - 收捕樊爱能、何徽及军使以上七十多人，骂他们：你们都是几朝的老将，望风就跑，就是想把我当奇货，卖给刘崇。全部斩首。
     - 赵匡胤升殿前都虞候；他乘胜攻太原城时左臂中了箭。
  4. **兵务精不务多**（954 年十月，《通鉴》卷292；#15）：
     - 司马光说五代的禁军"不走即降"，几个朝廷丢天下多半因为这个；柴荣从高平那天才看清。
     - 他对侍臣说：兵在精不在多，一百个农夫养不起一个甲士，怎么能拿百姓的血汗养这些没用的人；好的坏的不分，谁还肯出力。于是大简诸军，精锐升上军，老弱裁掉；又下诏招天下壮士到京城，让赵匡胤从里面挑最好的编成殿前诸班。
     - 写法提醒：这里只摆事实，不点破结局；适合由小李多问一句"挑兵的是谁"，大开只答"赵匡胤"，不接话。
- **主播分歧**：七十多个将校该不该全杀。小李觉得太狠，打了胜仗还要杀这么多人；大开说"不走即降"是五代的老毛病，柴荣不立这个规矩，下一仗还会有人解甲呼万岁。两人不必谈拢。
- **本幕落点**：挑殿前诸班的差事，交给了赵匡胤。记住这件事。

### 第三幕：四十二天（955–959，预估 8 分钟）
- **核心场景与时间线**：955 年《平边策》→ 955 年九月收铜铸钱 → 958 年长江边（一句）→ 959 年三月王朴灵前 → 三月至五月沧州、瓦桥关、安阳水 → 当夜瓦桥关。
- **内容要点**：
  1. **先南后北**（《通鉴》卷292、《五代史补》卷5；#16、#18）：
     - 高平之后，柴荣有了削平天下之志。王朴两句定位：柴荣最倚重的谋臣，后来做到枢密使；话说得硬，敢给皇帝排时间表。《平边策》：先取江北、江南，再岭南、巴蜀，南方定了，燕地必望风内附；河东北汉是必死之寇，留到最后。
     - 宋初笔记《五代史补》：柴荣问王朴我能在位几年，王朴说三十年以后的事臣算不出来；柴荣大喜，说那我十年开拓天下，十年养百姓，十年致太平，够了。（交代是笔记，谜底留到第四幕。）
  2. **若朕身可以济民**（955 年九月，《通鉴》卷292；#17）：
     - 朝廷很久不铸钱，民间又把铜钱熔了做器皿、佛像，钱越来越少。柴荣下令收民间铜器、佛像，照价给钱，五十天内交官铸钱。
     - 他对侍臣说：你们别因为毁佛犹豫；佛以善道化人，铜像哪里就是佛；我听说佛为了利人，连头和眼睛都舍得布施，要是我这个身子能救百姓，我也不吝惜。司马光评了一句：周世宗可以说是仁了，不爱惜自己而爱惜百姓。
     - 用处：给主角一个性格切片，后面"他赌命"有了来由。不讲成为了北伐毁佛（#17 边界）。
  3. **南方一句带过**（《通鉴》卷294；#19）：三次出征淮南，958 年南唐献出江北最后四州，画江为界。
  4. **王朴灵前**（959 年三月，《通鉴》卷294；#20）：王朴病逝，柴荣临丧，拿玉钺戳着地，痛哭好几回停不下来。几天后他下诏北巡。点出：排时间表的人不在了，他没按"先南后北"等下去。
  5. **北伐四十二天**（《通鉴》卷294、《辽史·穆宗纪》；#21、#23）：
     - 从沧州带步骑几万直入契丹境内，河北州县凡是车驾没经过的，老百姓都不知道。宁州刺史举城降，益津关守将降，赵匡胤先到瓦桥关，守将姚内斌降，莫州、瀛州刺史也相继举城投降，关南全平。呼应王朴的预言：燕地望风内附，应验了（适合由小李点出）。
     - 柴荣上岸往西赶路，夜里宿在野地，身边侍卫不满一旅，随从都怕；契丹骑兵成群在左右出没，不敢靠近。
     - 契丹那边：辽穆宗前一年从七月到九月在山里射鹿，不上朝。
  6. **回到冷开场那一天**（《通鉴》卷294；#22）：
     - 只用两三句把冷开场接上：议取幽州，诸将劝止，他不高兴，派先锋去固安，自己去安阳水看造桥。
     - 天黑回瓦桥关。就在这一天，病倒了。契丹那边正派人一天跑七百里去太原催北汉出兵，听说他南归，就罢兵了。
  7. **病龙台**（《五代史补》卷5，笔记；#24）：宋初笔记讲得更像一出戏：他登上一处高坡看六军，一百多个父老捧着牛酒来献，他问这地方叫什么，父老说世代相传叫病龙台；他不说话，上马就走，当夜病倒。（交代：正史只写"不豫"，病龙台是笔记。）
- **主播分歧**：柴荣是不是太急。小李认为，他没等南方平定就北上，跳过了王朴排的次序，又在野地里宿营，是在赌命；大开认为，窗口就这么几十天，对面皇帝去年还在射鹿，可能一停就再没机会，但也承认"侍卫不满一旅"确实是在赌。
- **本幕落点**：离幽州最近的那天晚上，他病倒了，大军回师。

### 第四幕：点检作天子（959–960，预估 5 分钟，尾声另计）
- **核心场景与时间线**：959 年回京路上 → 六月开封滋德殿 → 960 年正月陈桥（一笔）→ 961 年杜太后病榻。
- **内容要点**：
  1. **一块三尺长的木头**（《宋史·太祖本纪》；#25）：回京路上，柴荣翻看各地文书，翻出一个皮口袋，里面一根三尺多长的木头，写着点检作天子。史书只写他"异之"。当时的点检是张永德，高平那天的左翼；回京后，他把点检换成了赵匡胤，高平那天的右翼。不说木头是谁放的（#25 边界）。
  2. **三十九岁与七岁**（《新五代史》卷12、《五代史补》卷5；#26、#18）：
     - 回京后才封儿子宗训为梁王，宗训七岁。959 年六月柴荣去世，三十九岁。
     - 王朴三十年的谜底（笔记）：柴荣在位五年零六个月，五六三十。十年开拓天下，他只用了五年半。
  3. **陈桥一笔**（《宋史·太祖本纪》；#27）：
     - 小李带出课本第 8 课：960 年陈桥兵变、黄袍加身。大开只补三点：出兵的理由是边报北汉勾结契丹入寇；即位二十多天后，镇州报契丹和北汉的兵都退了；小皇帝和符太后被迁到西宫。
     - 回扣第二幕：拥立赵匡胤的，就是柴荣从高平以后亲手练出来的禁军；点检的位子，是柴荣亲手换给他的（#15、#25）。只摆事实，不评赵匡胤。
  4. **杜太后的解释**（《宋史·后妃传》；#28）：
     - 961 年杜太后病重，问赵匡胤：你知道自己怎么得的天下吗？太后说，正因为周世宗让幼儿主天下；周家要是有个年长的君主，天下哪轮得到你。
     - 交代：这是金匮之盟的出处，真伪历来有争议。这句话下一期还要用：二十五年后，宋朝拿它去看辽国。
- **主播分歧**：金匮之盟可信不可信。小李怀疑是后来编的；大开认为真伪可以存疑，但宋朝官方流传下来的这个说法里，赵家自己把得天下归因于对方是个孩子。
- **本幕落点**：七岁的孩子，和一个他父亲亲手提拔的点检。

### 尾声与下期（预估 2 分钟）
- **内容要点**：
  1. **赵匡胤的存钱库**（《长编》卷19、《宋史·食货志》；#29）：
     - 他另开一座封桩库，私下对近臣说：石晋为了自己，割幽蓟给契丹，让那一方百姓被隔在境外，我很怜悯；等库里攒满三五十万，就派人去跟契丹谈，肯还地还人，这些钱全当赎金；不肯，就拿这些钱招募勇士去打。没等到，976 年他去世了。
     - 接上三十万这根线：石敬瑭用每年三十万匹帛送出去的地，赵匡胤想拿三五十万买回来（适合由小李点出；"三五十万"原文没写单位，不说"两"）。
  2. **赵光义看库**（《长编》卷19；#30）：太宗刚即位去看左藏库，对宰相说：金帛堆得像山，怎么用得完，先帝总为经费操心，何必呢。封桩库改了名。
  3. **下期钩子**：一个攒钱想赎，一个看着钱觉得够打。三年后，赵光义去打了；替他守北边的，是一个刚投降过来的北汉老将，号称无敌。（燕云02）
  4. **互动设计**（二选一）：柴荣要是多活十年，燕云十六州能回来吗？／高平以后柴荣把禁军交给赵匡胤去挑，换了你是他，会不会这么用人？
