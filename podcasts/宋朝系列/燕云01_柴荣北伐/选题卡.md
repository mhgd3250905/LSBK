# 选题卡：燕云01 柴荣：离燕云最近的四十二天（工作标题 A）

> 2026-10-13 建（原燕云01，936–986 一期讲完）；**10-15 按主人 10-14 的标准拆期重写**：原燕云01 有柴荣、杨业两个主角，拆成两期，本期只跟柴荣，杨业那半是燕云02。本卡只做选题与史料方向，**不含台词**；史料逐条边界见同目录 `史料核对.md`（10-15 重编号），四幕结构见 `大纲.md`。选材依据 Notion《澶渊之盟·燕云线 叙事时间线》。

## 基本信息
- **选题缘由**：大家只知道儿皇帝石敬瑭把燕云十六州割了出去，以为从此再没回来过。其实 959 年回来过一块：后周皇帝柴荣北伐，四十二天兵不血刃拿下关南的瀛州、莫州和三关，议取幽州的那天晚上病倒，一个月后死了，三十九岁。半年后，他亲手练出来的禁军、亲手换上的点检赵匡胤，在陈桥把他七岁儿子的江山拿走了。这一期讲燕云是怎么丢的、怎么差一点回来，讲一个人怎么离它最近、又怎么倒在那一天。
- **题型**：系列连载·开篇 / 一个人的命运（新君 → 高平 → 四十二天 → 病倒 → 江山易姓）
- **系列归属**：燕云十六州大系列·第一部分第一期（前史 936，主体 954–959，尾声到 976）。第一部分两期：燕云01 柴荣、燕云02 杨业（979–986，尾声到 998）；第二部分燕云03 澶渊之盟（999–1005）；第三部分（10-15 定四期：燕云04 寇准、05 宋神宗、06 赵良嗣、07 李纲，PR #40）讲盟约之后到北宋覆亡。
- **主角**：柴荣。
- **命运线**：一个在姑父家长大的养子，三十四岁接过一个将领"不走即降"的后周 → 高平差点送命，回头把禁军从头练起 → 四十二天拿回关南，在离幽州最近的那天病倒 → 三十九岁死，半年后他练的兵、他换上的点检拿走了他七岁儿子的江山。
- **照出的时代变局**：五代的兵换主子像换衣服；柴荣用自己练出来的兵差一点终结乱世、拿回燕云，结果落在赵家手里。宋朝从他手里接过了军队、人，和燕云这件没做完的事。
- **配角**：石敬瑭（前史）、冯道、张永德、赵匡胤、王朴、杜太后（第四幕）、赵光义（尾声）。

## 核心认知反差（生死线）
- **你以为的**：
  1. 儿皇帝石敬瑭是个认贼作父的老头，燕云十六州是被契丹逼着割出去的；
  2. 燕云十六州丢了以后，中原再没拿回来过一寸；
  3. 赵匡胤黄袍加身，靠的是自己的兵变手腕。
- **实际上的**：
  1. 石敬瑭生于 892 年，耶律德光生于 902 年，"儿子"比"父亲"大十岁。称臣、认父、割地，是石敬瑭自己写进求援表里的条件；刘知远当场劝过（#1、#4）；
  2. 959 年柴荣北伐，关南州县一个接一个举城投降，拿回瀛、莫二州和三关；议取幽州的当天，他病倒了（#21、#22）；
  3. 赵匡胤是柴荣一手提拔的：高平之后升殿前都虞候，替柴荣挑殿前诸班；959 年柴荣翻出写着"点检作天子"的木头，回京就把点检张永德换成了赵匡胤（#14、#15、#25）。宋朝皇室自己的总结更直白：杜太后说，天下能到赵家手里，正因为周世宗让幼儿主天下（#28，金匮之盟，真伪有争议）。
- **反差的强度自评**：⭐⭐⭐⭐⭐（每一处反转都有原文）

## 核心问题（这期节目回答的一句话问题）
中原离拿回燕云最近的那一次，为什么停在了瓦桥关？
（往里一层：柴荣亲手练出来的兵，为什么最后成了赵家的？）

## 三大基因自检
- [x] **小切口**：一天。959 年五月初二，瓦桥关，议取幽州，当夜病倒。
- [x] **大纵深**：936 割地 → 954 高平、整军 → 955 平边策 → 959 北伐、病倒、去世 → 960 陈桥 → 976 太祖死、太宗看库。
- [x] **人性内核**：一个人拼命练出一支能打的兵，想拿回燕云；兵练成了，人倒下了，兵成了别人的。

## 冷开场方向（只写方向与名场面要素，不写台词）
- **类型**：主角名场面（高潮那一天的前半天）。
- **名场面要素**（《通鉴》卷294；#22）：
  - 显德六年（959）五月初，瓦桥关行宫；从沧州出兵才半个月，关南州县一座接一座举城投降；
  - 庆功宴上议取幽州；诸将说陛下离京四十二天、兵不血刃，这是不世之功，契丹骑兵都聚在幽州北面，不宜深入；
  - 他不高兴，当天就派先锋去占固安，自己到安阳水边命人造浮桥；
  - 天快黑了，他往瓦桥关回走。
- **落点**：这是中原离燕云最近的一天。（不说病倒，留到第三幕。）
- **结构提醒**：两段式规范——大开约 1 分钟具象冷开场，直接讲故事，不报幕；随后进入标志性报幕。冷开场内引语一律第三人称转述。

## 结尾设计 与 系列衔接
- **回扣点**：第四幕陈桥回扣第二幕：拥立赵匡胤的，是柴荣高平以后亲手练的禁军；点检的位子，是柴荣亲手换给他的。
- **尾声**：赵匡胤的封桩库，攒满三五十万去赎燕云，没等到；赵光义看库，"何其过也"。三十万这根线：936 年帛三十万匹 → 太祖想攒的三五十万。
- **下一期怎么接**：一个攒钱想赎，一个觉得够打。三年后赵光义去打了；替他守北边的，是一个刚投降过来的北汉老将，号称无敌（燕云02 杨业）。
- **互动设计**（二选一）：柴荣要是多活十年，燕云十六州能回来吗？／高平以后柴荣把挑禁军的差事交给赵匡胤，换了你会不会这么用人？

## 写稿风险提示（摘要，详见史料核对"证据禁区"）
- 王朴"三十年"、病龙台出自宋初笔记《五代史补》，与正史有出入，讲时交代出处，只用到"当夜病倒"；
- 杜太后"幼儿主天下"是金匮之盟那段，真伪历来有争议；
- "四十二天"是诸将原话，和《通鉴》干支对不上，台词说"将领们说"，不自己算；
- 柴荣收回的是十六州中的瀛、莫二州和关南之地，不说"收复燕云"；病因不推测；
- 不说木头是赵匡胤放的、陈桥边报是假的；烛影斧声不讲；
- 不说"为了北伐毁佛"；不说"燕云一丢中原就无险可守"这类定论。
