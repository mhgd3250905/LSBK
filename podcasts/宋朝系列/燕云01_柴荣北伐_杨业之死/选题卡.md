# 选题卡：燕云01 儿皇帝卖掉的燕云十六州，大宋为什么五十年都拿不回来？

> 2026-10-13 建。系列：燕云十六州大系列·第一期（放在第二季·大宋篇里连载）。本卡只做选题与史料方向，**不含台词**；史料逐条边界见同目录 `史料核对.md`，四幕结构见 `大纲.md`。选材与分期依据 Notion《澶渊之盟·燕云线 叙事时间线》（第一期 936–986，尾声带到 998）。

## 基本信息
- **选题缘由**：澶渊之盟的岁币"银十万两、绢二十万匹"是课本里最熟的数字之一。往前推七十年，936 年石敬瑭为了当皇帝，向契丹称臣、认父、割燕云十六州，每年送帛三十万匹。此后五十年，中原三次想把十六州拿回来：柴荣四十二天兵不血刃拿下关南，病倒在瓦桥关；赵匡胤攒钱想赎，没等到；赵光义两次硬打，高梁河一战《辽史》说他坐驴车逃走，雍熙北伐三路大败，杨业死在陈家谷。本期讲燕云怎么丢的、怎么差一点回来、为什么又打不回来，给第二期澶渊之盟铺好路。
- **题型**：系列连载·开篇 / 战争与人性型（失地 + 两对孤儿寡母 + 名将之死）
- **系列归属**：燕云十六州大系列·第一期（936–986，尾声带到 998）；第二期从 999 年辽军再南下讲到 1005 年澶渊之盟；第三部分讲盟约之后的影响，燕云这块心病怎么一步步长成北宋覆亡的导火索（分几期后面再定）。
- **主角**：上半场柴荣（954–959），下半场杨业（979–986）。石敬瑭、赵匡胤、赵光义、萧太后是配角。

## 核心认知反差（生死线）
- **你以为的**：
  1. 儿皇帝石敬瑭是个认贼作父的老头，燕云十六州是被契丹逼着割出去的；
  2. 燕云十六州丢了以后，中原再没拿回来过一寸；
  3. 赵匡胤黄袍加身，靠的是自己的兵变手腕；
  4. 杨老令公是被奸臣潘仁美害死的，最后撞死在李陵碑上；
  5. 辽国皇帝年幼、太后当家，正好趁机去打。
- **实际上的**：
  1. 石敬瑭生于 892 年，耶律德光生于 902 年，"儿子"比"父亲"大十岁。称臣、认父、割地，是石敬瑭自己写进求援表里的条件；当场刘知远就劝他：称臣可以，认父太过，给金帛就够请兵，不必许以土地，恐怕以后成为中原大患。他没听（《资治通鉴》卷280）；
  2. 959 年柴荣北伐，四十二天兵不血刃收回瀛、莫二州和三关，契丹守将一个接一个举城投降；议取幽州的当天，他病倒了（《资治通鉴》卷294）；
  3. 赵匡胤是柴荣一手提拔的：高平之战后升殿前都虞候；959 年柴荣在北伐路上翻出写着"点检作天子"的木头，回京就把点检张永德换成了赵匡胤（《宋史·太祖本纪》）。宋朝皇室自己的总结更直白：杜太后说，天下能到赵家手里，正因为周世宗让幼儿主天下（《宋史·后妃传》，即"金匮之盟"那段，真伪有争议）；
  4. 潘仁美是小说戏曲里的人物，原型潘美是宋初名将。正史里逼杨业出战、又擅自离开谷口的是监军王侁；朝廷的处分是潘美降三官，王侁除名发配。杨业被擒后，《宋史》说他绝食三日而死，《辽史》说他中流矢落马被擒、伤发不食三日而死，首级还被送去传示诸军；
  5. 萧太后自己也哭过"母寡子弱"，韩德让、耶律斜轸一句"信任臣等，何虑之有"把局面接住了。宋朝以"契丹主少，母后专政"为由三路北伐，岐沟关、陈家谷、君子馆连败三阵，献策的贺令图在君子馆被诱擒。

## 核心问题（这期节目回答的一句话问题）
宋朝的天下得自一对孤儿寡母；二十多年后，宋太宗想趁辽国的孤儿寡母收回燕云，为什么这一次输的是宋朝？
（外层问题：儿皇帝卖掉的燕云十六州，五十年里三次差点回来，为什么都没成？）

## 三大基因自检
- [x] **小切口**：三十万。936 年岁输帛三十万匹 → 太祖封桩库想攒满"三五十万"赎回燕云 → 1005 年岁币银十万两、绢二十万匹，合三十万。
- [x] **大纵深**：936 割地 → 947 契丹入汴又北撤 → 954 高平 → 959 北伐四十二天、柴荣之死 → 960 陈桥 → 976 太祖死、太宗改库 → 979 高梁河 → 982 辽景宗死 → 986 雍熙北伐、杨业之死、君子馆 → 988–998 → （第二期）1004 澶渊。
- [x] **人性内核**：人会拿自己发家的经验去揣度对手。赵家从"幼儿主天下"里得了天下，就认定辽国"主少，母后专政"是机会；可萧太后身边有人扛住了。另一条：被怀疑的人只能拿命自证——杨业那句"业，太原降将，分当死"。

## 结尾设计 与 系列衔接
- **回扣点**：贺令图在君子馆被诱擒——献"契丹主少，母后专政"之策的人，同一年父子俱陷（父亲贺怀浦随杨业北征战死）。两对孤儿寡母在这里合上：959 年那一对，身边握兵的人成了新天子；982 年这一对，身边的人说了句信任臣等，真扛住了。
- **尾声两三句**：988、989 年宋军在唐河、威虏军两次击退辽军；990–998 年九年无大仗（《辽史》记 994 年宋两次遣使求和，辽不许）；997 年宋太宗去世。
- **下一期怎么接**：999 年辽军重新南下，此后几乎年年来；1004 年萧太后和辽圣宗亲征到澶州——回到开场那三根手指。三十万这根线：936 年帛三十万匹 → 太祖想攒的三五十万 → 1005 年银绢三十万。

- 王朴"三十年"、病龙台出自宋初笔记《五代史补》，与正史有出入（笔记说柴荣没回到京城就死了，正史说回京后六月才死），讲时交代出处，只用到"当夜病倒"；
- 杜太后"幼儿主天下"是金匮之盟那段，真伪历来有争议，讲成"《宋史》这样记，后人多有怀疑"；
- 太宗中箭、烛影斧声、萧太后与韩德让的私情都不讲；
- 杨家将是演绎：潘仁美、碰碑、两狼山不当史实；不把潘美讲成奸臣，也不替他全盘开脱；
- 萧太后年龄《辽史》无载，不报；圣宗十二岁（《辽史》）；
- 雁门之战功劳两说（《杨业传》记杨业，《太宗本纪》记潘美）；"主将戍边者多忌之"没点名，不说是潘美；
- 柴荣收回的是十六州中的瀛、莫二州和关南之地，不说"收复燕云"；
- 不说"燕云一丢中原就无险可守"这类定论，地理只讲十六州的范围（今北京、天津北部、河北北部到山西大同一带）。
