## 选题评估

**结论**：值得做。杨业是大众最熟的宋朝武将之一（杨家将、杨老令公），正史里他的死法和戏里很不一样；主角立得住，冷开场和高潮落在同一个谷口，结尾落在同一座城（云州）。主要风险是前十分钟主角容易被太宗的仗挤掉，对策是高梁河压到一两个话轮，第一幕从太原城上的杨业讲起。

### 好在哪里

1. **熟人进门**：杨家将、潘仁美、碰碑是大众常识，正史和戏文对得上又对不上，反差现成。
2. **反差有原文**：逼杨业出战的是监军王侁，先离开谷口的也是王侁（#17、#19）；潘美有失职，够不上陷害（#23、#24）；两部史书都说他三天后死，死法不同（#21、#22）。
3. **一句话撑一期**："太原降将，分当死"（#18）。降将这个身份从第一幕带到第四幕：太原城上卸甲（#30）、谤书（#10）、"得非有他志乎"（#17）。
4. **一座城撑起燕云线**：云州。挂名 → 打下 → 让出 → 赠官又是它（#31、#16、#42、#43）。
5. **给后面铺路**：杨延昭十三年后守遂城（#29 → 燕云03 #6）；设伏的萧挞凛十八年后死在澶州城下（#39 → 燕云03）。

### 风险和对策

1. **主角出场晚**：979 年灭北汉、高梁河都是太宗的仗。对策：冷开场先让杨业出场；第一幕从太原城上的杨业讲起（#30），高梁河压成一两个话轮并交代他不在场。
2. **配角多**：潘美、王侁、刘文裕、曹彬、贺令图、萧太后、耶律斜轸、韩德让。对策：按"人物两句定位清单"出场；曹彬、贺令图只在第三幕各一两句；耶律休哥本期不单独出场。
3. **两说太多变成对账**：降宋、寰州、战死月份、最后三天都有异说。对策：台前每处最多一句"史书有两种说法"，细节全留在史料核对（统一口径第 12 条）；只有"最后三天"做一轮宋辽对照。
4. **戏文的情感预期**：听众带着"潘仁美害死杨令公"进来。对策：第四幕处分和戏文合成一轮，不嘲笑戏文。
5. **结局压抑**：主角死在高潮。对策：不渲染惨烈，靠"望见无人""你们回去报天子"这几个具体画面；末尾交给赠官诏书上的云州和下一期。

### 冷开场与报幕（预估 2 分钟，归第一幕文件）
- **内容要点**：
  1. **两段式冷开场**（#33、#17、#18）：
     - `[00:00-01:00]` 大开纯具象冷开场（《宋史》卷272、《长编》卷27），要点按顺序：
       - 时间地点：雍熙三年（986）夏，代州一带。宋军西路奉命撤回，要护送云、应、寰、朔四州百姓内迁；辽军大队压回了寰州（#33，宋方说萧太后亲自带兵，这一层冷开场不讲）。
       - 撤退前的商量（原文只有"业谓美等曰"，不写军帐）：杨业说辽兵正盛，不能硬拼；从大石路走，让云州百姓先出，朔州百姓进石碣谷，谷口摆强弩、中路骑兵接应，可保万全。监军王侁驳他：带几万精兵还这么胆怯；素来号称无敌，如今见敌不战，莫非另有心思（#17）。
       - 临出发前，杨业流着泪对主帅潘美说：这一去必定不利；自己是太原降将，本该一死，皇上不杀，还给了兵权。他指着陈家谷口，请诸位在这里布下步兵强弩，等他转战到这里就夹击救他，不然一个都回不来（#18）。
       - 落点：约好了，谷口有人。（停在这里，不说结果。）
       - 写法提醒：纯场景，不报幕；引语一律第三人称转述；不下评语；强弩不报数；潘美在这段没有表态，不替他编话。
     - `[01:00-02:00]` 标志性双人报幕 + 破题：
       - 报幕：节目固定的双人报幕原句（见写作交接"撰稿规范对齐"）。
       - 破题方向（要点，不是台词）：小李从评书戏台的版本切入（潘仁美、两狼山、李陵碑；用"评书里讲""戏台上唱的"起头，不用问卷式垫话）→ 大开指出戏文和正史在"谁逼的""怎么死的"两处对不上 → 抛出问题：一个号称无敌的人，为什么说自己本该一死 → 回到七年前太原城下。

### 第一幕：降将（979，预估 5 分钟）
- **核心场景与时间线**：前情一句 → 979 年五月太原城上 → 高梁河（一两个话轮）→ 冬天派往代州。
- **主角锚点**：主子降了，他还在城上；他卸甲那一刻，就是"降将"两个字的来历。
- **内容要点**：
  1. **前情一句**（#3）：上一期结尾，太祖攒钱想赎燕云；太宗即位后看左藏库，说先帝何必这么操心。一个想赎，一个看着满库金帛觉得够打（后半句是节目概括）。
  2. **杨业其人**（#8）：两句定位：北汉名将，二十岁上下就跟着北汉开国的刘崇（上一期高平那个北汉皇帝，高平那天他在不在阵中史书没写），所向克捷，国人叫他无敌；年轻时说自己将来带兵就像放鹰犬追野鸡兔子。那时他姓刘，叫刘继业。
  3. **太原城上**（#30、#4）：
     - 979 年太宗亲征，太原孤城撑不住，五月北汉主刘继元投降。
     - 《长编》正文：主子降了，他还据城苦战；太宗早知道他勇，想活着要他，让刘继元派亲信去叫；他朝北拜了两拜，放声大哭，脱了甲来见。太宗很高兴，让他复姓杨，单名一个业，给了大将军的官。
     - 台前一句两说：《宋史》本传说城快守不住时是他劝主子投降、为了保全城里军民；李焘不信这一说（细节留在史料核对）。
  4. **幽州（一两个话轮）**（#4、#5）：太宗没回开封，带着打完太原的兵直扑幽州；七月高梁河大败（《辽史》说宋主坐驴车逃走，点到就收）。交代：杨业不在这一仗里，史书没写他随征。
  5. **派往代州**（#32）：这年冬天，太宗说他熟悉边事、懂敌情，派他守代州，还私下封了一包财物重重赏他。点出：北边最要紧的门，交给了半年前还在城上跟宋军拼命的人。
- **主播分歧**：他算不算忠。小李先拿《宋史》"劝降保全军民"那一说替他辩护；大开拿出《长编》的另一种经过（主子降了他还在打），小李反过来觉得这样的人才更忠，大开补一层自己的看法：对旧主忠到最后一刻的人，新主子用他也会留一手（主播观点，不当史实）。（对话改变至少一方的看法。）
- **本幕落点**：一个刚卸甲的降将，守着宋朝北边最要紧的门。

### 第二幕：杨无敌（980–982，预估 5 分钟）
- **核心场景与时间线**：980 年三月雁门北口 → 当年十二月（公历已是 981 年 1 月）领云州观察使、谤书封付 → 代州冬天 → 对面：982 年辽景宗死、宋朝请和被退回。
- **主角锚点**：仗打赢了，头衔是一座敌国的城，身后是一摞谤书。
- **内容要点**：
  1. **雁门北口**（#9）：980 年辽军南下雁门，潘美在代州一线，杨业带一支骑兵从西陉出、绕小陉到雁门北口，从北往南打，和潘美前后夹击，辽军大败。从此契丹望见杨业的旗号就退。功劳本纪记在主帅潘美名下，传记写杨业——不说"两部书打架"，留给主播争"功劳算谁的"。骑兵数不报。
  2. **云州观察使**（#31）：这年十二月，朝廷让他兼领云州观察使。点出：云州是燕云十六州之一，这时在辽国手里，头衔是挂名的。
  3. **谤书**（#10）：同一天的记载里，戍边的主将多嫉妒他，有人偷偷上谤书；太宗都不问，把谤书封好交给他本人。"主将"没点名，不说是潘美。
  4. **代州的冬天**（#40）：别人裹毡子，他只穿丝绵袍子露天坐着办军务，旁边不生火，侍从冻得快站不住，他没事人一样；吏民喜欢他，士卒愿意替他卖命。（这是史书的总评，不编具体日子。）
  5. **对面（一两个话轮，适合小李点出对照）**（#11、#12、#36）：982 年辽景宗死，十二岁的儿子即位，太后摄政；她哭着问母寡子弱怎么办，耶律斜轸、韩德让说信任臣等。宋朝这边，《辽史》记了三个月后宋朝派人带着犀带去讲和，辽以没有国书退回。
- **主播分歧**：太宗封谤书给杨业，是信任还是敲打。小李觉得是敲打，再看同一天给的是一个敌国城池的头衔，更像"你去把它打下来"；大开觉得史书是当信任写的。都不当定论。
- **本幕落点**：他挂着云州的名，守着代州的门；对面换了一个十二岁的皇帝。

### 第三幕：拿下四州（986 年春夏，预估 6 分钟）
- **核心场景与时间线**：986 年初献策（一两句）→ 三月出雁门、寰朔应州降、四月拿下云州 → 儿子朔州城下中箭 → 五月应朔老人到开封 → 东路败报 → 诏书弃地迁民 → 辽军压回寰州，接开头。
- **主角锚点**：他挂了六年名的云州，真打下来了；接着他接到的命令，是把它让出去。
- **内容要点**：
  1. **献策（开头一两句）**（#13、#2）：贺令图等人上言契丹主年少、国事决于其母、宠臣当权（《长编》点名韩德让），请趁机取幽蓟，太宗信了。上言的人里有刘文裕，他后来就是西路监军之一（点到为止，不推动机）。杜太后回扣两三句（适合小李想起）：宋朝自己说过，赵家得天下正因为周世宗让幼儿主天下；"宋朝拿这个经验看辽国"是节目推断，台词用"咱们不妨这么看"。
  2. **出雁门**（#14、#31）：太宗的盘算一句带过：东路曹彬声称取幽州、持重缓行，把辽军主力吸走，西路先拿山后。西路主帅潘美，副帅杨业，头衔还是云州观察使。
  3. **全期最高点：连下四州**（#16、#29）：三月寰州刺史开城降、朔州降、应州降，四月拿下云州。儿子杨延昭当先锋，朔州城下一箭穿臂，打得更急；杨业说过这个儿子像他，每次出征都带着。战功记在西路名下，不单记在杨业头上。
  4. **重见天日**（#41）：五月，潘美把应州、朔州的将吏和老人送到开封；老人说陷在边地这么多年，有粮不能吃，有儿子养不活，没想到这把年纪还能重见天日。点出：这时东路已经败了，开封还不知道。
  5. **败报**（#15）：写成消息传到西路那一刻：东路曹彬冒进，诸将听说西路、中路屡屡立功，争着再进，盛夏缺粮，五月岐沟关大败（一句公道话，不全推给曹彬）。东边萧太后亲自带兵到了涿州城下（#34，《辽史》说；"母后专政"的回扣落在这里）。
  6. **转折：诏书**（#42）：诸路班师；朝廷让潘美、杨业带着本部兵，把四州的百姓迁到内地。打下来的城交回去，只带人走（迁民人数最多说"史书记了七万多口人"）。
  7. **辽军压回寰州，接开头**（#33）：辽军大队压回寰州（台前一句两说）。大开一两句接回开头那场商量，不重复细节。
- **主播分歧**：四州打下来又让出去，值不值。小李觉得白打了；大开说朝廷的盘算是东路一败、西路孤悬，守不住，能把人带回来已是保住了一样东西；小李追问：那带人的活儿交给谁、怎么走，正是开头吵起来的地方。
- **本幕落点**：萧太后的兵没到西路，可辽军已经到了寰州；杨业要带着几州百姓从辽军眼皮底下走。

### 第四幕：谷口（雍熙三年夏，公历 986 年 8–9 月；末尾并入，预估 9 分钟）
- **核心场景与时间线**：撤退前的商量（接开头）→ 陈家谷口寅时到巳时 → 杨业午后到天黑 → 被擒、三天 → 处分与戏文（一轮）→ 末尾三轮闭环。
- **主角锚点**：他约好的谷口，空了；他最后三天，两部史书各记一种死法。
- **内容要点**：
  1. **"我先去"**（#17、#18）：补开头没讲的部分：刘文裕附和王侁；杨业说他不是怕死，是时机不利，白白让士兵死伤；既然你们怪我不肯死，我先去。王侁两句定位：监军，皇帝派来盯着将领的人（武臣近侍出身，不讲成文官）。
  2. **谷口无人（全期高潮）**（#19、#20）：
     - 潘美和王侁在谷口列阵，从寅时等到巳时；王侁派人登上托逻台远望，以为契丹败走，想抢功，带兵离开谷口；潘美拦不住，沿河往西南走了二十里；不久听说杨业败了，就带兵撤走。
     - 杨业从中午打到天黑，果然退到谷口，一看没人，捶胸大哭，带着剩下的人再战，身上受伤几十处，还亲手杀了几十上百人；马重伤走不动，被擒，儿子杨延玉战死。
     - 身边还剩一百多人时，他说你们都有父母妻儿，跟我一起死没用，回去报天子吧；大家哭着不肯走；部将王贵箭射完了，拉着空弓又打死几十人，战死；没有一个人活着回来。
  3. **最后三天（只做这一轮宋辽对照）**（#21、#22、#35）：
     - 宋方：被擒后叹息，皇上待他厚，反被奸臣逼着去送死，没脸求活，绝食三天而死（"奸臣"没点名）。
     - 辽方：到一个叫狼牙村的地方，嫌地名不吉，左右再三请才走；中伏，中箭落马被擒，伤口发作不吃东西，三天死，首级传示诸军；斜轸当面问他跟辽国较量三十多年，今天还有什么脸见我，他只说死罪。
     - 收在一句：死法不同，三天相同。"恶其名"点到为止。时间只说雍熙三年夏天。
  4. **处分与戏文（合成一轮）**（#23、#24、#25）：小李抛出评书里的潘仁美 → 大开用处分诏一句回答：诏书说群帅败约、援兵不前；处分最重的是王侁（除名、发配），刘文裕同样除名，潘美降三官 → 潘美一句定位（开国名将，女儿嫁给了太宗的儿子，不推论处分轻重）→ 戏里的两狼山，《辽史》里是狼牙村。
     - 回扣开头：戏里的奸臣是主帅；正史里说"莫非另有心思"、先离开谷口的，是监军。
  5. **末尾（尾声并入，按下面顺序，不单列一幕）**：
     1. **余波**（#29、#39、#37）：朝廷给杨业的儿子们授了官；那天在路上设伏的辽将叫萧挞凛。宋朝再没有大举北伐，辽国十多年没有再大举南下，边上仍有交手（不说"九年无大仗"）。可选一句：那年冬天献策的贺令图也被擒走了（#26）；太宗 997 年去世（#38）。
     2. **下期钩子**（#29 → 燕云03 #6）：999 年辽军又南下，杨延昭守着一座叫遂城的小城。这一回，宋朝的皇帝要自己决定过不过河。
     3. **互动题**（二选一）：如果你是杨业，听到那句"莫非另有心思"，你出不出战？／杨业之死，你觉得该记在潘美还是王侁头上？
     4. **三轮双人闭环**（AI书写规范 §一.5）：
        - 小李：全期回扣与情感沉淀（建议回到谷口和那一百多人，或回到太原城上那一拜；不重复互动题）。
        - 大开：一句话历史注脚，停在画面上：赠官诏书上写的是大同军节度使，大同军就是云州的军号——他活着挂的是云州的名，死了赠的还是云州（#43、#31）。
        - 小李：固定告别语原句（见写作交接）。
- **主播分歧**：杨业之死该算谁的。小李先认定潘美（主帅、谷口是他守的、人是他撤走的）；大开拿出"美不能制"和处分诏，小李修正为"王侁逼战、抢功在先，潘美失职在后"，再追问监军和主帅的权责：监军能逼动副帅，主帅却拦不住监军。（对话真的改变了小李的判断。）
- **本幕落点**：谷口那片空地；末尾停在赠官诏书上的云州。
