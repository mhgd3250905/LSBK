## 基本信息
- **选题缘由**：大家熟悉的杨老令公，是被奸臣潘仁美陷害、在两狼山撞死在李陵碑上的。正史里没有潘仁美，也没有碰碑：他是一个北汉降将，被监军一句"您号称无敌，莫非另有心思"逼上战场，临走流着泪说自己是太原降将、本该一死，指着一个山谷约好接应；打回谷口时，一个人都没有。这一期讲这个降将怎么被宋朝用、怎么被宋朝逼，讲他在两部史书里的两种死法。
- **题型**：系列连载 / 一个人的命运（降将 → 无敌 → 拿下云州 → 奉诏弃地 → 被逼出战 → 谷口无人）+ 戏文与正史
- **系列归属**：燕云十六州大系列·第一部分第二期（主体 979–986，尾声到 999 年钩子）。第一部分两期：燕云01 柴荣（936–959，尾声到 978 太宗看库）、燕云02 杨业；第二部分燕云03 澶渊之盟（999–1005）；第三部分四期（10-15 主人定）：燕云04 寇准、05 宋神宗、06 赵良嗣、07 开封城·最后一年（话题中心型，10-15 定）；05、06、07 都已交 PR。
- **主角**：杨业。
- **命运线**：北汉的"无敌"，在太原城下等来了主子的投降（他是劝降的人还是死战到最后的人，两部书记法不同，#30）→ 降宋后守代州，雁门北口抄后路，契丹望旗而退；挂着一个在辽国手里的"云州观察使"，背后谤书不断 → 986 年北伐，西路连下云、应、寰、朔，云州真打下来了 → 东路一败，诏书让他把四州的人带走、地让出去；辽军压回寰州，他被监军一句"莫非另有心思"逼出战 → 说自己是太原降将、本该一死，约好谷口接应，打回谷口一个人都没有，三天后死。
- **照出的时代变局**：宋初怎么用降将、怎么用兵：皇帝把谤书封给他本人，也派监军盯着他；监军能逼动副帅，主帅拦不住监军。雍熙北伐失败以后，宋朝再没有大举北伐，燕云从"打得下来"变成"守不住、只能把人带回来"。
- **燕云挂钩**（10-16 补，按前置材料规范 §4）：
  1. 杨业 980 年起挂"云州观察使"（《长编》卷21 太平兴国五年十二月丁丑，公历 981 年 1 月；《宋史》卷5 雍熙三年二月仍称"云州观察使杨业"）。云州是十六州之一，当时在辽手里，这是个挂名的头衔（#31）。
  2. 986 年他所在的西路真打进了云、应、寰、朔，这四州都在十六州之内（燕云01 #3、#5；本期 #16）；应、朔老人被送到开封，说没想到还能重见天日（#41）。
  3. 朝廷让他把四州百姓带回来、把地留下，他死在撤出燕云的路上（#42、#19）；死后赠"大同军节度使"，大同军就是云州的军号（#43）。
- **配角**：赵光义、潘美、王侁、刘文裕、萧太后（对面）、耶律斜轸、杨延昭。

## 核心认知反差（生死线）
- **你以为的**：
  1. 杨业是被主帅潘仁美陷害死的；
  2. 杨业撞死在李陵碑上；
  3. 杨业一直是大宋的忠臣良将。
- **实际上的**：
  1. 正史里逼他出战、又抢功先离开谷口的是监军王侁；主帅潘美"不能制"，听说杨业败了也撤走，有失职，够不上陷害；朝廷处分王侁最重（#17、#19、#23、#24）；
  2. 宋方说他被擒后绝食三天而死，辽方说他在狼牙村中箭落马被擒，伤口发作三天而死（#21、#22）；
  3. 他是北汉降将：主子降了以后他还在太原城上打，主子派人来叫才拜哭卸甲（《长编》）；《宋史》则说是他劝的降（#30）。在宋朝守边七年，身后一直有谤书，最后被一句"莫非另有心思"逼上战场。他自己的话是：我是太原降将，本该一死（#10、#17、#18）。
- **反差的强度自评**：⭐⭐⭐⭐⭐（每一处反转都有原文；有异说的地方都写出异说）

## 核心问题（这期节目回答的一句话问题）
一个号称无敌的人，为什么流着泪说自己"本该一死"？
（往里一层：约好的谷口，为什么没有人？）

## 三大基因自检
- [x] **小切口**：一个山谷。雍熙三年（986）夏，陈家谷口，从寅时等到巳时，人走了。
- [x] **大纵深**：979 太原城下 → 980 雁门、云州观察使 → 982 辽景宗死、萧太后摄政 → 986 拿下四州、岐沟关、弃地迁民、陈家谷 → 尾声到 999 年遂城（燕云03）。
- [x] **人性内核**：一个降将拼命想证明自己，最后被一句"莫非另有心思"送上死路。
