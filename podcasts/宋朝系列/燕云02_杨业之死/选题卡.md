> 2026-10-15 建。原燕云01（936–986，一期讲完）有柴荣、杨业两个主角，主人 10-14 定了标准（每期一个故事主角或一个话题中心，有命运起伏、影视化，不排流水账），拆成两期：燕云01 柴荣，本期燕云02 杨业。本卡只做选题与史料方向，**不含台词**；史料逐条边界见同目录 `史料核对.md`（由原燕云01 表第 31–55 条重编，另补一条），四幕结构见 `大纲.md`。选材依据 Notion《澶渊之盟·燕云线 叙事时间线》。原燕云02（澶渊之盟）顺延为燕云03。

## 基本信息
- **选题缘由**：大家熟悉的杨老令公，是被奸臣潘仁美陷害、在两狼山撞死在李陵碑上的。正史里没有潘仁美，也没有碰碑：他是一个北汉降将，被监军一句"您号称无敌，莫非另有心思"逼上战场，临走流着泪说"我是太原降将，本该一死"，指着一个山谷约好接应；打回谷口时，一个人都没有。这一期讲这个降将怎么被宋朝用、怎么被宋朝逼，讲他在两部史书里的两种死法。
- **题型**：系列连载 / 一个人的命运（降将 → 无敌 → 被逼出战 → 谷口无人）+ 戏文与正史
- **系列归属**：燕云十六州大系列·第一部分第二期（主体 979–986，尾声到 998）。第一部分两期：燕云01 柴荣（936–959，尾声到 976）、燕云02 杨业；第二部分燕云03 澶渊之盟（999–1005）；第三部分（10-15 定四期：燕云04 寇准、05 宋神宗、06 赵良嗣、07 李纲，PR #40）讲盟约之后到北宋覆亡。
- **主角**：杨业。
- **命运线**：北汉的"无敌"，太原快守不住时劝主子投降，为的是保全城里军民 → 降宋后守代州，雁门北口背击契丹，契丹望旗而退，背后谤书不断 → 986 年宋朝趁辽国"主少，母后专政"北伐，东路一败，他被监军一句"莫非另有心思"逼出战 → 说自己是太原降将、本该一死，约好谷口接应，打回谷口一个人都没有，三天后死。
- **照出的时代变局**：宋初怎么用降将、怎么用兵：皇帝把谤书封给他本人，也派监军盯着他；监军能逼动副帅，主帅拦不住监军。986 年以后宋辽攻守换位，宋朝从去打变成守。
- **配角**：赵光义、潘美、王侁、萧太后（对面）、贺令图、杨延昭（尾声）。

## 核心认知反差（生死线）
- **你以为的**：
  1. 杨业是被主帅潘仁美陷害死的；
  2. 杨业撞死在李陵碑上；
  3. 杨业一直是大宋的忠臣良将。
- **实际上的**：
  1. 正史里逼他出战、又抢功先离开谷口的是监军王侁；主帅潘美"不能制"，听说杨业败了也撤走，有失职，够不上陷害；朝廷处分王侁最重（#17、#19、#23、#24）；
  2. 《宋史》说他被擒后绝食三天而死，《辽史》说他在狼牙村中箭落马被擒，伤口发作三天而死（#21、#22）；
  3. 他是北汉降将，太原快守不住时劝主子投降；在宋朝守边七年，身后一直有谤书，最后被一句"莫非另有心思"逼上战场。他自己的话是：我是太原降将，本该一死（#8、#10、#17、#18）。
- **反差的强度自评**：⭐⭐⭐⭐⭐（每一处反转都有原文）

## 核心问题（这期节目回答的一句话问题）
一个号称无敌的人，为什么流着泪说自己"本该一死"？
（往里一层：约好的谷口，为什么没有人？）

## 三大基因自检
- [x] **小切口**：一个山谷。986 年七月，陈家谷口，从寅时等到巳时，人走了。
- [x] **大纵深**：979 灭北汉、杨业降宋、高梁河 → 980 雁门 → 982 辽景宗死、萧太后摄政 → 986 雍熙北伐、岐沟关、陈家谷 → 冬君子馆 → 988–998 攻守换位。
- [x] **人性内核**：一个降将拼命想证明自己，最后被一句"莫非另有心思"送上死路。

- 贺令图只说"反缚而去"，不说被杀；
