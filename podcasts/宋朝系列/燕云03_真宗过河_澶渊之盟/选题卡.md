## 基本信息
- **选题缘由**：课本里澶渊之盟就一行字：宋每年给辽银十万两、绢二十万匹。真宗出发前说实在不行一百万也行，使者回来比了三根手指，他以为是三百万，听说是三十万，高兴得不得了。这一期讲这三十万是怎么来的。1004 年秋，萧太后和辽圣宗倾国南下，要的是当年柴荣收回来的关南；宋朝这边，寇准当宰相才两三个月，皇帝真宗一路想往回走，被寇准、高琼一步一步推过了黄河；和谈的信，是一个真宗以为已经战死的旧人写来的。最后地一寸没给，钱一年三十万，誓书写下"各守疆界""各无所求"。一年后，"城下之盟""孤注"两句话把寇准打下了相位，真宗的心病也从这里落下了。
- **题型**：系列连载·第二部分 / 战争与谈判型（亲征 + 和谈 + 被推着走的人）
- **系列归属**：燕云十六州大系列·第二部分（999–1005，尾声带到 1006）。第一部分两期（燕云01 柴荣、燕云02 杨业）讲 936–998 燕云怎么丢、怎么差点回来、为什么打不回来；第三部分（燕云04 起，分期方案待主人选，PR #40）讲盟约之后的影响，燕云这块心病怎么一步步长成北宋覆亡的导火索（分几期后面再定）。
- **主角**：宋真宗（10-15 按"一期一个主角"定为一人）。寇准是在后面推他的人，第二条线是王继忠。萧太后、曹利用、高琼、王钦若、杨延昭是配角。
- **命运线**：一个总要人推的皇帝：想回后宫被拦 → 两张南逃的图摆在面前 → 韦城动摇、南城想住下 → 浮桥上车停住，被高琼捅着抬辇人过了河 → 心里的线是一百万，谈回来三十万，高兴得不得了 → 一年多后被王钦若点破"陛下，寇准之孤注也"。

## 核心认知反差（生死线）
- **你以为的**：
  1. 澶渊之盟是宋朝打了败仗、被逼着花钱买的和平；
  2. 宋真宗御驾亲征，是自己拿的主意；
  3. 辽国大军压境，就是来抢钱的；
  4. 寇准是千古名相，澶渊一战之后功成名就；
  5. 杨家将里的杨六郎、杨四郎都是戏里的人。
- **实际上的**：
  1. 两边谁也没打垮谁。辽军攻瀛州没打下（《辽史》自己写"不克"），绕开了孙全照大开北门的大名，主帅萧挞凛在澶州城北中床子弩而死；辽军也拿下了祁州、德清、通利，一路打到黄河边，宋朝定州的大军奉诏一个多月没赶到。和谈也不是打完才开始的：闰九月王继忠的劝和信就到了开封，比萧挞凛中弩早两个月，李焘明说"挞览死，寇始求和"是错的（《长编》卷57、58，《辽史》）；
  2. 真宗是被推着走的：五封急报之后他想回后宫，被寇准拦住；朝中有人递上金陵、成都两张图；到了韦城，宫里人问"何不速还京师"；到了澶州南城，他想就住在河南岸；车上了浮桥又停住，殿前都指挥使高琼拿挝去捅抬辇人的背（《宋史·寇准传》、《长编》卷57、58）；
  3. 辽国是来要地的，要的是关南，也就是当年石敬瑭割出去、柴荣四十二天拿回来的瀛、莫一带。《宋史》记萧太后的话："晋德我，畀我关南地，周世宗取之，今宜还我。"真宗在王继忠的信到的当天就定了底线：派使者、送财货可以，提关南就断绝和议、亲自去打（《长编》卷57，《宋史·曹利用传》）；
  4. 寇准景德元年八月才拜相，两个月后就碰上这一仗。和约之后一年多，王钦若一句"城下之盟，《春秋》耻之"，再一句"陛下，寇准之孤注也"，寇准就被罢了相（《宋史·寇准传》、《长编》卷62）；
  5. 杨六郎是真人：杨业的儿子杨延昭，999 年冬泼水成冰守住遂城；澶渊议和时他上书说趁辽军人马疲乏截击，"幽、易数州可袭而取"，"奏入，不报"（《宋史·杨延昭传》）。杨四郎是戏，可真有一位宋将，真宗以为他战死了，他却在辽国娶妻、封王，劝成了和约，自己再也没能回家——王继忠（《宋史》《辽史》王继忠传；不说他是杨四郎的原型）。
- **反差的强度自评**：⭐⭐⭐⭐⭐（每一处反转都有原文；浮桥挝背、"何不赋一诗"、"晋德我"、死人来信、"孤注"都是现成的名场面，而且大多出自《长编》）

## 核心问题（这期节目回答的一句话问题）
辽国倾国南下是来要关南地的，宋朝皇帝一路想往回走，最后为什么是地一寸没给、钱一年三十万，而把皇帝推过黄河的寇准，一年后被一句"孤注"打倒？

## 三大基因自检
- [x] **小切口**：一座浮桥。澶州城跨着黄河，南城和北城之间是一座浮桥。999 年冬（咸平二年十二月，公历已是 1000 年 1 月）真宗第一次北巡时到过这座桥；1004 年他的车在这座桥上停住。过不过这座桥，是全期的节点。
- [x] **大纵深**：999 辽军再南下、遂城冰城 → 1003 望都、王继忠陷没 → 1004 八月寇准拜相 → 闰九月金陵成都之议、王继忠来信、王钦若出镇大名 → 十月瀛州 → 十一月大名、北巡、韦城、萧挞凛中弩、过河 → 十二月关南之争、三十万、誓书 → 1005 年初回京、改军名、罪己诏 → 1006 孤注、寇准罢相 → （第三部分）王钦若"唯有封禅泰山"。
- [x] **人性内核**：被人推着赢下来的人，最怕别人提醒他是被推着的。另一条："誓书之外，各无所求"，这句话让两边打仗的人回了家，也让一个人再也回不了家。

## 阵容配置（固定双人）
- **主讲**：大开（把真宗、寇准、王钦若都讲公道：真宗是被推着走的，但"给钱不给地"的底线是他自己定的；寇准有胆，也自矜其功；王钦若请幸金陵，也在大名把城守住了）
- **主持**：小李（代听众说出常识：课本那行字、杨六郎、四郎探母、"孤注一掷"；负责追问"皇帝该不该上前线""到底谁先求和""寇准是不是在赌""为什么不追""三十万是不是太多"）

## 冷开场方向（只写方向与名场面要素，不写台词）
- **类型**：人物名场面（A，建议用）；备选 B：浮桥上停住的御辇（名场面闪前）。
- **A 名场面要素**（《宋史·寇准传》）：
  - 1004 年深秋（传文作"是冬"），开封；辽军大举南下，边关急报一夜送来五封；
  - 宰相寇准一封不拆，照样喝酒说笑；
  - 第二天同僚报给皇帝，真宗大惊，问寇准；寇准说陛下想了结这件事，不过五天，请皇帝去澶州；
  - 同僚吓得想告退，寇准拦住，让他们等皇帝起驾；真宗为难，想回后宫；寇准说陛下一进去，臣就见不着了，大事就完了，请别回去，直接走。
- **A 落点**：一个想回后宫的皇帝，就这样被推上了去黄河的路。
- **B 名场面要素**（《长编》卷58）：1005 年初，澶州南城；李继隆劝皇帝就住南城；寇准、高琼坚请过河，冯拯呵斥，高琼让他作诗退敌；车上了浮桥又停住，高琼举挝捅抬辇人的背。B 只演到车停在桥上、挝举起来为止。
- **结构提醒**：两段式规范——大开约 1 分钟具象冷开场，直接讲故事，不报幕；随后进入标志性报幕。冷开场内引语一律第三人称转述。用 A 的话，出处在报幕后交代一句（只见于《宋史·寇准传》）。冷开场不提三根手指（第四幕完整演），不剧透三十万和誓书。

## 结尾设计 与 系列衔接
- **回扣点**：冷开场是寇准拦住想回后宫的皇帝；结尾是王钦若一句"陛下，寇准之孤注也"。皇帝这才听明白，自己在那一局里是被押上桌的那份赌注。寇准罢相。
- **尾声两三句**：王继忠每见宋使必哭，求回家，真宗答复"誓书约各无所求"；王钦若说要洗耻只有发兵取幽燕，真宗说河北百姓刚免了兵祸，王钦若说那就只有封禅泰山。
- **下一部分怎么接**：第三部分从"唯有封禅泰山"讲起（天书封禅）。可以再留一个钩子：寇准说过几十年后辽国还会生事，庆历二年（1042）辽国果然屯兵边境，又派萧英、刘六符来要关南，最后宋朝又加了岁币（《宋史·富弼传》《食货志》，原文已核，见史料核对）。誓书"有渝此盟，不克享国"这句，第三部分讲海上之盟时再用，本期只念出字面。
- **互动设计**（二选一）：如果你是真宗，到了南城，过不过那座浮桥？／一年三十万，换来宋辽一百多年没有大战，是屈辱还是划算？

## 写稿风险提示（摘要，详见史料核对"证据禁区"）
- 冷开场 A 只见于《宋史·寇准传》，《长编》没收，讲时交代出处；"不过五日"不说应验；
- 李焘辨过的几处按李焘：金陵之议在闰九月朝中（不在澶州）、萧挞凛中弩时真宗还没到、寇准约高琼在韦城、"挞览死，寇始求和"是误；
- 谁先求和、"孤注"是谁说的、王继忠的结局，都两说并陈；"同一份札子"是推断，讲成推断；
- 只说相持，不说宋朝打了败仗，也不说澶州大胜；瀛州"杀伤十余万"不报；岁币占财政多少不报；
- 兄弟之称出自王继忠转达的"愿兄事南朝"，誓书正文没有"兄弟"二字；
- 王继忠不说是杨四郎原型；萧太后与韩德让的私情不讲；日食、日抱珥不讲成预兆；
- 陈瓘把景德和靖康连起来的评论、1042 年关南再起、海上之盟，都是第三部分的材料，本期最多一句。
