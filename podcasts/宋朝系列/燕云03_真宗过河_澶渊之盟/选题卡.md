## 基本信息
- **选题缘由**：课本里澶渊之盟就一行字：宋每年给辽银十万两、绢二十万匹。真宗出发前说实在不行一百万也行；使者回来比了三根手指，内侍以为是三百万，真宗失声说太多；听说是三十万，高兴得不得了。这一期讲这三十万是怎么来的。1004 年萧太后和辽圣宗倾国南下，要的是当年柴荣北伐收回来的关南；宋朝这边，寇准当宰相才两三个月，皇帝真宗一路想往回走，被寇准、高琼一步一步推过了黄河；和谈的信，是一个真宗以为已经战死的旧人写来的。最后地一寸没给，钱一年三十万，誓书写下"各守疆界""各无所求"。一年多后，"城下之盟""孤注"两句话把寇准打下了相位。
- **题型**：系列连载·第二部分 / 战争与谈判型（亲征 + 和谈 + 被推着走的人）
- **系列归属**：燕云十六州大系列·第二部分（999–1005，尾声带到 1006）。第一部分两期（燕云01 柴荣、燕云02 杨业）讲 936–998 燕云怎么丢、怎么差点回来、为什么打不回来；第三部分四期（10-15 定：燕云04 寇准·献天书、燕云05 宋神宗、燕云06 赵良嗣、燕云07 开封城·最后一年〔话题中心型，主人 10-15 定〕，四期都已交 PR）讲盟约之后燕云这块心病怎么一步步长成北宋覆亡的导火索。
- **主角**：宋真宗（一期一个主角）。寇准是在后面推他的人；王继忠是真宗命运里的一面镜子，每次出场都从真宗这边进（以为他死了 → 收到他的信 → 拒绝他回家）。萧太后、曹利用、高琼、王钦若、杨延昭是配角，只在和真宗相关时出场。
- **命运线**：一个总要人推的皇帝：想回后宫被拦 → 两张南逃的图摆在面前 → 韦城动摇、南城想住下 → 浮桥上车停住，被高琼捅着抬辇人过了河 → 心里的线是一百万，谈回来三十万，高兴得不得了 → 一年多后退朝目送寇准，被王钦若一句"陛下，寇准之孤注也"点破。这条命运照出的时代变局：宋朝对辽的路子从此定成"地不给，钱给"，燕云成了誓书里"各守疆界"的那条疆界。

## 核心认知反差（生死线）
- **你以为的**：
  1. 澶渊之盟是宋朝打了败仗、被逼着花钱买的和平；
  2. 宋真宗御驾亲征，是自己拿的主意；
  3. 辽国大军压境，就是来抢钱的；
  4. 寇准是千古名相，澶渊一战之后功成名就；
  5. 杨家将里的杨六郎、杨四郎都是戏里的人。
- **实际上的**：
  1. 这一仗两边谁也没打垮谁。辽军攻瀛州没打下（《辽史》自己写"不克"），大名也没打下，统军萧挞凛在澶州城北中床子弩而死；辽军也拿下了祁州、德清、通利，一路打到黄河边，宋朝定州的大军奉诏一个多月没赶到。和谈也不是打完才开始的：闰九月王继忠的劝和信就到了开封，比萧挞凛中弩早两个月（#10、#13、#14、#17、#19、#23）；
  2. 真宗是被推着走的：五封急报之后他想回后宫，被寇准拦住；朝中有人递上金陵、成都两张图；到了韦城，宫里人问"何不速还京师"；到了澶州南城，他想就住在河南岸；车上了浮桥又停住，高琼拿挝去捅抬辇人的背（#1、#8、#20、#24）；
  3. 辽国是来要地的，要的是关南，也就是当年石敬瑭割出去、柴荣北伐收回来的瀛、莫一带。《宋史》记萧太后说"周世宗取之，今宜还我"。真宗在王继忠的信到的当天就定了底线：派使者、送财货可以，提关南就断绝和议、亲自去打（#11、#31）；
  4. 寇准景德元年八月才拜相，两三个月后就碰上这一仗。和约之后一年多，王钦若一句"城下之盟"，再一句"陛下，寇准之孤注也"，寇准就被罢了相（#2、#41）；
  5. 杨六郎是真人：杨业的儿子杨延昭，999 年冬泼水成冰守住遂城；澶渊议和时他上书说"幽、易数州可袭而取"，"奏入，不报"（#6、#37）。杨四郎是戏，可真有一位宋将，真宗以为他战死了，他却在辽国娶妻、封王，劝成了和约，自己再也没能回家——王继忠（#7、#40；不说他是杨四郎的原型）。
- **反差的强度自评**：⭐⭐⭐⭐⭐（每一处反转都有原文；浮桥挝背、"何不赋一诗"、"晋德我"、死人来信、三根手指、"孤注"都是现成的名场面，大多出自《长编》）

## 核心问题（这期节目回答的一句话问题）
辽国倾国南下是来要关南地的，宋朝皇帝一路想往回走，最后为什么是地一寸没给、钱一年三十万，而把皇帝推过黄河的寇准，一年后被一句"孤注"打倒？
（外层问题：仗没打输，宋朝为什么每年还要给辽国三十万？）

## 三大基因自检
- [x] **小切口**：一座浮桥。澶州城跨着黄河，南城和北城之间是一座浮桥。咸平二年冬（公历已是 1000 年 1 月）真宗第一次北巡时到过这座桥；景德元年他的车在这座桥上停住。过不过这座桥，是全期的节点。
- [x] **大纵深**：999 辽军再南下 → 1003 望都、王继忠陷没 → 1004 八月寇准拜相 → 闰九月金陵成都之议、王继忠来信、王钦若出镇大名 → 十月瀛州、祁州 → 十一月北巡、韦城、萧挞凛中弩、过河 → 十二月关南之争、三十万、誓书（公历已是 1005 年 1 月）→ 回京、罪己诏 → 1006 孤注、寇准罢相。
- [x] **人性内核**：被人推着赢下来的人，最怕别人提醒他是被推着的。另一条："誓书之外，各无所求"，这句话让两边打仗的人回了家，也让一个人再也回不了家。

## 写稿风险提示（摘要，详见史料核对"证据禁区"）
