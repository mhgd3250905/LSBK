## 选题评估

**结论**：值得做。寇准是宋朝人物里大众最熟的几个之一（澶渊、戏里的寇老西），可他后半生几乎没人讲：最早不信天书的人，亲手献了一部假天书回朝；回朝不到一年就被拖下去，死在雷州。主角立得住，转折落在一个具体的动作上（献书），结尾落在一个画面上（犀带、面北再拜）。主要风险是天书年代（1008–1017）主角大多不在场，和 1020 年宫廷斗争人物多、线头乱。

### 好在哪里

1. **熟人进门**：澶渊之盟是课本常识，寇老西是戏台常识（#39）；燕云03 刚讲完他把皇帝推过黄河，听众带着"大忠臣"的印象进来，本期第三幕就让他献假天书。
2. **反差有原文**：《宋史》说"始不信天书者准也"，同一句话后面就是"准从上其书，中外皆以为非"（#19）。门生给他的三条路，他选了最下的那条（#21，B）。
3. **一个动作撑一期**：献书。前面两幕都在给它垫：天书怎么来的（#9、#11）、王旦怎么不说话（#10、#16）、寇准为什么回不去（#13、#15）；后面一幕都在还它的账：替他造天书的周怀政、朱能，最后把他拖下去（#27、#28）。
4. **燕云线有一句硬话**：王钦若"陛下以兵取幽燕，乃可涤耻"，皇帝说河北百姓刚喘口气（#9）。燕云从这一年起不再是要打的地方，变成了一句激将的话，这是整个第三部分的起点。
5. **首尾相扣**：冷开场的丁谓、蒸羊，在第四幕拂须那里有了来由（#23）；"十八年前把皇帝推过黄河"（#1）和结尾"面北再拜"是同一个人的两头。
6. **给下期铺路**：尾声天书随葬（#33）、寇准死后十九年辽国又要关南（#40），燕云05 从富弼进殿开门。

### 风险和对策

1. **天书年代主角不在场**（1008–1017）：对策：第二幕压到 5 分钟左右，按寇准的去向排（陕州 → 泰山 → 大名 → 回朝不到一年 → 河南、永兴），天书的事写成他在外地知道的消息；王旦收珍珠酒作对照，王钦若只讲"以兵取幽燕"和"以人力为之"两句（#9、#10、#13）。
2. **献书的年份和人物两说**（#19）：对策：年份用天禧三年（1019）；出主意的人说"有人"，王旦那一说交代时间对不上；女婿王曙、门生三策带"后来的编年史记"（B）。
3. **1020 年宫廷斗争线头多**（刘皇后、太子监国、杨亿、钱惟演、周怀政、杨崇勋、曹利用、丁谓）：对策：只跟寇准的三个动作：请太子监国（#25）→ 罢相 → 被周怀政牵连（#27）；刘皇后、钱惟演各一两句，杨亿只出名字，杨崇勋只说"有人告密"。
4. **把寇准讲成小人或讲成完人**：对策：献书是他自己选的，宦者传说他"好胜，喜其附己"（#18）照讲；史书没有他参与政变的记载（#27），不能说他谋反。
5. **B 级材料多**（第三、四幕不少细节只见毕沅《续资治通鉴》）：对策：主线用《宋史》本传和本纪能撑住的事，B 级只作补笔，讲时带一句出处，最多五六处。
6. **结局压抑**：对策：不渲染惨，靠犀带、朝服、面北这几个具体动作；最后落在公安县的竹子和下一期的门。

       - 消息：把他贬到这里的丁谓自己也倒了，被贬去更南边的崖州（今海南），要路过雷州（#5）。

### 第一幕：孤注（1006–1007，预估 4 分钟）
- **核心场景与时间线**：1006 年二月朝会后 → 罢相出陕州 → 张咏来访。
- **内容要点**：
  1. **回扣澶渊**（#1，两三句）：上期的南城北城、黄龙旗一句带过，以燕云03 为准。
  2. **孤注**（#2）：王钦若对真宗说城下之盟是耻辱；又说赌钱的人输到快光，把剩下的全押上，叫孤注，陛下就是寇准的孤注。真宗从此待他淡了。景德三年二月他罢为刑部尚书，出知陕州；真宗对新宰相王旦说他"拿国家的官爵赏赐去求虚名"。
     - 小李追问：孤注这话对不对。大开：这是攻击他的话，不当结论；宋人有个评论替他辩，说他哪里是孤注之计（#3，一句）。
  3. **"《霍光传》不可不读"**（#6）：寇准在陕州隆重招待从成都回来的张咏；送到郊外问他有什么指教，张咏只说《霍光传》不可不读。他回去翻，读到"不学无术"，笑了：这是张公在说我。
  4. **人物侧写**（#7，两三句）：年少富贵，爱喝酒，请客关门卸马不让走；家里从不点油灯，厨房厕所都点大蜡烛。
  5. **早有人说过**（#8 第一句）：李沆早年对王旦说，和议好是好，边患一平，恐怕皇帝要渐渐生出侈心。给第二幕开门。
- **主播分歧**：张咏那句话是什么意思。小李觉得是骂他没学问；大开觉得张咏只说了一句，寇准自己认了"不学无术"，可霍光传里还有别的，两人各猜一层，不替张咏定意思（#6 边界）。
- **本幕落点**：功臣出了京城，皇帝那边，有人在想怎么洗掉这个耻。

### 第二幕：天书（1007–1017，预估 5 分钟）
- **核心场景与时间线**：澶渊之后一两年王钦若进言 → 王旦赐酒 → 1008 年正月承天门 → 十月泰山 → 寇准在大名、回朝、又出 → 1017 年王旦临终。
- **内容要点**：
  1. **燕云线的那句话**（#9，放显眼处，不压缩）：王钦若揣摩皇帝不想打仗，偏说：陛下要洗这个耻，只有拿兵去取幽燕。真宗说河北百姓刚免了兵祸，我怎么能干这个，你想想别的。王钦若说：那只有封禅泰山，可以镇服四海、夸示外国；可封禅要有天瑞。又说：天瑞哪能说有就有，前代有拿人力做的，只要皇帝深信、崇奉，昭示天下，就跟真的一样。
     - 点出：燕云在这里第一次被当成一句激将的话说出来；王钦若明知皇帝不肯打才这么说（"谬曰"）。
     - 真宗怕王旦反对；秘阁值夜的老儒杜镐随口说"圣人以神道设教"，皇帝主意定了。
  2. **珍珠酒**（#10）：皇帝召王旦喝酒，赐一坛，说回去和妻儿一起喝；回家打开全是珍珠。从此天书、封禅，王旦不再说不。
  3. **承天门上的黄帛**（#11）：大中祥符元年正月初三，真宗对宰相们说梦见神人许诺降天书；皇城司报告承天门屋角的鸱吻上挂着一卷黄帛。皇帝步行到门下焚香望拜，派两个内侍爬上屋顶捧下来，其中一个叫周怀政（点名，后面要回来）。帛上写着"赵受命，兴于宋，付于恒"，恒是真宗的名字。十月封泰山。
  4. **寇准这些年**（#13，按他的去向讲）：泰山他跟着去了；后来知天雄军（大名府）；1014 年回朝当枢密使，不到一年又罢，他走、王钦若进。皇帝嫌他"刚忿如昔"；王旦说他喜欢人家感恩又要人家怕他。
  5. **王旦和寇准**（#14、#15）：寇准常说王旦坏话，王旦专说寇准好；寇准托人求使相，王旦拒绝，后来照样荐他，寇准知道了自愧不如。寇准在任上过生日搭山棚大宴，被人告到皇帝那里，王旦一句"寇准确实贤能，就是犯傻"替他挡过去。1017 年王旦病危，皇帝问谁能接，他撑起来举着笏板说：莫如寇准。皇帝说：寇准性子刚褊，你再想想别人。
  6. **王旦的后悔**（#16，B 级带出处，可作本幕落点）：他当天书使，每次奉着天书出行都闷闷不乐；临终对儿子说：我别的没有过错，只有没谏天书这一件，罪过赎不了，死后给我剃发穿僧衣入殓（后来的编年史记）。
  7. **史臣一句**（#12，可选，一句）：修《宋史》的人说那些年"一国君臣如病狂然"。
- **主播分歧**：天书到底为了什么。小李觉得就是皇帝自己要面子；大开引史臣的猜测，说有人想拿天书去震住信天的契丹（#12），可这只是猜测，史臣自己也说"计亦末矣"。各留一句。
- **本幕落点**：王旦死了；这十年里最早不信天书的那个人，还在外地。

### 第三幕：献书（1019，预估 6 分钟）
- **核心场景与时间线**：周怀政、朱能（前情）→ 天禧三年三月乾祐山天书 → 四月天书进京、上疏 → 五月寇准来朝、门生三策 → 六月拜相。
- **内容要点**：
  1. **造天书的人**（#18）：周怀政，就是当年爬上承天门的那个内侍，后来天天随侍天书，又管太子东宫的事，权势大，"酷信妖妄"。他引进一个叫朱能的人，在终南山修道观、造符命。朱能做了寇准辖区的巡检。宦者传说：朱能想借寇准的旧名望坐实这件事，寇准好胜，喜欢别人附和自己，多半依着他。
  2. **皇帝要寇准来献**（#19，**全期的转折和高潮**）：
     - 乾祐山"降了天书"。皇帝问大臣，有人说：寇准向来不信天书，让他来献，百姓一定服。《宋史》里出这个主意的是王旦，原话是"最早不信天书的就是寇准"；可王旦这时已经去世一年多，时间对不上（两说，主播交代一句）。
     - 后来的编年史记：寇准起初不肯，他女婿王曙写信劝他，他才答应（B）。
     - 天禧三年三月，寇准奏上：天书降在乾祐山中。《宋史》五个字："中外皆以为非。"
     - 写法提醒：不编寇准怎么想、为什么答应；留给主播分歧。
  3. **天书进京**（#20）：四月，仪仗到琼林苑把天书迎进宫。孙奭上疏骂朱能是奸邪小人，说朝廷上下"痛心疾首，反唇腹非"；后来的编年史还记了他两句：天都不说话，哪来的书？天下人都知道是朱能干的，只有陛下一个人不知道（B）。孙奭骂的是朱能，不说他骂寇准。
  4. **门生的三条路**（#21，B，本幕的落点之一）：五月寇准从永兴进京，临走门生劝他：到河阳就称病，坚决求外放，是上策；进京就揭穿乾祐天书是假的，还能保住一辈子正直的名声，是中策；最下，就是再进中书当宰相。他不高兴，作个揖起身走了。史家补了一句：最后到底招了祸（放到第四幕再回扣）。
  5. **拜相**（#22）：六月，王钦若罢相；四天后，寇准拜中书侍郎、平章事。同一天进中书当参知政事的，是丁谓。回扣第一幕之前李沆的话（#8 第二句）：丁谓是寇准当年一再推荐的人，李沆说这人能让他在人上吗。丁谓在中书事奉寇准很恭谨。
- **主播分歧**：寇准为什么献。小李觉得他就是想回朝，回朝才能做事，献一部假天书换一个宰相，他觉得值；大开觉得《宋史》说的是"好胜，喜其附己"，他未必觉得自己在交换，可"中外皆以为非"，所有人都看见了。两人各留一句，不下结论。
- **本幕落点**：最下的那条路，他走上去了；旁边站着丁谓。

### 第四幕：拂须（1019–1022，预估 8 分钟，尾声另计）
- **核心场景与时间线**：中书会食 → 1020 年真宗中风、密请太子监国、六月罢相 → 七月周怀政之变 → 七八月三贬到道州 → 皇帝问"久不见寇准" → 1022 年二月真宗死、贬雷州 → 回到冷开场。
- **内容要点**：
  1. **拂须**（#23）：中书一起吃饭，羹汤沾了寇准的胡子，丁谓起身慢慢替他擦掉。寇准笑：参政是国家大臣，倒给上司擦胡子？丁谓很惭愧，从此倾轧越来越深。小李插一句"溜须"的说法，大开说那是后来的说法，史书只记了这件事。
  2. **得罪的不止一个**（#24）：澶渊去辽营讲价的曹利用，寇准当面说他"你一个武夫，哪懂这种大体"（B）。丁谓抓他的错处。可以接史臣那句"当面诋毁同僚，缺少包容的度量"（#38 论曰）。
  3. **太子监国**（#25）：真宗中风，刘皇后在宫里管事。寇准找机会单独对皇帝说：太子是众望所归，请传位给他，挑正直的大臣辅佐；丁谓、钱惟演是佞人，不能辅少主。皇帝同意了。寇准让翰林学士杨亿秘密起草表章，请太子监国。事情泄露，天禧四年六月罢为太子太傅、莱国公，离拜相不到一年。怎么泄露的史书没写清楚，不讲醉酒漏言。
     - 可选：钱惟演对皇帝说"朝廷的人分三份，两份都附了寇准"（#26，B，一句）。
  4. **周怀政之变**（#27）：周怀政怕被追究，和弟弟密谋：召几个武官，约好二十五日动手，杀丁谓，复相寇准，奉真宗为太上皇，传位太子。前一晚有人去丁谓家告密，丁谓连夜换了便服坐牛车去找曹利用，第二天上奏。周怀政被斩于城西普安寺。他父亲早骂过他：砍头的小子，终究要连累我。
     - 点出：十二年前爬上承天门屋顶捧天书的那个内侍（#11）。
     - 红线：史书没说寇准参与这次密谋，只说周怀政要"复相寇准"；不能说寇准谋反。
  5. **三道命令**（#28、#29）：七月降太常卿、知相州；八月朱能听说捉他的使者来了，披甲杀了使者造反，兵败在桑林里自缢；寇准再贬，徙安州，又贬道州司马。一个多月里三道命令。当年替他造天书的人，最后把他拖了下去。王曾想替他说话，丁谓一句"居停主人勿复言"堵回去：王曾把房子借给寇准住过（两说，口播只说"贬他的时候"）。
     - 可选：去道州路上，蛮人抢了他的行李，酋长骂"怎么抢贤宰相的行李"，叫人送回去；在道州每天早上照样穿朝服（#30，B，一两句）。
  6. **"吾目中久不见寇准"**（#31）：病中的真宗过了一年多问左右：我怎么好久没见到寇准了？左右没有一个人敢答。《宋史》说他到死都还信寇准和李迪可以托付。
  7. **雷州**（#32）：乾兴元年二月真宗死；十天后，寇准从道州司马再贬雷州司户参军。新皇帝十来岁。回到冷开场：同一年，丁谓也倒了，路过雷州，那只蒸羊（#4、#5）。
- **主播分歧**：寇准是怎么输的。小李认为是丁谓、钱惟演这拨人害他；大开认为史书里先动手的是他（请太子监国、点名说丁谓是佞人），可把他拖到雷州的，是他自己献天书时借的那股力：周怀政、朱能（#18、#27、#28）。史臣的说法是"臣不密则失身"（#38），节目可以问一句：只是不密吗。
- **本幕落点**：十八年前把皇帝推过黄河的人，在雷州给路过的仇人送了一只羊。

### 尾声与下期（预估 3 分钟）
- **内容要点**：
  1. **天书随葬**（#33）：1022 年秋，下诏天书跟着真宗葬进永定陵。修《宋史》的人说：仁宗以天书殉葬，贤哉。
  2. **可选**：枢密院题名石上，有人把寇准的名字凿掉，说"逆准削而不书"（#34，B，一句）。
  3. **犀带**（#35，结尾画面）：天圣元年（1023），他在雷州一年多了。派人去洛阳取来太宗赐的通天犀带；带到了几天，他沐浴，穿上朝服系好带子，面朝北拜了两拜，叫左右赶快铺床，躺下就死了。闰九月初七。
     - 写法提醒：只用这几个动作，不编临终的话；"北面"是朝着开封的方向，可以点一句；不报享年。
  4. **人死了，调令才到**（#36）：五天后，调他去衡州的命令才下，他不知道了。妻子请求归葬洛阳，准了。
  5. **公安的竹子**（#37）：灵柩过荆南公安县，百姓在路边设祭、哭，折竹子插在地上挂纸钱。《宋史》说一个多月后枯竹都长出了笋，百姓给他立了庙（按"《宋史》里这样记"讲）。
  6. **身后**（#38，两三句）：死后十一年平反，谥忠愍；后来仁宗亲笔给他的碑篆了"旌忠"两个字。
  7. **下期钩子**（#40）：寇准死后十九年，1042 年，辽国在边境屯兵，派人来要关南；去辽国谈的人叫富弼。燕云05 从富弼说起，主角是一心要收燕云的宋神宗（结尾不展开）。
