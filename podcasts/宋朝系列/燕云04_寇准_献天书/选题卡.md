## 基本信息
- **选题缘由**：上一期（燕云03）讲完寇准把皇帝推过黄河，大家记住的是一个大忠臣、戏台上的寇老西。他后面十八年几乎没人讲：澶渊回来第二年就被一句"孤注"赶出京城；皇帝不打燕云了，改造天书，《宋史》说最早不信天书的就是他；1019 年，他亲手献上一部朝野都知道是假的天书，换回了宰相；不到一年又被拖下去，死在雷州。
- **题型**：系列连载 / 一个人的命运（功臣 → 罢相 → 献书 → 贬死）+ 正史里的寇准与戏台上的寇老西
- **系列归属**：燕云十六州大系列·第三部分第一期（主体 1006–1023）。全系列七期：燕云01 柴荣、02 杨业、03 澶渊之盟（真宗）、**04 寇准**、05 宋神宗、06 赵良嗣、07 开封城·最后一年（话题中心型，主人 10-15 定）。05、06、07 都已交前置材料 PR。
- **主角**：寇准。
- **命运线**：把皇帝推过黄河的功臣（1004，#1）→ 一句"孤注"罢相，"不学无术"也笑着认了（1006，#2、#6）→ 皇帝不打燕云、改造天书，这十来年他大多在外地，替他说话的王旦死了（1007–1017，#9–#16）→ 亲手献上一部天书，朝野都知道是假的，只有皇帝不疑，他回朝拜相（1019，#19、#22）→ 不到一年罢相，周怀政的密谋把他拖下去，**不到一个月（25 天）里三道命令**，再贬雷州；道州接敕时借来一件短绿衫拜敕（1020–1022，#25–#32、#41）→ 系上太宗赐的犀带，面北再拜而死；**他死后第五天，朝廷才下调他去衡州的命令**（1023，#35、#36）。
- **照出的时代变局**：澶渊之后宋朝不打燕云了，改演太平：天书、封禅，修《宋史》的人说"一国君臣如病狂然"（#12）。这套戏里，能打仗、敢顶撞的人没有位置；最硬的寇准也得献一部假天书才回得去，回去靠的是造天书的那拨人，最后也被那拨人拖下去（#18、#27、#28）。
- **和燕云线怎么挂上**：王钦若对真宗说，要洗城下之盟的耻，只有拿兵去取幽燕；真宗说河北百姓刚喘口气，那就封禅，天瑞可以人做（#9）。**这一整段归本期**（燕云03 尾声停在孤注罢相）。燕云从这里起变成一句激将的话，第三部分从这里开门；下一次有人认真想打，是燕云05 的宋神宗。
- **配角**：真宗、王钦若、王旦、丁谓、周怀政（贯穿：1008 年捧天书，1020 年政变）、朱能；刘皇后、曹利用、李迪、王曾、张咏、李沆、孙奭各一两句。

## 核心认知反差（生死线）
- **你以为的**：
  1. 寇准一辈子刚直，对天书这种事一定是反对到底的；
  2. 寇准是被奸臣丁谓一手害死的；
  3. 寇准晚年凄凉，死得窝囊。
- **实际上的**：
  1. 《宋史》说最早不信天书的就是他，可 1019 年他亲手献了一部朱能造的天书，《长编》说朝野都看出是假的，只有皇帝不疑（#19）；门生劝他称病、或者揭穿，他选了"再入中书"（#21，《长编》正文，原出《湘山野录》）；
  2. 丁谓确实算计他（#23、#24、#43），可把他一路拖到雷州的，还有他自己献天书时借来的那股力：周怀政政变失败、朱能杀使者造反，每一次都追到他身上（#27、#28）；史书没有他参与政变的记载，李焘说"谋出怀政，准未必知"（#25）；
  3. 道州接贬雷州的敕书，中使马前挂着剑，他借件短绿衫拜了敕，回席接着喝（#41）；在雷州给路过的仇人送了一只羊，关门不让家僮报仇（#4）；死前取来太宗赐的犀带，沐浴、朝服、面北再拜（#35）。
- **反差的强度自评**：⭐⭐⭐⭐⭐（献书和"中外皆以为非"在同一段本传里）

## 核心问题（这期节目回答的一句话问题）
最早不信天书的人，为什么亲手献上了一部天书？
（往里一层：他献了，换回来的是什么？）

## 三大基因自检
- [x] **小切口**：一部天书。1019 年三月，陕西乾祐山，由寇准奏上。
- [x] **大纵深**：1004 澶渊 → 1006 孤注罢相 → 1007 王钦若"以兵取幽燕" → 1008 承天门天书、封泰山 → 1014–1015 回朝又出 → 1017 王旦死 → 1019 献书拜相 → 1020 罢相、周怀政之变、25 天三道命令 → 1022 真宗死、道州拜敕、贬雷州 → 1023 卒（1042 关南再起只一句，归下期）。
- [x] **人性内核**：一个一辈子不肯低头的人，为了回去，低了一次头；回去以后，低头借来的东西把他拖了下去；他在最低处，还是把朝服穿好了。
