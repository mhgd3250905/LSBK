## 选题评估

**结论**：值得做。宋神宗在大众印象里是"王安石变法那个皇帝"，变法讲得很多，他自己的心事讲得很少：他作诗揭在库上，问"何日成戎捷"，修《宋史》的人说他常恨契丹倔强、一心想收回幽燕（#1）；可十八年里，他一次也没跟辽国打过，辽国来要地时他心里想答应（#29），最后按辽国说的分水岭划了界，转去打西夏，在永乐城输得当着大臣哭。主角立得住，开头和结尾都落在库上，转折落在资政殿那一问上（#29）。主要风险是变法、熙河、地界、五路伐夏、永乐，线头多，容易讲成神宗朝大事记；B 级材料（笔记、续通鉴）不少，台前都要带出处。

### 好在哪里

1. **熟人进门、讲的却是另一面**：神宗＝王安石变法，听众熟；本期讲的是变法背后那个"为什么"。修《宋史》的人写他常恨契丹倔强、一心想收回幽燕，聚金帛、作诗揭库（#1，《宋史》卷165，A）；又说祖宗一直想拿下幽蓟、灵武，几次都败了，神宗一心要洗掉这几代人的耻（#4，B）。
2. **首尾一座库**：开头诗揭在库上，问何日成戎捷（#1）；照《宋史·食货志》的说法，这批库是太祖为燕云攒钱的那座库改的名（#2，不说死）；结尾苏辙说库里的财物堆成山（#45），钱一直在，仗一直没打。
3. **反差有原文**："何日成戎捷"是他自己作的诗（#1）；资政殿上"上意颇欲从敌所请"（#29，A）；"必谓我有图复燕南意"是韩琦替辽国看穿的（#27）。三句放在一起，就是"想"和"不敢"。笔记里还有一道手敕"卿姑如所欲与之"（#25，B），作补笔。
4. **一条"默然"线（10-16 重排）**：富弼劝不言兵，帝默然（#5）→"王安石何如？"富弼默然（#18）→ 吕大忠问关南，一本史书说他没出声，一本说他驳了一句，两本都记着他想答应（#29，两说）→ 永乐败后他对着大臣痛哭，说没有一个人说过不行，紧接着自己又点出两个说过的人（#42，笔记 B）。
5. **燕云03、04 的回声**：1042 年富弼守住的关南（#7–#13），三十多年后在吕大忠嘴里又出现（#29）；富弼"劝用兵者皆为身谋"（#10）接上燕云03 的"孤注"。
6. **给下期铺路**：四十年后徽宗的诏书说照神宗遗训，"能复全燕之境者"封王，兑现的是童贯（#46、#47）；燕云06 从一个燕京人说起。

### 风险和对策

1. **线头太多，讲成神宗朝大事记**：变法只一两句（#19），熙河只讲平戎策的顺序和解玉带（#20、#21）；第三幕压成四个围绕神宗的场面，不按月份排；五路伐夏不报总兵力，只讲灵州一个画面（#38）；每一段落在神宗的一个决定或沉默上。
2. **B 级材料**：手敕（#25）、早朝痛哭和"无一人言"（#42 后半）的源头都是邵伯温笔记，经李焘注引或采入《长编》；三天后（#17）、#5 日期是续通鉴；#4 赞、#45 苏辙是议论。对策：主线用 A 级能撑住的事（富弼本传、曹太后传、韩琦传、沈括传、徐禧传、吕大忠传、《长编》正文），B 级只作补笔，每次带一句出处；全期 B 级控制在八九处。
3. **数字容易出错**：纳/贡、增币、让地里数、永乐伤亡都有两说（史料核对对抗自审第 4、10、14 条）；对策：让地不报里数，伤亡最多一句带过，增币用三处对得上的数。
4. **把神宗讲成怂人或讲成英主**：他真攒钱、真练兵、真开了熙河（#19–#21、#27）；不打燕云有祖母和老臣的劝阻，也有打不起的现实（#22、#28、#38）；想答应辽国、永乐用人是他自己的决定（#29、#39）。不替他下"懦弱"或"雄主"的结论。
5. **和宋朝篇 S2E06–S2E08 撞车**（王安石、苏轼、沈括）：王安石只出"唐太宗何如"和解玉带，新法不展开；沈括只讲天章阁、使辽和永乐被贬，不带乌台诗案；曹太后救苏轼只回扣一句。
6. **1042 年的回忆**：按跨期口径，1042 年（庆历增币、富弼使辽）完整讲归本期，03、04 只留钩子。回忆段约 3 分钟，用神宗问边事、富弼答"二十年口不言兵"这一刻框住：讲的是"坐在他对面的这个老人，二十六年前经历过什么"，讲完回到小殿上的沉默。必留拆国书、献纳之争、"增岁币非臣本志"三处（#12、#13、#16）。

       - 交代范围：燕云十六州这条线，这期讲到宋神宗赵顼，从 1067 年即位讲到 1085 年去世，最后会说到四十年后。不报"系列第几期""第三部分第几期"（编号和期序主人没定）。

#### 第一幕正文
- **核心场景**：1068 年四月初一，内东门小殿，富弼入见；回忆 1042 年用这一刻框住；三天后王安石入对。
- **内容要点**：
  1. **即位**（#3，两三句）：治平四年正月，英宗死，他即位，不到二十岁。两句定位见人物清单。
  2. **富弼入见**（#5）：脚有病，特许坐轿到殿门；皇帝在内东门小殿见他，儿子扶着进来，叫他不用拜，坐着谈到太阳偏西。他问边事，富弼说：陛下刚即位，该先布德行惠，愿二十年嘴里不提打仗。**皇帝没说话**。
     - 小李在这里追问：一个老臣第一次见新皇帝，为什么张口就劝别打仗。大开引出：因为二十六年前，去辽国谈判的就是他。
  3. **回忆：1042 年的关南**（#7、#8，约 3 分钟起，主角视角：这是坐在神宗对面的人身上的旧账）：辽国在边境屯兵，派萧英、刘六符来要关南十县，就是柴荣当年收回来的那块（燕云01）。满朝没人敢去，宰相吕夷简推荐了富弼；欧阳修拿颜真卿出使被杀的事劝阻。富弼进宫叩头：君主忧愁是臣子的耻辱，我不敢惜命。
  4. **在辽廷**（#10、#11，挑着讲）：辽主说宋朝违约；富弼说劝你打仗的人，都是替自己打算，打赢了好处是臣子的，打输了祸是君主的。辽主说要的是祖宗的老地方；富弼说石晋把卢龙给了契丹、周世宗收回关南，都是前朝的事。（"一荣一辱"与"劝用兵者皆为身谋"二选一。）剩下两条路：结亲，或者加钱。
     - 可选：萧英托病不拜，被富弼一句话说得起身（#9）。
  5. **乐寿拆国书**（#12）：第二次出使，走到乐寿，他想：我当使臣没看过国书，要是和口头交代的不一样，事就坏了。拆开一看，果然不一样。掉头赶回京城，下午进宫，换了国书再走。谁改的，史书没说清（不点吕夷简的名）。
  6. **"献"还是"纳"**（#13、#14）：辽国不要结亲了，只要加钱，还要国书上写"献"，不行就写"纳"。辽主说：你们都怕我了，还在乎这两个字？富弼说：唐高祖向突厥借兵时才有过这种叫法，后来颉利被唐太宗抓了，还有这种礼吗？声色俱厉。他回来说：我拼死顶住了，他们气已经折了，可以不答应。朝廷还是给了"纳"字。辽国的史书写成"贡"（台前一句"两国史书记的字不一样"）；每年再加银十万两、绢十万匹，总数到五十万。
  7. **他自己怎么看**（#15、#16）：两次出使，一次听说女儿死了，一次听说儿子生了，都没回家。回来给他升官，他推辞：加岁币不是我的本意，只是朝廷正在打西夏，腾不出手跟辽国较劲，我才没拼死去争。第二年他说：别以为和好了就没事，愿陛下记住这个耻辱，卧薪尝胆。
     - 收回到 1068 年的小殿：二十六年前说卧薪尝胆的人，现在坐在年轻皇帝对面，说二十年口不言兵；皇帝没说话。
  8. **三天后**（#17）：另一个人越级进殿。皇帝问：治国先做什么？他说：先选对方法。皇帝问：唐太宗怎么样？他说：陛下该学尧舜，学太宗干什么。这个人叫王安石。可以点一句：唐太宗就是擒了颉利的那位，富弼在辽廷刚拿他压过辽主。（"三天后"带一句"后来的编年史排的日子"。）
- **主播分歧**：富弼是变了还是没变。小李觉得他老了、怕了，当年要卧薪尝胆，现在劝别打仗；大开拿证据回应：1042 年他就说过加钱是因为"腾不出手"，七年后辽国来要地，他给皇帝的回信是让边臣拿旧图籍据理去争，辽国来打就守，也不主张顺着辽国划（#28，《长编》，A）。他一直不想打，也一直不想白给。不替富弼定性。
- **本幕落点**：老臣劝他二十年别提打仗，他没说话；三天后，他问别人唐太宗怎么样。（过渡到下一段，不做阶段总结，不告别。）

### 第二幕：何待今日（1069–1073，预估 6 分钟）
- **核心场景**：熙宁二年起步的新法（一两句）→ 王韶平戎策 → 1073 年十月紫宸殿受贺 →（未系年）庆寿宫。
- **内容要点**：
  1. **变法为了什么**（#19，两三句）：熙宁二年开始变法。新法是什么不展开（宋朝篇讲过）；只讲它图什么：后来韩琦给皇帝的信里替他概括过：先攒钱、存粮、从百姓里招兵，然后就能鞭笞四夷。
  2. **可选**：富弼当了宰相，和王安石合不来，求退；皇帝问谁接替，他荐文彦博；皇帝半天才说：王安石怎么样？这回是富弼不说话（#18）。
  3. **平戎策**（#20）：王韶，一个考制科没考上、在陕西边上自己跑着打听边事的读书人，上了三篇《平戎策》：要取西夏，先收河湟。大开点出这个顺序：先河湟吐蕃，再西夏，燕云在最后头。先挑软的打。
  4. **解玉带**（#21，第二幕高点）：熙宁五年置熙河路；第二年十月，熙、河、洮、岷、叠、宕几州都拿下了，皇帝在紫宸殿受群臣朝贺，把自己身上系的玉带解下来，赐给王安石。
     - 小李在这里顺势追问：熙河拿下了，他是不是该往北看了。
     - 回声提醒：燕云06 有 1123 年"以收复燕、云，赐王黼玉带"（燕云06 #37），两期形成回声，由燕云06 做回扣；本期不提前说。
  5. **何待今日**（#22，第二幕落点）：有一回（史书没写哪年），他和大臣商量定了要动燕蓟，去庆寿宫告诉祖母曹太后。祖母问：钱粮赏赐备好了吗？兵器士卒精吗？他说：都办好了。祖母说：这事太大，一动就有吉凶；打下来，不过是坐在殿上受一回贺；万一不成，牵连的是百姓，说不清。要是能取，太祖、太宗早取回来了，还等今天？他说：不敢不听。
     - 写法提醒：曹太后两句定位放在这里；"南面受贺"和刚讲的紫宸殿受贺对一句；不编神宗的神情；年份说"有一回"（史料核对对抗自审第 8 条）。
- **主播分歧**：曹太后说得对不对。小李觉得她说得对：太祖太宗都没拿下，凭什么你能；大开觉得这话的毛病就在"何待今日"：照这个道理，什么事都不用做了；可她问的钱粮备了吗、兵精吗，后来的事证明一句都没白问（#38、#40）。两人各留一半。
- **本幕落点**：最得意的那一年，他去找祖母说燕云，回来说的是"敢不受教"。

### 第三幕：让地（1074–1075，预估 7 分钟，四个场面）
- **结构**：不按月份排；四个场面，每个落在神宗的一个决定或一句话上。刘忱、吕大忠、沈括、韩缜只在场面里出场；韩琦七事压成一两句，当"辽国看穿了他"的旁证；诏问四老、张方平、杨文广默认不用（见取舍建议 3）。
- **内容要点**：
  1. **场面一·便殿和手敕**（#24、#25）：熙宁七年，辽国使臣萧禧来说河东的边界不对，要按分水岭划；哪座山都有分水岭，这条线怎么划都行。派去谈的刘忱在枢密院查过档案，对皇帝说本朝没占辽国一寸地，我去了就以死相拒，皇帝点了头。宋人笔记还记着：刘忱出了境，皇帝写了道手敕给他，说辽国理亏了就会发火，你就按他们要的给吧；刘忱没照办（B，带"宋人笔记里记了一笔"，并且这条只作补笔）。
     - 小李在这里把它和开头那首诗对上：同一个人，一边问哪天打个胜仗，一边让使臣照人家要的给。
  2. **场面二·资政殿上那一问**（#29，第三幕转折）：第二年三月萧禧又来，住着不走。皇帝召宰执和刘忱、吕大忠商量，**心里想答应**（"上意颇欲从敌所请"，A）。吕大忠说：派一个使臣来就给五百里，要是哪天派个亲王来要整个关南，陛下也给吗？刘忱说这是社稷大计，请陛下想清楚。这一回他的反应，史书记得不一样：一本说他没出声，一本说他回了一句你这是什么话（台前就这一句，不对版本）。点一句：关南，就是三十三年前富弼守住的那块。结果是两个不肯给的人被撤下来，改派韩缜。
  3. **场面三·天章阁**（#30–#32）：沈括去枢密院翻旧档，找到早年议界的文书：旧界在古长城，辽国现在要的往南多了三十里。皇帝休息日打开天章阁召见他，高兴地说：大臣们不查本末，差点误了国事。赐他一千两银子，派他去辽国。六次谈判只用一句结果：沈括带着随员背熟的几十份文书去辽廷，谈了六次，辽国退了一步，换了要的地方（"理直的一方气壮"一句可留）。回来路上他画了一部《使契丹图》（可选）。
  4. **场面四·划界**（#27、#33，第三幕落点）：这时候他写信问过的老臣有了回音，韩琦说辽国是看出我们要收复燕南了，通高丽、建熙河、练保甲、河北设三十七将，一件件都看在眼里（挑两三件，一两句）。七月，王安石已经回来当宰相，朝廷派韩缜去河东，按辽国说的分水岭划了界，史书说"论者惜之"（不报里数，不用"将欲取之"）。有个御史叹气：按分水岭划界，中原的险要丢了（B，可选）。
- **主播分歧**：是"不敢"还是"不能"。小李觉得是不敢：沈括在辽廷都没让，朝廷回头还是照辽国说的划了；大开觉得是不能：韩琦数的那几件事说明他在准备，可准备好了吗？西边那一仗就是答案。两人不收口，接到下一段。
- **本幕落点**：沈括在辽廷没让，回来朝廷还是按辽国说的分水岭划了界，史书说"论者惜之"。（不说"同一块地他回来让了"，见史料核对证据禁区第 19 条。）

### 第四幕（含尾声与闭环）：永乐城（1081–1085，尾声到 1125，预估 10 分钟，其中尾声与闭环约 3 分钟）

#### 第四幕正文
- **核心场景**：种谔入对 → 灵州一个画面 → 筑永乐 → 开封读奏报 → 夜雨城陷 → 早朝 → 不复用兵。
- **内容要点**：
  1. **"秉常孺子"**（#36）：西夏国主秉常身边有人劝他把黄河以南的地归宋，母亲梁太后知道了，杀了那人，夺了秉常的权。种谔入对说：夏国没人了，秉常是个小孩子，我去拽着他的胳膊拉来。皇帝觉得他豪壮，决意西征。小李在这里追问为什么北边让了往西打；大开：北边打不起，西边看着打得起。
  2. **五路**（#37、#38）：五路大军，每路几万到近十万（不报总数）；带河东一路的宦官王中正誓师时说自己代皇帝亲征（可选）。高遵裕在灵州城下，西夏人决了黄河灌营，又断了粮道，剩下一万三千人；种谔那路断粮、下大雪，逃回塞内的才三万。西夏一个老将的主意：不拦，让他们深入，断粮道。
  3. **筑永乐**（#39）：第二年，徐禧主张在银、夏、宥三州交界的山上筑永乐城，那座山上没有水泉。种谔说：城一定守不住；守不住是死，不听你调遣也是死；死在这里，总比丢了国家的军队、死在外国强。他被调去守延州。两句定位：徐禧，没打过仗、靠议论边事得宠的文官，常说西北唾手可取（A）。
  4. **开封读奏报**（#49，神宗在场的瞬间）：夏兵来了，前线奏报说夏兵看见官军阵整齐，就退了。他看了发愁：没交战，怎么会马上退？后面一定有大军。后来果然。（不编他接着下了什么令。）
  5. **夜雨**（#40，第四幕高潮）：大将高永亨说城小、人少、没水，守不住，被戴上枷送进延州监狱。夏兵渡河，有人说趁他们渡到一半打，徐禧说王师不击鼓不成阵。水寨被夺，挖井挖不出水，士兵渴死大半。最后一夜下大雨，城破，徐禧、宦官李舜举、转运使李稷都死了。伤亡最多一句带过：前线报回来，一万两千多兵没了；《宋史》连民夫算，说二十多万（#41，不单列一段，不对数字）。
     - 写法提醒："渴死"和"大雨"挨着讲就够，不加感叹；夏兵"号称"三十万。
  6. **痛哭**（#42）：他听说徐禧他们死了，哭，吃不下饭（A）。宋人笔记里记，早朝他对着大臣痛哭，叹气说：永乐这件事，没有一个人说过不行（B）。有大臣说我说过，他说你哪说过；接着他自己又说，宫里只有吕公著、外头只有赵卨说过用兵不是好事。大开点破：说过的人还有种谔、高永亨，一个被调走，一个被关进了监狱。
  7. **不复用兵**（#43）：《宋史》说，从这以后，皇帝才知道边臣靠不住，深深后悔，不再用兵。沈括先去救被夏兵袭击的绥德，没赶上救永乐，被贬到均州；后来在润州住了八年，写了《梦溪笔谈》（一句）。
- **主播分歧**：永乐该怪谁。小李怪徐禧：不听劝、不懂兵；大开说史书里怪徐禧的多，可徐禧是皇帝选的，劝他别用徐禧的王安礼，皇帝也没听（#42，B）；"没有一个人说过不行"，是因为说了的人都被拿下了。不收成一句结论。
- **过渡**：西边不打了。北边那件事，他从来没碰过。（过渡句，不做阶段总结，直接接尾声。）

#### 尾声、下期钩子、互动题与三轮闭环（`脚本_第四幕.md` 末段，`--is-last-act`）
- **内容要点**：
  1. **死**（#44）：元丰八年正月病倒，三月死在福宁殿，《宋史》说三十八岁。永乐城败后两年半。不编临终的话，不说"气死""抑郁而死"。
  2. **库**（#45，结尾画面）：他死后第二年，苏辙上奏说：元丰库和内库里的财物堆得像山，都是先帝千方百计攒下、备急用的；积着不用，跟东汉的西园钱、唐朝的琼林大盈库有什么两样。大开把镜头拉回开头那批库（台词说"开头"）：钱一直在攒，诗里问的那一天一直没来。
  3. **遗训和封王**（#46、#47）：四十年后，1125 年，宣和七年六月，徽宗的诏书说，这是神宗留下的遗训：谁能收复整个燕地，就封他王爵。一个宦官照这道诏书封了广阳郡王，他叫童贯。（顺序是"诏书 → 封王"，不说"神宗临终留下一句话"；同年冬天金兵南下最多一句，或者不说。）
  4. **下期钩子**（#48）：燕京是怎么"收回来"的？要从神宗死后又过了二三十年、一个从燕京逃过来的人说起（或干脆不报年数；不说"政和年间"）。燕云06，主角赵良嗣（不展开）。
  5. **互动题**（放在闭环之前）：建议题目：要是你站在资政殿上，听见吕大忠问派个亲王来要整个关南也给不给，你会怎么回？（写稿时可换，但要落在神宗的一个具体处境上，不编听众反馈。）
  6. **三轮双人闭环**（全期唯一一次收口，合成前人工核最后 3 个话轮）：
     - 第 1 轮·小李：全期回扣与情感沉淀，落在"库满了、仗没打"上，带上他自己作的那句诗的意思（不加引号）。
     - 第 2 轮·大开：一句话历史注脚，落成一个画面（建议：那批库上的诗还挂着，四十年后兑现他那句话的，是一道诏书和一个宦官）。
     - 第 3 轮·小李：固定告别语原句（见写作交接"撰稿规范对齐"），一字不改。
     - 结尾停在库的画面上，不停在大开的悬念句或单人陈述上。

## 两位主播的真实分歧（汇总）
1. 富弼是变了还是没变：1042 年要卧薪尝胆，1068 年劝二十年不言兵，1075 年让边臣据图籍去争（第一幕）。
2. 曹太后说得对不对："何待今日"（第二幕）。
3. 是"不敢"还是"不能"：沈括在辽廷没让，朝廷回头还是照辽国说的划了（第三幕）。
4. 永乐该怪谁：徐禧、皇帝，还是"没有一个人说过不行"（第四幕）。
