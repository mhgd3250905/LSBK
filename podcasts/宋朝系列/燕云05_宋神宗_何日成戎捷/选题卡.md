## 基本信息
- **选题缘由**：大家记得宋神宗，是因为王安石变法。很少有人讲他为什么要变法：他在库房门口亲笔题诗"何日成戎捷"，那座库就是太祖攒钱赎燕云的那座。他攒钱、练兵、开熙河，是北宋少有的真想动手的皇帝；可十八年里，他一次也没跟辽国打过，反倒按辽国的意思让了一段边界，转去打西夏，在永乐城输得当着大臣哭。他死后四十年，一个宦官拿着他的遗训封了王。
- **题型**：系列连载 / 一个人的命运（雄心 → 退让 → 惨败 → 遗愿）+ "变法皇帝"背后的另一条线
- **系列归属**：燕云十六州大系列·第三部分第二期（主体 1067–1085，回忆 1042，尾声到 1125）。全系列七期：燕云01 柴荣、02 杨业、03 澶渊之盟（真宗）、04 寇准、**05 宋神宗**、06 赵良嗣、07 李纲。
- **主角**：宋神宗赵顼。
- **命运线**：不到二十岁即位，一心"雪数世之耻"（1067，#3、#4）→ 老臣富弼劝他"二十年口不言兵"，帝默然；三天后他问王安石"唐太宗何如"（1068，#5、#17）→ 变法攒钱练兵，先打河湟，熙河受贺解玉带（1069–1073，#19–#21）→ 祖母曹太后一句"何待今日"，他说"敢不受教"（#22）→ 辽国来要河东地界，他写手敕"姑如所欲与之"，沈括谈下来了，最后还是按辽国的意思划了界（1074–1075，#24–#33）→ 转打西夏，五路无功，永乐城夜雨城陷，他痛哭"无一人言其不可"，从此不再用兵（1081–1082，#36–#43）→ 1085 年死，库里财物山委；遗训"能复全燕之境者"封王，四十年后兑现给了童贯（#44–#47）。
- **照出的时代变局**：燕云在宋朝皇帝心里一直是祖宗的账：太祖攒钱想赎，太宗打输了，真宗改演天书（燕云01–04）。神宗是第一个真准备动手的，可他每走到燕云跟前就停下：怕的是"万一不谐"（#22）、"万一不测"（#26）。北宋到这时已经打不起一场对辽的大仗，连让一段边界都要皇帝亲笔下令（#25、#33）；西边一场永乐之败，就让他不再用兵（#43）。燕云从此成了一句遗训，下一代交给了童贯和一个燕京来的人（燕云06）。
- **和燕云线怎么挂上**：冷开场的库就是太祖攒钱赎燕云的封桩库（#2，燕云01 #29、#30）；1042 年富弼守住的关南（#7–#13）是柴荣收回的地（燕云01），三十多年后在吕大忠嘴里又被提起（#29）；韩琦说辽国以为宋朝"有图复燕南意"（#27）；遗训"能复全燕之境者"（#46）通向燕云06。
- **配角**：富弼（贯穿第一、三幕）、王安石、王韶、曹太后、萧禧、刘忱、韩琦、吕大忠、沈括、韩缜、种谔、徐禧、高永亨；萧英、刘六符、晏殊、文彦博、张方平、杨文广、李舜举、童贯各一两句。

## 核心认知反差（生死线）
- **你以为的**：
  1. 宋神宗是个只管变法、搞经济的皇帝；
  2. 澶渊之盟以后，宋朝皇帝都不想要燕云了；
  3. 想收复失地的皇帝，总会去打一仗。
- **实际上的**：
  1. 他在库门上亲笔写"何日成戎捷"，那座库就是太祖攒钱赎燕云的那座（#1、#2）；变法图的是"聚财积谷，募兵于民"，然后"鞭笞四夷"（#19）；连骂他的修史者都说他"志吞幽蓟"（#4，B）；
  2. 他真准备了：通高丽、开熙河、练保甲、河北设三十七将，辽国都看出来了（#27）；他还和大臣定了议，去跟祖母说要动燕蓟（#22）；
  3. 十八年里他一次也没跟辽国打过：祖母一句"何待今日"他就说"敢不受教"（#22）；辽国来要地，他写信让使臣"姑如所欲与之"（#25，B），最后真让了（#33）。
- **反差的强度自评**：⭐⭐⭐⭐⭐（"何日成戎捷"和"姑如所欲与之"出自同一个人）

## 核心问题（这期节目回答的一句话问题）
一个心里装了十八年燕云的皇帝，为什么一次也没敢碰它？
（往里一层：他怕的是什么？怕到最后，这个梦交给了谁？）

## 三大基因自检
- [x] **小切口**：一座库。元丰初年，景福殿库门上的两首诗，"何日成戎捷"。
- [x] **大纵深**：1042 富弼使辽（回忆）→ 1067 即位 → 1068 富弼"二十年口不言兵"、王安石入对 → 1069 变法 → 1072–1073 熙河、解玉带 →（未系年）曹太后"何待今日" → 1074–1075 河东让地 → 1078 前后库房题诗 → 1081 五路伐夏 → 1082 永乐城 → 1085 崩 → 1086 苏辙"财物山委" → 1125 童贯以神宗遗训封王 → 燕云06。
- [x] **人性内核**：一个人把梦想写在库门上，攒够了钱，却一直在等一个"万一不会出事"的时候；等到最后，梦只剩一句遗训，落到了别人手里。

## 冷开场方向（只写方向与名场面要素，不写台词）
- **类型**：主角名场面（一个物件，一句诗）。
- **名场面要素**（《宋史》卷179；#1、#2）：
  - 元丰初年（约 1078），开封宫里的景福殿库；
  - 皇帝亲笔写一首三十二字的四言诗，一个字做一座库的名字，三十二座库；钱又多了，再开二十座库，又题一首二十字的，最后一句"何日成戎捷"；
  - 这座库就是太祖为赎燕云攒钱的那座（燕云01 #29、#30）。
- **落点**：写这首诗的皇帝，在位十八年，一次也没跟辽国打过。
- **结构提醒**：两段式规范——大开约 1 分钟具象冷开场，直接讲故事，不报幕；随后进入标志性报幕。冷开场内除诗句外，古人原话一律第三人称转述。

## 写稿风险提示
1. **年龄和"十八年"**：即位"不到二十岁"，死时"《宋史》说三十八岁"；"十八年没跟辽打过仗"是节目算法，不说"一辈子没打过仗"（#3、#4）。
2. **童贯封王是 1125、四十年后**，不是 1123（#47）。
3. **B 级带出处**：手敕、诏问、吕大忠、痛哭"无一人言"、晏殊议、"三天后"都只见毕沅《续资治通鉴》（史料核对表头和对抗自审第 5、13、15、19 条）。
4. **两说并陈**：纳/贡（#13、#14）、黄嵬（#32、#33）、让地里数（#33，不报）、永乐伤亡（#41）。
5. **曹太后那番话没有年份**，口播说"有一回"（#22）；"金甲"之类轶事查无出处，不用。
6. **和宋朝篇的重叠**：王安石、新法、乌台诗案、沈括告密都不展开（写作交接"与已做各期的重叠与禁区"）。
