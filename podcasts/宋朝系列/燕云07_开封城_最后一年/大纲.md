## 选题评估

**结论**：值得做，而且适合给燕云系列收尾。"靖康之变"课本里有，听众知道结局（城破、二帝被掳），不知道开封在最后一年被围了两次、第一次是守住的，更不知道中间九个月里城里发生了什么。拿城当中心，有完整的起落：一座没法守的城 → 繁华到不识干戈 → 第一次守住 → 松下来 → 第二次被打开 → 被搬空。主要风险是线头多（两次围城、几十个人名、上百个日子），容易讲成"靖康大事记"；以及容易被某个人物（李纲、郭京）抢走中心。

### 好在哪里

1. **熟人进门、讲门后面的事**："靖康之变"听众熟；本期讲的是那座城被围两次之间的九个月。
2. **首尾一条线**：冷开场城门打开（#1）→ 落点太祖"不出百年"（#4、#5）；第一幕神运石"初得燕地"（#10）→ 第四幕艮岳拆了守城（#41）；第二幕"家家便设一锭金"（#19）→ 尾声"括金未足"杀户部尚书（#46）；第一幕孟元老"不识干戈"（#9）→ 尾声"但成怅恨"（#51）。
3. **反差有原文**："天下城池，岂有如都城者"（#15）；"上下恬然，置边事于不问"（#28）；"有告奸人妄言金人复至以恐动居民者，赏之"（#29）；"府库畜积，为之一空"（#47）。都是 A 级。
4. **给系列收尾**：柴荣筑的外城（#8，燕云01）、"初得燕地"的神运石（#10，燕云06）、二帝北去经过燕京（#49）、张叔夜死在白沟界河（#48）。

### 风险和对策

1. **讲成靖康大事记**：对策：两次围城各挑五六个画面，日子能不报就不报；每一段落在城的一个东西上；金方的进军路线一句带过（"东西两路"）。
2. **李纲抢走中心**：对策：李纲只讲他跟城有关的四下——"天下城池"（#15）、"愿死守"（#16）、被罢和复职（#25、#26）、被送出城（#31）；第四幕只一句在长沙（#43）。不讲他的生平和建炎以后。
3. **郭京抢走中心、变成笑话**：对策：郭京在冷开场出一次，第四幕末尾讲来历（#42），前面先把大雪、兵少、冰裂讲足（#39–#41），说清"他打开的是最后一道口子"（对抗自审第 11 条）。
4. **数字和日子多**：对策：城周、人口、开价、兵数都有边界（对抗自审第 3、5、7–9 条）；两处跨年（宣和七年十二月＝1126 年 1 月、靖康元年闰十一月＝1127 年 1 月）口播尽量说"那年冬天"。
5. **情绪过头**：对策：城破以后不渲染屠杀、掠人；尾声靠"一长串东西"（#47）和"过界河了"（#48）收住，不加煽情话。

## 幕次细化大纲

### 冷开场与报幕（预估 2 分钟）
- **内容要点**：
  1. **两段式冷开场**（#1、#2、#3、#4）：
     - `[00:00-01:00]` 大开纯具象冷开场（《宋史》卷23、卷353 为骨，会编补画面），要点按顺序：
       - 时间地点：靖康元年闰十一月二十五日，换成公历已经是 1127 年 1 月 9 日；开封外城南边偏东的宣化门。外面是护城河，十几丈宽，两岸种着杨柳（#3）。
       - 天气：雪已经连着下了好几天（#2，A）；宋人的记录里说，金军统帅讲，这雪等于给他添了二十万兵（B）。
       - 人和动作：一个自称会"六甲法"的人，让守城的兵全部下城，不许偷看；他自己坐在城楼上。城门大开，他招来的兵冲出去（#1）。
       - 转折：金兵分四路喊着冲上来；出城的兵退回来，掉进护城河，河里填满了尸体，城门急关（#1）。
       - 他对坐在旁边的人说：得我亲自下去作法。下了城，带着剩下的人往南跑了。当天，金兵登上了城墙（#1）。
       - 落点：一百五十年前，宋太祖站在洛阳，想把都城从这里搬走。他没搬成，说了一句话（#4）。
       - 写法提醒：纯场景，不报幕；古人原话第三人称转述；不说郭京的名字也可以（第四幕再交代）；不说"妖人"，说"一个自称会六甲法的人"；不说"开封就这样丢了"（对抗自审第 11 条）。
     - `[01:00-02:00]` 标志性双人报幕 + 破题：
       - 报幕：用节目固定的双人报幕，大开、小李各一句。
       - 破题方向：小李说出常识：靖康之变，开封城破，两个皇帝被抓走。大开接：开封在那一年里被围了两次，第一次是守住了的；同一道城墙，中间只隔了九个月。
       - 交代范围：燕云十六州系列最后一期；这一期不讲哪一个人，讲一座城，开封；从太祖那句话讲起，讲到 1127 年春天。上期结尾那个郭药师，这期第一幕会再出现一次。

### 第一幕：无险之城（976 回忆；1103–1125，预估 7 分钟）
- **核心场景与时间线**：976 年四月洛阳迁都之议 → 991 年汴河决口 → 995 年张洎奏对 →（城墙：956 柴荣筑，1016、1078、1116 修）→ 1103 孟元老到京 → 1117 艮岳 → 1123 神运石 → 1125 年十二月郭药师叛、内禅。
- **内容要点**：
  1. **太祖那句话**（#5，第一幕主场景）：开宝九年（976）四月，太祖到洛阳祭天，住下不想走了；他是洛阳生的，想迁都。将领李怀忠说：东京有汴河运粮，每年运来江淮几百万斛米，京城几十万兵都靠它吃饭；府库和重兵都在这里，根基不能动。晋王说迁都不便，太祖说：先搬洛阳，以后还要搬长安；我要西迁，是想占着山河的险要，把多余的兵裁掉，像周朝、汉朝那样安天下。晋王说：在德不在险。太祖没接话。等晋王出去，他对身边人说：晋王说得好，这次先听他的；不出百年，天下的民力就耗光了。
     - 大开点题：太祖担心的不是城守不住，是为了守这座城要养的兵太多。
     - 不讲半年后太祖之死、"烛影斧声"。
  2. **一条河**（#6、#7）：991 年汴河决口，太宗坐着步辇出宫，走进泥里一百多步，跟着的大臣吓坏了。太宗说：东京养着几十万兵、上百万户人家，天下运来的粮全靠这一条河，我怎么能不管。四年后宰执张洎说：天下的兵马都集中在京城，比汉唐的京城人多十倍；全国一半的财赋走汴河进来。
     - 两句话不报人口数（对抗自审第 3 条）。
  3. **城墙**（#8，两三句）：开封有三道城，外城最早是后周柴荣筑的（回扣燕云01），宋朝增筑、重修、往南展，到最后周长五十里上下；城门大多是三层瓮城。它有墙，没有山，没有险。
  4. **不识干戈**（#9，B）：一个 1103 年随父亲来开封、在这里长大的人后来回忆：太平日子久了，小孩只会打鼓跳舞，头发花白的老人没见过打仗；四海的珍奇都在市上，天下的美味都在厨房里。
     - 小李插一句《清明上河图》可以，大开不展开（对抗自审第 20 条）。
  5. **神运石**（#10）：1117 年起，徽宗在城东北堆一座假山，叫艮岳，山周十几里，十多年里全国的花竹奇石都运到这里。1123 年从太湖运来一块几丈高的石头，一千人拉船，沿路凿河、拆桥、毁闸，几个月才到京城，赐名"神运石"——因为这一年刚得了燕地。
     - 回扣燕云06："得的燕地"就是赵良嗣接回的那座空城（燕云06 #36）。大开点一句：记住这座假山。
  6. **燕京那道墙**（#11，可选，B）：第一次围城时去金营谈判的宋使后来自己写：朝廷一直指望跟金国讲和，拿燕山当屏障，内地和京城都没做打仗的准备。
  7. **墙倒了**（#12、#13）：1125 年十二月，童贯从太原逃回京城；金兵两路南下，燕山府的郭药师降金带路（回扣燕云06 #42 那句"要是来要我呢"）。十几天里，花石纲停了，罪己诏下了，徽宗把皇位传给太子赵桓。
- **主播分歧**：太祖那次该不该搬。小李觉得太祖看得远，要是搬到洛阳、长安，就不会有后来的事；大开觉得李怀忠说的也是实话：兵和粮都在开封，搬不动；而且晋王说"在德不在险"也没错。不替历史选。
- **本幕落点**：一座没有险可守的城，靠几十万兵和一条运河活着；一百多年没见过兵。1125 年冬天，金兵出发了。

### 第二幕：第一次围城（1126 年正月–二月，预估 8 分钟）
- **核心场景与时间线**：正月己巳金兵渡河 → 庚午上皇东去、百官潜遁 → 拦驾 → 癸酉金兵到城下、夜攻宣泽门 → 乙亥攻通津门、开价 → 丙子括借金银 → 丁亥种师道到 → 二月丁酉姚平仲劫营 → 戊戌罢李纲 → 辛丑伏阙 → 乙巳解严。
- **内容要点**：
  1. **城的第一个反应：跑**（#14）：金兵渡过黄河，上皇往东南走了，百官很多偷偷溜了；宰相要带新皇帝往襄阳、邓州跑。
  2. **"天下城池，岂有如都城者"**（#15，李纲两句定位）：宰相白时中说京城守不住；兵部侍郎李纲说：天下哪座城比得上京城？宗庙、百官、万民都在这里，扔了它往哪去？现在只有整顿兵马、稳住人心，一起坚守，等勤王兵来。
  3. **拦驾**（#16，第二幕主场景）：皇帝答应留下，没过多久又决定走；李纲赶到，禁军已经披好甲，车驾套好了。他冲着禁军喊：你们是愿意守宗庙社稷，还是愿意跟着走？禁军都说愿意死守。他对皇帝说：六军的父母妻子都在城里，半路上散了，谁来护卫陛下？皇帝不走了。禁军跪下喊万岁，听到的人都哭了。
     - 大开点题：这一下，是城留住了皇帝。
  4. **城下**（#17）：几天里备齐了守城的器具。金兵到城下，当夜攻宣泽门；两天后攻通津门、景阳门，从早打到晚，老将何灌战死。
  5. **开价**（#18、#19，B 带出处）：金人要的：金五百万两、银五千万两（宋方的记录），三个镇，亲王和宰相去当人质，逃到宋朝的燕云人全部交回。金使说：听说东京家家都摆得出一锭金。宋使回答：京城富，是因为客商多、买卖多，钱都压在货栈、当铺和船上，谁家会闲着钱买金子放着。
     - 小李追问：那到底给了没有？大开：给了不少，具体给了多少，史书没有总数（对抗自审第 7 条）。
  6. **城被刮了一遍**（#20，可选，一句）：城里开始搜刮金银，抄没倡优的家产。
  7. **老种来了**（#21、#22、#23）：种师道两句定位。兵少，一路贴榜说"种少保领西兵百万来"；他说：京城的人知道我来了，士气自己就起来了。围城以后城门全关，市场上没有柴、没有菜；他请开西面、南面城门，让百姓照常进出。勤王兵到了二十多万，金兵号称六万。李纲的主意：扼住黄河渡口，断它粮道，等它粮尽，放它北归时半渡而击。
  8. **劫营和罢官**（#24、#25）：姚平仲等不及，带一万人夜里劫营，想活捉金军统帅，失败后跑了（金国的史书说他带了四十万，可以一笑带过）。宰相对金使说：打仗是李纲、姚平仲的事，不是朝廷的意思。李纲被罢，接手的人下令：金兵攻城，不许随便放箭扔石头。
  9. **登闻鼓**（#26，全幕高潮）：太学生陈东带着几万人跪在宫门外上书，要求复用李纲、种师道；宰相来了被围着骂；宣旨的人迟迟不来，众人把登闻鼓抬起来敲破，喊声震地；来迟的宦官被众人打死（不渲染）。李纲复职。
     - 大开点题：这是城自己出声的一次。
  10. **解严**（#27）：李纲下令杀敌有重赏；金兵拿到割三镇的诏书和人质，退走了。前后三十三天，城没有被打破。追上去的将领被召回，"无不扼腕"；种师道劝趁金兵渡河时打，皇帝没听；他说：以后一定是国家的祸患。
     - 不说"李纲打退了金兵"（对抗自审第 10 条）。
- **主播分歧**：第一次是靠什么守住的。小李觉得靠李纲和城里的人；大开觉得金兵本来就是孤军深入，拿到了条件就走，城墙和勤王兵二十多万摆在那里也是原因。并陈，不下结论（#52 留到尾声）。
- **本幕落点**：城门关了三十三天，又开了。金兵走的时候，种师道说他们还会回来。

### 第三幕：解严之后（1126 年三月–十一月，预估 6 分钟）
- **核心场景与时间线**：二月乙巳解严 → 四月己亥上皇回京 → 四月丙辰"告奸人妄言"诏 → 种师道屯兵之议被否 → 六月戊戌李纲出京 → 九月丙寅太原陷 → 九月戊寅李纲罢、壬午童贯首 → 十月辛酉种师道死 → 十一月壬申禁浮言、丙子戒严、丁丑郭京和塞城门。
- **内容要点**：
  1. **"上下恬然"**（#28，第三幕主题句）：四月上皇回到京城。金兵走了，上皇回宫，上上下下都松了口气，边事没人管了。
  2. **举报有赏**（#29，第三幕主场景）：四月下了一道诏书：有人胡说"金兵还会再来"吓唬居民的，举报有赏。
     - 大开只念原文意思，不加评语；让小李反应。
  3. **"不宜劳师以示弱"**（#30，可选）：种师道请把关中、河北的兵屯在黄河边几个州，防金兵再来；朝廷说大敌刚退，动兵显得软弱。
  4. **送出城**（#31）：太原被围大半年，有人说救太原非李纲不可。李纲说：我是书生，实在不懂带兵，在围城里是不得已替陛下料理兵事。有人点破：这不是为了边事，是想借这个把你弄走，京城的人就没话说了。他带着一万二千人出了城。
     - 大开点题：那个说"天下哪座城比得上京城"的人，被送出了城。
  5. **秋天**（#32、#33）：九月太原城破，守将王禀战死；李纲被罢官，贬到江西（建昌军）。（可选一句：童贯的头挂在开封的街市上，回扣燕云06 尾声。）种师道判断金兵一定大举再来，请皇帝去长安避一避，被大臣说胆怯；十月他死了，七十六岁。
  6. **十一月的一天**（#34）：京城又禁止百姓传"浮言"；金人说要整个河北，京城戒严。同一天，一个叫郭京的人领了"选六甲正兵所"，城门被堵上了。
     - 三件事照日子摆，不加"讽刺的是"。
- **主播分歧**：解严以后该不该把李纲送走。小李觉得这是朝廷故意整人；大开说史书里确有人这么点破（#31），但太原确实危急、确实要人去救，李纲自己也说不懂带兵。并陈。
- **本幕落点**：九个月里，说"金兵会再来"的人要被举报，守城的人被送出了城，劝早做准备的老将死了。城门堵上的那一天，郭京领了差事。

### 第四幕：第二次围城（1126 年十一月–闰十一月，预估 7 分钟）
- **核心场景与时间线**：十一月乙酉斡离不到城下 → 己丑张叔夜到 → 闰月癸巳粘罕到、苦寒 → 甲午帝被甲登城、召李纲 → 丙申障泥乘马 → 癸卯溺隍 → 乙巳大寒 → 壬子冰裂 →（艮岳）→ 甲寅–乙卯大雪 → 丙辰宣化门（回到冷开场）。
- **内容要点**：
  1. **两路到齐**（#35）：这一次金兵东西两路都到了城下。派出去求救的蜡书，多半被金兵截住。
  2. **皇帝上城**（#36 可选、#37）：城里苦寒，百姓杀了一个统制官，不再让百姓上城。雨雪交加，钦宗披甲上城，把自己的饭赐给士兵，士兵都哭了；两天后他到宣化门，骑着马走在泥里，百姓也哭了。
     - 大开点一句：记住宣化门。
  3. **张叔夜**（#38，两句定位 + 熟人入口）：南道总管张叔夜带两个儿子、三万人赶到——他就是史书里招降宋江的那个人。他劝皇帝学唐明皇避安禄山，先去襄阳。皇帝把他的事迹写进蜡书传檄各地，没有一路兵来。
  4. **冷**（#39，第四幕主场景之一）：大寒，士兵冻得打颤拿不住兵器，有冻僵倒地的；皇帝在宫里光着脚求天放晴。能用的只有卫士三万，还折了一半多。（和第二幕"二十多万"对照。）
  5. **冰裂**（#40）：一次出城袭击，望见金兵就往回跑，掉进城壕淹死上千人；又一次一千人出城，过护城河时冰面裂开，淹死五百多人，从此士气更低。
     - 大开点题：护城河第一次挡住了金兵，这一次吞了守城的人。
  6. **艮岳**（#41，第四幕主场景之二）：围城久了，钦宗下令把艮岳里十几万只鸟兽放进汴河，让它们自己走；房子拆了当柴烧，石头凿成炮石，竹子编成篱笆，几百上千头鹿杀了给卫士吃。
     - 回扣第一幕：那块"神运石"所在的假山（#10）。
  7. **郭京**（#42，回到冷开场）：兵部尚书孙傅读到一首旧诗里有"郭京"这个名字，就在禁军里找到一个叫郭京的人。说他会六甲法，要七千七百七十七个生辰八字合六甲的人；十天就招满了，都是市井闲人。有武官想来当副将，他说：你明年正月就会死，别连累我。有人上书说自古没听说靠这个成功的，孙傅大怒：郭京简直是应时而生。（宋人的记录里说）他拿一只猫一只老鼠在殿前演法；满城人提起他就把手放在额头上，叫他"相公"。
     - 然后接回冷开场：雪下了几天，他说"不到最危急的时候我的兵不出"；最后，宣化门开了。
     - 不说"开封就是被他弄丢的"（对抗自审第 11 条）。
  8. **没赶到的人，没听的话**（#43、#44）：城破前二十多天，朝廷派驿马召李纲回来管开封府，他接到命令时在长沙，带湖南的兵往北赶，没到，城已经丢了。钦宗捶着胸说：不听种师道的话，才到这一步。（宋人的记录里说）那一夜城里火光照得通红，雪深几尺。
- **主播分歧**：城破该怪谁。小李说郭京和信他的孙傅；大开把前面的事摆出来：九个月里撤了防、送走了人、没来的勤王兵、二十多天的大雪；郭京是最后一下。不下结论。
- **本幕落点**：同一道城墙。第一次城下有二十多万勤王兵，城里的人敲破了登闻鼓；第二次城下没有一路兵来，城里的人在等一个会作法的人。

### 尾声（1126 年十二月–1127 年五月；1148，预估 3 分钟）
- **内容要点**：
  1. **刮**（#45 可选、#46）：城破以后全城大搜金帛；大雪苦寒，皇家园子里的花木让百姓砍了当柴。第二年二月，金人嫌金子不够，杀了户部尚书。回扣第二幕：那句"家家都摆得出一锭金"。
  2. **为之一空**（#47，尾声主场景）：1127 年四月初一，大风吹石折木，二帝北去。大开照原文念一长串：皇帝的仪仗、礼器、乐器、九鼎、浑天仪、铜人、刻漏、皇家藏书、天下州府地图，还有官吏、宫人、工匠、娼优——"府库畜积，为之一空"。
     - 回扣燕云06：四年前宋朝接回的燕京是一座空城；现在轮到开封。
  3. **过界河**（#48，系列收尾画面）：张叔夜随行北去，路上不吃粮食，只喝点汤。到了白沟，赶车的人说：过界河了。他猛地站起来，仰天大呼，从此不再说话，第二天死了。白沟是宋辽一百多年的界河。
  4. **燕京**（#49，可选一句）：二帝北去的路上在燕京住过一阵——就是宋朝花钱买回来的那座城。
  5. **赵构**（#50，可选一句）：五月，康王赵构在南京应天府即位。不展开南宋。
  6. **梦华**（#51，全期最后一个声音，B）：孟元老 1127 年离开开封到江南，二十年后写书：想起当年只剩怅恨；跟亲戚说起旧日，年轻人往往不信；他把书叫作《梦华录》。
  7. **一个问题**（#52）：李纲后来专门跟高宗讲过：金兵两次到京城，为什么一次守得住、一次守不住（传里没记他怎么说）。大开把问题留给听众，回到冷开场和太祖那句话：一百五十年前，太祖担心的是这座城要养的兵会把天下民力耗光。
  8. **系列收尾**：燕云丢了一百九十年，宋朝一直想把它拿回来；最后宋朝的两个皇帝是被押着经过那里的。不预告下一个系列。
