## 一、主人的标准（10-14）

> "很简单 我的标准是 不能像流水账，很散，听感很差 / 我希望我们每一期要么有一个故事主角，通过讲述他的经历故事 见微知著反映出历史时代变局 / 要么有个绝对的话题中心，比如戚家军，围绕中心讲述推演 / 流水账的写法绝对不可取 我需要设计为 有极强代入感、有大主角命运起伏的影视化听感"

落到每一期，开工前过四关：
1. **一个主角，或一个话题中心**：一句话说得出他从哪里起、落到哪里。一期不换主角，别人的事只在和他相关时出场。
2. **命运起伏**：四幕各有一个转折，有升有落，落差要大。主角不在场的大事，一两句带过，或者写成他得到消息的那一刻。
3. **见微知著**：他的命运照出哪一场时代变局，和燕云这根线怎么挂上。
4. **影视化**：冷开场是一个具体场面（时间、地点、人、原话，带史料编号）；高潮落在一个场面上；结尾停在一个画面上，给下一期留钩子。

不合格的样子：按年份往下排事件；一期里几拨主角轮流上场；"这几十年里发生了三件事"。第一版方案甲的燕云04（当时的编号）（1042–1111，富弼、沈括、神宗、杨文广各占一段）就是这样。

## 三、四期逐期设计

### 燕云04｜寇准：把皇帝推过黄河的人（1006–1023）

- **命运线**：澶渊功臣（1005）→ 一句"孤注"罢相（1006）→ 天书年代在外地，是最早不信天书的人（1008–1017）→ 献上一部"中外皆以为非"的天书，回朝拜相（1019）→ 密请太子监国，谋泄罢相，一贬再贬到雷州（1020–1022）→ 系着太宗赐的犀带，面北再拜而死（1023）。
- **冷开场**：1022 年，雷州。把他贬到这里的丁谓自己也被贬了，南下路过雷州。寇准派人带一只蒸羊到州界上送他，人不见；听说家僮要报仇，就关起门让他们赌钱，等丁谓走远才放出来（P6）。落在：十八年前，就是这个人，把皇帝推过了黄河。
- **四幕**：
  1. 孤注（1005–1006）：澶渊回来，他是功臣；王钦若对真宗说城下之盟是耻辱，"陛下，寇准之孤注也"，第二年他罢相（P3）。燕云03 尾声讲过，只回扣；陈瓘替他辩的话（P9）放这里。
  2. 天书（1008–1017）：王钦若说洗耻只有取幽燕，真宗不肯打，那就封禅（P4）；大中祥符元年正月天书降世，十月封泰山；王旦收了一坛"好酒"，回家打开全是珍珠，从此不再说话（P31）；史臣说"一国君臣如病狂然"（P33）。这些都从被晾在外地的寇准这边看。
  3. 献书（1019）：巡检朱能伪造天书，真宗偏要"始不信天书"的寇准来献；他献了，"中外皆以为非"，随即回朝拜相（P5，年份见第七节 P5 的备注）。
  4. 拂须（1020–1022）：丁谓给他拂须，反被他当众笑了一句，从此结仇（P6）；真宗中风，刘后预政，他密请太子监国，谋泄罢相；周怀政事发，他一路被贬到雷州；病中的真宗问"吾目中久不见寇准，何也"，左右没人敢答（P32）。
- **尾声**：1022 年真宗死，天书随葬（P33）。1023 年，寇准派人从洛阳取来太宗赐的通天犀带，沐浴，穿朝服系带，面北再拜，躺下就死了；调他去衡州的诏书到时，人已不在；灵柩过公安，路边插的枯竹长出了笋（P32）。
- **见微知著**：宋朝从此不再想打燕云，改用天书和封禅给自己挣面子。这套戏里，能打仗的人没有位置，最硬的寇准也得献一部假天书才回得去。
- **配角**：真宗、王钦若、王旦、丁谓、刘后。可换的主角：王钦若，"造天书的人"（P34）。
- **熟人入口**：杨家将戏里的"寇老西"（如《寇准背靴》），戏文和正史分开讲（C）；"溜须"常被说成出自拂须，正史只记了拂须这件事（P6）。
- **和已做各期**：燕云03 尾声讲过孤注，这里只回扣；S2E01 从 1036 年讲起，不重叠。
- **史料**：厚。《宋史》卷281、282、283，卷7–8 真宗本纪；《长编》卷62 以后（卷次开工时补）；PR #3 的 `S10_天书封禅_寇准孤注` 卡当线索，重核后用。

### 燕云05｜宋神宗：想了十八年的燕云（1067–1085，开头带回 1042，尾声到 1125）

> 10-15 开工，四件套已交（PR #43，目录 `燕云05_宋神宗_何日成戎捷`）。主题按 10-15 和主人聊定的："燕云在他手里，是一个想了十八年、始终没敢碰的梦"。比原设计改了四处：工作标题由"何日成戎捷"改为现名，原句作点题句；冷开场由庆寿宫改为 1078 年景福殿库题诗，曹太后挪到第二幕落点；河东让地单独成一幕（全期转折）；尾声年份更正为 1125。下面按四件套的结构写，细节以四件套 `史料核对.md`（#1–#48）为准。

- **命运线**：不到二十岁即位，一心"雪数世之耻" → 富弼劝他"二十年口不言兵"，帝默然；三天后问王安石"唐太宗何如" → 变法攒钱练兵，熙河受贺解玉带 → 曹太后"何待今日"，他说"敢不受教" → 辽国来要河东地界，手敕"姑如所欲与之"（只见毕沅《续资治通鉴》，B），最后按辽国说的分水岭划了界 → 永乐城夜雨城陷，痛哭，不复用兵 → 1085 年病死，库里财物山委；遗训"能复全燕之境者"封王，四十年后兑现给了童贯。
- **冷开场**：元丰初年（约 1078），景福殿库。太祖为赎燕云设的库（燕云01），他改名题诗，一字一库，共三十二库；后来又添二十库，诗里写"顾予不武姿，何日成戎捷"（P13）。落在：写这首诗的皇帝，在位十八年，一次也没跟辽国打过。
- **四幕**：
  1. 二十年口不言兵（1067–1068，带回 1042）：富弼坐轿进殿，"愿二十年口不言兵"，"帝默然"（P36）；回忆 1042 年约 3 分钟：拆国书、"献""纳"之争、"增岁币非臣本志"（P2、P8、P35）；落点：三天后进殿的是王安石，"唐太宗何如"。
  2. 何待今日（1069–1073）：变法为钱为兵一两句；王韶《平戎策》先取河湟；熙河受贺解玉带；曹太后"何待今日"（P37，本传没系年，口播说"有一回"）。
  3. 让地（1074–1075）：萧禧来要地界；刘忱"当以死拒之"与手敕（B）；韩琦"必谓我有图复燕南意"七事；富弼"不可许"；吕大忠"尽索关南地，亦与之乎"，帝默然（B）；沈括翻档案、天章阁、辽廷六会（P11）；最后韩缜按分水岭划界。杨文广（P12）可选一句。
  4. 永乐城（1081–1082）：种谔"秉常孺子"；五路伐夏、灵州灌营；永乐无水、种谔"城之必败"、夜雨城陷（P38）；"涕泣悲愤，为之不食"，早朝痛哭"无一人言其不可"（B）；"遂不复用兵"。
- **尾声**：1085 年崩（《宋史》"年三十有八"，虚岁）；苏辙"元丰及内库财物山委"；遗训"能复全燕之境者胙本邦，疏王爵"；**四十年后，宣和七年（1125）六月**，童贯照这句遗训封了广阳郡王（P14，10-15 更正：原写"三十八年后"、1123 有误）；钩燕云06。
- **见微知著**：神宗是第一个真攒钱、真练兵的人，可每走到燕云跟前就停下：怕的是"万一不谐""万一不测"。这一个"万一"让他让了地，也让他把梦留给了别人。
- **配角**：富弼（第一幕）、曹太后、沈括、徐禧、种谔、萧禧；辽兴宗、刘六符只在富弼的回忆里；王安石只一两句。可换的主角：沈括（使辽争地界，永乐城后被贬，晚年写《梦溪笔谈》）。
- **熟人入口**：王安石变法的那个皇帝；沈括和《梦溪笔谈》；富弼是晏殊的女婿（"殊妻以女"），范仲淹说他是"王佐才"（P35）。
- **和已做各期**：S2E04–S2E08 讲过变法和党争，只回扣；即位写治平四年（1067）正月（雷区表第二节）；沈括"告密"不带进来（S2E07）；曹太后救苏轼（S2E07）只回扣一句；苏轼 1084 年当面批评西边用兵（S2E08）可以回扣。S2E01 写富弼是 1043 年的枢密副使，1042 年他还不是，回忆里按当时身份写（雷区表第二节）。
- **史料**：已核（10-15）：《宋史》卷11、14–16、22、179、242、272、312、313、315、327、328、331、334、335、468、485–486，《辽史》卷19，毕沅《续资治通鉴》卷44–47、64–80。《长编》神宗朝和庆历二年各卷维基文库没有，用续通鉴补编年（B）；原计划"让地按《长编》写"做不到，改为口播不报里数（七百里、六百里两说）。银、绢分项已核（《辽史》"宋岁增银、绢十万两、匹，文书称贡"）。国书谁改的，本传没写，不往吕夷简身上安。

  2. 渡海（1120）：二月出使，"面约，不赍书，唯付以御笔"；登州泛海、辽东上岸、随军看攻上京（接冷开场）；龙冈"特许燕云与南朝"、岁币许三十万被顶到契丹旧数五十万、"不会说脱空"（奉使录，B）；西京、平营没说死，"不如约，则难依已许之约"；"将命至六七，颇能缓颊尽心"；十月方腊，王黼"兼弱攻昧"（P18）。
  3. 燕京（1122–1123，全期转折）：种师道"盗入邻家"、白沟辽使"弃百年之好，结豺狼之邻"、"帝闻兵败，惧甚"（P19、P40）；郭药师以涿易降、袭燕夺迎春门、三市失马、"皆弃马缒城而出"（P19、P41），常胜军来历两三句；同时他在金营写"闻道燕山好消息"，马扩说他"小器不知安危"（B）；刘延庆卢沟烧营夜遁、金人入燕（P20）；"中国何足道"（《北征纪实》，B）；六百万只要一百万，三道御笔层层加价，"一字不依"（P20）。

### 燕云07｜李纲：城破时他不在城里（1125–1127）

- **命运线**：太常少卿刺臂血上疏，请传位太子 → 拦下要出逃的皇帝，禁卫齐呼"愿死守" → 守住第一次围城 → 姚平仲劫营失败，他被罢 → 陈东和几万军民伏阙，打破登闻鼓，他复职，金兵退 → "欲援太原，非纲不可"，书生被派去河东，募的兵被撤 → 被贬；第二次围城，郭京开门，城破 → 两个皇帝被押北去。
- **冷开场**：靖康元年正月，天还没亮。禁卫已经披甲，车驾已经备好，皇帝又要走。李纲赶到，冲着禁卫喊："尔等愿守宗社乎，愿从幸乎？"齐声："愿死守！"（P42）落在：这一次他留住了皇帝；十一个月后城破，他已经被赶出了开封。
- **四幕**：
  1. 血书（1123–1125 年底）：先讲金兵的向导。两年半前，郭药师在后苑延春殿哭着说"闻赵皇如在天上"，徽宗解下珠袍给他（P41）；张觉被斩首送金，他说要是来要我呢（P22）；1125 年底他在白河降金，锁住蔡靖等人，领着斡离不南下（P24、P41）。这一段约 1.5 分钟，接着讲李纲刺臂血上疏，徽宗内禅（P42、P24）。
  2. 守城（1126 年正月–二月）：拦驾（接冷开场）；督战守城；金人要金帛数千万，要割太原、中山、河间三镇，要亲王、宰相作人质（P25）；种师道带西兵赶到（P44）。
  3. 伏阙（1126 年二月）：姚平仲劫营失败，李纲被罢；太学生陈东上书，"军民从者数万"，打破登闻鼓，杀了宦官，朝廷只好让他复职（P43）；金兵退，种师道劝半渡而击，不听（P44）。
  4. 河东（1126 年夏–秋）：耿南仲说"欲援太原，非纲不可"；他说"臣书生，实不知兵"，还是被派去；募来的兵被朝廷撤掉（P42）；九月太原陷，王禀死（P26）；他被贬出朝；十月种师道病死，七十六岁（P44）。
- **尾声**：闰十一月丙辰（公历已是 1127 年 1 月 9 日），郭京用六甲法大开宣化门，京城陷（P27）；钦宗捶胸："不用种师道言，以至于此！"（P44）；第二年三月、四月两个皇帝被押北去（P28）；五月赵构即位（P29）。系列在这里收尾。
- **见微知著**：北宋不缺能打、敢守的人，缺一个肯用他们的朝廷。澶渊以来拿钱买的和平，最后在开封城下变成了金帛、三镇和人质。
- **配角**：郭药师（第一幕）、钦宗、徽宗、种师道、姚平仲、陈东、耿南仲、郭京。可换的主角：种师道（1122 年反对伐燕，1126 年七十六岁带兵勤王，城破前病死）。
- **熟人入口**：《水浒》里的"老种经略相公"就是种师道（小说和史实分开讲）；课本里的靖康之变。
- **和已做各期**：S2E04、S2E08、S2E09 结尾拿靖康收束过一笔，这期正面讲；日期照雷区表第二节（蔡京死在靖康元年七月，京城陷落公历已是 1127 年）。
- **史料**：厚。《宋史》卷358–359 李纲传、卷335 种师道传、卷455 陈东传、卷23、卷353；原 S2E11 李纲守开封的材料（工作台存档）当线索。

## 附：六期稿里单做、10-15 并掉的两期

### 富弼：一个人去辽国（1042，尾声 1068；六期稿的燕云05）

> 10-15 定四期后不单做，四幕的材料挑着压进燕云05 宋神宗第一幕（只留拆国书、"献""纳"两场和"劝用兵者，皆为身谋耳"一句），尾声就是燕云05 第一幕开头。下面是六期稿原样，期号已改成四期的。

- **命运线**：被闹过不愉快的宰相推上去，欧阳修说这是让颜真卿去见李希烈 → 在辽主面前一番话说得对方点头 → 第二次出使路上拆开国书，发现和口头交代的不一样，连夜赶回 → "献"还是"纳"，声色俱厉，辽人夺不走 → 回到朝里，"纳"字还是给了辽 → 推掉封赏："增岁币非臣本志"。
- **冷开场**：1042 年，乐寿（今河北献县一带）。第二次出使的路上，富弼对副使说："吾为使者而不见国书，脱书词与口传异，吾事败矣。"拆开一看，果然不同；他掉头赶回开封，傍晚入见，换了国书再走（P35）。落在：要是没拆这封信，他会带着一份对不上的国书走进辽国的大帐。
- **四幕**：
  1. 没人敢去（1042 春）：辽兵压境，派萧英、刘六符来要关南十县，就是柴荣 959 年拿回来的那块（燕云01）；朝中"莫敢行"，吕夷简推荐了富弼，欧阳修引颜真卿的故事请留下他，不报；富弼说"主忧臣辱，臣不敢爱其死"；萧英托病不拜，被他一句话说得起身下拜，私下交了底（P35）。
  2. 大帐（第一次出使）：辽兴宗数落宋朝"违约"；富弼说两国通好，好处归皇帝，打起仗来，好处归臣下、祸归皇帝，"劝用兵者，皆为身谋耳"，辽主"首肯者久之"；他当面说"晋高祖欺天叛君""周世宗复取关南，皆异代事"；同去打猎，辽主拉他的马靠近，再要地，他说"北朝既以得地为荣，南朝必以失地为辱"；最后谈到结亲还是加钱（P35）。
  3. 一个字（第二次出使）：乐寿换书（接冷开场）；辽主不再提结亲，只要加钱，国书还得写"献"或"纳"："南朝既惧我矣，于二字何有？"富弼搬出唐高祖向突厥称献纳、后来颉利被唐太宗所擒，"声色俱厉"（P35）。
  4. 让出去的字（回朝）：他奏"臣以死拒之，彼气折矣，可勿许也"，朝廷"竟以'纳'字与之"；第一次受命时女儿死了，第二次受命时儿子出生，他都没回头；给他升官，他都推掉："增岁币非臣本志"（P8、P35）。
- **尾声**：熙宁元年（1068），六十五岁的富弼脚有病，神宗让他坐轿到殿门、儿子扶进来、不必下拜；神宗问边事，他说"愿二十年口不言兵"，"帝默然"（P36）。钩子：这个皇帝没听。
- **见微知著**：澶渊以后的和平，是一次次谈出来、加钱买出来的。地一寸没让，钱一年多二十万，字眼让了，宋朝的体面也开始有价钱。宋朝当时正跟西夏打仗，两边打不起（"方讨元昊，未暇与角"）。
- **配角**：辽兴宗、刘六符、萧英、吕夷简、欧阳修、宋仁宗。
- **熟人入口**：他是晏殊的女婿（"殊妻以女"），范仲淹见了说是"王佐才"（P35）；吕夷简、欧阳修是 S2E01、S2E02 的人物，在这里换个场合出场。
- **和已做各期**：S2E01 写富弼是 1043 年的枢密副使，1042 年他还不是，按当时身份写（雷区表第二节）；宋夏战事一两句（S2E01、S2E03）。

### 郭药师和常胜军：三易其主（1122–1126；六期稿的燕云08）

> 10-15 定四期后不单做：第一、二幕进燕云06 第三幕，第三、四幕压进燕云07 第一幕。下面是六期稿原样，期号已改成四期的。

- **话题中心兼主角**：常胜军这支兵。像讲戚家军那样，讲它从哪来、什么脾性、最后去了哪；郭药师是它的头。
- **命运线**：辽东饥民编成"怨军"→ 改名常胜军 → 1122 年带涿、易二州降宋，夜袭燕京差一点得手 → 1123 年进京，徽宗后苑召见，赐珠袍金盆 → 张觉被宋朝斩首送金，"要是来要我呢" → 号称三十万、"不改左衽"，朝廷当他是北边的长城 → 1125 年底降金，给金兵带路到开封。
- **冷开场**：宣和五年，汴京后苑延春殿。郭药师拜在殿下哭："臣在虏，闻赵皇如在天上，不谓今日得望龙颜。"徽宗让他去抓天祚帝，他变了脸："天祚，臣故主也……若使反故主，非所以事陛下"，涕泣如雨；徽宗把身上的珠袍解下给了他（P41）。落在：两年半以后，这个人领着金兵到了开封城下。
- **四幕**：
  1. 怨军（辽末–1122）：燕王耶律淳招辽东饥民当兵，"使之报怨于女真"，叫"怨军"；兵变，他杀了叛首；改名常胜军（P41；成军年份待核《辽史》）。
  2. 迎春门（1122）：带八千人、涿易二州降宋；袭燕京，甄五臣夺迎春门入城，萧后密召萧干回援，三市巷战，他丢了马，差点被擒，败退（P19、P41）。
  3. 珠袍（1123–1125）：后苑召见（接冷开场），他把赐的金盆剪开分给部下："此非吾功，汝辈力也"；张觉被杀，函首送金，他说要是来要我呢（P22）；"增募兵号三十万，而不改左衽"；童贯来察看，他说"太师，父也"，旗一挥，四山铁骑；金使见了他的兵都勒马让路，朝廷从此不防北边（P41）。
  4. 白河（1125 年底–1126）：金兵南下，他要降，蔡靖拔刀要自刎，他抱住，把使者们全锁在家里，出城迎拜斡离不；斡离不听说宋朝内禅想回军，他说"南朝未必有备，不如姑行"；后来到开封城下索要宫中宝器服玩，"皆药师导之"（P41、P24）。叛讯到京，徽宗还在议封他为燕王（P41）。
- **尾声**：他在金国的下场（《金史》郭药师传，待核）。
- **见微知著**：宋朝拿回了燕云的地，没拿回燕云的人。燕山的兵不改装束，朝廷靠赏赐笼着、不敢管；张觉一颗人头，把常胜军的心也送走了。北宋的门是从燕山打开的。
- **配角**：徽宗、童贯、张觉、蔡靖、斡离不。
- **和已做各期**：不重叠。燕云06 讲燕京之战的谈判一边，这期讲打仗一边；张觉在燕云06 只一句，这期是转折。
- **史料**：中。《宋史》卷472 本传很全；《金史》郭药师传、宗望传待核；《三朝北盟会编》（B）。
