## 基本信息
- **选题缘由**：主人 2026-10-14 批准的系列定位——全线一个问题：**九千岁的权力是从哪借来的？** 番外01 讲他怎么借到手，番外02 讲出借人（皇帝）在干什么，番外03 讲全国官员怎么替他放大。本期是收账：出借人一死，新皇帝坐上来，不到三个月，借出去的东西一件件收回；再用一份《钦定逆案》，把“放大器”也点了名。定调照旧：明朝的病养出了他，但下刀的是他自己——所以本期既不把崇祯写成神，也不让魏忠贤的倒台变成同情。**本期独立成立，不预设听众听过番外01–03。**
- **题型**：倒计时叙事（熹宗病危 → 信王入宫 → 两个月不动声色 → 阉党内讧 → 十大罪疏当面宣读 → 凤阳 → 阜城）＋ 话题中心型收口（魏忠贤死后，中心改为“九千岁那笔借来的权”：逆案怎么给一个死人定罪、那袋颂疏颂的是谁、谁进了名单、谁漏了网、权收回来以后谁先转身）＋ 辟谣尾巴（“忠贤若在，时事必不至此”）
- **系列归属**：《笑谈历史》明朝篇·天启与九千岁 4/4（番外01 权力链 → 番外02 木匠皇帝与辽东、财政 → 番外03 生祠群像 → **番外04 崇祯除阉与逆案**）
- **本期主角（主角锚点）**：**魏忠贤的最后七十多天**，对手是十六七岁的崇祯。第一、二段是人物型，锚在魏忠贤本人；**他在第二段末死去之后，第三、四段改为话题中心型，中心是“九千岁那笔借来的权”**，每一步都回到他身上（凌迟的是一个死人、颂疏颂的是他、正月磔尸悬首河间、“忠贤不过一人耳”、阮大铖“忠贤既诛”后的两道疏、“忠贤若在”的传言）。配角：张皇后（一句）、阮大铖（两道疏）。崔呈秀、霍维华、杨维垣、贾继春只作“提前转身的人”群像，不单独成段。史可法不出场（他是 main EP33《弘光开局》的主角）。
- **时间跨度**：天启七年（1627）七月熹宗得病（卷22“秋七月乙丑朔，帝不豫”）→ 八月十二日乾清宫当众作保、同日封魏良栋东安侯 → 二十二日熹宗崩 → 二十四日崇祯即位 → 九月客氏出宫 → 十月阉党内讧、钱元悫与钱嘉征上疏 → 十一月初一安置凤阳 → 初六（一说初七）阜城自缢 → 客氏笞死 → 十二月魏良卿等伏诛 → 崇祯元年（1628）正月磔尸 → 五月毁《三朝要典》→ 崇祯二年（1629）正月定逆案、三月颁行；收尾一句带到 1644 年南京“忠贤若在”传言出现。农历照用；跨年处可补公历年份（1627/1628/1629），不逐日换算。

## 核心认知反差（生死线）
- **你以为的**：
  1. 魏忠贤权倾天下、党羽遍布，崇祯一个十几岁的少年能扳倒他，靠的是天纵英明、步步为营的权谋；
  2. 魏忠贤是被崇祯下令杀掉的，还被千刀万剐；
  3. 阉党倒台，是东林正人君子群起而攻的结果；
  4. 崇祯后来后悔了，说过“魏忠贤要是还在，局面不至于这样”，还偷偷把他收葬了。
- **实际上的**：
  1. 熹宗死前十天还当众给他作保，同一天还给他侄子封了侯（#3），可皇帝一死，他的爵位、东厂、司礼监全是一道旨就能收的东西（#26、#27）；最先翻脸的是他自己的人——《明史》原话是杨所修、杨维垣“先攻崔呈秀以尝帝”（#18），霍维华、杨维垣、贾继春都抢着转身（#2、#19、#20）。崇祯的本事在于沉得住气：头两个月照样给魏家发赏（#16）；
  2. 他是在去凤阳的路上，在阜城的客店里自己上吊的（#29）；“凌迟”是逆案里给死人追加的名义，第二年正月才磔尸（#35、#40）；
  3. 定逆案时，几位阁臣（韩爌、李标、钱龙锡）反倒不想多抓，只报了四五十人，是崇祯嫌少，指着一袋颂扬奏疏逼着往里加（#39）；而当年在杨涟奏疏上“消音”的王体乾，逆案里只是革职抄家（#46）；
  4. 这句话只见一部不知谁写的日记（冯梦龙自述“不知出自何手”，#65）；同时代的杨士聪、王世德（转引）都斥为附会，杨士聪当时就质问：没听说曹化淳被特召，上哪儿去当面上奏（#66、#67，这是杨士聪的质疑，不当履历结论）；杨士聪还点明，这类话冒出来的时候，正赶上马士英、阮大铖要翻逆案（#66）。
- **反差的强度自评**：⭐⭐⭐⭐（“崇祯除魏忠贤”是课本熟脸 × 正史自带的镜头：去世前十天的公开作保、当面宣读十大罪疏、阁臣嫌多皇帝嫌少的逆案名单 × 一个人同时写好两道立场相反的奏疏看风向投 × 网上流传的“忠贤若在”有当年人的原文质疑；扣一星是新君入宫、客氏焚胎发、阜城《挂枝儿》几处最好看的画面都出自清初野史，须边讲边限定）

## 核心问题（这期节目回答的一句话问题）
一个能让全国给他建生祠的九千岁，为什么在新皇帝面前连三个月都没撑过？他手里的权，到底有几分是他自己的？

## 三大基因自检
- [x] **小切口**：天启七年十月底，一个嘉兴的贡生——还没做官的读书人——递上一道疏，列了魏忠贤十条罪。新皇帝让一个太监当着魏忠贤的面念（#22、#23）。三年前，另一个太监在另一位皇帝面前念另一道弹劾他的疏，把要紧的话都跳过去了（#24，番外01 讲过；本期不预设听众听过，放在第一段后半由小李自然想起，大开一两句交代清楚）。
- [x] **大纵深**：一头连着熹宗临终那句“委用忠贤”（#5，清初史书）和他死前十天的公开作保（#3），一头连着《钦定逆案》的六等名单（#40）；再往后，卷306 说到福王时“其案始翻”（#64，一句，不展开弘光朝）。
- [x] **人性内核**：权力是借来的，所以最先还账的是借了光的人。霍维华——颜继祖说他太监得势就借太监的势，太监倒了就跟着打太监（#45）；阮大铖——魏忠贤死后写好两道奏疏，一道骂魏忠贤，一道把账算到东林头上，看风向投（#55）。而一个被判了死罪又被放出来的老太监，在狱中写书，恨的是那些“漏网”的同僚（#47）。
