# 《笑谈历史》选题摸排｜南明十八年（1644–1662）

> 用途：长线选题摸排，非脚本。核对日期 2026-10-13。
> 已读：EP15《崇祯的最后十七年》（大纲/shownotes，止于1644年三月十九煤山）、EP17《投江殉道水太冷》（shownotes/大纲，钱谦益、龚鼎孳、周钟、陈名夏）。

---

## 一、建议分期（6期主线 + 1期可选）

**EP-A｜一年散伙的"南京临时政府"：弘光朝是怎么把半壁江山玩没的？**（1644.5–1645.5）
- 核心冲突：立福王还是潞王——"定策"之争把朝廷撕成马士英/阮大铖 vs 东林两派；江北四镇军阀化。
- 跌宕情节：①史可法反对立福王的信被马士英拿捏，"首辅"被挤去扬州督师；②南渡三案（大悲和尚、假太子、童妃）——三个冒牌货搅动整个朝堂，冷门、荒诞，适合双人对谈；③左良玉打"清君侧"顺江东下，马士英撂下一句"北兵至犹可议款，左逆至则我君臣独死"，把江防的兵调去打自己人。
- 钩子：清军南下时，南京的主力正在防左良玉。

**EP-B｜清军进南京几乎没流血，那江南的血是谁流的？**（1645.4–1645.10）
- 核心冲突：扬州血战之后，南京开城投降；真正的大规模抵抗，是剃发令下达以后的江阴、嘉定百姓。
- 跌宕情节：①扬州：守军"诸镇观望"，李栖凤、高岐凤临阵出降，城破后屠城；②弘光帝出逃被俘，南京百官迎降（这里一句带过钱谦益，引回EP17）；③"留头不留发"：江阴守城八十一日、嘉定三屠——反转点是：扛住清军的是乡绅和典史，不是正规军。
- 钩子：江南沦陷，南方同时冒出两个"明朝"。

**EP-C｜海盗老爹降清，儿子烧了儒服：郑家父子的分道扬镳**（1645–1647）
- 核心冲突：隆武（福州）与鲁监国（绍兴）争正统；隆武朝的兵权、财权全在郑芝龙手里。
- 跌宕情节：①隆武帝想要北伐，郑芝龙按兵不动，暗中与清方接洽；②郑芝龙降清后被挟北上，郑成功的母亲田川氏死于清军入安平（死因有自尽、遇害两说）；③郑成功到孔庙焚青衣起兵。可加：绍武、永历两帝同时称帝并互相开战。
- 钩子：最没存在感的永历帝，反而撑了十五年，靠的是昔日的"流寇"。

**EP-D｜张献忠的义子，成了大明最后的战神：两蹶名王**（1647–1652）
- 核心冲突：大西军余部（孙可望、李定国、刘文秀）从"贼"变成明军；孙可望讨要王爵，"秦王"封号风波。
- 跌宕情节：①借沙定洲之乱入滇，经营云南；②1652年桂林之战，孔有德自焚；③同年衡阳之战，阵斩敬谨亲王尼堪，黄宗羲称"两蹶名王，天下震动"。反转点：英雄早年也有屠晋宁的黑历史。
- 钩子：功劳太大，惹得大哥孙可望起了杀心。

**EP-E｜最大的敌人在自家帐篷里：孙李内讧与一张出卖西南的地图**（1652–1659）
- 核心冲突：孙可望想取代永历自立，李定国保驾。
- 跌宕情节：①十八先生之狱（永历密召李定国，事泄，十八名朝臣被杀）；②李定国"密迎"永历入滇，1657年孙李交兵，孙可望众叛亲离，转身降清，献出滇黔虚实；③清军三路入滇，磨盘山伏击因卢桂生泄密功亏一篑。
- 钩子：皇帝逃出国境，进了缅甸。

**EP-F｜1662，所有主角在同一年谢幕**（1659–1662）
- 核心冲突：流亡中的天子成了缅甸的筹码；吴三桂追进缅甸要人。
- 跌宕情节：①咒水之难：缅王莽白杀兄夺位，诱永历从官去塔寺"饮咒水"盟誓，伏兵屠尽，沐天波夺刀杀数人后战死；②缅方骗永历说"晋王来接"，抬上岸后才发现是吴三桂的前锋高得捷；③永历父子在昆明篦子坡被缢杀（"逼死坡"），李定国闻讯后病逝于勐腊，遗言"任死荒徼，毋降"。
- 收尾彩蛋：同在1662年，郑成功病逝台湾；据载鲁王朱以海也死于这一年（待核）。一年之内，四条线全部断掉。

**（可选）EP-G｜郑成功打到南京城下，又是怎么输的？**（1659长江之役 → 1661–62年收复台湾）：可单列一期，也可以并入EP-F。

## 三、流行说法站不住或有争议的点及建议表述

1. **扬州十日"八十万"**：这个数字是王秀楚的孤证。张德芳（1964）按扬州府人口推算，城内至多二三十万人；安东篱（Finnane）认为八十万应理解为"惨烈程度的表达"。建议表述：屠城数日，死者至少以十万计；王秀楚记八十余万，学界多认为夸大。不要把"80万"当作事实讲。
2. **史可法的形象**：忠烈没有疑问，但他统筹失当（重用高杰、拒绝刘肇基趁清军立足未稳出击），节目可以讲成"好人当不好督师"。死法以《明史》"被执不屈遇害"为主流；《明季南略》有"不知所终"的说法，梅花岭是衣冠冢。不要说"史可法尸骨葬在梅花岭"。
3. **咒水之难**：日期有六月十九、七月十八、七月十九、七月三十诸说，主流取七月十九日（1661年8月12日）。"咒水"是缅方以盟誓之名诱骗，不是巫术。
4. **"吴三桂用弓弦亲手绞死永历"**：康熙《云南府志》记为吴三桂"遣固山杨珅、章京夏国相等缢永历于篦子坡，焚其尸"。应表述为吴三桂下令、部下执行，弓弦勒死，不是吴三桂亲手动手。死期也有异说：多取四月十五（1662年6月1日），《也是录》作四月初八，另有四月二十五一说。
5. **永历致吴三桂"将军之心忍乎"书**：辗转见于清人笔记，文辞过于工整，真伪存疑。只能说"据传有一封信"。
6. **李定国结局**：《清史稿》载他发病后于六月乙丑卒于勐腊，是病逝，不是自杀，也不是被毒杀。另一说为卒于景线，日期各书在六月二十七至七月二十九之间。遗言"任死荒徼，毋降"有出处，但其子李嗣兴当年九月就降清了，这本身是个很好的反讽点。
7. **"清廷闻定国名，有弃七省议和之议"**：出自刘彬《晋王李定国列传》，维基已标"与来源不符"，不能当信史讲，最多作为"后人传说"。
8. **李定国"秋毫无犯"**：同时存在屠晋宁、截手的地方志记载（《晋宁州志》等）。建议两面都讲，正好用来做认知反转。

## 四、与 EP15、EP17 的重叠及处理

- **EP15**：止于煤山，核心是财政与组织管理，片尾挖坑"南明短命偏安"。与本线无实质重叠。建议EP-A开头用30秒回扣"然皆诸臣误朕"，接上"诸臣到了南京，又误了一次"。
- **EP17**：主场景是南京城破时的钱谦益（"水太冷""头皮甚痒"），外加降臣群像。与EP-B的"南京迎降、剃发"直接重叠。处理办法：EP-B只用一句"这事儿我们EP17细聊过"带过，把篇幅让给江阴、嘉定的平民抵抗，正好与EP17的"士大夫软骨"形成对照，一期讲士大夫投降，一期讲百姓死守。另外EP17讲的柳如是、复社人物，在EP-A的党争里不要再展开。
- 顺带发现一个问题：EP17 shownotes里的崇祯血书写作"诸臣误朕，文臣人人可杀"，与EP15的"然皆诸臣误朕"版本不一致，崇祯年龄也一处写33岁、一处写34岁，建议统一口径。这不在本次任务范围内，仅作提示。

## 五、总体判断

**素材够做长线**，而且天然有一条"越打越往南、越打越往外"的地理主线：南京 → 福州/厦门 → 肇庆/桂林 → 贵州安龙 → 昆明 → 缅甸。反转也密集：流寇变忠臣，降将（李成栋、金声桓）反正又覆灭，义兄弟相残，缅王杀兄卖客，最后四位主角同年谢幕。6期能撑住，7期也不水。

**最大风险**：
1. 人物爆炸：几十个朝廷、王号、将领，听众容易迷路。每期锁定一个主角（史可法 → 江阴百姓 → 郑成功 → 李定国 → 孙可望 → 永历），配一句"上回说到"的地图口播。
2. 民族叙事敏感：屠城、剃发容易滑向"排满"情绪，伤亡数字也容易被挑错。坚持"讲人、讲选择、讲数字争议"，引用学界的校正口径。
3. 中后期（EP-E、EP-F）史料薄、偏向一方，日期矛盾多。脚本里要习惯用"据某书""诸说不一"，不要讲死。
4. 节奏：南明是一连串的失败，容易越听越丧。建议每期留一个"差一点就赢了"的高光（衡阳、磨盘山、南京城下），撑住情绪。
