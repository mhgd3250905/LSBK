# 选题建议：张璁——七次落榜，47岁中进士，六年干到内阁首辅

> 选题建议（待评审）。按仓库选题三要素与 EP18 选题卡范式编写。
> 方向归属：明朝权谋线（嘉靖起源篇）｜题型：人物深度传记型

## 选题缘由

大明权谋线的"前传"：EP08《嘉靖大礼议》讲了事件，没讲操盘手。张璁（后改名张孚敬）是嘉靖朝第一个权相——以"部观政"实习期小官身份，一封奏疏站队嘉靖，从中进士到入阁拜相只用六年（"去释褐六年耳"），明代罕见的火箭升迁。他是张居正"史前版本"：任首辅期间"刚明峻洁"、打压六部参政权，内阁首辅的权力膨胀自他而始。

## 核心认知反差（生死线）

**你以为的**：
1. 明朝首辅都是翰林院熬资历熬出来的；
2. 大礼议是皇帝和文官集团的意气之争；
3. 张居正改革空前绝后。

**实际上的**：
1. 张璁七试不第，47岁（正德十六年，1521）才中进士；
2. 以"部观政"身份上疏议礼，嘉靖大喜："此论出，吾父子获全矣"；
3. 杨廷和反手"升官"把他打发到南京刑部主事——明升暗降；
4. 杀回北京后，嘉靖三年左顺门之争，议礼派全面胜利（134人下狱，16人杖死）；
5. "去释褐六年"拜礼部尚书兼文渊阁大学士入参机务；
6. 首辅任上"刚明峻洁，一心奉公"，但"搢绅之士，嫉之如仇"。

**反差强度自评**：⭐⭐⭐⭐⭐（五星满格）

## 核心问题（一句话）

一个47岁才上岸、七次落榜的老考生，凭什么六年干到首辅？当他把"站队"这门手艺做到极致，代价是什么？

## 三大基因自检

- [x] **小切口**：正德十六年（1521）七月，一份来自"实习期公务员"的奏疏，让嘉靖拍案"吾父子获全矣"；杨廷和看完，默默签发一纸"升官"调令——南京刑部主事，即日赴任。
- [x] **大纵深**：从大礼议、左顺门哭谏，到内阁首辅权力膨胀——张居正"我非相，乃摄也"的权力，制度源头是张璁打下的。
- [x] **人性内核**：站队的艺术与代价——第一个吃螃蟹的人，为什么总是两头不讨好？

## 标题候选（九型公式选优）

1. （反常识型）《张璁：七次落榜，47岁中进士，六年干到内阁首辅》（主选）
2. （戏剧张力型）《嘉靖朝第一权相张璁：靠一篇"作文"逆天改命，得罪整个文官集团》
3. （悬念疑问型）《"此论出，吾父子获全矣"：一份奏疏如何造就明代最快升迁神话？》

## 内容弹药

**主要素材/案例**（严格区分出处性质）：
1. 七试不第，47岁登第；御史萧鸣凤星术预言"三载成进士，又三载当骤贵"（正史：《明史·张璁传》系）
2. 正德十六年七月上疏议礼，嘉靖大喜；杨廷和"除南京刑部主事以去"（正史：《明史·张璁传》）
3. 嘉靖三年复疏，与桂萼合流赴京；左顺门哭谏，134人下狱、16人杖死，议礼派全面胜利（正史：《明史》/《明世宗实录》系）
4. "去释褐六年"拜礼部尚书兼文渊阁大学士——明代罕见火箭升迁（正史：《明史·张璁传》）
5. 首辅任上"刚明峻洁"，致力打压六部尚书参政权，六部议事权移转内阁首辅（近人研究：尤淑君《大礼议》）
6. "搢绅之士，嫉之如仇"——改革者与文官集团的死结（正史评价）

**可用的对照组**：
- 杨廷和（四朝老臣、文官集团领袖，体面致仕退场）vs 张璁（新贵孤臣，举朝皆敌）——两种首辅，两种结局；
- 夏言（张璁的继任首辅，同样靠礼制议题得宠，下场更惨）vs 张璁（病死任上、谥文忠，善终）——同一起点，不同终局。

**可交付的概念工具**：
- **"站队经济学"**：张璁把一次政治站队做成了职业生涯的全部杠杆；杠杆越高，反噬越狠。可映射现代职场/投资中的"all in 单一赛道"心态。

**降维三步法候选点**：
- "此论出，吾父子获全矣"：嘉靖的反应 → 吐槽这是皇帝版"终于有人替我说话了" → 比喻就像老板在全员反对时收到一封支持邮件；
- "明升暗降"：杨廷和把他发配南京 → 古代职场实录：升官文书背后的杀气。

**合法跑偏候选**：
- 跑偏 1：桂萼、方献夫、席书——议礼派小团伙的众生相；
- 跑偏 2：《明伦大典》对杨廷和一党的清算——赢家的"论功行赏"。

- **核心台词走向**：

  - 随后准时在 01:00 左右进入标志性正式报幕："大家好，这里是《笑谈历史》，我是大开 / 我是小李"，正式切入正题！
